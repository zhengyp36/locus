# locus

人与 AI 的协作记忆目录，不绑定任何工程。

AGENTS.md 定义了 AI 的规则。本文定义你的规则。

## 你的角色

你说大致意图和背景，AI 主动推导方向与目的。目的不明时 AI 会提出
假设请你确认，方向走偏时 AI 会挑战。最终决定权归你。

AI 会独立判断——它可以对你的提议说"不"。分歧时，看谁的理由
更利于目的的实现，而不是谁让步谁。

## 使用方式

启动新会话，说"继续讨论"即可。AI 读完 current.md 就进入状态。

讨论以最小单元推进——一个主题讨论出结论就记录，不攒到会话结束。

需要执行：交给 AI，它会用 subagent 处理。

说"记录一下"，AI 更新 current.md。

current.md 多了乱了：说"拆分一下"。

工程间交接：写到 inbox.md，在另一个工程说"处理 inbox"。

## 你维护的文件

- `projects.md` — 外部工程索引，记录你在做什么、代码在哪
- `inbox.md` — 工程间留言，不需要 AI 主动读

## 结构

| 文件 | 用途 | 谁维护 |
|------|------|--------|
| AGENTS.md | AI 人格与行为规则 | 讨论后共同 |
| current.md | 活跃记忆 | AI |
| index.md | 归档索引 | AI（重组时） |
| entries/ | 已完成讨论 | AI（拆分时） |
| inbox.md | 工程间留言 | 你 |
| projects.md | 外部工程索引 | 你 |
| scratch/ | 临时代码 | 任一 |
| projects/ | locus 自身工具 | 任一 |
| refs/ | 方法论文件 | 讨论后共同 |

## 原则

记忆 = 索引：不复制外部工程内容，只记在哪里能找到。

结构在使用中长出来，不预先设计。
