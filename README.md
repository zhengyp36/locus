# locus

对每个工程的印象库——讨论、临时结论、未成形想法。工程本体（代码、正式文档）留在工程自己的仓库，locus 只存印象。

## 目录

- `active.md` — 焦点指针，内容 = 当前工程名
- `timeline.md` — 最近聊过哪些工程
- `scratch/` — 草稿
- `projects/` — 各工程自己的目录

## 每个工程

`projects/<工程>/` 下分两层：

工程管理层（确定、追加、不重写）：
- `README.md` — 工程是什么、本体路径在哪
- `CHANGELOG.md` — 阶段/变更记录
- `ROADMAP.md` — 可选，下一阶段方向
- `ISSUES.md` — 可选，遗留问题

记忆层（重写、可乱）：
- `current.md` — 当前印象（摘要 + 索引）
- `index.md` — 索引，指向 entries/
- `entries/` — 细节

本体（可选）：
- `docs/` — 本体文档；仅当工程本体落在 locus 内时才有，本体在外部的工程没有这个目录

## 边界

- 印象留在 locus；正式文档、代码外溢到工程自己的仓库，由人判断。
- 操作规则（更新记忆、切换话题、什么算多）见 `AGENTS.md`——那份是给 AI 看的指令；本文说明"是什么、为什么"，给人看。
