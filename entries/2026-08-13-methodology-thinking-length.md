# 方法论 — 思考过长 / token 消耗（单位 #2）

> 2026-08-13

## 直接原因（5 条）

1. 思考只展开不压缩：读文件后整体复述+重推，不提炼，事实不收敛
2. 反复自我怀疑、多路推演（与问题3同源：无可复用结论 → 每步重推）
3. 工具选错：该 grep 却 read 整个文件
4. 事实/推断/候选混在一层，不分离
5. 任务当开放调查做，不先收窄

## 根因

不是"想得多"，是缺收敛机制：
- 风格层：训练分布倾向穷尽、留余地、多路推演（token 分布形状）
- 机制层：自回归生成无"简洁"代价函数、无"已结论即停止"的终止信号

深层统一根因（与单位 #1 同源）：缺"执行/调节层"——生成直接流动，无机制在"该停/该怎么做/该多长"时裁一下。AGENTS.md 指令本质是外部补这个调节层，故必须无条件硬触发。

## 修法

改风格治标（"请简洁"是软指令，时灵时不灵）；加硬约束治本：
- 强制决策模板（结论+依据，写完停）
- subagent 把事实收集挡在主上下文外
- grep 缩小单次生成空间
