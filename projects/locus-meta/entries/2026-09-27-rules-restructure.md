# 规则重构：AGENTS + rules/task 两文件（2026-09-27）

> 与 YZ 讨论定案。目标：救"规则乱"——原文只有 `AGENTS.md`（跨任务）与 `screenlab-rules.md`（任务）两份纪律，**边界没划**，导致重复 / 矛盾 / 错位。

## 结论

- **两文件，按"讨论期 vs 执行期"分**：
  - `AGENTS.md` = **常驻基线**（讨论期足够，也是所有会话底线）。块：表达与输出 / 工具执行 / 记忆 / 协作 / 任务规则指针。
  - `rules/task.md` = **执行期规则**，进入执行时加载（**YZ 在不在场都适用**）。块：裁决与自主 / 提交推送 / 告知升级停 / 长任务节奏 / 交接 / 验收 / 上下文卫生。
- 判据不是"讨论 vs 任务"（会话类型），而是**常驻 vs 执行期加载**；会话类型只是其代理。
- 旧 `rules/{memory,handoff,screenlab,README}.md` 解散：通用条入两文件；screenlab **环境事实（IP/账户/坐标/helper）是数据不是规则** → 迁 `../cogos/screenlab/tools/README.md`；`screenlab-rules.md` 消失。

## 关键裁决

- **不怕出错 + 思路先行**（替代旧"凭直觉…别想太多，思考过程要短"）：旧句打错靶——纠结的根是"怕错"，且"少想"与"思路先行"打架，反喂养"直接动手"。改为：先给判断 / 倾向（不反复自我怀疑）；动手前先说路线与取舍，YZ 在场**确认后再动**、动手是思路的延续不逐步问；偏离思路或冒出未覆盖的岔路 / 新范围 → **停下回讨论**。
- **"求助"是缺的第三条路**：原先只有"自决 / 等人"二分，且 task 里"不得因人有偏好改问 YZ"把求助也误禁。补：推不出、不阻塞、属 YZ 判断域 → **带倾向求助**（"我倾向 A，因为…；B 也成，你怎么看"）；不在场 → 升级。
- **提交默认自主**（YZ：想不到不提交的理由）：去掉"有规则按规则 / 无规则按判断"的循环句；红线只留不可逆 / 外溢（`secrets` 不入库）。
- **命令全走 terminal**：用机制说（命令结束会唤醒会话 / `terminal_notify`），不用"别 sleep"。
- **上下文看护**用 `start_context_watch`（间隔 20s、阈值 150K、超限只提醒一次）→ 收到即交接；10min 闹钟退为只盯偏航。
- **交接**用 `tools/handoff.py`（默认同目录、attach / 账号内置，起 session 并确认）；`-f` 是**整份文件当首句**，别传整份 `handoff-NN.md`。
- **task.md = 通用执行**（YZ 定，非"仅无人值守"）：在场 / 不在场降为文件内子条（告知、求助 vs 升级、闹钟）。

## 被否方案

- 多文件按场景拆（`memory` / `handoff` / `screenlab` / 新 `decide`）→ 否：一个任务要开多个文件；文件粒度应 = 场景，且"每个任务都吃的"回常驻。
- "讨论型专属 rules 文件"→ 否：讨论是默认态，会被"按名加载"机制架空。
- 保留旧"别想太多 / 思考过程要短"→ 否（见上）。
- 裁决 / 提交放独立 `decide.md` → 否：每任务都吃，属常驻底线；后并入 `task.md`（执行期）。
- 把 `task.md` 限死"无人值守"→ 否：这些是贯穿执行的规则，把属性错当文件边界。
