## 摘要（全文归档于 history-260813-2014.discussion.md）

### 方法骨架（单元 1）

- 文件=磁盘、聊天=内存；循环：/save 存档 → /new 清空 → /load 加载 → 继续。
- 四规则：文件是 truth / 单元把握归人 / 摩擦有利 / 每次一单元。
- 存档必须先于回退；/undo 只回退消息、不回退磁盘。
- save/load 跑主上下文（subagent 隔离不可行），命令体保持极简。

### 结论与方向（单元 2–4）

- 模式 = 偏置档位；显性指向偏置用"偏置模式"，复合词用"×式"（发散式/聚焦式/批判式/执行式）（单元 2）。
- 五档（发散/收敛/质疑/执行/转述）由"真实走偏场景 + 偏置真不同"收敛；与 Kilo 内置 agent 正交（偏置轴 × 任务轴），不合并（单元 3）。
- 单元 4 收敛：塑形被高估——只留结构（文件契约、交接协议、权限），砍掉话术（人格、态度、偏置档位）。
  - 内置 agent 实证：偏置 = 权限为主 + 极简话术；code/plan 无 system prompt。
  - 五档模式/agent 降级为未检验假设；记忆是唯一硬通货，管理协议要薄。
