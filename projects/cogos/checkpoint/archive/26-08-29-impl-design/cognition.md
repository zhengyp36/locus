# cognition — 认知框架笔记（本会话讨论）

> 来源：与 YZ 讨论认知过程（2026-08-29）。纯认知层讨论，尚未映射到 cogos 架构（意识子系统 / 元控制二分 / cu），留待后续挂接。

## 三层结构（功能视角）

| 层 | 干什么 | 产出 |
|---|---|---|
| 认知层（对象层） | 内容推理 | 念头（「是什么」） |
| 元层 | 监控 + 决定/控制 | 决定（「怎么办」） |
| 执行层 | 运动执行，自动化 | 动作 |

## 觉知视角（现象学）

- **焦点（nucleus）**：意识内容，可报告。
- **边缘觉知（fringe）**：焦点外模糊觉知（熟悉感、方向感等）。
- **动作感（sense of agency）**：意图与结果匹配的底层自动信号（前向模型 + 预测误差）。

对应：认知层→焦点；元层→边缘（被对象化即升入焦点）；执行层→动作感（只暴露结果，内部过程不生成意识内容）。

## 记忆

- 感觉记忆（毫秒）/ 工作记忆（几十秒，语音环路复述维持，容量 4±1 chunk）/ 长时记忆。
- 长时记忆两支：
  - 陈述性（外显）：情景 episodic（经历，有「我」+ 时空，remember 重新体验）+ 语义 semantic（知识，脱情境，know 知道）。
  - 非陈述性（内隐）：程序性（技能）、启动、条件反射等。
- 三层↔记忆：认知层↔工作记忆；元层↔元记忆（监控记忆的功能，非记忆类型）；执行层↔程序性记忆。
- 长时记忆 = 素材与归宿：提取 → 工作记忆 → 认知层加工 → 元层判定 → 反写巩固。情景经反复提取去情境化成语义。
- 元层产物无专属记忆库，分流两支：元认知知识→陈述性，元认知策略习惯→程序性；实时监控信号（FOK/JOL）不固化。
- 情景记忆编码 = 「焦点 + 边缘」打包：海马 binding 把焦点内容（深编码，清晰）+ 边缘背景（浅编码，模糊但留痕）+ 时空坐标绑成整体情景；编码单元是「整个事件」非「焦点快照」。
  - 注意只影响编码强度，不影响编码与否：焦点=深编码，边缘=浅编码（仍留痕）。
  - 边缘背景被编码的用途 = 提取线索（编码特异性 / 情境依赖记忆）。
  - 情绪（杏仁核）放大边缘编码：情绪氛围虽在边缘觉知，却可能记得很牢（闪光灯记忆）。
  - 情景 →（反复提取，去情境化）→ 语义：边缘背景被剥离，只剩焦点内容沉淀为知识。

## 关键结论

- **元层 = 转接层**：监控面朝认知、控制面朝执行；只控制「发起」不控制「完成」（交接后不回头，各层自有低层闭环：执行层前向模型，记忆系统巩固）。
- **元层决策 = 内容 × 标准**：认知层只产内容不产决定；元层单独决策，但依赖「标准/目标」。标准来自动机/情绪层（元层之下，非认知层提供）。
- **「清楚」≠「在焦点里」**：清楚可来自边缘觉知 / 底层身体信号（动作感），不需被关注。
- **难观察的两种原因不同**：元层（被意识到即对象化，观察它就改变它）vs 执行层（自动化本就不生成意识内容，只露结果）。
- **动机在意识之下**：意识层面的动机叙述大量是左脑「解释器」事后合理化（confabulation），真实驱动未必被自我知道。证据：Nisbett & Wilson 1977「说的比知道的多」、Gazzaniga 裂脑解释器、Wegner 显性意志错觉、Damasio 躯体标记。平衡：简单受控决策可内省，复杂/情绪驱动决策才常编造。

## 念头生成机制

- 间歇 burst + gap，非连续流；停顿期语音环路复述保持已成形内容。
- 生成候选 → 筛选/编辑（监察）→ 交接动作流（意图下达，前言语、一次性、不回头）。
- 动作流 = 筛选后内容的自动化转译，负担小；净产出与手速匹配，故「想得深、写得轻松」。
- 认知层念头产生也有动机参与，但作用方式与元层不同：动机给元层供「标准/价值」（判断依据），给认知层供「偏向/显著性」（联想方向）。同一动机系统，两种用途。
- 动机不直接产内容，只提供方向与能量：当前念头 + 动机偏向 → 激活扩散（联想）→ 选出最强联想节点 = 下一个念头（进入焦点/语音环路）。神经：DMN 自发活动 = 底噪，中脑边缘多巴胺标记显著性（油门/方向盘，非内容）。
- 动机是持续场，念头是场里的波纹；动机场持续注入偏向，念头链才不断、不收敛。动机场弱（没兴趣）→ 联想枯竭 → 念头流停。

## 元层-认知层的边界与时相

- 元层对象 = 加工过程的状态（信号），非念头内容；读 cue（流畅性/熟悉感/冲突 ERN），不读语义。
- 时相：监控 = 持续低维场（阈下自动），控制 = 离散事件（信号超阈值触发）。元层并行伴随，非插在念头间隙。
- 低带宽根源：每念头只贡献几个标量信号，带宽不随念头复杂度增长。
- 内容评估归认知层（下一个念头做连贯性响应），元层只做低维标注（顺不顺/熟不熟）。
- 联系多念头二分：内容联系（因果/逻辑）→ 认知层 binding；状态聚合（局部流畅度→整体信心）→ 元层（只处理信号统计量）。
- 元层↔认知层边界 = 对象化（objectification）滑动边界：元层产物一旦被意识到即落入认知层，元层不积累信息量，交棒给认知层。"信息量多了变认知层"实为对象化而非量变。

## 元层状态信号的来源与提取

- 提取机制 = 读泄漏非抽取：状态量是认知层加工的并行副产物，元层是仪表盘非质检员，接的是自然泄漏的读数。
- 状态四类：加工动力学（流畅性/检索耗时）· 记忆可及性（熟悉感/可及性/TOT，TOT 证明"知道在但拿不到内容"）· 冲突/误差（ACC 冲突·ERN·预测误差·动作感）· 情绪/躯体（效价/唤醒/躯体标记，爱荷华赌博皮肤电先于意识）。
- 关键机制 = 启发式归因（Koriat cue-utilization）：状态量模糊多义，归因方向决定含义（同一流畅感→熟悉/真实/喜欢，Alter & Oppenheimer 误归因）。
- 神经实现 = 神经调质全局广播：ACC 冲突、LC-NE 惊讶/唤醒、DA 奖赏预测误差/显著性、ACh 不确定性、前额叶元认知信心（Fleming & Dolan）。
- 状态量共同特征：低维标量（低带宽）· 必然副产物（不读语义）· 全局场性（不绑内容）· 需归因（多义）。

## 系统模拟映射（初步想法，待挂接架构）

- 核心原则：状态必须从认知层「执行痕迹」涌现，不能显式算内容；否则元层退化成第二个认知层（对象化、带宽崩）。红线：元层监控输入只能是 telemetry 标量流，不能用「另一个 LLM 读内容给评估」。
- 认知层 = LLM 调用 + 记忆提取 + 多流竞争，天然产生 telemetry，映射：流畅性→TTFT/生成速度/logprob 熵；熟悉/可及/TOT→检索 top-k 分数/命中率/部分命中；冲突/预测误差→多流并行不一致度/动机预期 vs 实际偏差；效价/唤醒→资源消耗率/能量下降/重试次数。
- 亮点：logprob 熵 ≈ 流畅性，逐 token、无语义、自动产生，最干净的信号源；冲突从「多流竞争」自然涌现，无需专门检测器。
- 修正：logprob 熵是厂商依赖的——OpenAI 支持 logprobs（top-k 截断近似熵），Anthropic 不支持，Gemini 部分支持，本地开源可拿完整 logits 算精确熵。应把「是否支持 logprobs」进 lm-service 能力表；不支持的厂商退化为时延/生成速率/重复/自我修正语言标记等代理信号。
- 机制层（资源级，预装不可自长）= 采 raw telemetry + 硬安全阀阈值；策略层（认知级，可自长）= 归因（同一熵→不确定 or 新颖）+ 软决策（换 tier/延时/暂停/求助）。挂接已有：资源级元控制横跨 lm-service 账本 + ce 速率、defer 纯机制、tier 强度轴。
- 边界：副产物对应成立（非比喻）；多义归因第一版显式规则，可自长留阶段三；TOT 可模拟（检索部分命中）。

## 元层对认知层的影响（控制通道）

- 对称性：元层读信号不读内容 → 影响同样不携带内容，只携带控制量（参数/开关/阈值）；进出两条通道都低带宽。
- 控制动作（Nelson & Narens 控制方向，均有研究）：资源/时间分配（学习时间分配研究）· 终止信号（TOT 停止搜索）· 策略切换（冲突后换策略）· 发起/意图下达（只控发起不控完成）· 纠错减速（ERN→post-error slowing）· 求助外发（help-seeking）。
- 机制 = 调节运行参数非注入内容：元层说「慢/继续/停/换方向/加资源」，不说「答案是 X」。
- 显著才影响 = 阈值触发的离散控制：监控持续、控制离散；信号超阈值才干预（Dehaene 全局工作空间点火阈值）。
- 系统对位：tier=换档、defer=暂停/终止、资源级元控制「换 tier/延时/暂停」=资源分配+纠错减速、求助=defer 触发上层。缺项待补：终止信号（停止生成）、检索策略切换（记忆提取换策略）。

## 认知层的划分（功能分层 vs 意识可达性）

- 关键：层级按功能划分，不按「能否被意识捕捉」划分。认知层=内容加工（对象层）、元层=监控+决定、执行层=运动执行；意识可达性是另一根轴（焦点/边缘/动作感），横切三层。
- 认知层内部大部分无意识：念头产生过程（联想激活/候选竞争）、记忆自动浮现过程都是对象层无意识加工，仍归认知层（冰山下层）。
- 自动浮现 vs 主动提取：差别在有无元层意图环节。主动提取可感知 = 元层意图下达被对象化入焦点，非「进入意识层」。
- 主动提取决定拆分：发起=元层（意图下达）、执行检索=认知层、终止=元层（TOT 停止搜索）。对应「元层只控发起不控完成」。
- 「决定」两分：内容选择（哪个联想节点胜出/候选选中）= 认知层自动做；监控-控制决定（发起/终止/换策略/分配）= 元层专属。认知层做「内容层面自动选择」，不做「监控-控制决定」。

## 自动浮现 vs 主动提取的关系

- 自动浮现 = 激活扩散（spreading activation），连续激活谱非二元成败：弱激活=内容浮不上来但残留熟悉感/FOK/TOT（可及性信号），非「提取失败」。
- 主动提取触发 = 元层读到「任务缺口（目标 vs 现状差距=预测误差）+ 熟悉感/FOK」→ 判断有内容未浮上来 → 下达意图 → 意图对象化被意识捕捉。缺口是元层监控对象，非认知层「看到」。
- 主动提取执行 = 认知层从被动联想切换到策略性搜索（strategic retrieval）：生成线索→激活候选→评估→不匹配换线索，形成「监控→控制(换线索)→加工→再监控」往复循环（自动浮现无此循环，联想枯竭即停）。
- 两条触发路径：补救式（自动浮现弱激活+熟悉感，如「这人眼熟叫啥来着」）+ 目标驱动（任务直接要求检索，无缺口无失败）。
- 系统对位：默认自动召回（相关性打分=激活）→ 弱命中留可及性信号（top-k 分数低）→ 元层读「缺口+FOK」→ 下达策略性检索（换线索/深度搜索）→ 循环至命中或终止。自动浮现=被动召回，主动提取=带意图战略搜索，执行路径不同。
