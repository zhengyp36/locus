## 挂接明细

### 1. LLM-Service
- 源码锚点：`../agent-study/agent-study/agi-core/lm_service`（`server.py` / `scheduler.py` / `providers/{openai,deepseek}.py`）+ `lm_call` 客户端
- 目标：封装厂商差异 + 控制并发

### 2. CogUnit / CogExecutor（`hooks.md:41-48`）
- code-as-action：代码片段作 action，高风险外部动作走受控 tool call（`:4`）
- 临时心智现场：每次调用前重构，模板按需组织不整包（`:5`）
- prompt = runtime contract：LLM 是动作生成器，输出契约明确（`:6`）
- smolagents 细节：实现时回源码（`:7`）
- 三类接口：取消 / 错误恢复（分类→自动恢复或上抛）/ 结果回填含错误归一化（`:2` 细分）
- 职责边界：语义归 LLM，程序管外围（触发/预算/存储/权限/回链/格式/结果使用）（`:18`）
- 资源级元控制：预算/停条件/循环上限随 CogExecutor 做（`:26` 细分）

### 3. 认知树（`hooks.md:50-63`）
- 行动规则类节点 schema + 生命周期（试用→验证→载体选择→淘汰）（`:15-16`）
- 上下文 = 树活跃片段，会反写树（`:17`）
- 词 = 折叠意义包/索引，节点标题是索引非内容（`:20`）
- rollout 状态快照/回滚/分支对照折叠展开继承（`:2` 细分）
- 外部分布式状态折叠进记忆，三维区分（内容类型/激活度/来源置信度）（`:21,24`）
- 存再生能力：骨架 + 回链 raw trace；世界图谱=前身（`:23`）
- 检索≠激活：共振非查询，多层保真度（`:22`）
- 方法论/编排也是树内容，可自我修订（`:26`）
- 折叠/展开/继承/选择/再生成 = 操作语义原型（`:28`）
- 根节点持久锚定目的，防语义流漂移（`:29`）
- 浮现底层 = 特征提取+匹配，对意识不可见（本次形成）
- 特征相似≠主题相似，不用 embedding，用结构化特征+程序粗筛+LLM 精筛（YZ 拍板）

## 遗留 / 坑
