# Checkpoint 5 — 认知树表达能力：焦点/边缘、自我、标签、迁移、视角

> 日期：2026-08-31。状态：讨论中，未写代码。从「认知树的表达能力」切入，收敛出两条主线：**标签 = 软边（第三维：特征）** 与 **迁移 = 视角投射（非模式匹配）**。全部结论未引入新结构，复用方案 A 的「节点 + 收纳节点」作标签附着点。

## 一、焦点/边缘/情景的表达

### 1. 焦点/边缘 ≠ 点亮/暗化（两轴正交）

- 点亮/暗化 = 明暗（调制，作用于任意主题，「亮多少」）。
- 焦点/边缘 = 主题类型（焦点 = 思考内容，边缘 = 自我与所处环境，「亮的是哪类东西」）。
- 正交：边缘可突然变亮（环境异常 →「我在哪」从背景抬成焦点），焦点内容可暗化（放下但还在）。

### 2. 边缘 = 标签，不是主题

- 边缘作为主题会和焦点在树里「假并列」；真实关系是交织，标签天然表达交织。
- 附着点统一为**节点**：边缘标签挂**收纳节点**（现场 = 方案 A 的收纳节点，边缘是「这次现场的环境属性」），关联标签挂任意节点。

### 3. 情景 = 现场/来源标签切片（派生的视图）

- 版本 = 偏序标签切片（时间轴）；情景 = 来源标签切片（共现轴，同一次 cu 写回的节点）。
- 情景和版本一样是**派生视图，非存储副本**。粘合剂不是 cu，是**自我**（共现于同一自我）。

### 4. cogos 的环境 = 人 + 时间节律（环境锚）

- **人 = 环境**：人的话 = 内容 + 意图/情绪（边缘）。只读字面就丢意图/情绪，需边缘通道捕获。
- **时间/节律 = 环境**：机器不是连轴转，有节律——这是它的「身体感」替代品，不参与内容但提供「此刻」的连续背景。
- 二者构成**环境锚**（区别于 checkpoint-1 结论 19 的目的锚）：目的锚会演化，环境锚更「底」、几乎不变，正是「始终在场」。

## 二、自我与塌缩

### 5. 自我不是节点，是读口主体（呈现，非存储）

- 自我一旦存成节点就成了客体，「谁在存」又后退一层。
- **目的是节点**（客体，checkpoint-4 结论 8），**自我不是节点**——自我是树的读口那一侧的主体。
- 咬合 checkpoint-4 结论 19：意图不存、主体不存，都在树的另一侧。树只能存「关于自我的客体信息」（边缘标签），存不了「正在读的我」。

### 6. 塌缩 = 位置性进入客体的统一动作（三元同构）

| 位置 | 塌缩后 |
|---|---|
| 边缘（环境） | 被当内容处理，失去边缘性 |
| 元层（元认知） | 被当认知内容，失去元性 |
| 自我（主体） | 被当客体思考，变成「关于我的一个想法」 |

- 统一：**树（内容层）只能装客体；主体、元、边缘都活在内容层之外**，通过标签或读口那一侧存在。这是「自我不能是节点」的根因。

## 三、标签：软边与第三维

### 7. 标签 = 软边，带来第三维 = 特征

- 层级边（空间）、偏序边（时间）= 结构内硬边；标签 = 结构外**软边**，可多可少、可增可删、可后期发现。
- 实现：多对多（一个标签是全局共享 key，多节点引用；一节点挂多标签）。**共享即关联**——看似无关的信息 = 两个不同分支节点引用同一标签 key 沿它共振。落地 checkpoint-2 :22「检索≠激活，靠相似性共振」。

### 8. 标签附着点 = 节点（统一三类作用）

| 标签 | 附着 | 作用 |
|---|---|---|
| 特征标签 | 任意节点 | 联想 |
| 模式标签 | 收纳节点 | 迁移 |
| 边缘标签 | 收纳节点 | 边缘感 |

- 模式标签与边缘标签附着点相同（收纳节点），靠**语义**区分，不靠结构区分——不新增节点类型或边。

### 9. 一棵树 + 正交标注层（不要两棵树）

- 两棵树代价 = **树间对齐**成第三层结构；标签附着现有节点，对齐免费。
- 标签不参与内容折叠/展开 → 慢变量（节律）不被内容折叠冲掉，天然解决快慢变量频率差异。

## 四、迁移与视角

### 10. 联想 vs 迁移（特征标签 vs 模式标签）

- 联想 = 共享单点特征（「都在夜晚」）；迁移 = 共享结构模式（「信任-请求」「张力-释放」）。
- 迁移要求标签附着在**子结构**（一组节点 + 关系）上——方案 A 的收纳节点天然是子结构锚。

### 11. 迁移拆两半：动力在 LLM，载体在树

- 看见相似（抽象）+ 认出模式（应用）= LLM 语义运算（checkpoint-1 结论 17/23 相似投射）。
- 沉淀/挂接/共振/检索 = 程序结构（模式标签 + 实例引用 + 权重）。
- 咬合 checkpoint-4 结论 6：程序管「模式存哪、怎么挂」，LLM 管「像不像、算不算同一模式」。

### 12. 迁移 ≠ 匹配，是「活跃视角的投射」

- 匹配 = 向后检索（新场景 → 翻所有模式 → 逐个比对），O(模式总数)，组合爆炸。
- 视角 = 向前投射（带着已形成的视角去看，模式自己凸显），O(1)。**看见发生在检索之前**。
- 咬合 checkpoint-2 :22：检索≠激活，激活靠共振非查询。

### 13. 模式是 what，视角是 how

- 模式/结构 = 被看见的对象（内容，可存）；视角 = 看见的能力/倾向（看的方式）。
- 此前只讲了 how 的对象（模式怎么存），漏了 how 本身。

### 14. 视角落点 = 读口/感知阶段（活跃视角集）

- 视角 = 感知阶段的**活跃投射预设**，来自树里高权重模式。咬合 checkpoint-2 结论七（标注发生在感知阶段、进意识之前）。
- 活跃视角集很小（N 个），感知开销 O(N)，非 O(全量)。机制：模式带权重 → 过阈值进活跃集 → 读口只拿这 N 个扫，命中即标注。

### 15. 迁移闭环 = 抽象 → 沉淀 → 投射 → 加固

1. **抽象**：LLM 偶然在两件事里看见相似 → 提炼模式（第一次「看见」慢、刻意）。
2. **沉淀**：模式进树带权重。
3. **投射**（非匹配）：权重够高 → 进活跃视角集 → 之后感知时自动投射，无需检索。
4. **加固**：每投射成功一次权重 +1 → 视角更稳 → 越用越顺。咬合 checkpoint-1 结论 14/16 痕迹强度。

## 五、场景条件化与强化

### 16. 视角 = 场景条件化的习惯（修正全局视角集）

- 视角不是全局的，是「场景 → 视角」的条件化。人分析问题时用分析视角、共情时用共情视角。
- 场景也是标签 → **视角选择 = 标签激活标签**，一次查询 O(1)，不遍历视角。

### 17. 两层选择：机制自动 vs 显意识意图

- **机制层**：场景标签 → 自动激活关联视角（潜意识/元层，cheap，不经过语义，咬合 checkpoint-1 结论 9）。
- **显意识层**：agent 意识到「该换视角」→ 主动选（决策时相，一次 cheap LLM 判断，checkpoint-1 结论 23）；落到操作 = 「换视角」是 LLM 可调用意图（checkpoint-4 结论 19）。
- 两条路通到同一操作原语「选视角」，只触发者不同。

### 18. 强化 = 场景-视角关联权重增删（倾向是反馈积累的）

- 好用 → `w(场景, 视角)` +1；不好用 → -1，转向找新视角。
- 倾向不是预设，是「用后反馈」积累出来的。**个性 = 场景-视角关联权重的分布**，不是「自我声明」（「我喜欢分析问题、搞清楚为什么」=「分析问题场景 → 因果分析视角」权重高）。

### 19. 探索 vs 利用

- 纯强化卡局部最优（第一次撞上的视角凑合好用就永远用它，视角集不增长）。
- 需留一点随机探索（激活时加随机），否则「转向、找新视角」无从谈起。不展开 RL 全套。

### 20. 场景识别 ≠ 视角选择（两个时相）

- 场景识别 = 感知阶段标注（程序标签，或从内容「看出」= 一次 cheap LLM 判断）。
- 视角选择 = 场景标签后的 O(1) 激活。识别与选择是两个时相，别混。

## 六、收口：最简原语 + 完整链条

### 21. cu 最简启示 → 树的最简原语

- cu 最简 = material 进 → content 出 → 死；组合力来自 parent/child + 起新 cu，不在 cu 内部复杂。
- 树最简原语 = **节点 + 两种边（层级/偏序）+ 折叠/展开 + 标签（偏序/来源/激活度）**。
- 版本、情景、焦点/边缘、差异粒度（X 骨架 + Y 差异标签）全是这几个原语的组合派生，不新增结构。

### 22. 完整链条（标签 + 权重统一全部）

```
感知标注场景标签 → 机制按关联权重激活视角（O(1)）
                → 显意识可选覆盖（换视角意图）
                → 用后反馈增删关联权重（强化 + 一点探索）
```

- 迁移、视角、场景、强化、个性，全串在「标签 + 权重」上，未引入任何新结构。
- 节点 = 收纳节点 + 内部偏序链（方案 A 不变）；边 = 层级（空间）+ 偏序（时间）；标签 = 软边（第三维：特征）；自我 = 读口主体（非节点）；边缘 = 挂收纳节点的标签。
