# Checkpoint 1 — 认知树讨论：从「LLM 自组织上下文」切入

> 日期：2026-08-30。状态：讨论中，未写代码，未收敛。

## 当前问题

认知树设计（阶段 1 底层三件之三）从哪入手没有思路；同时 YZ 被「LLM 自己组织上下文」吸引，从上下文替换/重组切入，发散踏入认知树主题。

## 关键结论 / 决策

### 1. 「认知树必然用 cu」这个前提不成立

- 认知树本体是**数据层**（树结构 + CRUD + 折叠/展开 + 持久化），纯程序活，不需要 cu。
- 需要 cu 的是树的**语义操作**（再生补全 / 摘要归并 / 浮现精筛），是树上的**可注入算子**，可后置（对应 plan 待定项「归并/摘要/浮现的执行者」）。
- 「LLM 自组织上下文」是**调度层（意识/意图）问题，阶段三的事**，不是认知树本阶段要解决的。

### 2. hooks 已有答案：上下文 = 树的活跃片段，会反写树

`docs/agent-study-hooks.md:53`（confirmed-conclusions.md:17）：上下文选取策略（从树+感知+意图取什么）+ 反写时机。CU 的 `material` 不是凭空组装，是从树选出的活跃片段；CU 的 `content` 输出反写回树。

### 3. 认知树与 cog-runtime 的对接面 = 两个口

- 读口：树片段 → `material`（CU 输入）
- 写口：`content`（CU 输出）→ 树节点（骨架 + 回链 raw trace）

最小闭环（一次调用→写树→二次调用）= 这两口串起来。**不是树用 cu，是调度层通过这两口在树和 cu 之间搬运。**

### 4. 核心二分：执行单元（cu）vs 语义线索（context thread）

- **执行单元（cu）**：资源持有者（semaphore/tier/tools/callbacks/状态机/parent-child/取消），关心「谁在跑、跑多久、预算、怎么停」。
- **语义线索**：连续变化的上下文轨迹，是 agent「心智现场」从 A 演化到 B 的连续体，是语义上的「自我」。

cog-runtime 现把两者**绑成 1:1**（一个 cu = 一个 material = 一条线索）。「替换上下文」打破了这个绑定——现场换了，但 cu 要不要换成了独立决策。

### 5. 连续性不能靠 cu 保证，必须靠外部状态

cu 会死（`_finish` 后 `_units.pop`），线索连续性不能存在 cu 内部状态里，必须存在外部状态 = 认知树。呼应「上下文=树的活跃片段」。

### 6. 三分立场（初成）

- cu = 执行壳（机制层）
- 线索 = 语义主体（策略层）
- 树 = 外部状态载体（线索的持久载体，cu 只是线索的一次执行瞬间）

### 7. 方式1 vs 方式2 = 「线索换现场」的两个壳策略

- 方式1：替换 material，一个 cu 自己轮转（壳不换、现场换）。省创建开销，但壳残留状态（tool_calls/_resp）要清干净，易脏。
- 方式2：生成新 cu，旧 cu 结束（壳换、现场也换）。壳干净，但连续性要靠外部显式记录。

本质同一操作「旧上下文→新上下文」的跃迁，区别只在执行单元是否复用。**真正要定的是：线索切换时，什么不变（身份/连续性）、什么变（现场）**。壳换不换是实现细节，可后定。

### 8. 替换 → 加权：连续性靠「线索不删、只调权重」天然保住

- LLM 无状态，完全替换 = 失忆。操作不可能是「换内容」，只能是「调权重」：整条线索历史一直在，每步重新分配注意力（点亮/暗化）。
- 连续性不再需要额外载体——线索从未被删，只是被重新加权。上一轮「替换 vs 重组」二分被升华：不是增删，是加权。

### 9. 点亮/暗化 = 对 LLM 激活状态的调制（潜意识，意识只看结果）

- 咬合 hooks:98（参数给潜在变换能力，上下文调制实际变换路径）：点亮/暗化不改参数，改变换路径。
- 咬合 hooks:62/:102（浮现对意识不可见 / 潜意识操作策略）：「无形的手」= 潜意识语义计算，显意识只看见「信息在变化」的结果，看不见 how。
- 谁来做拆两层：**机制原语**（预装、中性：对线索加权/折叠/展开/缩放 = 「存/激活/折叠/索引」档）vs **策略**（自长：点亮哪个暗化哪个，依据动机+焦点，是方法论，可被元控制改写）。

### 10. 推论：激活度 = 点亮程度的持久化，接回认知树 schema

- 上下文 = 线索历史在「动机+焦点」下的加权视图；每次 cu 的 `material` = 该视图的当前帧。
- 反写树 = 把加权后的帧固化回树（哪些亮了/暗了）→ 对应 schema 三维之「激活度」。点亮/暗化的结果落地点 = 节点激活度字段。

### 11. 时间 = 变换的副产品（偏序，非时间戳）

- 线索的变换隐含时间，但这是**变换的偏序**（A→B，B 在 A 之后，先后来自「B 是 A 变出来的」），不是墙钟时间戳。静止集合无时间感。
- 咬合 plan 后置阶段「时间=事件间偏序（先后=序位/同时=同时组），非时间戳」+ hooks:98「外部时间 vs 内部时间」：线索变换产生**内部时间感**（一个东西自身成长的先后），cu 轮转是**外部时间**（执行步骤）。两者不同。

### 12. 追加错觉 → 变换：纠偏「不删只调权重」

- 「线索不删、只调权重」有隐患：被误读成「历史永远在、只是注意力不同」→ 滑向无限追加的无锚日志（hooks 双力归一：认知树有锚，日志流无锚）。
- 正确表述不是「加」是「改」：线索 = **同一个东西的形态演变**。A→B 里 B 不是 A 叠东西，是 A 变成的新样子——有些真消失（非等效暗化）、有些真出现、关系被重连。同 hooks:103「方法论是改写不是 append」、折叠「不是压文本是转结构」。
- **同一性从哪来**（比「加权原语长什么样」更根本）：内容/关系都在变，凭什么说是「同一个东西」？候选答案 = hooks:61 根节点持久锚定目的（可回溯/被替换不消失/可重拉回）。正因它在变，才需要根锚防漂移。
- 澄清两层：**点亮/暗化**（一次 cu 内注意力调制，执行层）vs **变换/成长**（跨 cu 树结构改写，沉淀层）。「不删只调权重」只适用第一层，第二层该消失消失、该重连重连。

### 13. 消失的二分 + 梯度谱系（留痕 vs 不留痕）

- **否定 = 留痕的消失（影子）**：旧值 A 未真消失，作为「被否定的影子」留索引、指向新值 B；回溯可达「我曾持 A，现在否定了」。= 根节点「被替换不消失」机制推广到普通节点；与 hooks:103「改写不可回滚」不矛盾（回不到 A 作当前值，但可回溯「曾持 A」）。
- **遗忘 = 不留痕的消失**，分梯度（元痕迹的衰减谱）：
  - 幽灵（有元感）：内容没了，留「这里有过什么」的占位。
  - 真无（无元感）：连占位也衰减光。
- **消失是谱系非二值**：改写（留影子）→ 幽灵（留元感）→ 真无（无痕）。本质 = 痕迹的衰减梯度。
- 性质区分：**否定 = 语义上还活着（降级/重定向）；遗忘 = 语义上死了（区别只在留没留尸）**。
- 咬合：幽灵 = hooks「存再生能力」临界态（骨架掉、回链还在→可再生成；骨架回链都断→只剩元感）；回链断没断 = 幽灵与真无的分界。元感 = 与「无形的手」「浮现对意识不可见」同族（意识只见「好像忘了」，不见衰减 how）。
- 开放问题：~~遗忘是主动还是被动？~~ → 已裁决（见结论 14）：遗忘永不主动，主动的是否定。

### 14. 主动=否定=记住+打叉；记忆是增量版本共存（git 式）

- **遗忘永不主动**：主动的是「选择否定它」= 记住了它 + 打叉（叉也是一种记忆，让「A 错了」活着，参与「B 更正确」对比）。淡忘是被动：注意力没压上、痕迹自然衰减，是「没做」而非「做了」。
- 修正上一轮消失谱系：否定不在「消失」侧，和记住同侧。
- **记忆非原地改写，是增量版本共存（git 式）**：否则无法「记得它曾经的样子」。但版本是提取关键信息后的精简版（骨架），非全量快照，全量在 raw trace 回链。
- **调和 hooks:103「改写不可回滚」的张力**：拆「存储层」vs「当前指针层」。存储 = 增量追加历史（可回溯「我曾持 A」）；当前指针 = forward-only 不可后退（不可把 A 复位为当前，只能新 commit 修正）。→ 四个字：**可回溯，不可回滚**。hooks:103 的「改写不可回滚」指指针不可后退，「日志才是 append-only」把两层糊在了一起，git 模型正好拆开：历史 append-only，指针 forward-only。
- **版本可组合**：当前状态未必是线性链上的存好快照，而是**现场组合再生**（多骨架版本 + 当前情境，按动机+焦点加权，拼出当前帧）。= hooks「再生成」「折叠是转结构」「检索≠激活（共振）」。
- **收口**：点亮/暗化、变换/成长、版本共存，最终指向同一个动作 = **现场组合再生**（增量骨架版本 × 动机+焦点加权 → 当前状态）。这个动作 = 「无形的手」= 浮现/归并/再生成的执行者 = 一次 cu 的语义计算。

### 15. 差异粒度模型：版本是派生的，不是存储的（机制不重要，目标重要）

- **元立场**：改写 vs 版本 vs append 都是机制，机制不重要；目标是「能知道之前，也能知道现在，同时信息量可控」。
- **无版本，只有粒度**：信息以粒度存在，粒度无大小之分，只在是否有差异——无差异 = 不必切分的单元；有差异 = 自然切分成不同粒度。粒度上挂标签（「这是之前的看法」「这是现在的看法」）。
- **版本是派生的**：需要完整东西时，把粒度按标签组合即得。之前的/现在的版本 = 同一批粒度用不同标签组合出的两种视图。≈ git 底层（blob 内容寻址 + 差异共享），跳过 commit 链直达本质。
- **差异有损 → 历史版本天然不准确**：历史版本 = 用「之前」标签组合出的视图；差异提取本身有损（差异无法准确描述）→ 组合出的旧视图注定失真。咬合 hooks:57「存再生能力、再生易变幻觉」：raw trace 回链 = 给有损差异留无损兜底。
- **待补：标签需表达偏序**。二值「之前/现在」不够——多次否定 A→B→C 时无法区分 A、B 谁更前。标签须记偏序（链），才能组合任意历史视图。与「时间=变换的偏序非时间戳」一致。
- **收敛**：现场组合再生 = **按标签（时间性/激活度/置信度/来源）组合粒度**，版本只是组合的派生结果。切分/差异提取是有损语义判断 → 又是 cu 的活。

### 16. 显意识差异化 / 潜意识减负；差异强度 ≠ 痕迹强度（两正交维度）

- **一对相反力量**：显意识 = 差异放大器（分析差异、让差异显著化 → 能准确说出）；潜意识 = 相似合并器/减负（不分析差异、找相似、合并同类项、降低差异 → 模糊→消退）。咬合 hooks「机制做减法策略做加法」「潜意识同样总结提升」。
- **偏序不必完整保存**：潜意识合并相似段后，只剩差异显著的关键点，其先后关系才是被记住的偏序。= hooks「只存骨架+折叠」：相似段折叠、差异处留节点。偏序与差异粒度统一：偏序 = 差异显著化后关键点之间的先后，低差异段不占序列位置。
- **两正交维度**：差异强度/清晰度（显意识，决定能否准确说出）vs 痕迹强度/权重（潜意识，决定还在不在、多深刻）。正常同步；刻意回避使二者**解耦** → 模糊但深刻（压抑/创伤记忆机制）。
- **修正**：先前把「激活度」当单一维度是错的，「点亮」= 清晰度（差异显著化）+ 权重（痕迹强度），权重可脱离清晰度独立增长。
- **schema 影响**：节点标签多维——清晰度、权重、偏序（时间性）、置信度、来源；权重线可脱离清晰度独立走。

### 17. 修正：非对抗，是同一语义运算的两个投射角度（比例不同）；长期记忆固化待定

- **修正 16 的「对抗」表述**：显意识/潜意识不对抗。相似性与差异性 = 对同一份语料的**两个投射角度**（相似=看共同点/不变量，差异=看不同点/变化量），两边都在做语义运算，只是**投射角度按比例不同**——非「一个加差异一个减差异」，是「同样在看、重点不同」。连续谱上的不同配比，非两端点。
- **节能约束解释比例来源**：找相似比找差异更节能（相似=低维模式匹配，差异=细粒度比较）。潜意识节能型 → 推理受限 → 自然偏相似投射；显意识高能耗 → 撑得起差异投射。比例不是被规定的，是能量供应的自然结果；「差异显著化」是高能耗投射的副产品，非主动目标。
- **新问题：何时进长期记忆**。长期记忆 = 更稳定存储，与「当前帧（短期易变现场）」两级。固化条件候选：清晰度高（被显意识分析出差异）/ 权重高（反复激活或动机关联）/ 两者都要？「刻意回避」（高权重+低清晰度）是否以模糊团形式固化？
- 承接：这是「反写树时机」的具体化，之前一直未定。

### 18. tier = 推理强度档，按复杂度路由，不按重要性

- basic/advanced 已实现（lm-service），语义 = 推理强度档（能耗档），非质量档：basic=元层/潜意识（弱、节能），advanced=意识层（强、高耗能）。
- **路由原则：tier 由任务复杂度（难易）决定，不由重要性决定**。动机/方向极重要但简单 → basic；详细分析复杂 → advanced。
- 提醒：大脑无硬二分，个体差异来自「信息组织方式」非纯耗能；tier 是抽象档位，勿用死。

### 19. 容错 + 动态目标 = 同一性来自「锚的连续性」

- 错误不要紧，目标（根锚/动机场）把偏离拉回（hooks:61 + 歪了自愈）。
- 锚非固定：缓慢漂移（本想往东→分析后改东南，长时间回顾才见显著变化）→ 同一性缓慢演化；瞬时剧变（突然意识巨大冲突）→ 同一性断裂重建（震惊/不适应/拒绝）。
- **同一性 ≠ 内容不变，= 锚的连续性**：锚慢变同一性连续，锚剧变同一性断裂重建。

### 20. 焦点/边缘同构 + 两轴正交（精确化「节点 + 线索」）

- 元层:意识层 = 视焦:视野边缘（同构）：清晰焦点 + 模糊边缘共存、关联、构成整体，非分离两层。=「点亮/暗化」的整体性表述。
- **两轴正交**：瞬时截面（共时，一个时刻焦点+边缘的整体）= **节点**；时间轨迹（历时，截面沿时间连续变化）= **线索**。
- 新焦点：**流如何整合成整体**——意识流/潜意识流、焦点流/边缘流怎样在截面上并成一个整体、在时间上连成一条轨迹。

### 21. logprob 熵 = 流畅性信号，非正确性信号；升级信号用「多流竞争」

- 此问题 08-29 已想（`projects/cogos/checkpoint/archive/26-08-29-impl-design/cognition.md:73-75` + `docs/design-lm-service-min.md:106` logprobs 后置能力标志）。本轮钉死偏差：YZ 想用熵测「推理不顺/复杂度」，但 logprob 熵只能测「流畅性」。
- **token 熵（流畅性）≠ 推理正确性（顺畅度），正交**。LLM 生成机制「选下一个最可能 token」，搞不定复杂推理时不会卡顿，反而「流畅地错」，token 熵低——熵增在最需要处失灵。
- **有效边界**：logprob 熵只在事实/检索型有效（不知道答案→token 分散），推理型失效；「复杂问题」恰是推理型。
- **正确的升级信号 = 输出分布熵（多流竞争不一致度）**：同一问题弱模型多路跑、结果发散→冲突→升级（cognition.md:74「冲突从多流竞争自然涌现」）。替代：结构/契约违反（弱模型复杂任务破坏格式）、代理信号（时延/生成速率/重复/自我修正语言标记）、运行时观测（tool loop 循环/轮次超限，cog-runtime 已有预算上限）。
- **边界**：元层读 cue（顺不顺/熟不熟）不读语义（cognition.md:55/72 红线：监控输入只能 telemetry 标量流，不能用「另一个 LLM 读内容评估」）。
- 方向对（动态 tier：先弱后强遇阻升级），改的是「测什么」：从 token 熵改成输出一致性/结构违反。

### 22. 复杂度判断 = 结构型事前预路由（相似性任务，节能），与熵增是两时相

- **两时相**：结构判断 = 事前预路由（跑前用结构特征估复杂度→初选 tier，粗粒度）；熵增/多流竞争 = 事中动态调整（跑中读执行痕迹→升级，细粒度）。二者合起来才是完整 tier 调度，结构判断补上了「事前」层。
- **成立关键**：判断「这题难不难」= 相似性任务（匹配已知简单/复杂模式），低能耗，basic 就够；实际解题 = 差异性任务，高能耗才需 advanced。元判断比对象判断便宜——用便宜的判断（相似）决定要不要花贵的推理（差异），即元认知本质（cognition.md 低带宽、读 cue 不读语义）。
- **结构型特征候选（程序可算）**：任务形态（单步/多步/生成/推理粗分类）、规模（token 数/预期输出长）、约束密度（「必须且且」条件数）、信息源数量、是否有先例/模板（最节能，纯相似性匹配）。
- **定位 = 相对答案 / 大方向**：预路由是机制层，粗判断够（只答「够不够复杂到要 advanced」，不答「多复杂」）。机制做减法。
- **边界**：结构判断必须程序可算（长度/约束数/任务标签），不能滑成「LLM 读题给难度分」（越界成第二个认知层）；第一版显式规则。
- **延伸**：「是否有先例」把 tier 预路由接回认知树：复杂度预判 = 检索相似先例（方法论节点「类似复杂问题之前用 advanced 才解决」）→ tier 选择策略本身可作一条方法论存树、agent 自长（hooks「方法论=个体记忆一类内容」）。

### 23. 修正：结构判断是语义判断（决策时相），非程序计数；「顺利」≠正确（流畅性误归因）

- **「过于顺利是假象」= 流畅性误归因**（cognition.md:66 Koriat cue-utilization）：流畅感被误归因为正确/熟悉。推论：顺利/流畅（无论事前结构预判「简单」还是事中执行「流畅」）永远只能作资源分配参考，不能作正确性证据；「过于顺利」反该警惕（可能流畅地错）。正确性唯一可靠来源 = 输出侧（多流竞争/现实反馈/结构验证）+ 锚纠偏。
- **修正 22「程序可算」**：把 cognition.md:72 监控红线（telemetry 标量流）错套到决策上了。时相不同（cognition.md:56）：监控（持续/每念头）只能 telemetry 标量；决策（离散/每任务/超阈值）可以是一次 cheap 语义判断。结构判断属决策时相，稀疏，= 一次 basic tier cu（「任务形态/约束数/相似先例」本就是语义判断）。
- **闭环立场**：元层不是「无 LLM 的纯程序层」，是「用 cheap LLM（basic）做低维、稀疏判断的层」。与认知层区别 = ①能耗档位（basic vs advanced）②时相（持续监控 vs 离散决策）③对象（状态信号 vs 内容）。统一 cognition.md 时相划分 + 结论 18 tier 映射。
