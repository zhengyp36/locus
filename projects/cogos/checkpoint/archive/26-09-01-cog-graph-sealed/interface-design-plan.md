# 接口设计推进计划

> 日期：2026-08-31。方法：接口由原语 bottom-up 长（正确性），场景 + 信息维度 top-down 验收（充分性 + 不过度）。主导：AI；审核：YZ。每步先说明做什么、再做、YZ 基于理解审。

## 步骤

### 步骤 1：固化验收标准（两张清单）

- 目的：把「场景」和「信息维度」固定为验收靶子，之后只当验收清单、不当生成素材。
- 产出：A 场景清单（S0~S7 定稿）；B 信息维度四通道最小落点清单。
- 验收：YZ 确认两清单无遗漏、无多余。

### 步骤 2：钉关系类型最小集

- 目的：敲实候选 4 关系 + 2 状态，同时定属性位枚举、状态枚举。关系集是「信息维度」与「接口」的交汇点。
- 产出：关系类型枚举 + 属性位枚举 + 状态枚举（定稿）。
- 验收：对照四通道无多余无缺失；YZ 审。

### 步骤 3：从五样原语 bottom-up 列原子操作 = 候选接口

- 目的：只求正交，不看场景；产出候选接口清单。
- 产出：节点 / 关系 / 标签 / 属性 / 状态各自的原子操作清单（含签名草案）。
- 验收：正交性检查；YZ 审。

### 步骤 4：拿场景 + 维度双重验收

- 目的：验证候选接口充分（能组合出所有场景）且不过度（无任何场景用不上的接口）。
- 产出：验收表（每个场景 ← 哪些接口组合；每个维度 ← 哪些接口表达）+ 多余/缺失清单。
- 验收：YZ 审，回改接口或回改验收标准。

## 状态

- 步骤 1：进行中
- 步骤 2~4：待开始
