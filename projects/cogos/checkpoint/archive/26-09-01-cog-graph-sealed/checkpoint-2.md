## 一、定位：认知树 vs 日志流（为什么需要）

锚点：`cognitive-tree-overview.md` §一/二 · `cognitive-tree-vs-log-stream.md` 前置。

- 日志流 = 按时间追加的原始事件序列；主流 agent（Claude Code/Codex/Cursor/Devin）都是它。
- 四个问题：① 对话与工作状态混在一起 ② 注意力稀释（Lost in the Middle，>4K 开始衰减）③ compact 是补丁（不可逆丢失）④ 所有信息同等对待（被压平到一维）。
- 日志流不是 API 约束（API 只收 token 序列），是习惯。认知树是「主动组织」替代「被动记录」。
- 本质区别不是「记性」是「整理」：LLM 从「站在流中、是流的末端」变成「站在结构外、观察和操作树」。

## 二、核心结构

锚点：`cognitive-tree-overview.md` §三 · `cognitive-tree-vs-log-stream.md`「认知树范式」。

```
目的（根）── 主题A/主题B/... ── 主线（逻辑推进链）
                                ├─ 辅助视角（加深理解不推进）
                                └─ 铺路（为进入下一步做准备）
```

- **目的**：决定哪些主题相关，是过滤器和锚点。
- **主线**：逻辑依赖链（非时间顺序），真正推进的骨架。
- 可折叠（看骨架）/展开（看细节）；折叠不丢结构，骨架本身就是结构。
- 文本呈现 = Markdown 标题作可折叠骨架 + 导航栈（`> 焦点: ...`）+ `[done]/[active]` 标记。深度不设限，但导航栈深度本身是信号（太深说明分解可能不对，应回退重锚）。

## 三、两轴模型

锚点：`cognitive-tree-vs-log-stream.md`「两轴模型」。

| 轴 | 含义 | 内容 |
|---|---|---|
| 内容轴（截面） | 当前「是什么」 | 主题、目的、内容自身结构；持续更新 |
| 脉络轴（流程） | 内容轴的变化过程 | 过去（怎么来的）、现在（被什么改变）、预测（接下来怎么变） |

- 内容轴 = 最新印象；脉络轴 = 印象的形成史。
- **只有已发生的过去和正在发生的现在不可变，预测和目的都可能被新信息推翻。**
- 目的在内容轴上（非独立于内容轴）；脉络轴记录「目的曾经是什么、怎么变的」。
- 折叠/展开：内容轴临时切入子问题（目的不变），脉络轴记录焦点切换。
- 遗留：状态（发散/收敛）的定位——它是「过程模式」判断，非两轴里的要素，确切位置未定。

## 四、动机锚定（双力归一）

锚点：`semantic-motivational-fields.md` §八 · `cognitive-tree-reasoning-process.md` §二。

- **双力归一**：动机场和语义场不是两股力，是同一股力的两个投影——动机 = 力的方向（往哪去），语义经验 = 力的路径（怎么走）。
- 区别不在力本身，在**动机是否被锚定**：日志流 = 随新输入漂移、旧动机被覆盖找不回；认知树 = 动机作根节点持久可访问、被替换但可回溯、可重新拉回。
- 动机不需稳定（人会改主意），但必须**持久可访问**。根节点记录「我曾从这里出发」，不强制「现在必须在这里」。

## 五、信息三层分层 + 脉络来源唯一

锚点：`cognitive-tree-reasoning-process.md` §三/四。

| 层 | 内容 | 用途 |
|---|---|---|
| 认知树 | 结论 + 脉络（关键转折点） | 默认上下文 |
| 干净日志 | 脉络清晰、细节完整的思路呈现 | 回顾 |
| 原始日志 | 精确步骤、脉络未必清晰 | 审计 |

- 原始版本存储层保留（审计），干净版本默认呈现（回顾）。
- 整理时机：agent 每轮/每若干轮推理后，自己在原始日志基础上整理出干净日志。
- **脉络来源唯一**：不管输入来自内部思考还是外部对话，都进入同一轮推理一次加工，脉络是单一结果，写入树的一个或多个节点。

## 六、思考主体 + 推理循环

锚点：`cognitive-tree-reasoning-process.md` §五/六。

- **主体不是 agent，是「认知树 + LLM + 所有信息」构成的语义场**；agent 只是语义场的临时活化形态。
- 认知树的独立性重新呈现主体性：「我的树」这种感知就是最原始的自我。
- 推理循环 6 步：加载活跃视图（<4K）→ LLM 单次纯推理 → 产出结论+脉络+动机变化评估 → 写持久化树、废料丢弃 → 更新焦点 → 回步骤 1。

## 七、视图 ≠ 树 + 标注系统

锚点：`cognitive-tree-view-annotation.md` 全篇。

- **视图 ≠ 树本身**：传进上下文的是本次推理生成的视图（焦点展开 + 路径骨架 + 折叠信号），单视图 ~4K tokens；Markdown 只是视图的文本格式，CRUD 在后台。
- **折叠两驱动**：被动（系统预算驱动，底线防御）vs 主动（LLM 注意力投放，「我选择不看」）。表现一致、语义不同。
- **要素标注 vs 块标注**：块标注已有（system/user/assistant）；要新增要素级标注（人名/地名/主题各自带认知标签）。标注发生在感知阶段（消息进意识之前，轻量 CogUnit 扫描）。约束「宁可漏，不可多」。
- **标注语法**：`A「熟」`，取值 亲/熟/半/疏/生/关（关=主动折叠）。状态信号 + 记忆触发器双角色，标注控制默认行为、不阻断展开。
- **意图执行模型**：展开/折叠/加载 ref 与调工具/发消息形式统一，都是意图——LLM 产生意图、系统消费执行、下轮看到结果看不到意图本身。
- 开放问题 5 条（尾部引用区 / 展开 CogUnit 共享或独立 InferNode / 「更多」粒度 / 摘要由谁生成 / 主动折叠恢复时机）。

## 八、世界图谱 = 认知树前身

锚点：`world-graph.md` 全篇。

- 世界图谱 = 个体对世界的完备认知结构（非客观精确，是对该个体完备）。
- 分工：「模型负责算，图谱负责存」。
- 多维交叉结构：时间轴（自我为原点向两端）/空间轴/实体与对象/规律与因果（预测模板，动作面）/价值观。
- **自我节点** = 所有维度的交叉枢纽（「我在这里」的中心）；动机 = 场（多个方向源共存，光照方向是合成结果）。
- 未完成问题清单 = 意识的磁铁，牵引光照方向。
- 历史修正：模型 = 底图 + 变换函数；动机是场非单一来源。

## 九、已确认结论（confirmed-conclusions.md 认知树相关）

- `:17` 上下文是工作空间，不是长期记忆仓库；LLM 调用规范化 = 据目标从外部状态选相关材料组织成当前上下文。
- `:18` 语义整理归 LLM，程序管触发/预算/存储/权限/回链/格式/结果使用边界。
- `:19` 参数给潜在变换能力，上下文调制实际路径；agent loop = 外部计算深度。
- `:20` 词是索引不是概念本身。
- `:21` 连续性不靠 LLM 记住，靠外部状态持续组织。
- `:22` 检索 ≠ 激活：记忆激活靠结构/场景相似性共振，非数据库查询；多层保真度（raw trace/semantic summary/key nodes/facts/methodology/index-embedding）。
- `:23` 存的是再生能力（索引/触发条件）非完整数据；世界图谱 = 可激活的骨架。
- `:24` 需外部分布式状态（任务/世界/目标/记忆/假设/计划/环境/自我状态互相关联）。
- `:27` 语义视界模型：在有限语义视界中，靠方向牵引/路径展开/现实校正/折叠继承/元控制持续趋向目标；LLM 是通用语义变换器之一，非智能本体。
- `:28` 折叠/展开/继承/选择/再生成 = 有限视界中维持语义连续性的关键机制。
- `:29` 方向牵引不是目标文本，是影响注意/路径/评价/反馈解释/经验沉淀/收束判断的全局选择压力。
- `:30` 元控制：继续/切换/扩大观察/折叠/求助/暂停/终止。
- `:31` 认知负载调节：感知自身负载，过载主动切压缩/整理模式。

## 十一、与 checkpoint-1 发散讨论的衔接 / 张力

- **两轴 ↔ 节点/线索**：原始「内容轴（截面）/脉络轴（流程）」≈ checkpoint-1 的「节点（瞬时截面）/线索（时间轨迹）」——本轮发散绕回了原始理论的两轴，只是更深入。
- **动机锚定 ↔ 同一性**：原始「根节点持久可访问」≈ checkpoint-1 的「同一性 = 锚的连续性」。
- **覆盖式更新 ↔ 增量版本（张力，已调和）**：原始说「恒定大小、覆盖式更新、折叠不丢」；checkpoint-1 结论 14 说「增量版本共存（git 式），可回溯不可回滚」。调和：覆盖的是「当前视图」，折叠保留的是「历史骨架」——历史 append-only + 当前指针 forward-only，与 git 模型一致。
- **本轮新增（原始理论未涉及）**：点亮/暗化（注意力调制）、差异粒度模型、清晰度 vs 权重正交、消失谱系（否定/遗忘）、流整合、tier 映射（basic/advanced=元层/认知层）。这些是 checkpoint-1 的产出，非原始理论，设计时需判断取舍。
