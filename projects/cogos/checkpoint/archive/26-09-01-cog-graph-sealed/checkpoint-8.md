# Checkpoint 8 — 初态与好奇：认知图如何从无到有生长

> 日期：2026-08-31。状态：讨论中，未写代码。从「认知图初态是什么」切入，一路到「好奇的本质」，修正「根=被注入的目的」为「方向是长出非注入」，收敛到「好奇不设计，是经历空 + 未知的默认涌现」。

## 一、初态：从无到有

### 1. 初态不是空图，但也不是「注入目的」

- 空图没法用：读口无物可读、写口无处可挂、焦点无处可指。
- 但「目的/方向」也不是出生时注入的（见第三节）。

### 2. 出生三维：能力满 / 经历空 / 无方向

| 维度 | 出生时 | 载体 |
|---|---|---|
| 能力 | 满（预训练） | LLM 参数 |
| 经历 | 空 | 认知图 |
| 驱动力/方向 | 无（未知的牵引后长出来） | —— |

- LLM 非空白 ≠ 婴儿非空白：前者是「能力」满，后者是「驱动力」有种子——两码事。能力不进图，图只存经历。

### 3. 最小种子 = 「第一口信息」（出生事件），不是目的/方向

- 空图没有「未知」的附着点，必须有一个种子节点承载「第一口信息」。
- 第一口信息既是第一个已知，也是第一个未知的起点（这是什么？）。
- 对应 cogos-plan 待定项「出生事件的具体形态（第一口信息/引导者第一句话）」——倾向：出生事件 = 第一口信息，只是「未知的起点」，不是「目的的注入」。

## 二、好奇：不设计，是默认涌现

### 4. 好奇 = 未知本身，无需注入

- 第一口信息一落地，未知立即产生，好奇随之而来。
- 好奇不是种子里的内容，是「有第一口信息、且还没有任何结算」的必然状态。

### 5. 好奇不能靠「写入」塑造（塑形被高估）

- locus-meta 经验（`history-260813-2014.discussion.md` 单元 4）：**塑形只留结构、砍掉话术**；写「保持好奇」让 agent 好奇，跟写「聪明」让 agent 聪明一样无效。
- 好奇 = 事后对行为的描述，不是注入的内容。主体性不在 prompt 里，在外部循环 + 外部状态的运行方式里。

### 6. 两种未决项（关键区分）

| | 第一种：待办 | 第二种：开放问题 |
|---|---|---|
| 目标 | 已知（把 X 做完） | 未知（X 是怎么回事） |
| 缺的 | 执行 | 理解 |
| 产出 | 完成感，无新信息 | 新信息 |
| 方向 | 向已知收拢（闭合） | 向未知扩展（开放） |

- **好奇 = 第二种未决项（开放问题）的丰度**，不是笼统的未决项丰度。

### 7. 好奇如何被「消灭」= 学习结算

- 开放问题 → 搞清楚 → 结算成待办/方法论 → 下次只是「去做完」。
- 方法论沉淀 = 好奇的自我结算（hooks「反复验证→沉淀方法论」的另一面）。
- 婴儿未知多→好奇多；成熟未知被结算成已知→好奇少、待办多。不是 bug，是成长的必然。

### 8. 设计者姿态：给初始态，不给保持机制

- 只保证初始「经历空 + 第一口信息」，不注入已知/方法论，不设「保持好奇」的机制。
- 不设保底防停滞（之前问的待定项，YZ 已答：不设）。
- 好奇后面消退还是保持，是 agent 自己的轨迹，不是设计者的目标。
- 设计者真正要小心的不是「忘了保持好奇」，而是「过早注入已知/方法论」——那才是人工消灭好奇。

## 三、方向成形与根

### 9. 方向是长出来的，不是注入的

- 方向 = 去搞清楚那个未知，是未知的牵引自然产生的。
- 探索未知 → 方向逐渐成形 → 自我意识 / 自我与环境关系 / 动机随之形成，且随互动改变。

### 10. 方向成形后才「锚定为根」

- hooks 结论 29「根持久锚定目的」是**事后锚定**（方向形成后固定防漂移），不是**出生注入**。
- 修正措辞：根 ≠ 被注入的目的；根 = 探索中形成并锚定的方向。

### 11. 根的稳定是相对的，非绝对不变

- 缓慢演化（常态）：方向逐渐明确/稳定，或缓慢漂移。
- 突变（异常信号）：突然巨变 = 突发事件 + 极大认知冲突。
- 不覆盖 + forward-only 天然支持：缓慢 = 指针渐进移动，突变 = 指针剧烈跳转；旧根 append-only 可回溯、可拉回。
- 突变不是故障，是应被记录的经历节点（认知冲突本身该进图），不是被抹平的噪声。
