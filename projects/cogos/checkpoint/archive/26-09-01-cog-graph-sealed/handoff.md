## 当前状态

cogos 阶段 1 底层三件：**lm-service、cog-runtime 已完成**，第三件已从「认知树」转向「**认知图**」（checkpoint-7）。本次会话确立：底层原语 = **节点 + 类型化关系**（带类型边的图），树/列表/队列/集合都是「按关系类型切出的视图」，平级、不存副本。设计思路定为**从使用场景出发**——不先抽象接口，先列使用场景，接口从场景长出。

初态与好奇已收敛（checkpoint-8）：出生 = 能力满 + 经历空 + 无方向；最小种子 = **第一口信息**（非目的注入）；**好奇不设计**，是「经历空 + 未知」的默认涌现；方向是长出后锚定为根，根稳定是相对的（缓慢演化常态 / 突变=认知冲突）。

重大纠错（checkpoint-9）：**认知图 replace，非 append-only**——append-only 归日志（两套记录），「过去」= 现在信息上的标签，潜意识压缩合并。场景已梳理（S0~S7），关系类型候选 = 4 关系 + 2 状态，待敲实。恢复 = 焦点延续 + 边缘流动；时间 = 偏序链 + 周期锚点切段。

接口方法论 + 信息维度 + 情绪（checkpoint-10）：**接口不为场景定制**——场景是验收非生成，接口由原语 bottom-up 长、场景 top-down 验收；**信息维度是关系集缺的另一半切面**，四通道（关系/标签/属性/状态）涵盖，补齐靠「属性」「状态」通道非加关系类型；**情绪是现象非原语**（=张力+评价，效价×唤醒，唤醒双下游=显著性+投入调制），三条先不装后置观察；体验=信息（幻肢痛论证）。

图无决策 + S2 展开（checkpoint-11）：**图无决策**——图只给正交基础能力（增删改查/遍历/读状态），策略归调用者/装配层，「尊重折叠态」是把策略焊进接口，拆掉（折叠态状态保留）；读口「取什么」三层归属（锚=程序状态 / 候选集=程序图查询 / 定稿=LLM 可能）；单图动机=带权未决节点；cu 链是装配层。

**必要性质疑（checkpoint-12）**：cu 有「就该这样」的直接感受（必要性是物理的：LLM forward 原子 → 壳），认知图没有（必要性是假定的：从「需要记忆」推出「所以要图」，起点是假设）。症结 = **LLM 上下文窗口本身就是记忆**，图必要性在上下文局限（有限/贵/不持久），不在「抽象需要记忆」。方向修正 = 图可能不是「预先设计的第三件」，而是「cu 跑起来后从痛点长出」（对齐「好奇不设计」）。之前图设计（关系/四通道/图无决策/情绪）是预研，非必须现在实现。

**4K 聊天机器人 MVP（checkpoint-13，当前结论）**：图封存为预研，转向 4K 上下文聊天机器人，记忆先不用图、用文件组织（`profile.md` replace + `events.log` append）。两个工具：**工具1 组织上下文**（入参=下次上下文，锚点位置永不丢）；**工具2 存取信息**（存→id 非路径 / 取→id / 读后失效 / 文件≤4K / 多文件 / LLM 重组）。预算控制定稿：**软预算 + 冗余**（名义 4K、实际预留更长，不硬截断），每轮程序检测超限，超了注入指令整理，整理时暂停思考、整理完继续。关键边界：主 cu 无容量感知、无历史感，超限元信息只进整理 cu。核心结论：**预算外包（机制），取舍自学（语义）**——控长度是机制，会取舍才是智能。

## 核心结论（checkpoint-7）

1. **改名**：认知树 → 认知图。树从引入标签软边起就名不副实（标签=多对多，是图非树）。
2. **图原语**：节点 + 类型化关系；树=层级关系视图、队列/列表=偏序关系视图、集合=标签共享视图，平级。
3. **路 A**：单一原语 + 多视图，不存副本；弃多容器并存（路 B）。
4. **解耦 cu**：认知图不 import cu，不知道 material/tier/tools；两个口只认图自己的类型，片段→material 翻译归上层装配。
5. **验证标准升级**：从「跑通闭环」→「原语能否组合出上层」（场景/联想/迁移/折叠全由「节点+类型化关系+标签」派生）。
6. **抓手**：图的自由度用「关系类型最小受控集合」兜底——机制层预装最小集，策略层自长新类型。

## 初态与好奇（checkpoint-8）

- **出生三维**：能力满（LLM 参数）/ 经历空（图）/ 无方向。
- **最小种子 = 第一口信息**（出生事件），非「目的注入」；空图无未知的附着点。
- **好奇不设计**：好奇 = 未知本身，是「经历空 + 未知」的默认涌现，不能靠「写入」塑造（塑形被高估）。
- **两种未决项**：待办（目标已知/闭合/无新信息）vs 开放问题（目标未知/扩展/有新信息）；好奇 = 开放问题丰度。
- **好奇被学习结算**：开放问题→搞清楚→结算成待办/方法论；方法论沉淀 = 好奇的自我结算。
- **设计者姿态**：给初始态（经历空+第一口信息），不给保持机制，不设保底防停滞。
- **方向长出非注入**：方向 = 搞清楚未知的牵引；成形后才锚定为根（hooks 结论 29 是事后锚定）。
- **根稳定相对**：缓慢演化是常态；突变 = 突发事件 + 极大认知冲突（应记录的经历节点，非被抹平的噪声）。

## 已确立的语言约定（避免新会话混淆）

- **cu = cog-unit** = 一次「启动→停」的完整闭合循环（执行壳），不是 LLM 一次 forward。
- **认知图 = 纯程序数据层**：程序管动作推进，LLM 管内容语义。原语 = 节点 + 类型化关系。
- **树/列表/队列/集合 = 视图，非存储容器**：按关系类型切出，不存副本。
- **层级边只表达真实从属，不假装集合**；集合感交给标签。
- **折叠 ≠ 摘要**：折叠是视图切换（不丢内容，纯程序）；摘要有损压缩（需 LLM 生成内容）。
- **有损是特征不是缺陷**；raw trace = 观测旁路给开发者，不回流 agent。
- **版本 / 情景是派生的视图**，不是存储的副本。
- **上下文 = 图的活跃片段**（局部），不是与图对等的独立层。
- **焦点/边缘 ≠ 点亮/暗化**（两轴正交）。
- **标签 = 软边（第三维：特征）**，附着节点，可共享（共享即关联）。
- **自我不是节点**，是读口主体（呈现非存储）；塌缩 = 边缘/元层/自我进入客体位置的统一动作。
- **迁移 = 视角投射，非模式匹配**；模式是 what，视角是 how；视角落点 = 感知阶段。
- **同一性 = merge 历史**（分身 = 分叉 + 汇合，无汇合即分裂）。
- **认知图 replace，日志 append-only**（两套记录）：记忆只有「现在」，变迁全程在日志（raw trace 旁路，不回流 agent）。
- **过去 = 现在信息上的标签**：没有「昨天的节点」，只有「现在的印象 + 标签」；潜意识压缩合并，精确起始丢失。
- **恢复 = 焦点延续 + 边缘流动**：隐式继续，非显式回忆；读口拼「焦点 + 当前边缘」，不拼「你昨天思考 X」的元叙述。
- **时间 = 偏序链 + 周期锚点切段**：非时间戳；「昨天」= 相对当前锚点的前一段；同时用同时组。
- **接口不为场景定制**：场景是验收非生成；接口由原语 bottom-up 长（正确性）、场景 top-down 验收（充分性+不过度）。
- **图无决策**：图只给正交基础能力（增删改查/遍历/读状态），每个接口行为明确且无策略；「怎么用」（遇折叠展不展开、取哪段、按什么排）是调用者/装配层的决策，图不替调用者决定。
- **信息维度四通道**：关系（节点间）/标签（软边）/属性（节点上的值）/状态（读口动态）；关系类型集只管「关系」通道，别把属性、状态硬塞成关系。
- **情绪是现象非原语**：= 张力（程序可算）+ 评价（LLM 语义）；效价×唤醒是二维（效价=正负、唤醒=激活强度）；体验=信息（幻肢痛），状态由功能角色定义非物理实现。
- **上下文窗口本身就是记忆**：LLM 最自然的记忆形态；图的必要性只在上下文的局限（有限/贵/不持久），不在「抽象需要记忆」。
- **图可能非预先设计**：图是 cu 跑起来后从具体痛点长出的东西（对齐「好奇不设计」）；此前关于关系/四通道/图无决策/情绪的讨论是「图长出来该长什么样」的预研，非必须现在实现。
- **MVP 记忆 = 文件组织，非图**：`profile.md`（replace，单份上下文：锚点+印象）+ `events.log`（append-only 旁路）。使用驱动 > 设计驱动，场景是假设别信。
- **两个工具**：工具1 组织上下文（入参=下次上下文，锚点位置永不丢、程序拼入）；工具2 存取（存→id 非路径 / 取→id / 读后失效 / 文件≤4K / 多文件 / LLM 重组）。
- **预算外包，取舍自学**：控长度是机制（程序检测超限 + 注入指令整理），会取舍才是智能（LLM 决定留什么丢什么）。让 LLM 自学适应超限会把守预算焦虑前置到表达阶段、降低质量。
- **软预算 + 冗余**：名义 4K、实际预留更长（如 32K），不硬截断；每轮程序检测超限，超了注入指令整理，整理时暂停思考、整理完继续。
- **主 cu 无容量感知、无历史感**：上下文里没有「4K」概念；只有一份现在态、无对照，看不到「被改」痕迹。超限元信息只进整理 cu，不进主 cu。
