## 正在做什么

认知图设计转向（checkpoint-7）：推翻了「树是底层原语」的隐含假设，改名「认知图」。底层原语 = 节点 + 类型化关系（带类型边的图）；树/列表/队列/集合都是「按关系类型切出的视图」，平级、不存副本（路 A：单一原语 + 多视图）。

与 cu 解耦：认知图不 import cu，不知道 material/tier/tools；两个口只认图自己的类型，片段→material 翻译归上层装配。

验证标准升级：从「跑通最小闭环」→「原语能否组合出上层」（场景/联想/迁移/折叠全由「节点 + 类型化关系 + 标签」派生）。

设计思路（抓手）：不先抽象接口，先列使用场景，接口从场景长出。读/写太底层，接口该是「图的语义操作」。

初态与好奇（checkpoint-8）：出生 = 能力满 + 经历空 + 无方向；最小种子 = 第一口信息（非目的注入）；好奇不设计，是「经历空 + 未知」的默认涌现；方向是长出后锚定为根，根稳定是相对的（缓慢演化常态 / 突变=认知冲突）。

纠错 + 场景 + 时间（checkpoint-9）：认知图 replace 非 append-only（append-only 归日志，两套记录，过去=标签，潜意识压缩合并）；场景 S0~S7 已梳理，关系类型候选 = 4 关系（层级/偏序/来源/标签）+ 2 状态（焦点/折叠态）；恢复 = 焦点延续+边缘流动；时间 = 偏序链+周期锚点切段。

接口方法论 + 信息维度 + 情绪（checkpoint-10）：接口不为场景定制（场景=验收非生成，接口由原语 bottom-up 长、场景 top-down 验收）；信息维度是「关系类型最小集」缺的另一半切面；四通道（关系/标签/属性/状态）涵盖信息维度，补齐靠「属性」「状态」通道非加关系类型；情绪是现象非原语（=张力+评价，效价×唤醒，唤醒双下游=显著性+投入调制），三条先不装后置观察；体验=信息（幻肢痛）。

图无决策 + S2 展开（checkpoint-11）：「尊重折叠态」是把策略焊进图接口，折叠态（状态）保留、尊重行为拆掉；图只给「读折叠态 + 遍历选项」，策略归装配层；读口「取什么」三层归属（锚=程序状态 / 候选集=程序图查询 / 定稿=LLM 可能）；单图动机=带权未决节点（动机强度=权重=张力）；cu 链是装配层非认知图。

必要性质疑 + 方向修正（checkpoint-12）：cu 有「就该这样」的直接感受（必要性物理），认知图没有（必要性假定，从「需要记忆」推出）；症结 = LLM 上下文窗口本身就是记忆，图必要性在上下文局限（有限/贵/不持久），不在「抽象需要记忆」；方向 = 图可能不是预先设计的第三件，而是 cu 跑起来后从痛点长出；之前图设计是预研非必须实现。

4K 聊天机器人 MVP（checkpoint-13）：图封存为预研，转向 4K 上下文聊天机器人，记忆先不用图、用文件组织（profile.md replace + events.log append）。两个工具：工具1 组织上下文（入参=下次上下文，锚点位置永不丢）；工具2 存取信息（存→id 非路径 / 取→id / 读后失效 / 文件≤4K / 多文件 / LLM 重组）。预算控制定稿：软预算+冗余（名义 4K、实际预留更长，不硬截断），每轮程序检测超限，超了注入指令整理，整理时暂停思考、整理完继续。关键边界：主 cu 无容量感知、无历史感，超限元信息只进整理 cu。核心结论：预算外包（机制），取舍自学（语义）——控长度是机制，会取舍才是智能。
