# Checkpoint 9 — append-only 纠错 + 场景梳理 + 时间机制

> 日期：2026-08-31。状态：讨论中，未写代码。本段回到「梳理场景」主线，途中发生一次重大纠错（认知图 replace 而非 append-only），并补上恢复语义与时间序列机制。

## 一、重大纠错：认知图 replace，append-only 归日志

### 1. append-only 从来不该落在认知图

- hooks 依据：「方法论是**改写**不是 append」「**日志才是 append-only**」「**记忆 vs 日志两套记录**」。
- 之前 checkpoint-4 六件之「不覆盖（append-only + forward-only）」→ **改归日志**；认知图本身是 replace。
- 之前「每次重新表达都是新节点」的说法作废 → 重新表达 = replace 覆盖旧内容，旧内容只留日志。

### 2. 两套记录

| | 认知图（记忆） | 日志 |
|---|---|---|
| 操作 | replace（改写） | append-only |
| 内容 | 只有「现在」 | 变迁全程 |
| 「过去」 | 现在信息上的标签 | 逐条记录 |
| 谁看 | agent | 设计者（raw trace 旁路，不回流） |

### 3. 「过去 = 现在信息上的标签」

- 认知图没有「昨天的节点」，只有「现在这个印象 + 标签」。
- 不陷入极端：标签不会无限累加，**潜意识压缩合并**，时间长成「最近这段时间都在想」，精确起始丢失。
- 精确起始靠「特别的事」作为锚点事件推断（呼应「时间=偏序」）。

## 二、场景梳理（S0~S7）

1. **S0 出生**：第一口信息落种子节点 + 置焦点；无根、无已知、无方法论。
2. **S1 醒来/恢复**：焦点延续 + 边缘取当前（见第三节）。
3. **S2 拼现场（读口）**：取焦点展开的可见片段（沿边、尊重折叠态）。
4. **S3 沉淀（写口）**：结果挂焦点下 + 标 source。
5. **S4 换视角**：折叠当前子图、展开另一个（视图切换，不改存储）。
6. **S5 建立关联**：打同一个标签（软边）。
7. **S6 回溯**：沿偏序/来源关系导航。
8. **S7 未决项牵引**：按「未决」标签找开放问题、按权重排；是 S1/S2 读口「读什么」的策略来源，让好奇从机制涌现。

### 关系类型候选（待敲实）

- **关系 4 类**：层级（真实从属）、偏序（先后）、来源（source）、标签（软边）。
- **状态 2 类（非关系）**：焦点（读口指针）、折叠态（视图标记）。

## 三、恢复 = 焦点延续 + 边缘流动

### 4. 恢复不是「回到快照」

- 「回到昨天」= 恢复状态快照（错误模型，把焦点和边缘一起冻结回昨天）。
- 「从今天继续」= 焦点连续（「我想到哪了」锚不动）+ 边缘流动（环境已流到今天）。
- **隐式继续，非显式回忆**：不读档，直接处于「继续」状态；不做「昨天 vs 今天」显式 diff。

### 5. 读口拼 material 的姿态

- 直接拼「焦点 + 当前边缘」（让 LLM 自然处于继续思考的状态），
- 非拼「你昨天思考 X，现在继续」的元叙述（显式回忆，会把思考对象变成回忆本身）。
- 这是方式二（重新表达产生漂移）成立的现实前提：喂焦点不喂原文，否则 LLM 趋近复述、退化成加标签。

## 四、时间序列机制（三层）

### 6. 时间序列 = 偏序链 + 周期锚点切段

- **第一层：偏序边**（机制层原语，已定）——事件先后直接连边，非时间戳。
- **第二层：周期锚点事件**——醒来/睡觉/天亮/天黑/时钟读数，是边缘信息节点，天然在偏序链里，有周期语义。**什么算锚点 = 策略层自长**（机制不规定「睡眠=一天边界」）。
- **第三层：切段视图**（读口操作）——沿偏序链遇锚点切段；「昨天」= 相对当前锚点的前一段（非绝对时间戳）。
- **同时 = 同时组**（cogos-plan 已定：感知事件 = 内容+通道+序位+同时组）；偏序只表达先后，不表达同时。

## 五、协作方式（主体在 handoff）

- 用户延伸发散、AI 补全规整落盘；两条线（主线收敛 vs 支线发散）。
- 支线 = 主线的压力测试 + 素材储备；「纠正方向」还是「储备后续」往往事后显形。
- AI 职责：发散收敛到可记结论就落盘 + 标记「待回主线裁决」；回复有密度有钩子。
