# Checkpoint 7 — 认知树转向认知图 + 设计思路定为「从使用场景出发」

> 日期：2026-08-31。状态：讨论中，未写代码。本次从「换个有抓手的角度」切入，推翻「认知树」命名与「树是底层原语」的隐含假设，收敛到「认知图 = 节点 + 类型化关系」，并确立接口设计思路 = 从使用场景出发。

## 一、命名与底层原语：认知树 → 认知图

### 1. 「认知树」名不副实，早在引入标签软边时就已不是树

- 标签让节点多对多关联，违反树的单父/无环约束——它一直是「图」，名字从 checkpoint-4 引入标签起就不准。
- 弃「认知树」，用「认知图」（cognitive graph）。名字次要，概念先钉死。

### 2. 底层原语 = 节点 + 类型化关系（带类型边的图）

- 树/列表/队列/集合都是「图」的特例，谁都不是谁的上层：
  - 树 = 只留层级关系、限单父、限无环
  - 列表/队列 = 只留偏序关系、限线性
  - 集合 = 只留标签共享
- 图 = 节点 + 关系，不加任何结构约束，是它们的最小公共超集且不多余。
- agent 外部状态最自然的原始形态 = 「一堆东西 + 它们之间的关系」。

## 二、单一原语 + 多视图（路 A，YZ 拍板）

### 3. 路 A vs 路 B

- 路 A：单一原语（节点+类型化关系），多种视图（树/列表/集合是「按关系类型切出的视角」，不存副本）。
- 路 B：多容器并存（树、列表、队列各自独立存储）。
- 选 **路 A**：路 B 让同一内容多处各存一份，撞已拍板的「不覆盖」「单一持久化」，还要维护一致性。
- 用户的「多种结构并存」直觉 → 理解为「异质关系并存」，非「多容器并存」。图天然容纳异质。

### 4. 图的自由度用「关系类型最小受控集合」兜底

- 抓手不来自「树的结构约束」，来自「关系类型是受控的有限词汇」：机制层预装最小集，策略层可自长新类型。
- 对齐 hooks「机制做减法、策略做加法」：机制给「节点 + 有限类型关系」，agent 自己决定怎么组织。
- 层级边只该表达真实从属，不假装集合；集合感交给标签。

## 三、解耦 cu

### 5. 认知图与 cu 各自独立实现，不绑定

- 之前误把「最终装配」当「实现契约」（在 cu.on_ready/on_done 读写）。最终搭建系统时可能这么做，但最小版不绑定。
- 认知图不 import cu，不知道 material/tier/tools 是什么。两个口只认图自己的类型。
- 读口产出「图片段」（纯节点子图结构），非 material；「片段→material」翻译归上层装配。
- cu 只是未来调用方之一，非认知图的契约对象。

## 四、验证标准升级

### 6. 从「跑通闭环」→「能否组合出上层」

- 认知图 = 记忆存储的基石/最小积木。判断够不够，不看功能多寡，看**原语能否派生出后置能力**：
  - 场景 = 标签切出的视图；联想 = 特征标签（软边）；迁移 = 模式标签/视角投射；折叠/展开 = 视图切换。
- 派生全落在同一件事：「节点 + 类型化关系 + 通用标签挂载」三样原语要完备。

## 五、设计思路：从使用场景出发（本次确立的抓手）

### 7. 不先抽象接口，先列使用场景，接口从场景长出

- 读/写接口太底层（任何存储都有），当认知图的接口等于没抽象。
- 接口该是「图的语义操作」，读/写只是这些操作底下的实现。

### 8. 使用场景清单（初稿，待增删）

1. 醒来/恢复：agent 启动，要知道「我上次在哪」——看根 + 当前活跃节点，一层概览。
2. 调用前拼现场：取「当前焦点子树展开后的可见内容」。
3. 调用后沉淀：把结果挂到当前焦点下，标来源。
4. 换视角：折叠当前子图，展开另一个子图（切主题，不丢内容）。
5. 建立关联：两件看似无关的事相关，打同一个标签（软边）。
6. 回溯：沿偏序看「最近做了什么 / 这件事怎么来的」。

### 9. 从场景长出的操作（图专属，非通用读写）

- 看全景（根 + 子图根，一层）
- 展开 / 折叠某个节点
- 取某节点的可见片段（沿边走、尊重折叠态）
- 挂节点（层级关系 / 偏序关系）
- 加标签 / 按标签找
- 沿边导航

## 六、下一步抓手

### 10. 钉「关系类型的最小受控集合」

- 这是新原语的真正抓手，下一步第一件事。
- 最小版六件（checkpoint-4 结论 5）几乎不推翻，只重述：两种边（层级/偏序）→ 两种基础关系类型；标签是第三种关系；关系类型集可生长。

## 七、验证用例

### 11. 未决项 = 「原语够用」的正面证据

- 不要造「总未决项」人为父节点；每个未决项是图里真实节点（各在各位置），各挂「未决」标签 + 权重值。
- 「未决项列表」= 按「未决」标签切出的视图，按权重排序。
- 「总未决项」的别扭感 = 「为了统一而统一」的信号，提醒：层级边只表达真实从属，集合感交给标签。
