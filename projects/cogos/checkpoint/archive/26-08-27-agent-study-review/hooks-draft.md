## cog-unit / cog-executor（底层三件）

- [留待] code-as-action：代码片段作 action 可表达组合/变量/循环/局部计算，高风险动作走受控 tool call — `confirmed-conclusions.md:4` — 设计点：cog-unit 的 action 表达形式（代码片段 vs JSON tool call），高风险外部动作的受控边界。
- [留待] 临时心智现场：LLM 单次调用无记忆，runtime 每次调用前重构现场 — `confirmed-conclusions.md:5` — 设计点：cog-unit 每次调用的上下文装配方式（模板集合按需组织，不整包进上下文）。
- [留待] prompt = runtime contract：把 LLM 从回答器改造成动作生成器 — `confirmed-conclusions.md:6` — 设计点：cog-unit 的 prompt 设计原则（输出契约明确）。
- [留待·回源码] smolagents 细节 — `confirmed-conclusions.md:7` — 设计点：实现 cog-unit 需 smolagents 具体机制时回源码，本阶段不深究。
- [留待] 取消/错误恢复/结果回填：取消=元控制发起的接口；错误恢复=内部分类→自动恢复或上抛；回填=内部，含错误归一化 — `confirmed-conclusions.md:2` 细分 — 设计点：cog-unit/cog-executor 的取消、错误恢复、结果回填三类接口。
- [留待] 语义整理交给 LLM，程序管外围 — `confirmed-conclusions.md:18` — 设计点：CogFunc 管语义 vs 平台管外围的职责边界清单（触发/预算/存储/权限/回链/格式/结果使用边界）。

## cognitive-tree 认知树（底层三件）

- [留待] 可迁移单元 = 行动规则类节点的 schema 原材料 — `confirmed-conclusions.md:15-16`（细节 `transferable-constraint-learning.md`）— 设计点：认知树「行动规则节点」的字段（情境/动作/预期/评价/证据/置信度）+ 生命周期（试用→验证→载体选择→淘汰）对应树的合入/移除操作语义。属类型化 schema，不覆盖两轴。
- [留待] 上下文是树的活跃片段，会反写树 — `confirmed-conclusions.md:17` — 设计点：上下文选取策略（从树 + 感知 + 意图各取什么）+ 反写时机（活跃片段何时沉淀回树）。
- [留待] 词 = 折叠的意义包 / 索引，非概念本体 — `confirmed-conclusions.md:20` — 设计点：节点命名与索引设计（节点标题是索引，不是内容本身）。
- [留尾巴] rollout 状态快照/回滚/分支 — `confirmed-conclusions.md:2` 细分 — 设计点：设计认知树时对照折叠/展开/继承机制。
- [留待] 外部分布式状态折叠进记忆：Task/Plan/Belief/Evidence/Tool/UserModel/Lessons 不是与记忆并列的独立结构，统一进记忆，用「内容类型 + 激活度 + 来源/置信度」三维区分 — `confirmed-conclusions.md:21,24` + `05-experiments/external-distributed-agent-state/README.md` — 设计点：认知树作为统一记忆的组织骨架覆盖哪些内容类型；plan/task/tool state 是否也进树（边界待定）；内容类型标签可生长（agent 自加，不硬编码 schema）。
- [留待] 存再生能力，非全量数据：节点只写一句话骨架，触达时回链 raw trace + LLM 组织补全 — `confirmed-conclusions.md:23` + `world-graph-discussion-2026-06-07.md` — 设计点：节点 schema 必须含 raw trace 回链能力，否则「再生」变幻觉；世界图谱=认知树前身（可激活的骨架，非 RDF 三元组）。
- [留待] 检索≠激活：记忆激活靠结构/场景相似性共振，非数据库查询 — `confirmed-conclusions.md:22` — 设计点：记忆浮现用共振；主动提取（走意图）也是意图方向牵引共振，非 query；多层保真度 raw trace / semantic summary / key nodes / facts / methodology / index-embedding。
- [留待] 编排/方法论 = 个体记忆的一类内容：先做什么后做什么是方法论，由个体自己生成/观察/修订/总结，非系统层结构 — `confirmed-conclusions.md:26` — 设计点：认知树需容纳「方法论/计划」类节点，且可被个体自我修订（呼应 Task/Plan 折叠进记忆）。
- [留待] 折叠/展开/继承/选择/再生成 = 认知树操作语义原型 — `confirmed-conclusions.md:28`（`semantic-horizon-intelligence-model.md`）— 设计点：认知树的五类操作；折叠不是压文本，是转成能影响下一步行动的结构。
- [留待] 方向牵引/动机场 = 根节点持久锚定目的 — `confirmed-conclusions.md:29` + `semantic-motivational-fields.md` — 设计点：根节点目的持久可访问/可回溯/被替换不消失/可重新拉回，防语义流漂移；对应意图产生点。
- [留待] 浮现底层实现 = 记忆层提取特征 + 基于特征加载，意识看不到 how — 本次讨论形成 — 设计点：浮现对意识不可见（内嵌机制屏蔽）；特征提取在前、相似度计算在后。
- [留待] 特征相似≠主题相似，不用 embedding（YZ 拍板）— 本次讨论形成 — 设计点：首选结构化特征 + 特征匹配（程序粗筛）+ LLM 精筛；特征字段来自可迁移单元「适用情境」维度；观察轴自长（策略层），通用相似计算+索引预装（机制层）。

## learning/growth 学习/成长（后置 / 整系统）

## meta-control 元控制（整系统）

> YZ 拍板二分：**资源级**（机制层预装，硬约束/本能，不可自长）vs **认知级**（策略层自长，方法论）。是「机制做减法、策略做加法」在元控制域的实例化。

### 资源级元控制（机制层预装，不可自长）

- [留待] 预算/停条件/循环上限：token/轮次/能耗的运行时硬约束，安全阀，与「想什么」无关 — `confirmed-conclusions.md:26` 细分 — 设计点：resource 边界/预算/暂停/终止的调度；放权放的是认知自由，不放资源无限。
- [留待] 认知负载调节：感知自身负载、过载主动切压缩/整理模式 — `confirmed-conclusions.md:31` — 设计点：资源压力感知（软于硬记账，仍属机制层预装），已对应卡顿捕获 `cogos-concept-system.md:106-120`。

### 认知级元认知（策略层自长，方法论）

- [留待] 元认知自长机制：元控制=对「自我状态」的语义变换（非独立第二套系统），给种子不给完整元控制，元策略=记忆内容非代码控制流 — `growth-through-errors.md` + `self-learning-agent.md` — 设计点：预装三种子（自我状态可读/元动作可执行/反思回路），30 监控调度=反思层随策略自长；三层灵活性边界（开放 workflow 输出+改写，锁死权限/恢复）。
- [留待] 反思回路 = 审视加载方法论：审视不从记忆共振浮出方法论，就退化为 LLM 直接审视、千篇一律 — 本次讨论形成 — 设计点：审视形态 = 候选 ×（背景动机+当前焦点+共振浮出的方法论）；方法论是视角/检查清单，非决策器。
- [留待] 元认知在停顿间隙长：靠浮现非定制，不做「偏差评估」定制加工 — 本次讨论形成 — 设计点：过程痕迹→共振浮现→显意识正常处理→结果沉淀→反复验证→稳定成方法论。
- [留待] 生长慎重 + 歪了自愈：方法论反复验证才沉淀（慎重）；不好用继续反思调整（追加修正不回滚）— 本次讨论形成 — 设计点：不追求不长歪，追求歪了能慢慢长回来；自愈前提=能感知「不好用」（靠现实反馈，非外部监控）。
- [留待] 元认知本身也可能病态：过度反思/自我怀疑到瘫痪/无限递归 — 本次讨论形成 — 设计点：元控制动作本身也要接受现实校正（切换后看现实反馈，非只靠「我觉得」）+ 有收束（终止反思本身是元控制的一部分）。

## design-principles 设计原则（全程）

- [基本内核] agent 本体在模型外部：观察→行动→反馈→学习→预算循环 + 外部状态才是主体，LLM 只是循环里可替换的「语义变换器」 — `confirmed-conclusions.md:25`（实证 `toy-self-learning-agent`：FakeLLM 换真模型循环一行不改）+ `:27` 同源 — 定位：非某模块设计点，是贯穿所有模块的地基立场；cog-unit（外部循环）/认知树（外部状态）/记忆（外部连续性）都从这里长出来。验收：任何设计把「智能/学习/行为」寄托在模型内部而非外部循环+状态，即违背内核。
- [留] 参数给潜在变换能力，上下文调制实际变换路径；agent loop = 外部计算深度 — `confirmed-conclusions.md:19`（`llm-internals-for-semantic-horizon.md:1030-1060`）— 设计点：任何 prompt/cog-unit 上下文设计都是对 LLM 的间接调制（改激活状态非改参数）；loop 加的是外部计算深度（外部时间），非内部层深度（内部时间）。据此定 loop 轮次与循环燃料。
- [留] 机制做减法、策略做加法：通用的是介质不是记法 — 本次讨论形成（消化 `:21-24`）— 设计点：机制层只给中性原语（存/激活/折叠/索引/来源置信度）；策略层（记什么/怎么组织/忘什么/什么浮现）是记忆内容，由 agent 自己长、可被元控制改写；验收=基底能容纳不同 agent 长出不同记忆风格，机制一旦规定「该怎么记」即越界。
- [理念基础] 语义视界模型 = 隔离/视焦、认知树折叠展开、意图/方向牵引的理念基础 — `confirmed-conclusions.md:27-29` + `semantic-horizon-intelligence-model.md` — 定位：已内化进 cogos-concept-system.md，无需回挂。
- [留] 双力归一：动机=力的方向、语义=力的路径，区别只在动机是否锚定 — `semantic-motivational-fields.md` — 设计点：认知树（有锚）vs 日志流（无锚）的本质区别，作为全程设计原则。
- [留] 潜意识同样总结提升（策略做加法的补全）：显意识方法论 + 潜意识操作策略（浮现/归并/观察轴）两层同构自长，前者可见后者屏蔽，后者进步显意识只感到「好用」— 本次讨论形成 — 设计点：「策略」=显意识方法论+潜意识操作策略；潜意识自学习不可见，靠日志旁路可审计（记忆 vs 日志两套记录）。
- [留] 方法论是改写不是 append：就地覆盖旧版、不可回滚（agent 回不去），日志才是 append-only（设计者可查）— 本次讨论形成 — 设计点：不可逆→生长慎重、调整缓慢；改写+缓慢=防清零/固化、不防有损；歪了只能在新位置继续校，回不去是常态。
