第七组「记忆与连续性」（结论 21-24）YZ 拍板：4 条全部「结论已内化 + 细节挂认知树」，并新形成一条设计原则。

- 【留 · 认知树】外部分布式状态折叠进记忆 — `:21,24`：Task/Plan/Belief/Evidence/Tool/UserModel/Lessons 不是与记忆并列的独立结构，统一进记忆，用「内容类型 + 激活度 + 来源/置信度」三维区分。设计点：认知树覆盖哪些内容类型、plan/task/tool state 是否进树（边界待定）、内容类型标签可生长（不硬编码 schema）。

- 【留 · 设计原则】机制做减法、策略做加法：通用的是介质不是记法；机制层只给中性原语（存/激活/折叠/索引/来源置信度），策略层（记什么/怎么组织/忘什么/什么浮现）是记忆内容由 agent 自己长、可被元控制改写；验收=基底能容纳不同 agent 长出不同记忆风格。
