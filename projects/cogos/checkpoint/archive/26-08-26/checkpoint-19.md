# checkpoint-19 — 动机、决策与全貌

## 当前问题

自我驱动机制收敛后，追"动机从哪来""如何决策""4K 上下文如何组织全貌"。

## 结论

### 动机：碰撞中显现

- 单条信息闭合是单向的；多条信息闭合方向不一致 → **碰撞** → 动机在碰撞中显现（做 B 偏离 A，A 是动机；X/Y 冲突需调和）。
- **动机 = 多条闭合方向碰撞中"胜出的持续在场约束"**，不是存着的目标标签。
- 碰撞前提 = 多条信息共时在场 → 意识不是纯单点（checkpoint-6 焦点），而是"**强焦点 + 弱背景（动机锚点持续在场）**"。
- 反驳"动机全在语料"：语料给的是"闭合能力/路径"，不是"方向/对象"——否则"日志流漂移"不成立（日志流与认知树同 LLM 同语料，方向内在于语料的话日志流不会漂）。
- 统一：**闭合力（能力）语料免费给；方向（闭合什么）由树里的动机/未决项给；时机（何时闭合）由节律给。** 三样 = 自我驱动。

### 决策：无决策器

- 没有决策器，LLM 就是决策器；认知树让 LLM 看全貌，LLM 自己做决策。
- LLM 只是运算，无决策能力；**决策在信息中，信息经 LLM 运算显露决策能力**。
- "没有胜出规则"（YZ）：原理层成立；机制层，胜出规则从"显式决策器"转移成"认知树喂什么视图"（LLM stateless 只能考虑它看到的）。
- 立场转变（标出）：推翻 agent-study"决策显式化需显式设计"——合理性在"认知树保住了全貌（日志流会丢全貌）"。
- **决策在折叠层做（比相对张力），执行在展开层做（看细节）。**

### 全貌与 4K

- LLM 连续看有记忆（单次 stateless，连续 = LLM + 认知树）；4K 恒定窗口 = 工作记忆。
- 全貌 = 缩放（折叠概览），局部 = 放大（展开），任何情况 ≤4K。
- 4K 四区组装：**锚点区**（动机持续在场）/ **全貌区**（折叠骨架）/ **焦点区**（展开）/ **碰撞区**（冲突并排）。
- 规模：分层分治（将军/副将），递归分类/结构化解决任意规模；每层看本层层级全貌，无单层看原始全貌。

### 分类有损

- 分类有损、LLM 运算也有损；不追求无损，也不该追求无损（看全貌 = 拿细节换概览）。
- **防的不是有损，是固化；分类是动词非名词，要流动。**
- 重分类触发 = 节律/重置（"睡一觉组织方式改变"）。
- 全貌 = 当前分类下的有损概览，暂时、可推翻重组。

## 总收束

一条线：**信息驱动 → 运算有损 → 抽象分层 → 分类流动。**
