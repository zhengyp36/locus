# checkpoint-18 — 概念重构：独立认知个体与自我驱动

## 当前问题

摘要评估暴露概念混乱（agent 临时 vs 个体持久、谁驱动、动机从哪来）。YZ 澄清概念，重新定义个体与自我驱动。

## 结论

### 独立认知个体（换词：agent → 独立认知个体）

- 个体 = **认知树（体/身份/自我）+ 推理节点（用/LLM，可替换）+ 多子系统**，构成一个运行时。
- 认知树 = 身份/自我的代表（静态内容：我是谁、我的动机、我的历史）；边界 = 自我与外界划界的动态动作（权重场）。一体两面。
- 换词消除摘要里"agent 临时、不维护身份"与"个体持久"的伪矛盾：身份落在树上，不在临时对象上。

### 临时 vs 持久（两步实现）

- 临时 = 能跑一次（会话生命周期）；持久 = 让临时进入"不停"状态。
- 即使停了可重新动：状态都在认知树，重启即恢复（体持久、用可替换）。
- **连续性 = 状态持久 + 可恢复，不是进程常驻。** 验证标准不是"24 小时在线"，而是"重启后还是不是它"。捡回"同信息异时异果"的为什么：验的是"体"的跨运行持久性。

### 自我驱动（谁推动）

- 无独立推动者。驱动力来自信息（树中的动机、未决项张力 + 外界输入），LLM 解读信息，涌现自我驱动。
- 但 LLM stateless，需"何时跑"机制 = **节律（起搏器/心跳）**。节律不决定方向（方向在信息），只保证系统一直在走。

### 节律是机制的，不是自主的（YZ 修正 AI）

- 节律像生物钟，是规律的、定时触发的，不必"自己决定何时醒"。
- 事件驱动：定时本身是事件；外部事件（飞书消息）可唤醒；个体可自设闹钟。
- 切割：**何时醒/歇 = 机制/事件；做什么 = 自主**（动作来源在内部状态）。
- 自主 = 可以硬抗（有阻力）、可以设闹钟提前醒——对节律的覆盖/调整，而非节律本身由自己决定。

## 遗留

- 第二步（让临时不停）不是顺理成章，是难点：需节律 + 张力评估 + 醒/歇切换。
- "引路人 vs 对等伙伴"的成熟判据未扣。
