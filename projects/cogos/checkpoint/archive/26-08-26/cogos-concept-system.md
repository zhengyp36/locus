# CogOS 概念体系

> 目的：把 26/08/24–26/08/25 讨论中的概念梳理成体系，服务 CogOS 平台搭建。
> 只留结论 + 锚点，不搬过程。锚点 = 本目录 checkpoint-<N>.md / cogos-design-theory-summary.md。

## 一、定位（CogOS 是什么）

- **CogOS = 认知操作系统 = agent 平台层，不是 agent 本身**。
- **AGI = CogOS 实例 + 初始动机 + 持续运行（不关机）**。
- 平台把工具执行、循环驱动、身份全部藏进内部，对外只露「一棵树 + 一个推理引用」。
- 锚点：`cogos-design-theory-summary.md §一`。

## 二、静态结构（由什么组成）

### 平台三大件（一等公民）

1. **认知树（体）**
   - 持久、可积累、可分享的知识结构；有独立 CRUD 与操作语义。
   - 身份/自我的静态内容（我是谁、动机、历史）。
   - 树结构：共享主干 + 私有子树 + **写时复制** + **异步合入**；共享/私有边界对 agent 透明。
2. **InferNode（用）**
   - 瞬时、可替换的推理能力。
   - 封装 API 凭证（隐私边界）+ 资源管理 + 成本信号。
3. **基础设施 / 多子系统**
   - 工具执行能力、循环驱动、身份；多子系统并行微弱运行。
   - 子系统四件：**意识 / 意图 / 记忆 / 感知**。

### agent 实例

- **agent = 认知树视图 + 运行平台 + 运行时**；临时构造，生命周期 = 一个会话，不持有工具/循环/身份。
- **独立认知个体 = 认知树（体）+ 推理节点（用）+ 多子系统**，构成一个运行时。
- 临时 vs 持久：**连续性 = 状态持久 + 可恢复，不是进程常驻**；体持久、用可替换，重启即恢复。
- 锚点：`cogos-design-theory-summary.md §一`、`checkpoint-18.md`。

## 三、动态原理（怎么运转）

### 自我驱动（谁推）

- 无独立推动者；驱动力来自信息（树中动机/未决项张力 + 外界输入），LLM 解读信息，涌现自我驱动。
- 三样合一：**闭合力（能力）语料给；方向（闭合什么）树里动机/未决项给；时机（何时闭合）节律给**。
- 切割：**何时醒/歇 = 机制/事件；做什么 = 自主**（动作来源在内部状态）。

### 节律（起搏 + 衰减）

- 双重身份：**起搏器**（保证系统一直在走）+ **显著性强制衰减**（保护自主性不被环境俘获）。
- 非定时器；衰减弱化的是「信息对行动的牵引力」，不是信息内容。
- 节律是机制的、非自主的（生物钟式）；可硬抗、可设闹钟提前醒。

### 边界 = 权重场

- **自我 = 边界**；边界在世界内部划出，自我是信息流里涌现的结构。
- 边界不是门（去留），是权重调制器：`事件 × 内部状态 → 权重`，权重决定记忆强度/进意识概率/动作牵引力。
- 统一原则：**不删信息，只调权重**（与节律衰减同源）。
- 感知/记忆划分 = 出处划分（外界 vs 内部），非可靠度分级。

### 动机（碰撞中显现）

- 多条信息闭合方向不一致 → **碰撞** → 动机显现。
- **动机 = 多条闭合方向碰撞中「胜出的持续在场约束」**，不是存着的目标标签。
- 意识 = **强焦点 + 弱背景**（动机锚点持续在场），非纯单点。

### 决策（无决策器）

- 没有决策器，LLM 是运算器；**决策在信息中**，信息经 LLM 运算显露决策。
- 机制层：胜出规则从「显式决策器」转移成「认知树喂什么视图」。
- **决策在折叠层做（比相对张力），执行在展开层做（看细节）**。

### 全貌与 4K

- 认知树替代日志流（主动组织 vs 被动记录）。
- 4K 恒定窗口 = 工作记忆；全貌 = 缩放（折叠概览），局部 = 放大（展开），任何情况 ≤4K。
- 4K 四区：**锚点区**（动机在场）/ **全貌区**（折叠骨架）/ **焦点区**（展开）/ **碰撞区**（冲突并排）。
- 规模：**分层分治**（将军/副将），递归分类解决任意规模，每层只看本层全貌。

### 分类有损

- 分类有损、LLM 运算也有损；**不追求无损**（看全貌 = 拿细节换概览）。
- **防的不是有损，是固化**；分类是动词非名词，要流动。
- 重分类触发 = 节律/重置（「睡一觉组织方式改变」）。
- 全貌 = 当前分类下的有损概览，暂时、可推翻重组。

### 划分 / 视焦 / 隔离

- 动机：让意识只看内容、屏蔽过程细节。
- 隔离屏蔽的是机制（how）非内容（what）；隔离线画在机制/内容之间。
- 收益：准确性 + 可靠性（隔离 = 故障边界，一子系统崩不拖垮全局）。
- 划分其他作用：确立自我边界（出处划分）+ 分工/并行。

## 四、连接主线

**信息驱动 → 运算有损 → 抽象分层 → 分类流动**

- 价值链：**价值 ← 自主发现问题 ← 持续积累的自我视角**。
- 稳定性根因：U 型注意力（机制）/ 目标漂移（结构）/ 干扰放大（组织）/ 上下文污染（组织）。
