# checkpoint-5 — 设计目标收敛：自维持认知循环

## 当前问题

定 D1 前，先定"智能系统设计目标"本身。YZ 描述心里想要的样子（子系统划分 + 视焦思想 + "像人"的特性），但目标仍宽泛、易漂向具体架构。

## 讨论结论

目标收敛为一句：**造一个能自维持运转的认知循环，进而成为可共事的对等个体。**

- 架构形态（意识/意图/感知/记忆/LLM server/cog-unit/cog-func）是手段。
- 持续性/节律/信息驱动是运行特性。
- "像人"不可验证、不可作目标（人是黑箱，永远觉得"不够像"）。

## 自维持认知循环的特征（YZ 确认全要，无多余）

1. 信息驱动，非指令驱动
2. 持续性：不因任务完成而停
3. 节律：醒/歇节奏，歇 = 低强度整理（记忆）
4. 有积累（内在状态）：非每次从零，同信息异时异果
5. 意图自主性：有找不到对应外部指令的动作
6. 对等：与人对 agent 同一语言通信，可共事

闭环：感知(事件) → 意识(思考) → 意图 → 工具/通信 → 结果回流 → 记忆 → 影响下次。

## 关键判断

"自维持"是整体涌现性质，非某模块单独实现。D1 边界候选：先做"闭环能持续转"本身（各环节粗糙可），验证不停/有积累/因信息而动，再单点做精。

## 节律深化（YZ 补充）

节律不是硬性调度，而是「趋势 + 阻力」：默认有醒/歇节律倾向，意识可用意图覆盖（如工作/兴趣牺牲睡眠），但偏离默认越久阻力越大，阻力最终胜出但可被推迟。歇不是被时钟强制，而是内部多个倾向博弈的结果。→ 节律与意图自主性统一为「环内倾向间的博弈」。
