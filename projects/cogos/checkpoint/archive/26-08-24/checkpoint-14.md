# checkpoint-14 — 方法论锚定 + D1 最终定义

## 方法论（YZ 锚定，飞书先例）

- 把整系统拆成独立模块/子系统，各自独立验证、实现，最后拼装。
- 不是"demo"（完整粗糙版），不是"各个击破后重来"（推倒式），是**模块化增量**：每个模块独立可验证、收口后成为地基。
- 先例：飞书通信层（Phone 抽象）独立做 → 真机验证 → 收口 → 现成 agent 的地基。

## D1 最终定义

### 目标
验证**记忆连续性**（同信息异时异果），不验自发、不验未来感。

### 组成（五部件）
1. 飞书收发（Phone，现成）
2. 记忆存储（结构化文件 / 简单库）
3. 记忆沉淀（专门 LLM：自动提取未决项 / 摘要 / 时间线 / 关于 YZ）
4. 记忆检索（决策前注入相关记忆，D1 记忆小 → 全量）
5. 意识决策（综合 LLM：消息 + 记忆 → 回应）

### 隔离（记忆机制对意识不可见）
- 记忆是独立子系统（专门 LLM），意识不知道存哪、怎么组织、怎么检索，只拿到"相关记忆"这个结果。
- 分工：**我们造机制（身体 / 海马体），agent 造内容（自我 / 人生）**。
- 对应 checkpoint-6 意识-记忆隔离 + checkpoint-7 专门 vs 综合分工。

### 自我 / 边界
- 独立身份：飞书账号，第一人称"我"。
- 第一人称记忆维度：我是 / 我的目标 / 我答应过待办 / 我目前认为 / 我经历的（时间线）/ 关于 YZ。
- 边界：记忆只属于 agent，YZ 只能对话影响、不能直接改；agent 只能通过消息了解 YZ。

### 验证标准
同信息异时异果：同一信息，前后回应可验证地不同，且能指出是哪个沉淀导致。2-3 个跨时间追问场景。

### 明确不做
自发 / 内源节律 / 焦点 / 张力 / 多 agent / 多渠道 / 记忆门槛 / 价值认同。

### 难度
五部件均低。唯一真难点 = 沉淀 prompt 的稳定性（可调，非算法难）。约 1 周内。

## 遗留

- 差异定位、顺序（先定界再定向精读 vs 先精读）仍待 YZ 裁决。
- D2 难机制（节律 / 焦点 / 张力）留 D1 后仔细讨论。
