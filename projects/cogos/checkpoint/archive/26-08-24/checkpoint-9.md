# checkpoint-9 — 差异定位 + D1 边界提案

## 当前问题

基于 research-1（机制被业界全覆盖、原创性非价值点），讨论「我们的差异在哪」+ 定 D1 边界（最小闭环 + 飞书入口）。

## AI 观点（含不同意见）

### 差异定位：机制无差异，差异在「目标 + 环境」

- 不再在机制层找差异（GWA/张力/EMBER 全覆盖，找到也不值钱）。
- "差异"唯一用途 = 决定 D1 借力什么 / 必须自己验证什么。
- 问题重述：**别人没有直接对标的是什么？**
- 答案：**「对等个体在真实共事环境里自维持运转」**。
  - 业界 self-evolving 终点 = 任务性能工具（benchmark）；我们终点 = 可共事对等个体（衡量持续运转/因信息而动/有积累）。
  - 两处无法照抄：① 环境 = 飞书 + 真人对等（Phone 已就绪）；② 验证标准 = 自维持（benchmark 测不了，自己定义）。
  - 机制层全部照抄/借力。

### D1 边界提案

1. 环境：飞书，YZ 单人 + 单 agent 对等对话（多 agent/群聊/上网/多模态不做）。
2. 最小子系统：感知（飞书消息事件）→ 意识（单 LLM 综合决策）→ 意图→动作（发消息 + 内部动作）→ 回流 → 记忆（朴素持久化 JSON：未决项+摘要）。
3. **内源节律极简雏形必须进 D1**（哪怕一个定时器：无外部输入时周期动一次，查未决项/主动发起）。理由：否则 D1 退化为普通 chatbot，验证不到目标。
4. 记忆门槛/验证 D1 不做（单 agent 记忆极小，污染临界远未触及）。
5. 趋势+阻力、精细焦点/吸引力、张力可计算代理 → 留 D2。
6. D1 验证标准（~1 天）：a) 回应受记忆影响（同信息异时异果弱版）；b) 无消息也主动动；c) 不因单次任务完成而停。

### 顺序：先定 D1 边界，再定向精读

- 不同意见：research-1 的"先精读三篇"应反转为"先定边界，再带着 D1 需要定向精读"，避免泛读漂移。
