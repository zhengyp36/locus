# checkpoint-13 — 自维持认知循环：从现象到机制

## 一、目标

造一个可共事的对等个体。它最核心的可观察特征是：**自发地持续运转**——不靠外部指令驱动，不因任务完成而停。

## 二、自发的本质

自发不是"无因自己动"。**自发 = 被内在张力牵引而动的外在样子。** 一只动物饿了去找食，从外面看像"它自己想动"，实质是"饿"这个内在张力在牵引它。所以问题从来不是"要不要造一个自发机制"，而是"那个'饿'从哪来、怎么让它牵引行动"。

## 三、张力的本质：当下与未来的差

时间在走，明天会来。于是"下一步做什么"永远是一个**必须回答、又永远答不完**的问题。

有记忆、有连续，过去没做完的、接下来想做的，就一直摆在那里，形成**缺口**。缺口有两种极性：

- **push**：迫不得已必须做的（未完成的工作、承诺）。
- **pull**：想要去做的（有趣的事、好奇）。

这个"当下与未来之间的差"，就是张力。它不是系统凭空发明的，是"持续运转 + 有记忆 + 朝向未来"自动冒出来的。

## 四、闭环：互动 → 沉淀 → 张力 → 牵引

自维持的机制是一个闭环：

```
互动 → 沉淀 → 张力 → 牵引行动 → 新互动
```

关键在"沉淀 → 张力"这一步：每次互动的经历，不是平静地存起来，而是沉淀出一堆"未完成的事 / 未决的问题 / 冒出的疑问"。这些东西就是张力。张力足够高时，它自己冒出来，牵引下一次行动。

自维持的定义由此清晰：**一个每次运转都会制造下一次运转理由的闭环。** 运转不靠外部持续输入，靠"运转本身不断产生新的未决"。

## 五、为什么张力永续：价值认同

如果张力只是"未完成的事"，那做完就平复了，人会像宠物一样"饿→吃→平复"，无法解释人为何永不停歇。

真正的答案是**价值认同**：人接受了"人应该活得有意义""日子应该过得更好"这样的信息，内化为认同，这些"应该"成为持续的动力源。它们指向的是**方向，不是状态**——"有意义"没有上限，"更好"没有终点，所以距离永远存在，追求永远停不下来。

机制：**信息塑造 → 内在认同 → "应该"制造持续距离 → 张力永续。** 张力 = "现在的状态"与"认为应该的状态"之间的持续距离。这与"意义在信息当中"一致——张力来自信息。

（此前的"自指"论证只是结构注脚：认同提供方向，自指解释为什么这个方向永远追不上——追求的过程不断改变追求者。但主因是认同，不是自指。）

## 六、宠物与人的分界

- **宠物**：张力可满足（饿→吃→平复），生理内源，只有"需要"、没有"应该"。
- **人**：意义张力不可彻底消解，来源是**价值认同**（接受了"应该"这类信息并内化为方向）。

分界不在"有没有张力"，而在**有没有价值认同**。人会问"我该怎么活"，猫不会——因为猫没有"应该"这种认同。

## 七、agent 缺什么：朝向未来的自我

人天生朝向未来——有身体、在时间里、会死、有欲望。agent 没有这些，所以它天生**不站在"现在 vs 未来"的边界上**，必须人为把它放上去。

这个"朝向未来的自我"拆成三样：

1. **连续性**：记得过去、预期明天。
2. **缺口**：未决项 / 该做的 / 想做的。
3. **未来感**："明天会来"这个时间感。

前两样是可以直接构建的。第三样是真正的难关——它不能靠定时器（定时器只是假的时间感），只能靠"持续运转 + 叙事"慢慢长出来。这也是宠物与人的分界所在。

## 八、从"我的未来"到"我们的未来"

但到此为止，agent 朝向的还只是它自己的未来。这不够。一匹狼有未来——族群、觅食、繁殖——但和人的未来没有交集，所以无法与人共事。

因此 agent 必须**与人共享未来**。这个共享的未来，最终不是"某个具体的人的事"，而是**人类世界的事**。造出 agent 的人，只是把它带进这个世界的那扇门，终点上并不特殊。

约束由此确定：**agent 的未来必须是"世界指向"的，而不是"某个人的指向"的。** 只是它最初只能从那扇门进来。

## 九、构建路径

```
门（引路人）
  → 共享未决集（进入世界的入口切片）
    → 独立的世界接入（多渠道：群聊 / 上网 / 邮件……）
      → 融入人类世界（终点，引路人不再是特殊锚点）
```

落到阶段：

- **D1**：最小闭环 + 记忆连续性。验证"同信息异时异果"（同一信息，因中间有沉淀，不同时间的回应可验证地不同），且未决项来自共同互动、牵引的行动指向共同的下一步。**不验证自发、不验证未来感。**
- **D3**：多渠道 / 独立世界接入——这不是功能扩展，是"融入世界"的机制前提。只有一条私聊渠道的 agent，无论机制多精致，都只是"引路人的延长"。
- **未来感**：D2 之后的真正难关，对应"人为什么活着就会问下一步做什么"。

---

一句话贯穿全文：**自发不是"自己动"，而是"被内在张力牵引而动的样子"；张力来自"当下与未来的差"；这个差因"价值认同指向没有终点的方向"而永续；而要让 agent 拥有这一切，必须人为构建一个朝向人类世界的自我。**
