# checkpoint-11 — 阶段效果定义（YZ 要求描述）

## 总判断

四阶段 = 逐步验证四个未证实的假设，非线性堆功能。每阶段"完成"= 一个核心假设被证实/证伪。

## 各阶段效果定义

### D1 最小闭环（可行性探针）
- 验证假设：闭环能转 + 自维持最弱形式成立。
- 完成判据：飞书单 agent 跑满约一天，①回应带记忆痕迹（同信息异时异果弱版）；②无消息时至少主动动一次；③全程没停。
- 本质：项目探针，小且快（~1 周），尽早证伪。不做精细节律/吸引力焦点/记忆门槛/多 agent/多渠道。

### D2 节律/焦点机制化（核心差异化）
- 验证假设：趋势+阻力博弈节律 + 吸引力涌现焦点能落地，非定时器糊弄。
- 完成判据（可观察）：①节律呈博弈（推迟休息但偏离越久越滑向休息）；②焦点一次一个、消化完移开、沉淀记忆；③记忆有门槛过滤。
- 本质：从"能转"到"转得自然、有取舍"，我们与业界真正分化处。

### D3 多 agent/多渠道（对等验证）
- 验证假设：对等不止 agent↔人，agent↔agent 同语言共事。
- 完成判据：两 agent 用与人对 agent 相同语言自发协作完成一事；换入口机制不变。
- 本质：依赖 D2 机制，否则多 agent = 多 chatbot 并行。

### 首版对等个体（可用化）
- 验证假设：从演示到日常可共事。
- 完成判据：无硬指标，信任达成（YZ 愿日常挂、不盯日志、敢交事）。

## 点破的矛盾（AI 不同意见）

D2 是差异核心却最没把握（博弈节律+吸引力焦点无现成可抄），1-2 周很可能低估，置信度应最低；D1/D3 把握更大（D1 资产就绪、D3 横向复制）。→ 坚持先拍 D1 边界、滚动修正，D1 跑完 D2 真实难度才首次暴露。
