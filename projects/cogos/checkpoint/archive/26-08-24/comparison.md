# comparison — 我们的设计 vs 业界（对照清单）

> 用法：逐条过。分三档——【同】可直接借力、【近】路线不同需取舍、【空白】业界没做=我们的差异/难点。
> 出处：我们的观点标 cp 编号；业界标论文（GWA/EMBER/ST=Structural Tension/Letta/StateM/VaG）。

## 第一档【同】业界已做、我们基本照搬

1. **改 harness 不改权重**（cp9 路线）↔ StateM：durable states + runbook，95.3% raw accuracy。→ 支持 D1 不碰模型。
2. **回流闭环**（cp6）↔ self-evolving 公共底座：行动→新输入→更新。→ 最没争议，照搬。
3. **记忆有积累/分层**（cp5 特征4）↔ Letta：memory blocks + sleep-time compute 空闲自整理，24k stars 成熟。→ 照搬。
4. **记忆门槛防污染**（cp9 留 D2）↔ VaG：Pre-Commit Gating，污染结构性不可逆。→ D1 不做，D2 必加。

## 第二档【近】业界做了但路线/成熟度不同，需取舍

5. **全局工作空间形态**（cp7）↔ GWA：同名理论（Baars 1988）落成 LLM 架构，开源。
   差异：GWA 是**单 LLM 扮演三角色**（Generator→Critic→Meta 仲裁），我们要**独立 actor 各自跑**。→ 借"广播+竞争"机制，不借并发实现。
6. **意识=综合 vs 专门，无本体差别**（cp7）↔ GWA Meta Agent（综合仲裁）+ Generator/Critic（专门）。→ 同源，直接印证。
7. **焦点=谁强谁进意识**（cp6）↔ GWA 候选竞争进入 workspace（Critic 评分+Meta 拍板）。
   差异：我们提"吸引力涌现+生命周期（聚焦→消化→释放→沉淀）"，比 GWA 的静态评分更细；但 GWA 的评分是可跑的，我们的吸引力是纸面。
8. **自己动起来/内源节律**（cp6）↔ EMBER：SNN 22 万神经元 + STDP，无输入时靠背景噪声自发放电，7 次对话+8h 空闲后主动联系用户。
   差异：EMBER 重路线（双 GPU、N=1），我们走 LLM 侧轻路线。→ 印证"内源可造"，但不抄 SNN。
9. **内在燃料/未决项**（cp6）↔ 拼凑：GWA `[THINK_MORE]` + EMBER episodic memory + Letta sleep-time compute。→ 无单一实现，需自己拼。
10. **张力**（cp6 统一隐喻）↔ ST：同名"Structural Tension"，但**纯理论、零实现、零验证**。
    差异：业界只有公式，我们 cp13 已到"价值认同"层，实质领先；但落地双方都空白。→ D2 没得抄。
11. **记忆机制对意识不可见（隔离）**（cp14）↔ EMBER："SNN 决定关联、LLM 只推理"的分工=隔离。→ 有先例，但 EMBER 未开源。

## 第三档【空白】业界没有，我们的差异/难点所在

12. **价值认同**（cp13）：张力永续靠"应该→方向→永续距离"，业界只有熵/冲突/内源损失这类技术驱动力。→ 我们独有。
13. **朝向未来的自我**（cp13）：连续性/缺口/未来感三样，第三样"未来感"是真正难关。→ 业界无对应。
14. **共同未来=融入人类世界**（cp13）：世界指向、非 YZ 指向；业界终点是 benchmark 工具。→ 我们独有。
15. **自我也是环境/双环同构**（cp6）：记忆↔意识 = 世界↔个体同构，边界可移动。→ 业界无对应。
16. **对等个体（非工具）**（cp5 特征6 + cp9 差异定位）：业界终点=任务性能工具，我们终点=可共事对等个体。→ 差异的总纲。

## 一句话总结

16 条里：4 条照搬、7 条借框架换路线、5 条业界空白。
→ 真正要我们自己攻坚的是第三档 5 条，其中"张力→持续自发"是核心（对应 D2 最难、置信度最低）。
