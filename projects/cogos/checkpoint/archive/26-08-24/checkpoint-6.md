# checkpoint-6 — 机制讨论：如何自己动起来 + 张力统一

## 当前问题

目标（自维持认知循环）已收敛，进入核心难题：①如何让它自己动起来而非外部驱动；②"动得有意义"的难点。

## 三机制共识（YZ 认可，必要）

1. 内源节律：决定何时醒/歇。非硬性调度，是「趋势 + 阻力」——意识可用意图覆盖（牺牲睡眠），但偏离越久阻力越大，阻力最终胜出、可被推迟。
2. 内在燃料：记忆未决项 / 信息流 / 意图残留，让醒来有可处理的东西。
3. 回流闭环：动作 → 新输入，保证真转而非空转。

## 焦点 / 关注机制（难点展开）

- 焦点 = 一次一个点，清晰靠排除，注意力稀缺。
- 来源：吸引力涌现（新信息显著性 / 内在燃料张力 / 节律倾向），非中央指派。
- 移动：生命周期 聚焦 → 精细化 → 释放（吸引力下降）→ 移开，产物 = 记忆沉淀。
- 核心：意图只能从「被聚焦且被消化的点」产生（结构过滤噪声，不设评判模块）。
- 空转 = 歇：无足够吸引力点 → 不产生意图 → 滑入歇（节律阻力拉向低强度）。

## YZ 观点：意义在信息当中

- 信息自带方向：①自身方向（未决项 / 事做到一半自然指向下一步）；②已有信息 vs 新信息：一致 = 助力，相反 = 阻力 / 引发思考选择。
- 意义是「机制 + 系统运转」的产物，不是预设；源于环境互动（猴子的环境决定猴子的意义）。

## 张力统一隐喻（AI 提，YZ 认可）

- 意义/方向 → 势差/张力；机制 → 张力生灭循环（产生 → 感知/聚焦 → 消解 → 沉淀）。
- 统一前面全部：节律阻力 = 想歇 vs 想继续张力；内在燃料 = 未完成张力；冲突 = 新旧势差；焦点 = 谁张力大看谁；意义 = 张力消解产物。
- 边界：张力非代码规格，落地需可计算代理（未决项优先级 / 一致性度量 / 意图未兑现时长），留 D1 后。

## 环境含义

意义源于环境互动。环境 = **人构建的真实世界**（第一等、给定、不需设计）；渠道 = 飞书/邮件/上网/用电脑，是从环境获得信息的多种方式，可替换；共事 = 融入世界的方式（途径非目标）。感知子系统的「事件」抽象 = 环境的统一接口，渠道只是事件生产者（呼应 Phone 可换 client 哲学）。

## 渠道方向 + 自我也是环境（YZ 补充）

- 渠道按方向分类：双向（飞书：与个体对话）/ 输入型（上网：了解世界）/ 输出型（写博客）。对应感知（入）与意图兑现（出），渠道可按方向组合、可扩展（多模态识图等）。
- **自我也是环境的一部分**：双环结构——外环（个体↔世界，经渠道事件进出、影响环境收反馈）、内环（意识↔记忆/认知，自动调出+沉淀，内部状态变）。两环经「意识」节点连接。
- 同构：记忆相对意识 = 环境相对个体，都是「个体之外、经事件接口接入、机制不可见」的信息源。→ 个体与环境无绝对分界，边界可移动（记忆=体内环境，世界=体外环境）。呼应意识-记忆隔离。
