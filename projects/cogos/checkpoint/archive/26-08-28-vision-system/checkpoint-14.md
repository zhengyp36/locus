# checkpoint-14 — 视觉系统进入意识：模态解绑 + 图像上下文 + 对焦遮蔽 + 显意识边界

## 当前问题

视觉信息如何进入意识系统、意识边界如何划定。

## 关键结论

### 1. 子系统与模态解绑

- 子系统不跟模态绑定，需要什么语义计算就调什么 LLM；LLM-Service 已屏蔽差异（能力声明 + 自动推断路由，checkpoint-11）。
- 视觉信息**不转文字**：无视觉能力的 LLM 无法真正理解图，转文字是降维。
- 结论：根本不需要「传递信息」——上下文里有图像时，CogUnit → LLM-Service 自动路由到 vision LLM 即可。**信息在模态内传递，不做跨模态转换**（读到的是图，传的就是图）。

### 2. 图像上下文表征 = 原图 + index（range × scale）

- 一张原图 + index（对原图范围的引用）；图简单时 index 可表示全部。
- 计算机图无「对焦」问题，只有「分辨率/像素量」问题 → 图像金字塔（多级分辨率）预生成 1/1、1/2、1/4…
- **index = range（范围）+ scale（分辨率级别）两个维度**；取图 = `原图 + range + scale`，返回对应像素块。
- 放进上下文的信息：原图多大 + index 表示哪个部分（范围 + 分辨率级别）+ 提取出的图像信息。

### 3. 视觉子系统 = 感知侧 io 层（对意识只呈现结果）

- **对意识只呈现结果，内部可含潜意识推理**（含对焦/清晰度判断）。隔离 = 可见性隔离（不浮现进意识上下文），不是能力隔离（不是「不能有推理」）。
- 语义理解（看懂图里有什么、哪里有意思）在意识层调 vision LLM；视觉子系统做取范围 / 缩放 / 清晰度检测等 io 原语。
- 定位 = 感知侧最底层 io 原语，与「lm-service = 底层 io 抽象、cog-unit = 其上调度」分层一致。
- 聚焦回路：意识调 vision LLM 看全景 → 判断兴趣 → 意图「看局部 X」（纯语义 range）→ 意图翻译成 range → **视觉子系统内部完成取图 + 对焦（scale 自动）** → 清晰图像回传。对焦起止都在视觉子系统内，意识不参与。

### 4. 对焦遮蔽 + 多级分辨率

- 清晰度 = 可计算低层信号（人眼：对比度/高频能量峰值搜索，无语义、自动、遮蔽）。计算机里清晰度 = 分辨率级别。
- 默认某低分辨率全景**始终在场**作模糊背景（非一次性输入），聚焦局部取高分辨率。
- **scale 旋钮不在意识手里**：意识只发 range 意图，视觉子系统内部推 scale（预算内最高可用分辨率）完成对焦。
- 两条通道并存：自下而上（显著刺激 = 浮现机制）+ 自上而下（意识凭兴趣主动扫视）。
- 同构：视觉「模糊全景背景 + 清晰局部焦点」= 意识「强焦点 + 弱背景」。

### 5. 画面感回忆 = 记忆存图

- 纯「文字骨架 + 回链 raw trace」做不到画面感回忆：raw trace 会归档清理（回链断）、文字不是画面。
- agent 的「画面感回忆」= 在 vision LLM 上下文里重新出现一张图（LLM 无内部视觉浮现）。
- 记忆应存图：**缩略图（整体模糊印象）+ 兴趣点局部（高清关键细节）**，不存原图全像素。
- 认知树「骨架 + 回链 raw trace」升级为「骨架（文字/index/描述）+ 记忆内存储的图（缩略图 + 兴趣点局部）」，图是一等公民。
- 与「资源索引不做」不冲突：存的是「印象图」，不是「原始大图索引」。

### 6. 保真 vs 重建

- 捏造/补全不是缺陷，是主体性进入记忆的通道（期望/恐惧渗入处）。保真不是智能的特点，是介质记录的特点。
- 落到「记忆 vs 日志」两套记录：日志 / raw trace / 存图 = 介质记录（保真锚点，非智能）；记忆 = 智能层，浮现/回忆时重建，允许捏造。
- 「存图 vs 重建」是伪对立，两者并存：存图保回忆不彻底漂移（有真实素材可回），回忆是重构而非回放（带主体性颜色）。

### 7. 多模态表征调研（图 vs 词能否激活相似区域，2026-08-28）

- 能，部分共享。证据：
  - Anthropic 情绪实验 `Emotion Concepts and their Function in a Large Language Model`（arxiv 2604.07729）：steering 情绪向量因果改变行为（desperate 捷径率 5%→70%、勒索率 22%→72%），情绪在纯文本 LLM 内有可定位、因果性表征。
  - VLM 神经元 `Deciphering Functions of Neurons in VLMs`（arxiv 2502.18485）：visual / text / multi-modal 三类神经元——图词共享部分表征，但分模态专用神经元并存。
  - 对齐机制 `How Visual Representations Map to Language Feature Space`（arxiv 2506.11976）：adapter 把视觉特征硬桥接进语言特征空间，逐层渐进、早期层不对齐、中后层收敛。
  - modality gap（arxiv 2502.14888）：视觉与语言是「相邻但分离」的子空间，不完全重叠。
- 结论：图转文字近似**部分成立但有损**（vision-dominant 信息文字承载不了）。

### 8. 单次 vs 多次：文字中转的定位

- 单次理解图 = 模态内传图（第 1 节），不需文字中转。
- 多次局部读取理解图 = 需要「纸」（上下文外工作记忆）做文字中转。
- 文字中转定位 = **记忆层持久中间表示**，非理解层替代；跨多次调用拼连续画面靠它。

### 9. 纸 = 可改写的工作记忆（scratchpad）

- 本质 = 上下文外可读写中间状态：写不进的中间结论写到外面，按 index 读回。
- 机制做减法、策略做加法：只给三样硬条件——(1) agent 有绝对操作权的工作纸（可 append/改写/删）；(2) 多级缩放原语；(3) 上下文预算闸门（装不下兜底降精度）。LLM 自己决定先看哪 / 记什么 / 何时关联 / 何时降精度。
- 纸可改写非 append-only，对应「方法论是改写不是 append」（agent-study-hooks.md:54）；日志保持 append-only 做保真锚点（呼应第 6 节两条路）。
- 候选载体 = 认知树骨架 / 工作记忆侧，**非**过程记录（append-only）。

### 10. 显意识边界（回响 / 意图无声 / 记忆边界）

- **回响** = 浮现到显意识的内容（脑内声音 / 视觉印象 / 感觉），来源 = 潜意识多流微运行成熟浮现（concept-system 的「浮现」）。
- **意识 = 回响输入 + 无声输出**：意图是意识发出的，但意图本身无回响、听不见自己——回响是意识的一部分，不是全部。
- **显意识 = 可感知，不等于「可用文字描述」**：文字是共通性（人与人交流）的产物，不是意识的边界。
- **显意识工程边界 = 意识子系统上下文的内容集（token 流）**：在上下文里 = 显意识 = 落记忆 = 构成自我；不在 = 潜意识 = 不落记忆 = 不影响自我。
- **记忆边界 = 显意识边界**（concept-system.md:57）：不进显意识 → 不落记忆 → 想不起来 → 不影响自我 → 清理即可；但日志 append-only 仍兜底（介质记录，自我不记得 ≠ 系统没记录）。
- **边界划在接口上，不划在时间/过程上**：对焦作为过程整体归视觉子系统，起止都在内部，边界才清晰。
