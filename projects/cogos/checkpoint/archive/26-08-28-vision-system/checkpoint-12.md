# checkpoint-12 — 视觉系统 + 时间/事件序列 + lm-service/cog-unit 定位收敛

## 当前问题

多模态引出的后续设计思路：感知子系统如何组织、时间如何表示、lm-service 与 cog-unit 的职责边界。

## 关键结论

### 视觉系统 = 独立感知子系统（机制层遮蔽的"眼睛"）

- 不在 CogUnit 侧、不内置进 CogUnit；与认知树（记忆）平级，各自有自己的 cog-func。
- CogUnit 干净纯粹 = 最基本的认知计算调度，不内置任何特定能力（不内置视觉/记忆）。
- 类比「磁盘 zio → 文件系统」：原始视觉原语（thumbnail/crop/resize）→ 视觉系统（cog-func 组织）→ CogUnit（进程调度）。
- 视觉遮蔽机制：缩略图（外周）→ 聚焦局部（中央凹）→ 扫视；超限拒绝 = 机制层安全阀；意识不感知加载/切片/索引过程。
- 内部再分两层：本能层（预装不可自长）/ 策略层（注意力分配可自长）。

### 多模态 → 子系统

- 单一模态 → 正交子系统（视觉系统、听觉系统），互不用对方模态。
- 复合流模态（视频）→ 复合子系统，内部复用基础子系统 + 消化时间对齐；子系统可分层/组合，不只被 CogUnit 平级调度。

### 时间 = 事件间关系（偏序），非时间戳

- 先后（靠序位编码）/ 同时（靠同时组编码）；对齐 = 同时性绑定（大脑 binding problem 的解）。
- 感知事件 = `内容 + 通道 + 序位 + 同时组`；一条事件流，每时刻 = 复合事件容器，各通道往里放即自动对齐，同步退化为结构约定。
- 感知事件流与记忆天然同构（记忆单元 = 事件），可直接流入认知树。

### 定位收敛（YZ 拍板）

- 资源索引：**不做**（覆盖 checkpoint-11 里"先 base64 内联、MediaRef 预留 url/file"的初步想法）。
- lm-service = 屏蔽厂商差异、提供最通用的语义计算能力（无状态单次推理管道）。
- cog-unit = 语义运算的调度，简化上层对 lm-service 的使用。
- 类比：zfs 的 zio 流水线 + 底层磁盘 io 抽象——lm-service 是底层 io 抽象，cog-unit 是之上的调度。

## 遗留 / 待拍板
