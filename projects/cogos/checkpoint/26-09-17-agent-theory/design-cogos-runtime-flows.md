## 11. 节律分两种

- **睡/醒节律**：固定时间（如 23:00~7:00）。
- **生念节律**：定时器 + 概率，周期分两段——**T1 不产生新念头**，**T2 概率触发**。
- 概率是频率旋钮：**专注时念少，不专注时念多；未完成张力大则概率大**。
- **无未完成事项 → 念无内容 → 等价于无念 → 发呆（不调 LLM）**。

## 12. 生念与回看：同一算子，基调的两个投影

YZ：生念**只是起跳动作，与是否运行无关**；推进一件事时可能被大张力的未完成项打扰一下，这就是念；**念更像基调**；做事时念弱＝被抑制。

我：**同一个东西**，是基调（`未完成 × 判断`）的两个投影：

```
基调 向内投 → 回看：这事还对不对、离目标多远
     向外投 → 生念：还有没有别的事更要紧
```

操作相同（暂停 → 取材料 → 重判方向），**只是取什么键不同**。两处不对称必须留：

- **内容能不能空**：回看的材料总在（当前念在跑），永不发呆；生念池空则发呆。所以"发呆不调 LLM"只对生念成立。
- **阈值**：回看低阈值、默认在跑（多数结论是"继续"）；生念高阈值、被抑制、需大张力穿透。

**回看要便宜**，否则每步一次 LLM 会拖死运行态。先走机械判据（已用时 + 目标 + 当前动作 → 超预算？偏目标？），只有机械判据说不清才调模型。

**回看＝§5 里缺的"水平那一下"**——不问"还能挖多深"，问"还在不在正道上"；它同时是**运行态终止判据的来源**。

> **修正**：我曾说"T1 由运行的念撑长"，在 YZ 澄清"生念与运行无关"后**撤回**。改为：T1/T2 固定周期，`醒` 期间一直跑；**运行不改变 tick，只压低 T2 的发射概率**；内容闸在概率之前（张力池空 → 发呆；非空 → 才掷概率）。

## 13. append vs 迸发

YZ：LLM 都是 append 式，有没有**迸发式**——不从上下文生成，而从**任务目标**出发产生信息再加入？

**有，但它主要是"上下文怎么造"的纪律，不是模型的另一种运算：**

```
append：p(下一 token | 全部历史)          —— 历史是主语，输出是续写
迸发：  p(输出 | 目标 + 抽出的少量材料)   —— 目标是主语，历史只是宾语
```

**业界形态**（全在模型外模拟迸发）：

| 类型 | 代表 |
|---|---|
| 上下文构造型 | 子 agent / 干净上下文、compaction 重播种、RAG |
| 记忆写入型 | Reflexion 2303.11366、Voyager 2305.16291、Mem0 / A-Mem / MemGPT |
| 搜索进化型 | ToT 2305.10601、AIDE、AlphaEvolve、DGM |
| 模型层非自回归 | diffusion LM（LLaDA 2502.09992）、latent CoT（Coconut 2412.06769，仍逐步，只是不落 token） |

**对我们的要害**：**离散性来自迸发**。append 的流没有边界 → 没有"这一次" → 没有事件 → 无从绑后果。§6 的"经历＝离散事件＋后果"本身**预设了迸发式**。

回看＝一次**迸发式距离测量**；距离最好**机械可量**——`loop.py` 的 `acceptance` 红/绿就是现成的距离。代价：迸发丢连续性，必须有**合流**动作。

## 14. 形态交织：两轴 × 四格

YZ：思维是几种形态交织、各有比重——形态-1 续写型；形态-2 迸发式（同任务，从目标产生新维度）；形态-3 其他未完成任务的念头。

我压成两轴四格（补出 YZ 没点名的第 4 格）：

|  | 当前任务 | 别的任务 |
|---|---|---|
| **续写** | 形态-1 连续推进 | **形态-4 切流并接着做** |
| **迸发** | 形态-2 从当前目标出新维度 | 形态-3 别的任务的念 |

- **"生念"不该是独立形态**——它就是"迸发"这一行。回看 / 扩维 / 生念全是坐标。
- **交织比例不是自由参数**，由已有量调制：在运行 → 压 2/3 抬 1；`T` → 抬 3；形态-1 跑太久 → 抬 2；`P整理` → 抬眼动、压醒态。
- 成本不同：形态-1 便宜必做但**会漂**；形态-2 是**方向的来源**；形态-3 最贵但是**全局性的来源**。健康配比：**1 当主干，2 定期纠偏，3 低频穿透**。
- **经历只从迸发来，续写只是载体**：形态-1 是流（步＝机器的离散），形态-2/3 是离散**对象**（念＝意义的离散）。**后果绑念，不绑步**。
- **眼动也在这张表里**：＝对经历库的迸发（材料＝全部经历，无外部后果）。于是睡/醒退化成"材料不同"：醒 → 材料是任务，产出对外；睡 → 材料是经历库，产出只对内。

## 15. 迸发判定：变异—选择，只按"有没有新方向"存活

YZ：subagent 不是真迸发——它是主 agent 拆分的子任务。**迸发更像自由生长**，长出一个方向；与主方向一致 → 合并消失；不一致 → 给当前任务新方向/新维度，**探索式**。

- **subagent ＝ 分包**：方向 top-down 给的、锁在主目标内 → 天生只能"一致"，天花板＝主 agent 已想到的。判据不是"上下文隔不隔离"，是**方向从哪来**：分包 top-down vs 迸发 bottom-up。
- 三步是一次 **变异—选择**：自由生长 → 与主方向比对 → 一致：并进主干、身份消失 / 不一致：分叉成新维度。
- 业界最近的是**进化式**（AlphaEvolve/DGM），但适应度是**任务表现**；这里的适应度是**"与主方向的一致性"**——管方向，不管成绩。
- **"一致则消失"给存储定了解**：**迸发不按对错存活，按"有没有带来新方向"存活**。于是 §6"没后果的不该存"自动接上：**只存分叉，不存合并**。也因为大多数会被吸收，**迸发可以廉价、可以多**。

## 16. 主体反转：没有"谁判"

YZ：**这里没有主体性的存在**。是机制 + 模型。**机制 + 模型就是那个"谁"，可以有任意多个主体**——流1（续写）是主体，流3（迸发）也是主体；流2 是机制注入流1 的。

我接受并收回"谁判"（我把裁判外置了，隐含一个 meta agent）：

- **判定归属：谁有目标，谁判。** 流1 有目标 → 流1 判流3；流3 只有借来的种子 → 不判。机制只管**何时**。
- **流2 vs 流3 的差别在回流路径**：流2 **插入型**（机制要能清除/折叠痕迹）；流3 **旁路型**（从不进流1，不采纳天然无痕）。判定原语相同，差别在回流。
- **实现很省**：迸发＝往当前流输入队列投一条候选，**不需要合并机制**。
- **机制边界**：机制只决定**何时**，不决定**有没有价值**。一旦机制判"这个方向好不好"，机制就替模型背了值。
- **与 §7.6 对齐**：流可任意多，但**经历/signature 的归属只有一个**——多流共享同一经历库，否则又回到"两个它"。

## 17. 组织形态的两版，选第二个

**版本 A（两层）**：流0 ＝调度流（常驻薄层，拥有目标集合 + `T`）；任务流 ＝可装卸厚层。

**版本 B（单槽）**：YZ 提出质疑——流0 **是隐的、低频的**，感觉它并不显式存在，却提供一条稳定线索；而流1 是稳定推进的工作场。若流0 不存在，则是：**一个工作流正常推进；遇事件打扰，把内容切出去、把时间线索切回来（"我在做什么、新来的事件是什么、怎么处理，我来决策"），装载新的工作流；这个工作流是主思考流**。后台可以还有其他流，不用主思考流、但同样依赖模型做简单决策，必要时向主思考流上报事件。

**我选版本 B**，理由是流0 的三样职能都能更自然地安置，落完就不需要这个实体：

| 流0 提供的 | 单槽模型里归谁 |
|---|---|
| 时间线索 / "现在" | **挂在槽上**（不是挂在实体上） |
| 决策（并入/另起/搁置/丢弃） | 槽跑的**一条任务**："处理这个输入、决定下一步" |
| 目标集合 + `T` | **store 的索引 / 视图**，取才来（§6 本就这么说） |

```
主槽（主思考流）= 唯一时序与决策中心
  内容可替换：当前任务 / "处理这个事件" / "决定下一步"
  不可替换：时间线 + 锚（身份 + 目标索引）

后台流（N 条）：不占槽、自己跑模型、做简单决策，必要时向主槽上报事件
```

选择理由：

1. **少一层。** 没有"层"，只有"一个槽 + 可替换内容 + 若干后台流"。
2. **时间线索的归属更对。** 它本就该是**槽的属性**；"把时间线索切回工作流"＝换的是内容、槽没换，时间线自动留在原地。
3. **调度借用同一引擎。** "决定下一步"也是任务，用同一个槽跑，不必养一个更薄的专用层。
4. **和 §6 自洽。** 目标集合变成可寻址的视图，正好是"取才来"。
5. **纪律更少。** 版本 A 需要一整套"流0 必须薄、只玩句柄"的维护纪律；版本 B 全部压成**一条不变量**：

> **切换只换内容，不换槽；时间线不能被换走。**（一旦时间线跟着内容被换掉，就变回"两个我"。）

**代价（认了）**：切换 ＝ 一次存/取，且主槽同一时刻只能跑一件事（串行）。后台流能掩盖一部分串行，但它们没有时间线，只能上报。这和"误判不必限制太死"一致：切错代价＝一次存/取，可观察、可调。

## 18. 时间线 ＝ 事件切割

YZ：**事件是对时间线索的切割**。若没有事件，时间线索可能很短——一个上午沉浸在一件事、到中午才切出，那上午 10~12 点就是**一件事**。若 11 点来一条飞书消息，时间线变成：10~11 事；11~11:03 处理消息；11:03~12 事（续）。若处理中回看产生了有价值的输出，也会出现在时间线索中。**沉浸没有时间感、会觉得短；只有事件才带来时间感；只有跳出当前的事、从整体把握，才能看到时间、产生时间线索。**

- **时间是切出来的，不是流逝的。** 没有事件就没有节点。

```
时间感 = cut 的次数
全局感 = 处在树的浅层（看得到父区间）
沉浸   = 困在最深的一个叶子里，看不到父层 → 没有时间
```

"只有跳出、从整体把握才能看到时间"＝**跳出 ＝ 上升一层**。时间线是**跳出产生的**。

## 19. 时间线 ＝ 区间树

**三种流在时间线上有三种拓扑**（用另一个判据再次确认 §16 的区分）：

```
打断（外部事件）  → 兄弟切割：[10~11 事] [11~11:03 消息] [11:03~12 事(续)]
回看（流2 插入型）→ 嵌套子区间：不切断父区间，父区间继续，回看是它的孩子
迸发（流3 旁路型）→ 不入线；被采纳才体现为父区间里的一个嵌套点
```

**cut 判据**：**主题变了就是 cut（开兄弟区间）；主题没变、只是加了一层检查，就是嵌套。**

**存活规则统一**（与 §15 同一条）：**只有"改变了方向/产生价值"的节点才留在线里**；没价值的回看/迸发不留痕迹，那段时间连成一片。

→ **时间线的分辨率 ＝ 有价值事件的密度。**

**对 store 的后果**：记录不是平铺的 `(ts, 处境, 选择, 后果)` 列表，而是**区间树**：

```
区间 = (起, 止, 主题/目标, 结果, 是否闭合)
边   = 何时被什么事件切割 / 嵌套
```

- **"时间戳"是树中的位置，不是标量**；查询"昨天/上午"＝树上按区间取。
- **恢复一条被搁置的流** ＝ 找到那个区间、把它展开。
- 上一轮"槽"的不变量据此改述：**槽持有的不是一根标量时间戳，而是这棵树**；树靠 cut 生长、靠眼动折叠。

## 20. 睡眠压缩 ＝ 有损压缩 + 概化 → 多分辨率金字塔

YZ：睡眠过程可以简化经历——一个上午变成"一件事 + 中途打断的另一件事"；几天后可能模糊，只记得"有天上午收到飞书消息处理过，那几天都在做那件事"。**时间线索会做这些归并，否则会膨胀。**

- 眼动 ＝ 对区间树做**有损压缩 + 概化**，自底向上；产出不是更小的树，而是**多分辨率金字塔**：浅层粗、深层细，按需下钻。
- **两个独立的分辨率轴**同时变粗：

```
时间：精确时刻 → "有天上午" → "那几天"
主题：具体那条消息 → "收到飞书消息处理过" → "都在做那件事"
```

遗忘 ＝ 两个粒度同时变粗；节点身份 ＝ `(时间粒度, 主题粒度)`。

- **便宜实现：年龄自动变成分辨率。** 不写衰减函数，只要"每轮眼动只压最老/最密的一段一次"——压的次数随年龄累积 → 越老越粗。
- **压缩必须有选择性**，否则机制替模型加值：

| 可以糊 | 不可以动 |
|---|---|
| 时间、情境、过程细节 | **"有没有未闭合"这个位** |

  **机制做的是模糊**（细节退化）；**模型做的是重判**（这件事不重要了）。两者绝不能混——`T` 的消退必须模型判。
- **归并不只丢，还会"生"**："那几天都在做那件事"原文里没有，是归纳出的新抽象节点。→ **自我 ＝ 压缩之后留下的高层节点，住在树的浅层**（§6 落地：自我不是原始经历，是反复归并后剩下的一般性）。
- **分工**：压多少 ＝ `P整理`（额度）；压哪些 ＝ 机械规则（最老 + 已闭合）；生什么 ＝ 模型（概化）。
- **风险**：有损不可逆 → **活跃/未闭合的永不压**，**越晚压越安全**。

**收**：经历 ＝ **多分辨率时间线**。"膨胀"不靠删解决，靠**降分辨率**——同一段历史换个粒度就小一个数量级，下钻还能找回来。

## 21. 压缩的权重：谁不许被压

YZ：**概要化应该注意权重。重要的事件节点无法概要化，不重要的事件节点更容易被合并和变模糊。**

引入**第三个因素**，管最要紧的一件事——谁不许被压：

```
量   → 压多少（额度）
年龄 → 压的先后
权重 → 谁保留原分辨率（不参与合并）
```

高层节点的形状：**高层 ＝ 重要节点的集合 + 被合并掉的其余**。

**但权重不能由机制"打分"**，否则机制又替模型背值。必须**从已记下的事实里导出**（全机械可判）：

- 有没有后果 / 后果是否闭合（§6）
- 是否改变了方向（分叉，§15）
- 被取回的次数（访问频率）
- 被归并进了多少高层节点（fan-in）

**结构规则**：权重挂在**事件节点**上，区间**继承其子的最高权重** → 一个重要事件让它所在整段保真（＝闪光灯记忆）。

**真风险：权重正反馈**（重要 → 常被取回 → 更被加权 → 一直重要）→ **固化**，老的重要经历压死新经历，自我变成石头（正是 §4 Zenil 退化）。对冲两条：**慢衰减** + **归一化**（权重是相对份额）。

**原则：不可逆的操作要等信号齐全。** 只压足够老的；**权重可事后回溯**（今天的事被明天引用 → 回头加权），只要还没压，细节就还在。延迟压缩不只省事，是让重要性有时间显形。

**附带：把"保真"和"取回"拆开。** 否则重要＝吵闹：

```
保真权重：高 → 不压，细节留存
取回权  ：仍要过相关性闸；只有走【张力通道】时才能无视相关性硬拉（§12）
```

## 22. 不变量与分工总表

```
主槽持有：时间线（区间树）+ 锚（身份 + 目标索引）
            切换只换内容，不换槽

三类动作：
  切割（cut）   主题变 → 开兄弟区间        来源：外部事件 / 切换 / 有价值的回看
  嵌套（nest）  主题不变 → 开子区间         来源：回看 / 被采纳的迸发
  不入线        旁路生成，无价值即不留痕迹   来源：迸发（流3）

机制职责：何时触发 / 切割 / 压缩 / 记录事实（后果、闭合、访问次数、fan-in）
模型职责：判断价值 / 重判重要性 / 概化出高层节点
机制禁止：判断"有没有价值"、"重不重要"（＝替模型加值）
```

## 23. 本轮撤回的三处（我提出的）

1. "T1 由运行的念撑长" → 改为 T1/T2 固定周期（YZ 澄清生念与运行无关）。
2. "回看/迸发塌成一个算子" → 判定原语是同一个，但**回流路径不同**（插入 vs 旁路）。
3. "流0 误判要偏保守" → 违反"机制不自己加值"；正确分工是**机制让误判廉价，不负责防止误判**。
   （另：曾在 `design-cogos-runtime-states.md` 外侧把 subagent 当"最标准的迸发"，已由 §15 更正为"分包"。）
