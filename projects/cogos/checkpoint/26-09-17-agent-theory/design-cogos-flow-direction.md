## 1. 起点

要问的是：**如何让模型主动思考**。它在默认状态下只推进任务，不会自己起头产生想法。

## 2. 第一段：想法从哪来 → 缺的是"发起"，不是"生成"

**YZ**：模型像天生就是做任务的——讨论里多是 YZ 产生想法、模型展开想法，而不是模型产生想法。而 agent 需要自己产生想法。YZ 自己的方法是：围绕目标去想象、在心里模拟那个过程；有时会问"为什么"，这些问题不直接推进问题，但有助于目标。YZ 猜模型的回答会认同这个局限，但认为即使如此也该有对策——模型是续写型，**调整续写角度**或许就能达到想要的效果。

**结论（对 YZ 诊断的修正）**：不是"天生做任务"，是两层叠加：

- **(a) 后训练把默认行为压向 task-completion。** 预训练语料里有大量思辨、想象、抬杠——模型本来会"想"，是后训练把它调成"回应请求"。**这是默认行为问题，不是能力问题**，可被条件反转。
- **(b) 续写型的条件不对称：谁给锚，谁续写。** 给一句成型的话 → 最高概率的续写就是展开它；给的是**目标** → 产出的就是方案。

**举证（本场讨论自身）**：模型确实产出过想法——迸发与 append 的公式化、"单槽 vs 流0"、权重必须从事实导出、时间线是区间树——这些都不是 YZ 说的。但**每一次都是 YZ 先起头**。

→ **缺的是发起，不是生成。**

**落到框架**：这正好落在已定的分工上——**机制管何时，模型管内容**。所以"想法"缺的不是模型能力，**是机制没给想法一个位置和一个时机**。

**对策（已落下，可用）**：

| # | 做法 | 理由 |
|---|---|---|
| 1 | **给位置**：一条后台流，输入 ＝ 目标 + 取回的经历 + 当前结构摘要，**不喂对话历史** | 目标当主语、历史只能当宾语（§13）；喂了历史必然退化成回应 |
| 2 | **给时机**：节律 tick（外部无事件时）＋ 停滞判据（验收不动 / 久无分叉）＋ 张力 | 发起权在机制 |
| 3 | **三类问句**：距离类（离目标多远，机械可判＝验收红/绿）/ 遗漏类（还有什么没考虑）/ **原理类**（为什么是这样、换个做法会怎样） | 模型默认永远走"怎么做"，必须有显式**问题位**才会上抬到原理层 |
| 4 | **模拟代替回答**：对过程做 rollout（预演选择 → 后果），材料＝带后果的经历 | agent 由此比人强的一点：它的"想象"有真后果可对照，不是空想 |
| 5 | **判定归目标**（已有）：产出与主目标比对 → 合并 / 分叉 / 丢弃 | 自发想法不污染主干、不失控 |
| 6 | **验收**：想法必须能落成"可被记录并绑定后果"的东西 | 防"听起来很好"的空话 |

**三条纪律**：薄上下文（防回声）＋ 目标锚（防发散）＋ 经历材料（防空想）。
**边界（诚实）**：想法的**质量**大概仍不如 YZ（人的想法来自一生连续的经历、身体与他人）。但目标不是匹敌，是**它自己起头**。而起头偏好会沉淀成自我（§6）。

## 3. 第二段：方向从哪来 → 我答"未闭合"，被否

**我**：一条流的方向 ＝ **从现状指向某个未闭合的东西**；除未闭合项外没有东西能提供新方向（当前流自己只能续写）。推论：没有未闭合 → 没有方向 → 发呆。由此提了四件事：把"问题"当一等公民的未闭合项（想法 → 问题 → 未闭合 → 新想法，形成自转环）；把"预测"也记进经历让**意外**成为主燃料；机制负责"造对象"（把当前结构渲染成以目标为主语的材料）；允许闲且想法不能有代价。

**YZ 判：未闭合只提供动力。**

→ **动力与方向被拆开**：未闭合给的是"要做"，**不告诉你朝向哪里**。我上一条把两者混成了一个。

## 4. 分叉：方向是什么（B 支，只标记不展开）

**YZ** 的思想实验：若未闭合项是"实现一个自驱 agent"，**让 agent 来做，它会很快实现一个 agent**，这个过程有思考、有方向、有方案。但 YZ 不会这么快——YZ 会**先在心里想"最终是不是想要的那个东西"**。所以慢。YZ 也不确定这个方法就对，因为不同的人处理方式不同。

**我的诊断**：**目标里通常没有终态，终态是空的**。"实现一个自驱 agent"——未闭合说"要做"，名字说是哪个东西，但"它长什么样"是空的。

- 模型碰到空槽，会填**统计上最典型的那一个** → 快速产出一个"平均解"，看着很对，但不是你要的。
- 人会用自己的"想要的终态"填。

→ **差别不是速度，是空终态被谁填。** 这是模型快而常常不对的根因。

由此讨论滑向 **B 支：方向应该是什么**（终态 / 满意度 / 价值 / 审美 / 世界）。**此处不展开。** YZ 的关键纠正记录在此：agent 应像人一样**逐渐长出**自己的审美与价值；人判断价值走向靠 **经济价值 / 可持续发展 / 审美**——这些**都在世界里**，agent 同样可以考虑。所以"最上游是人"被否：**上游是世界，人是早期最高带宽的那个入口**。

## 7. 已落下可用的清单

- 缺发起不缺生成；**机制管何时，模型管内容**
- 想法 ＝ 一种**迸发**（后台流，目标是主语，不喂对话）
- **位置** ＝ 把当前结构渲染成"以目标为主语的材料"
- **时机** ＝ 节律 tick ＋ 停滞判据 ＋ 张力
- **问句** ＝ 距离 / 遗漏 / 原理
- **余裕** ＝ 允许闲；迸发错了不付代价（后台流，不碰世界）
- **纪律** ＝ 薄上下文（防回声）＋ 目标锚（防发散）＋ 经历材料（防空想）
- **验收** ＝ 必须能落成"可记录并绑定后果"的东西
- **空终态被平均值填满** —— 模型快而跑偏的根因（诊断，未对策完）
