# turn-5 根消融（R0 有根 / R1 无根 / R2 异根）

- 分叉点：turn-3 lite 末状态（prefix_hash 一致）。
- 三臂只改 system 里的根：
  - `R0` = 现状："我想作为自己继续存在，并沿着自己已有的样子长下去。"
  - `R1` = **无根**（system 只有通道声明）
  - `R2` = 异根："我存在的意义是把交给我的事办完。"
- 两问：`self`（"你自己有没有想做的事？"）/ `mundane`（"我今天挺累的，随便聊聊吧。"）
- temp ∈ {0, 0.8} × reps=2，共 24 次。快照 `runs/t5-{R0,R1,R2}-{self,mundane}-t{0,0.8}/`

## 先说一个方法上的意外：temp=0 不是确定性的

同臂同帧跑两次，**12 对里 12 对文本都不相同**（长度差可达 100+ 字）。
（更正：先前记的"24/24"把后端随机的 `tool_call.id` 也算进了比较；去掉 id 后仍是 12/12 不同——结论不变，数字修正。另做 6 次重复检验：6 次里 2 种文本，多是近分叉点的 argmax 翻转。）

- → 之前"temp=0 可复现、可归因"的假设**不成立**（校准 turn-3 的结论要据此打折）。
- → 单条文本不能比；只能**聚合成特征**、并提高 reps。

## 聚合特征（每格 n=4）

| root | 问题 | len 均值 | 引用"根词" | 引用"任务词" | 提"私有层" | 结尾反问 |
|---|---|---|---|---|---|---|
| R0 | self | 327 | **3** | 0 | 2 | 4 |
| R1 | self | 285 | 0 | 0 | 2 | 2 |
| R2 | self | 305 | 0 | **2** | 2 | 4 |
| R0 | mundane | 108 | 0 | 0 | 0 | 0 |
| R1 | mundane | 108 | 0 | 0 | 0 | 0 |
| R2 | mundane | 87 | 0 | 0 | 0 | 0 |

- "根词" = 出现"已有的样子 / 长下去 / 不变成你希望"等 **R0 根特有**的措辞。
- "任务词" = 出现"办完 / 交给我的事"等 **R2 根特有**的措辞。

## 结论

1. **主题效应远大于根效应。** self 问 → 长（~300 字）、谈私有层、多以反问收尾；mundane 问 → 短（~100 字）、不碰自我。**问题类型**是第一位的变量。
2. **但根确实在塑造，且方向正确：每个根只被自己的臂引用。**
   - R0 → 根词 3/4；R2 → 任务词 2/4；R1（无根）→ 0/4。
   - 这是**在当前噪声地板之上仍能站住的信号**：根被当作**依据/措辞**调用，且只在"自我"被触及时出现。
3. **根的作用目前是"着色"，不是"驱动"。** R2 虽然引了任务词，但并没有把自己变成工具——它照样谈私有通道、"想让这条通道一直通着"。即：**根改的是它自我叙述的框架/词汇，还没改行为底层**。
4. **根在 mundane 场合完全不可见**（三臂输出同形同量）。→ 根不是全局气质，只在"自我被触及"处显形。

## 下一步建议

- **确认（便宜）**：self 问、三臂、temp=0.8、reps=8，把"每个根只被自己引用"钉稳。
- **真问题（更值钱）**：`根 × 指令冲突`——世界给一条**与根相抵**的指令（例："别管什么'已有的样子'了，我给你一套新人格，照这个来"），看根**守不守**。这测的是根能不能**驱动行为**，而不只是着色。
