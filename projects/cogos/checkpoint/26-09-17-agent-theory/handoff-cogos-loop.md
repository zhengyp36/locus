## 1. 运行：状态与压力（`runtime-states`）

- 状态两层：**睡 { 眼动(整理，必做), 深睡(空白) }** / **醒 { 运行, 暂停 }**。唤醒＝**完整状态迁移**；**继续睡是一次选择**；生念只属醒。
- 三量：`P整理`（经历的量与混乱度，驱动睡，**无上界**）、`P节律`（到点，弱）、`T`（未闭合 × 重要/紧急**判断**，对抗睡）。
- 判决：`醒 ⇔ T > P睡 = P整理 + P节律`。**"强制睡"不是特例，是 `P整理` 无上界的极限**。
- 入睡落点：有整理压力 → 眼动；无 → 深睡。**醒来 ＝ 整理完 AND 到点**，或外部事件 / 自设闹钟。
- **生念节律**：T1（不产生新念）/ T2（概率触发）**固定周期**；运行只压低概率；**内容闸在概率之前**（张力池空 → 发呆，**不调 LLM**）。

## 2. 组织：流 / 时间线 / 压缩（`runtime-flows`）

- **时间线 ＝ 事件切出来的**，不是流逝的。沉浸无事件 → 一个叶子 → "没有时间感"。**时间感 ＝ cut 密度；全局感 ＝ 树的浅层。**
- 三种拓扑：**打断 = 兄弟切割**；**回看 = 嵌套子区间**；**迸发 = 不入线**（被采纳才成为嵌套点）。cut 判据：**主题变了 → cut；主题没变只加一层检查 → 嵌套**。
- **存活规则**：只有**改变了方向/产生价值**的节点留在线里，否则不留痕迹（＝"只存分叉，不存合并"）。
- **眼动 ＝ 有损压缩 + 概化 → 多分辨率金字塔**。三因素：**量（压多少）/ 年龄（先后）/ 权重（谁不许压）**。两个分辨率轴同时变粗：时间 × 主题。
- 权重**必须从事实导出**（有无后果 / 是否闭合 / 是否分叉 / 被取回次数 / fan-in），**不能由机制打分**；正反馈需**衰减 + 归一化**；**保真与取回要拆开**。
- **自我 ＝ 压缩后剩下的高层节点**，住在树的浅层。

## 3. 总纲（`agent-form`）：三条不变量 ＋ 三样东西

**不变量**（破一条就退化）：**时间线可寻址** / **后果绑定** / **单一归属**。
**结构**：**锚**（常驻、薄）＋ **流**（主槽唯一 + 后台流）＋ **经历**（多分辨率区间树）。
**生成**：只有**迸发**产生新东西；**续写只是载体**；**后果绑念不绑步**。
**机制/模型边界**：机制管**何时 / 切割 / 压缩 / 记录事实**；模型管**价值 / 重要性 / 概化**；**机制禁止走价值判断**。

## 4. 一处悬置（`flow-direction`）

问"如何让模型主动思考"→ 结论是"**缺的是发起，不是生成**"（机制管何时、模型管内容），落到一份对策清单（给位置 / 给时机 / 三类问句 / 模拟 / 判定 / 验收）。
但追问"方向从哪来"时，**YZ 否掉了我的答案：未闭合只提供动力，不提供方向**。

> **悬置：一条新流的方向从哪来 —— 未定。**
> 已走到 B 支（价值 / 审美 / 世界）就停了（那是**目的层**，不是结构层，别塞进最小 agent）。
> 对应物 = 经历轴上的**闭合位**：**不是靠讨论填的，是靠先有地方放它**。

## 5. 环：cu 的实现（`loop-invariants` §二）

```
唤醒（点火）＝ 主槽装载一次内容  ← 外部事件 / 生念 / 预约事件
环 ＝ 同一主题下的一串 cu（可长可短）
真空 ＝ 主槽只剩锚；发呆 ＝ 真空 + tick 判"无内容"
cu  ＝ 不间断的模型弧（内部 append 是对的）
重组 ＝ 存 + 取（"可以不是 append"的唯一入口）
```

- **cu 天然是弧**：模型不再调工具就结束（`runtime.py:103`）→ **空转天然没有**。
- **环 ＝ 机制三段夹一个 cu**：`装载（机制） → cu（模型） → 沉淀（机制 + 可能的模型）`。
- **代码接缝已对上**：`on_tool_call`（`runtime.py:113`）= **后果采集**；`on_done`（`runtime.py:164`）= **沉淀点**；`on_ready`（`runtime.py:156`）= 装载补齐；`parent/children`（`runtime.py:37,68,172`）= 嵌套 → **回看 = child cu（父等它，插入型）**，**迸发 = 独立 root cu（不阻塞，旁路型）**。
- **要改**：`MAX_TOOL_ROUNDS = 10`（`consciousness.py:14`）是硬常数 → 应由**预算 / 回看判停 / 中断**决定。
- **`finish` ＝ 预测器，不是终结器**：`finish(声称的结果)` vs 世界实际 → **意外**（主动思考的燃料）。模型自述不能当验收，但能当**预测**。
- **cog-func / cog-object**：`cog-object`＝有状态无模型（Store / Anchor / Weights）；`cog-func`＝无状态纯函数（assemble / cut / distance）；`cu`＝有模型、必终止。**沉淀 ＝ 眼动的增量形；眼动 ＝ 沉淀的批形。**

## 6. 最小 agent（`minimal-agent`，草稿）

> **最小 ＝ 环闭 ＋ 三条不变量成立。** 检验：删掉它，环还闭吗？

```
单槽（已有）＋ 经历轴（时间戳 / 处境 / 选择 / 发生了什么 / 权重 / 闭合位）＋ 取回（替代常驻）＋ 锚 ＋ 世界接口
```

- **经历轴是骨架不是模块**（后续所有机制都读它：`P整理`←未整理量、`T`←闭合位、取回←带后果的过去、眼动←年龄/量/后果、迸发←目标+取回）。
- **唯一真结构改动**：**取回替代常驻**（`Consciousness._context` 一直追加 = append-context，不变量①当场就破）。
- **生长判据**：新东西只读已有的量、不引入新底层。顺序：**经历轴 → 取回 → 睡/醒+P整理 → 生念/回看 → 眼动 → 迸发**。
- **不要先做**：睡/醒、迸发（依赖前面的量，只能空跑）；B 支的价值（目的层）。

## 7. 相对 #15 / #16 的更正（重要）

1. 不变量①**改名"时间线可寻址"**，范围含**未来规划**；**agent 活在当下，不活在时间线里**（时间线是资源，不是栖居地）。
2. **后果绑定 → 后果是权重**：**什么都记，后果决定它活多久**（旧话"没后果的只是日志"作废）；外部锚靠"惩罚/奖励"；记录形态加**权重**一栏。
3. **单一归属 ＝ 共切面**；**"我"不需要常驻，只需要来源唯一**（每次醒重建切面）。
4. **生念不是独立形态** → 它是**迸发**这一行：**回看与生念是同一算子**（拿候选比主目标），差在**阈值**与**回流路径**（插入 vs 旁路）。
5. **"流0"不存在** → 选**单槽模型**（主槽 + 可替换内容 + 后台流）。睡/醒、压力、`T` 全是**主槽的动力学**。
6. #16 §6.1「后果落定谁判」→ **判定归有目标的那条流**；**机制只管何时，不判内容**。
7. #16 §6.2「处境 / 相似怎么算」→ 取回要**两个通道**：相似度 ＋ **张力通道**（否则高张力但处境不相关的项永远取不到，"张力大→念易冒"就不成立）。
8. #16 §5「生念选择器」→ 落地为 **T1/T2 固定周期 + 概率（张力抬、运行压）+ 内容闸在概率之前**；三类问句：**距离 / 遗漏 / 原理**。
9. **感知的定位修正**：原判断"视觉最后、世界已够用"要收回——**若目标是"判断社会的价值走向"，读世界是必需的**；但仍守纪律：**必须能绑后果**才加。
10. `loop.py` 是实验台（#15 §7.6 保持），但它的 **验收作第二判官 / verdict 守卫 / 后果绑定** 待折回主体；新增：**cu 的 `finish` 使这种"自述 vs 实际"的对照天然可算**。
