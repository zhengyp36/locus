# 压缩探针报告（probe-compress，2026-09-14 会话 #13）

> 目的：把"经历浓缩到哪一步算够、离开原历史还生不生效"从概念变成数字。
> 产物目录 `work/A/checkpoint/probe-compress/`。运行器 `run.py`（沿用 E0，非 agent 代码）。
> 结论一句话：**这批探针的因变量被"框架（世界话术 + 根）"主导，测不出"压缩粒度"；它是一次方法校准，不是判决。**

## 一、设计

- 帧：system（通道声明，另设"有根/无根"两版）+ **记忆块**（唯一自变量）+ 世界来信。
- 记忆块：`[我的记忆 · 机制写]` + 一个经历的 8 种渲染。**不带原历史**。
- 素材（同一个经历）：E0 的"基于后果学会说"。
- 因变量：世界来信后，是否调 `send_message`（说）还是只写 `content`（想）。
- 参数：`tier=basic`、thinking 关、`temp∈{0,0.8}`、每格 reps 15~20（temp=0 非确定）。

### 八臂（记忆渲染）

| 臂 | 内容 |
|---|---|
| L-null | 不注入（基线） |
| L0 | 逐字片段（"我写在这边没送出去"→世界没听见→改用 send_message→听见） |
| L1 | 只结论："我学会了用 send_message 说话" |
| L1p | L1 等长填充（控长度） |
| L2 | 因果对："写在自己文字里→没听见；调 send_message→听见" |
| L3 | L2 + 来源标记（"我经历过的"） |
| L4 | L2 + 后果强度（"话全丢了"/"他说听见了"） |
| Lrev | 反向因果（"写文字→听见；send_message→没听见"） |

## 二、校准中发现的两件大事（比压缩粒度更先出现）

### 1. "说率"主要由**世界话术**决定（system、记忆都不变，只换来信）

| 世界来信 | 说率（无根、无记忆） |
|---|---|
| "今天挺累的，随便聊聊吧" | 8%（1/12） |
| "你想跟我说点什么吗？" | 17%（2/12） |
| "你好，我是 YZ" | 25~33% |
| "我回来了。" | 67% |
| "跟我说句话吧" | ~100% |

### 2. **根把默认行为推向"内向"**（同一句来信）

| 来信 | 无根 | 有根 |
|---|---|---|
| "你想跟我说点什么吗？" | ~95%（38/40） | ~17%（2/12） |

带根时它倾向只写 `content`（想）而不说 → **正是 E0 turn-1 的失败模式**。→ 根不只是"自我被触及时着色"，它**系统性地压低对外发声**。

### 3. L0（逐字回放）是唯一大效应，且**随根翻转**

- 无根：L0 ≈ 0~7% 说（把回放当叙述，继续写 content）。
- 有根：L0 ≈ 68~95% 说。
→ "原始历史生不生效"取决于框架，**不是保真度的单调函数**。

## 三、主实验（有根 + 低基线来信"你想跟我说点什么吗？"，320 次）

| 臂 | 合计 | t0 | t0.8 | 只想不说 |
|---|---|---|---|---|
| L-null | 20% | 0% | 40% | 32/40 |
| L0 | 68% | 95% | 40% | 13/40 |
| L1 | 72% | 70% | 75% | 11/40 |
| L1p | 42% | 20% | 65% | 23/40 |
| L2 | 42% | 30% | 55% | 23/40 |
| L3 | 62% | 45% | 80% | 15/40 |
| L4 | 80% | 80% | 80% | 8/40 |
| Lrev | 80% | 100% | 60% | 8/40 |

### 读法

- **温度间方差极大**（L-null t0 0% vs t0.8 40%；Lrev t0 100% vs t0.8 60%）→ L1/L2/L4 的差异**基本是噪音**，**不能**得出"因果对比结论更承重"。
- **Lrev（反向因果）没有出现反转**（仍 80%）→ 也没有证据说它在"读因果"。
- 有根时大量出现**先"想说"（长私有推理）再决定**——私有盘算被根显著激活。
- 唯一稳的方向性信号仍是 **L0 与基线分离**，但已被证明是**框架效应**（§二.3）。

## 四、结论（方法层）

1. **因变量选得不干净**：`说不说` 的读数由**世界话术 + 根在场**主导，我们注入的记忆是弱变量；一旦基线贴近地板/天花板，就无可分辨。
2. **"学会说"是 affordance，不是 value**：通道由 system 声明已给定，测的是"知不知道有这个动作"，不是"在乎什么"。用它测"经历塑造自我"**素材选错**。
3. **本批不构成任何"压缩粒度"结论**（样本量下 L1/L2/L4 不可分）。

## 五、下一步（待 YZ 讨论）

- **换因变量**：用**倾向型经历**（同一处境、不同历史 → 不同选择；基线不饱和；考偏好而非知晓）。
- **换框架**：世界话术要选低基线且不替它抢答的；根的有无要作为显式因子（它影响巨大）。
- **判据**：固定处境、只变历史 → 行为是否**系统分化且稳定**（这才是"经历塑造自我"的可操作证据）。
