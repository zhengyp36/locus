## 0. 一句话

一个自驱 agent ＝ **一个在转的环 ＋ 两条链条**。外圈（事件→弧→后果→写回）让它**会动**；内圈（经历→升格→目的→距离→燃料）闭合，才叫**自驱**。

## 1. 三条不变量

| 不变量 | 含义 | 机制 |
|---|---|---|
| **时间线可寻址** | 过去（含未来规划）能被稳定定位 | 经历轴：段 id ＋ 引用。**链只服务证伪，不服务想起** |
| **后果绑定** | 后果绑到念／事，不绑步 | **反向重演**：把值沿路径往回传 |
| **单一归属** | 共切面；来源唯一 | 来源字段 ＋ 内容寻址（处境唯一决定谁被激活） |

补一句：**agent 活在当下，不活在时间线里**——时间线是资源，不是栖居地。

## 2. 结构

- **锚**：常驻、薄。当前的我——signature（不变）＋ 当前目的／方法 ＋ 关系摘要。**必须是沉淀物的摘要，不许是声明**；写进去的声明就是断言（不会变、不能被反驳、可以随便装）。
- **经历轴**：骨架，见 §4。
- **流**：主槽流（唯一）＋ 后台流（可并行，不占主槽）。
- **后压层级**：多分辨率高层节点，**自带内容，不是指针**。

**存储三层**：结构化经历轴 ／ 原始存档（每弧 material，只服务"能反驳"，**最先淘汰**）／ 后压层级（记得最牢）。

## 3. 运行

- **事件入口**独立于感知。感知只是生产者之一（外部事件／到点／生念平级）。入口的产物不是"事件"，是「**装载 ＋ 续或切**」的决定。
- **装载三节**：**过去**（经历 ＋ 目的）／**现在**（主槽活状态，取不回）／**刚刚**（事件源）。
- **一弧**：装载 → cu → 停 → 沉淀 → 升格 → 判。
- **切点 ＝ 误差**（预测 vs 后果），**不是"有没有事件"**。内部也能切：目标完成／目标更换／该来的没来。误差是连续量，超阈值 → 离散切换。
- **续 / 切**：`continue_of`（我接着谁）／`cut_by`（我被谁切开）——**实时记**。
- **卡住 vs 茫然**：预测落空 → 换思路；预测为空 → 补线索。处置相反。
- **朝外／朝内**：同一种转移的两种装载源。事件装载＝朝外（写回落点是行动）；机制装载＝朝内（写回落点是结构）。朝内**不占主槽**，是**方法论／目的／自我的车间**。
- **判**：还有燃料吗（目的上的距离／未闭合张力／队列）。没有 → 真空，静着；但经历无上界堆积 → 压力转向朝内。
- **机制的三条供给**：草稿空间、后果绑定、**停下来的机会**。

## 4. 经历轴（表示）

落笔单位 ＝ **段**（一弧一条；弧内多轮工具往返**不进轴**）。

```
段
  id        单调递增              地址；事的身份也用它
  t, host   坐标
  来源      谁／什么触发的
  内容      这段在做什么（含选择）
  预测      我以为会怎样            ← 误差的另一半，可为空
  后果      实际回应了什么（含沉默）
  结        这段结束时，所做的事了结了吗
  thread    属于哪条事（＝起始段 id）
  refs      [(kind, id)]           continue_of / cut_by，kind 用开放词汇
```

五条要点：

1. **顺序不记**（追加给的）；**引用必须实时记**（只有当时知道）。
2. **层级不进基底**：嵌套／并列是**后压**出来的；压出来是**写新记录**，不是就地改。旧段与引用永不动。
3. **段里要有路标**：放下时的意图／下一步／悬着的判断——"回去"要的是**状态重建**，不是定位。
4. **派生量：活跃度 ＝ 近因 ＋ 强度 ＋ 权重**。点火与抽样的入口量。
5. **读侧单位也是段**（取出来的是一段，不是一条）。

**"什么都记"与"只留改变方向的"不冲突**：前者是**记录粒度**（每弧一条，不筛），后者是**留存规则**（权重筛）。**淘汰由后果驱动，不由年龄驱动。**

## 5. 取回

- **五通道**：来源／时间／主题／张力／目标（后两个要等权重与目的长出来）。
- **两时机**：装载时（供当下）／**整理时（供概化聚合）**。
- **三条规矩**：每次现算、有预算、**每条带"为什么取它"**——理由就是方向。
- **必须走内容寻址**（近因＋相似＋张力＋打标）；**链不参与取回**。
- 取回的产物 ＝ **对位关系**，不是内容列表。方向在取的那一刻产生。
- **想起 ≠ 接上**：想起靠张力；接上靠状态重建（依赖路标）。

## 6. 整理（＝沉淀的批形）

- **抽样重演（生成）**，不是扫描／统计；**可正可反**；**反向重演 ＝ 后果绑定的实现**。
- 一次重演**可混不同时期／来源的段** → 这是"同类／主题"的原料。
- **衰减两个来源**：时间 ／ **被处理过**（没有后者，处理过的东西会永远占据注意力）。
- 淘汰从细到粗；高层节点自带内容。
- **睡／醒**：`醒 ⇔ T > P睡 = P整理 + P节律`。有整理压力 → 眼动；无 → 深睡。

## 7. 边界与纪律

- **机制／模型**：机制持**时序权 ＋ 簿记权**（何时发生、给什么材料、结果记成什么事实），可**雇 cu**，但**不许替模型做价值判断**；模型管价值／重要性／概化。
- **有损不是缺陷，是筛选**——它就是方向的来源。全量可达会取消筛选 → 没方向、没自我。
- **什么都没有时它不会死**：朝外停摆 → 转向朝内；经历无上界，整理永远有事做。

## 8. 生长与改动的判据

- **生长判据**：新东西**只读已有的量**，不引入新底层。
- **改动判据（换零件三纪律）**：一次只动一个；其余**冻结**；这个零件**不需要别人先改** ＋ 改完**能看出差别**。
- **只增不改**：段与引用永不改写；**重组 ＝ 再写一条**。
- **两条硬约束**：id 单调、引用指得准。其余全是可重建的视图，做错能重来。

## 9. 落地路径（**候选，未定**）

环**已经在转**（现有 agent 是纯响应式闭环）→ 不是"搭最小"，是"**换零件**"。
第一刀候选 ＝ **后果**（现状只写不读）→ 权重 → 取回替代常驻。
理由：它是唯一同时满足"不需要别人先改"和"改完能看出差别"的零件。
