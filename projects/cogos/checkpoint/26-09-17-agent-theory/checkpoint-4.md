## 一、把三个词接起来（对本轮之前的澄清）

- **自驱** = 议程的更新函数 `A_{n+1}=f(A_n,结果)`。静态议程不驱动，**ΔA 才驱动**。**自主度 = agent 在 f 里的占比**。跑通回路 ≠ 自驱，那只是自动。
- **源外移** = 回路每格（`议程/触发/执行/验证/写回/停问`）都有一个"源"，终点两类：落**壳**（机制、确定）= 自动；落 **agent**（认知、会错）= 自驱。现状账：执行→agent（早已）、触发→壳（S3）；**议程/验证判据/记忆仍在人或壳**。已发生的外移终点**全是壳**，所以 S3 跑通仍觉得"它本来就该通"——是自动，不是自驱。
- **S4** 不是一件事，是**这条外移轴上的持续动作**：每次只把一格从"人/壳"挪到 agent，每挪一格配一个安全件，一阶一交付、可回退。
- **为什么第一阶不挪议程源**：议程源（L3 自生议题）最深最危险，立刻面临议程爆炸/自我扩权；生成权、终结权、丢弃权须同时具备，而现在还没有"停/丢"机制。判据源是缝、风险最小、省人时最多，且没有自产判据，连自生议题"值不值得做"都判不了（S3 验收空转即预演）。

## 二、YZ 修正：最终态是"双自驱共驱"，不是"接管"

纠正"源从人单向挪到 agent = 人退出"的隐含读法：

- **终点**：人有自己的 f，agent 有自己的 f，**两个 f 更新同一份议程**（共同目标 = 更新的对象是同一个 A）。外移消灭的是"人被迫当机制操作员"，不是"人"。
- **"身体"类比**（YZ）：agent 不能改自己的机制，正如人不能改自己的基因/架构。精确成**两层的不对称**：

| 层 | 人 | agent | 关系 |
|---|---|---|---|
| **机制层**（身体/架构） | 不能自改 | 不能自改 | **不对称**：所有权在"造它的人"，不在自己 |
| **认知层**（判断/策略） | 自驱 | 自驱 | **对等**：都是自驱主体 |

  - "不能自改机制"不是 agent 的特殊限制，是**一切主体性的一般条件**。
  - 机制**可塑性本身是预装的**（人能练身体/学知识，agent 能长认知/策略）；能动的是能力，不是机制。
  - 机制层的改动权在**外部设计者**——这是"人在场"的最终理由，也是底。
- **边界模糊的落点**：共同目标定了之后，角色不按"人/机"分，而按**此刻谁握着调度权**分（接 cog-func"主体性=流动的调度权"）。agent 可带人、人可带 agent、可平级。**不是所有事都商量 = 各自握 f 自主推进**；商量只发生在**目标冲突/高风险/互相不确定**处。
- **一句话**：认知层人机对等、双自驱、按调度权流动协作；机制层不对等、agent 不可自改、所有权在人。

## 三、源外移判据的修正（本轮最有用的产出）

原判据"源往 agent 挪"会误导成单向转移。改为看**人的角色**：

> 这格里的人，是**机制性依赖**（不做，回路就停/就错），还是**同级认知贡献**（各持一个判断）？
> **外移 = 消灭前者，保留并放大后者。**

- 人写判据、卡在流程里 → 机制性依赖 → 外移。
- 人复核判据"合不合理" → 同级认知贡献 → 保留，这就是 L4 里人的位置。
- 每阶问的不是"agent 能不能做"，而是"**这格里还需要人吗，是因为缺判断，还是因为流程上必须有人？**"——只拆后者。
- "不确定就问"是一等安全件：它是保留认知贡献，不是补机制缺口。

## 四、S4 从哪里开始挪（本轮推出，待 YZ 确认）

**起点 = 验证格里的「判据内容」**（不是验证机制）。理由用新判据看得很干净：

- 当前唯一"人不写就停"的格子就是验收判据（人不给判据 → 验收空转）。
- 它只需挪**内容**（谁来写这条测试），**机制**（怎么执行、怎么判红绿、退出码）留壳——这正是"机制/认知两层"的最小示范。
- 风险最低：红→绿是可判的真假，且**红→绿硬门顺带治 S3 验收空转**。
- 它给出后续每一阶的**模板**：人从"提供者"变成"复核者"。

**第一阶具体形态**（承 `checkpoint-3.md` §五）：

```
只有标题的 issue
  → agent 先写会失败的红测试（判据相，停）
  → 壳确认初始红（非红 = 无效判据 → needs_human）
  → agent 实现
  → 红转绿（实现相）
  → 人只复核「判据合不合理」
```

- 最小机制：验收分两相——**判据相**要求初始红 / **实现相**红转绿；初始非红 → `needs_human`；复用 cu 续轮 + task-5 phase 计时。
- 验收 = ① agent 自产判据（人没写测试）② 判据合理（初始红 + 人复核认可，防"无关红测试"钻空子）。
- **先别做**：L3 自生议题、全量常驻、大重构。
- 靶子：`state.md` §三候选无"最小+可验+无需决策"项 → 造最小靶或取某候选的最小子切片。**待 YZ 选靶/开题。**
- 分工：适合工位 A（B 忙 task-6/7）。

**后续排序（按"人的角色"风险由低到高）**：

1. 判据内容（本次）—— 人从提供者→复核者。
2. 议程内容（L3）—— 需先有终结/丢弃权，防爆炸扩权。
3. 跨会话记忆 —— 不是人卡点、是能力缺失，属支线，随需接。
