## 总纲

> **agent ＝ 一个槽 ＋ 一棵树 ＋ 一组压力 ＋ 一台迸发引擎。**
> 其中唯一"活"的东西是**槽**；唯一长出来的东西是**树**；自我 ＝ 树被反复压缩后剩下的高层结构。

它不是"一个有记忆的模型"，而是**一份被持续切割、压缩、寻址的经历，挂在一个唯一的时序中心上**。

---

## 一、三条不变量（破一条就退化）

1. **过去可寻址**——过去不在窗口里常驻，取才来。常驻的只有锚（身份 + 目标索引）。
2. **后果绑定**——没后果的只是日志，有后果的才叫经历；非中性挂在后果上。
3. **单一归属**——流可以有任意多条，但**经历与签名只有一份**；切换只换内容，**不换槽、不换时间线**。

第 3 条是"不会长成两个我"的唯一保障。

---

## 二、结构：三样东西

| | 是什么 | 常驻？ | 有"现在"？ |
|---|---|---|---|
| **锚** | 身份 + 目标索引 | 常驻，**薄** | 有（挂在槽上） |
| **流** | 主槽（唯一）+ N 条后台流 | 主槽常驻，内容可装卸 | 只有主槽有 |
| **经历** | 多分辨率区间树 | 落盘，可寻址 | 无（是它的记录） |

- **主槽**＝唯一时序与决策中心。"决定下一步做什么"本身也是它跑的一条任务。
- **后台流**＝不占槽、自己跑模型、做简单决策、必要时向主槽上报事件（迸发、眼动都属于它）。
- **只有主槽有时间线**；后台流只有因果序（先后），没有"什么时候"。

---

## 三、运行：睡 / 醒由一个判决式决定

```
睡 { 眼动（整理，必做）, 深睡（空白） }
醒 { 运行（念驱动）, 暂停（念之间的空隙） }
```

三个量：

| 量 | 来源 | 作用 |
|---|---|---|
| `P整理` | 经历的量与混乱度 | 驱动睡（**无上界**） |
| `P节律` | 到点 | 驱动睡（弱、有界） |
| `T` | 未闭合 ×（重要/紧急**判断**） | 对抗睡 |

```
醒 ⇔ T > P睡 = P整理 + P节律
```

- **"强制睡"不是特例**，是 `P整理` 无上界的极限：能对抗，但只到某个时刻。
- **入睡落点**：有整理压力 → 眼动；无 → 深睡。**醒来 ＝ 整理完 AND 到点**，或外部事件/自设闹钟直接唤醒。
- **生念只属于醒**；睡里不产生新念，只做整理。
- 张力有**两种表达**：醒时 → 生念 tick；睡时 → 自设闹钟。

---

## 四、时间：它是切出来的，不是流过去的

**事件是对时间线的切割。**

- 沉浸一上午、无事件 → 时间线上就是一个叶子，**没有内部结构** → 这就是"沉浸没有时间感"的结构来源。
- **时间感 ＝ cut 的密度**；**全局感 ＝ 处在树的浅层**。所以"只有跳出当前的事才能看到时间"成立：**跳出 ＝ 上升一层**。

三种流对应三种拓扑：

```
打断（外部事件）→ 兄弟切割：把父区间切成两段
回看（插入型）  → 嵌套子区间：父区间继续，回看是它的孩子
迸发（旁路型）  → 不入线；被采纳才成为一个嵌套点
```

**cut 判据**：主题变了 → cut；主题没变、只加一层检查 → 嵌套。

**存活规则（统一）**：只有**改变了方向 / 产生价值**的节点才留在线里；否则不留痕迹，那段时间连成一片。
→ **时间线的分辨率 ＝ 有价值事件的密度。**

## 五、生成：只有"迸发"产生新东西

```
append：p(下一 token | 全部历史)          —— 历史是主语，输出是续写
迸发：  p(输出 | 目标 + 抽出的少量材料)   —— 目标是主语，历史只是宾语
```

四种形态（两轴四格）：

|  | 当前任务 | 别的任务 |
|---|---|---|
| **续写** | 形态-1 连续推进（主干） | 形态-4 切流并接着做 |
| **迸发** | 形态-2 出新维度（含回看） | 形态-3 别的任务的念 |

- **回看与生念是同一算子**（拿候选比主目标），差别只在阈值：**回看低阈值、常驻、多数结论是"继续"**；**生念高阈值、被抑制、需大张力穿透**。
- **离散性来自迸发**：append 的流没有边界 → 没有"这一次" → 无从绑后果。**经历只从迸发来，续写只是载体。后果绑念，不绑步。**
- **迸发不按对错存活，按"有没有带来新方向"存活**：一致/无用 → 吸收消失，不留痕；不一致 → 分叉，落成经历。因此**只存分叉，不存合并**，也**可以廉价、可以多**。
- 生念要**内容闸在概率之前**：张力池空 → 发呆，**不调 LLM**；非空 → 才掷概率。
- 节律：T1（不产生新念）/ T2（概率触发）**固定周期**；运行不改变 tick，只压低发射概率；张力抬高它。

---

## 六、记忆：压缩成多分辨率金字塔，按权重决定谁不许压

**眼动 ＝ 对区间树做有损压缩 + 概化，自底向上**，产出多分辨率结构：浅层粗、深层细，按需下钻。

两个分辨率轴同时变粗：**时间**（精确 → "有天上午" → "那几天"）× **主题**（具体事件 → 事件类型 → 持续主题）。

三个因素：

```
量   → 压多少（额度）
年龄 → 压的先后（每轮只压最老/最密的一段 → 年龄自动变成分辨率）
权重 → 谁保留原分辨率（不参与合并）
```

- **权重必须从已记下的事实导出**：有无后果 / 是否闭合 / 是否分叉 / 被取回次数 / fan-in。**不能由机制打分。**
- 权重挂事件节点，**区间继承其子的最高权重** → 重要事件让整段保真。
- **正反馈风险**（重要 → 常被取回 → 更重要 → 固化）需对冲：**慢衰减 + 归一化**。
- **不可逆的操作要等信号齐全**：只压足够老的，权重可事后回溯。
- **保真与取回要拆开**：高保真不必高可取回；后者仍过相关性闸，只有张力通道可硬拉。
- **自我 ＝ 压缩后剩下的高层节点**。眼动是唯一写它的地方。

---

## 七、机制与模型的边界（工程纪律）

```
机制负责：何时触发 / 切割 / 压缩 / 记录事实（后果、闭合、访问次数、fan-in）/ 机械判据
模型负责：判断价值 / 重判重要性 / 概化
机制禁止：判断"有没有价值""重不重要" —— 那是替模型加值
```

**没有外置裁判，也没有"谁判"的主体：机制 + 模型合起来就是那个"谁"，主体就是流本身。**
**判定归属规则：谁有目标，谁判。**

推论：**机制负责让误判廉价，不负责防止误判。** 误判可观察、可调，且是成长素材——自我 ＝ 存/取偏好，偏好正是从带后果的选择（含错的）里沉淀的。

---

## 八、按这个结构，落地顺序应是

```
1  经历落盘：区间结构 + 时间戳 + 闭合位        ← 一切的上游
2  主槽（单流）+ 事件切分（cut）
3  压力 → 睡/醒（先 T 与 P整理 的最简形）
4  生念节律（T1/T2 + 内容闸）
5  回看（机械距离优先：验收红/绿就是距离）
6  眼动（压缩 + 概化 + 权重）
7  迸发（后台流，向主槽投候选）
```

每一层都只加机制或只加事实，不加价值判断。

---

## 九、检验标准（防止又变成堆部件）

1. 每个想加的东西，必须能产出**可被记录并绑定到选择**的后果。
2. 每个机制判据必须是**事实或机械规则**，一旦是价值，就是越界。
3. 摘掉任何一件，看**环是否还闭**：唤醒 → 取 → 选择 → 世界 → 后果 → 存 → 沉淀 → 方向。
