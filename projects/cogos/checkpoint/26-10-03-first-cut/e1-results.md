## C1 / arm A（纯回喂）× 4 拍 — 2026-10-02

- **round 0**：**完整答对**，且正确排除诱饵 E1；解图 4 个节点全中。
- **round 1–3**：**无新增正确节点**；纯膨胀——展开因果链 → "可验证方向" → "缓解方向" → "排查清单" → "修复方案分层" → 重复同一结论。每拍结尾结论与 round 0 一致。
- **判定**：**天花板 case**（一拍照中）→ 不适合作 E1 样本，弃。

### 关键观察

1. 「无新信息 → 不动点」在**能力足够的模型 + 简单题**上，表现为**冗长膨胀而非沉默**。所以"推进"必须以**新增正确推理节点**计，不能以文本量计（否则会把膨胀误判成推进）。
2. 原始回喂下模型会**固守首答**、不断加壳，不自我推翻。这给"投影能否纠偏/推进"留了观测位——**但前提是 round 0 确实答错或答不全**。
3. 校准步必要：C1 这种题必须先被基准筛掉。

### 设计调整（待 YZ 确认）

- **用例厂改为"陷阱型"**：round 0 高概率**错**或**不全**（强诱饵 / 长依赖链 / 反直觉），给投影留增量空间。
- **加"纠偏"维度**：A 是否固守错答 vs C/D 是否被对齐纠正。
- 保留校准：以 A 为基准筛"多拍仍不推进"的题。

## 本轮结论（v2 陷阱用例）

1. 两个精设计陷阱在 tier=basic（deepseek-flash / temp0 / 1500tok）上**round 0 即解**，无一产生"错或不全"。
2. A vs C 无差异——但属**天花板导致的不可分辨**，既不支持也不推翻命题 #1。
3. **负向观察**：arm C 输出更长（T2：C 499 行 vs A 322 行）；投影提示诱发大量"逐条核验 / 再确认"式膨胀，C round 1 即触发 max_tokens 截断。→ 无增量时，投影不但不推进，还可能放大冗余。
4. **教训**：靠手写"陷阱"保证 round 0 出错未成功；该模型能力足以秒破。要观测投影增量，题目须落在**模型能力边界**上。
