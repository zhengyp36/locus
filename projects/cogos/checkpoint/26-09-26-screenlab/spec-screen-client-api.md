## 1. `[目标]` 本步用到的条文（引自 §5.1，编号一致）

1. 每 agent 有若干账户（归属单位），可 ssh 使用。
2. 账户有一块**可操作的图形界面**，发动作能读回结果（闭环）。
3. 操作要**像真人、不被检测**；可逐步实现，方向能加固。
4. 默认**不抢物理屏**；需要时人能看到、能介入。
5. 三种关系：自用 / 授权他 agent（显式可收回）/ 与人双向。
6. 一账户同一时刻一块界面；"要"是**幂等**的。
7. agent **只面对客户端**，不面对平台细节。

## 2. `[目标]` → 推导链（每条挂账）

- **D1** 动词集 = agent 的**唯一界面**；签名里不得出现平台细节。← 目标 7
- **D2** 要打开的东西**统一是"一台电脑"**；对 agent 而言"接入别人的机"与"用自己的账户"是**同一个动作**，只有**凭证来源不同**（长期身份 / 临时凭证）。← 目标 1 + 5a + 7（2026-09-22 YZ：接入 = 打开另一台电脑，那台是别人的）
- **D3** "一块界面 + 幂等" ⇒ **没有资源创生 / 销毁语义**，只有"要一块界面 / 不要它"。← 目标 6
- **D4** "操作 + 有反馈" ⇒ 动词必须成对：**操作** / **反馈**（反馈含"当下状态"与"画面"）。← 目标 2
- **D5** "像真人"是**默认行为**，不是 agent 的开关——暴露开关等于让 agent 面对细节，也等于允许它关掉目标前提。← 目标 3 + 7
- **D6** "不抢屏 + 人能看" ⇒ **"看"与"点亮物理屏"解耦**：看只是取走输出，不改变屏是否点亮。← 目标 4
- **D7** "授权显式、可收回" ⇒ 权限是**独立于身份**的动作；**观察口 = 只读的授权**，不需要另立动词。← 目标 5
- **D8** 授权对象可以是 agent 也可以是**人** ⇒ 动词不区分接收者类型，只认一个不透明标识；**凭证怎么送达由语言层负责**（故动词面没有"发现 / 连接他人"这一族）。← 目标 5 + 7
- **D9** "不面对细节" ⇒ 坐标、按键、文本合成方式都不进签名；agent 只表达**语义意图**（"点这里"、"输入这段字"）。← 目标 7
- **D10** 收回的最终裁决在服务端 ⇒ 动词面只需**权限可见**（谁在操作 / 我还有什么位）与**被收回时可感知**，不需要"抢占"动词。← 目标 5
- **D11** 操作是**基于某次观察**发出的 ⇒ 操作必须**绑定它所依据的那次反馈的世代**（否则"看着这帧、拿着上帧的点位去点"）。← 目标 2
- **D12** 物理屏的数量 / 排布是**平台细节** ⇒ agent 面对的是一块**逻辑屏**；多屏在服务端合成或选主屏。← 目标 7
- **D13** "要画面还是要结构"是**语义选择**，不是平台细节（目标 7 禁的是平台细节）⇒ 可以给 agent 显式通道，但**默认由服务端路由**。← 目标 2 + 7

## 3. `[方案·可换]` 动词表

| 动词 | 语义 | 关键入参 | 返回 | 挂账 |
|---|---|---|---|---|
| `open(target)` | 要一块界面；**幂等** | target | 界面描述（现状） | 目标 6/7（D2/D3） |
| `close(target)` | 不要它；幂等 | target | 无 | 目标 6（D3） |
| `state(target)` | 读当下状态 | target | 尺寸 / 输入者 / 我的权限位 / 世代 | 目标 2/5（D4/D10） |
| `capture(target, view?)` | 取反馈 | target + 视图（默认 `auto`） | 帧 / 结构 + 世代号 | 目标 2/4/7（D4/D6/D13） |
| `act(target, action, 世代)` | 注入操作 | target + 语义动作 + 依据的世代 | 受理结果 + 世代号 | 目标 2/3/7（D4/D5/D9/D11） |
| `yield(target)` | 让出输入，保留通道（输入交接的唯一手段） | target | 当下状态 | 目标 2/5（D4/D10） |
| `grant(target, receiver, bits, ttl)` | 发一份带位凭据 | target + 接收者 + 位 + 期限 | 凭据描述 | 目标 5（D7/D8） |
| `revoke(target, receiver)` | 收回 | target + 接收者 | 无 | 目标 5（D7/D10） |

- **`bits` 只有两位**：`看` / `操作`。观察口 = `grant(bits={看})`；**接收者不区分人与 agent**，`grant(bits={看,操作})` 对人同样有效（D8）。← 目标 5（D7）
- **target 只描述"哪台电脑"**：`{归属: 自己的 | 别人的, 标识}`；**凭证不属于 target**（见 §4·9）。**agent 不需要区分"自用"与"接入"**。← 目标 1/5a/7（D2）
- **没有 `display` 维度**：多屏是平台细节，agent 只面对一块**逻辑屏**（§4·13）。← 目标 7（D12）

### 已收口（原"备选/待裁决"）

- **不用会话句柄**：「每次带 target」优于「`open` 返回句柄」——目标 6 的幂等使"账户本身即是句柄"，断线重连不必保存句柄（更贴合目标 7）。← 2026-09-22 定

## 4. `[方案]` 语义细则

1. **幂等**：`open` 对同一 target 恒返回**同一块**界面的现状，不报错、不新开。← D3
2. **世代（单调号）**：`capture` / `act` 带世代号，客户端据此判断"是否变过"；服务端可对无变化的取帧返回"未变化"。← D4（省带宽 / 省算力；代价是客户端要处理"未变化"这一结果）
3. **权限在服务端判决**：每次调用都按**凭据的位**判，不足即拒（返回错误），不依赖客户端自律。← D7/D10
4. **被收回可感知**：操作被收回后，`act` 返回"权限已失效"，`state` 显示当前输入者。**起步不做推送**。← D10
5. **坐标基准归服务端**：`act` 的位置用**帧坐标或归一化坐标**，映射到平台由服务端 / 适配器做。← D9
6. **文本输入走合成**：`act` 的文本动作语义是"输入这段文字"，逐字合成与否是服务端默认行为。← D5
7. **不做反检参数**：动词面不出现任何"拟真度 / 延时 / 随机化"入参。← D5
8. **输出形态不外露**：动词面没有"点亮屏 / 关闭屏"，也没有"沉浸模式"之类；屏的亮灭是服务端事。← D6
9. **凭证最小集：语言给"应该"，机制给"只能"** ← 目标 5（D7/D10）
   - **语言层**负责社会契约：谁被允许、什么时候结束、现在归谁（"我授权你" / "结束了，我收回"）。
   - **机制层**只保证契约失效时的**安全下限**，三条：
     a. 凭证有**有效期**（授权方设）——兜底"忘了告知 / 对方已走开"；
     b. 可**吊销**；因**服务在目标机上**，吊销**本地立即生效**（不依赖通知到对方，故能立刻断掉接入者的操作）；
     c. 服务端**按位判权**，不依赖对方自律。
   - **不做**：心跳、协商、状态机、优先级抢夺协议。目标 5 的"可收回"由这三条即已满足。
   - **第一版形态**：凭证就是一串字符，**在对话里递**（零基础设施）。
10. **界面是资源、通道是接入** ← 目标 6 + 5
   - 界面：一账户一块，`open` 的**幂等作用在它身上**。
   - 通道：**可以多条**（owner / 被授权 agent / 观察者各一条），每条带自己的位；`revoke` 的对象是**通道**（及派生它的凭证），不是界面。
11. **传输不入方案** ← 纪律（防耦合，2026-09-22 YZ）
   - 方案只假定"**有一条能通的字节流**"；网络（同机 / 局域网 / 隧道 / tailscale / NAT）由外部提供，**不进目标也不进方案**。
   - 客户端依赖的东西因此只有一个：一个 endpoint 标识 + 一条能通的流。
12. **主人侧 = 服务 + 长期身份；客侧 = 客户端 + 临时凭证** ← 目标 1/5a
   - **谁拥有那台机，谁装服务、持长期身份**；接入方只用客户端 + 临时凭证。
   - 与服务在目标机一致（§4·9b）：吊销在本地生效。
   - 装配可能**由 agent 代劳**（例如经 ssh）⇒ 装配必须**可远程、无交互**完成。
13. **多屏 = 逻辑屏** ← 目标 7（D12）
   - agent 面对的永远是**一块**逻辑屏；多块物理屏在服务端**合成**（或按装配期设定选主屏）。
   - "有哪些物理屏"是**装配期能力探测**，不进 agent 的日常动词面。
14. **反馈视图默认 `auto`，保留显式** ← 目标 2 + 7（D13）
   - 默认由服务端按内容路由（能读结构就给结构，否则给画面）。
   - 保留显式选择当**保险**：auto 猜错（canvas / 验证码只有画面）时代价很高，而"要画面还是要结构"是语义选择、不违反目标 7。
    - **硬要求**：同一世代下，结构与画面**必须同源同帧**——否则点位与看到的画面会错位（配合 §4·2 世代与 §2·D11）。
15. **owner / guest 只是一个区别** ← 目标 5 + 7（D2/D8）
    - 一个账户 = 一个服务 = 一块界面（幂等）= **一个 owner + N 个 guest**。
    - **owner** = 传输已认证的本地身份（长期身份）；**guest** = `open` 时用凭证换出的通道（临时凭证）。判据就一个：通道有没有凭证来源。
    - 四种关系只是"谁持 owner"的排列：② A=owner / B=guest；③a 人=owner / agent=guest；③b 与"人介入 agent 机" agent=owner / 人=guest。
    - 由此派生的行为差别只有两处：owner 可在输入上抢占 guest（guest 对 guest 是**先占者持有**）；只有 owner 能 `grant` / `revoke`。
    - **人一律是 guest**：`{看}` = 观察，`{看,操作}` = 介入。人要介入而 owner（agent）正持输入时，由 owner **让位**（`yield`）；owner 恢复操作时**自动取回**（owner 抢占）。所以 ③b 与"人介入"是同一件事，只差 bit。
    - **机制外边角**：owner 不在（agent 卡死/无响应）时没人能发凭证——这不在机制内，由 OS 力量（停进程 / 关机 / 改密码）兜底。

- **无"抢占"动词**（服务端行为）。← D10
- **无反检开关**。← D5
- **无资源创生 / 销毁动词**（`open/close` 已覆盖）。← D3

- **无文件传输**（属另一能力面）。

## 6. 判据自检：三种关系只用这套动词表达

| 关系 | 序列 |
|---|---|
| ① 自用 | `open(账户)` → `state` → `capture` → `act` → 循环 → `close` |
| ② 授权他 agent | owner：`grant(账户, B, {看,操作}, ttl)` →（语言层送凭据）→ B：`open(端点, 凭据)` → `act` / `capture` → owner：`revoke(账户, B)` → B 下次 `act` 被拒 |
| ③b 人看 agent 机 | owner：`grant(账户, 人, {看}, ttl)` →（语言层送）→ 人：`open(端点, 凭据)` → `capture`（无 `act`） |
| 人介入 agent 机（③b + `{操作}`） | owner（agent）：`grant(账户, 人, {看,操作}, ttl)` →（语言层送）→ 人：`open(端点, 凭据)` → owner `yield` → 人 `act` → owner 下次 `act` 自动取回 |
| ③a agent 接入人的机 | 人：`grant(..., A, {看,操作})` →（语言层送）→ A：`open(端点, 凭据)` → `act` → 人 `revoke` 即夺回 |

结论：**所有场景只用 8 个动词**（`yield` 只在"人/客当 guest 且要介入"时需要），且没有为"共屏"另立概念。

### 8.3 由对照产生的新待裁决 → **已全部收口**

- 5. `open/close/grant/revoke`：**进 agent 面对的接口**（§7·5）。
- 6. 接入他人机的通用形态：**已消解**——就是"打开别人的一台电脑"，只剩"凭证怎么送达"（语言层）。
- 7. `paste`：**已删**（09-23 C4），见上。
- 8. `displays` 的表述：**不进 agent 面**，见 §4·13（§7·6）。
- 9. `act` 带反馈世代：**已补进 §2·D11**。

### 8.4 `paste` 的解法（讨论，供 YZ 参考）——**作废（09-23 C4）**

`paste` 已从协议删除；剪贴板改由命令面 `surface clip` 提供。以下原讨论仅存档。

要害不是"用了粘贴"，而是**文本凭空出现、不产生任何输入事件**。真实用户也会粘贴，所以解法可以是：
- **写成"写剪贴板 + 合成粘贴按键"**（产生真实的按键事件序列）→ 与真人无差别；
- 或**默认逐字合成**，仅在超长文本时降级为上述粘贴；
- 保留 `paste` 作为逃生门，但把它定为"痕迹档位"里的可调项（进加固清单）。
