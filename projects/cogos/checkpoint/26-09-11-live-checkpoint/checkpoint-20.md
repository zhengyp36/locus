# checkpoint-20 — 视觉理解范式："整体印象→局部展开→信息回填" + A/B 分层共识

接 handoff-2 / checkpoint-19。本次讨论由"图组织关系如何验证"切入，但被 YZ 纠正了讨论的层面的定位——不是解决"锁定目标"这个特定问题，而是**模型如何理解图**的范式。到收口时形成 A/B 分层共识，与人的视觉认知对应。

## 当前问题（一句话）

模型理解图时应采用"整体印象→局部展开(中央凹)→信息回填(不是图像回填)"的循环方式；其中"视觉暂存(A, 图像层)"与"信息回填(B, 记忆层)"**都要、不可缺一**。身份/定位稳定只是该范式顺带解决的结果，不是设计目的。

## 本次讨论要点（按对话顺序，含 YZ 纠正）

### 1. 我最初的命题被 YZ 纠正为偏窄

- 我起手把"图组织关系"定位成"两段式 coarse→fine 之间如何保持目标身份、防 crop 混入相似 decoy 被带走"(T1.6 崩的根因)。
- **YZ 不认可这个定窄**：目的不是为某单一问题设计机制，而是**让模型形成理解图的方式**：整体印象 + 局部展开 + 局部信息回填；身份问题只是该范式成立后才顺带被解决。

### 2. 人眼模型（YZ 提出的隐喻，含猜测成分）

- **整体印象**：起手不是高清全景，而是布局层感知——"那里有东西、在中央偏右、散着几块"，低精度不聚焦。
- **中央凹展开**：注意力移向某区域，局部获得清晰信息(此即"看清")。
- **回填是"信息"不是"图像"**：看清后不是把更清晰的图塞回整体，而是把"对这块的理解"作为一条**信息**回填进整体认知。高清图可能被丢弃/压缩，**理解被写入**。
- **循环**：整体骨架 + 各局部理解往复，形成"理解过的场景模型"(全局骨架 + 局部语义填充)，非一张静态图。

### 3. 这个范式下"身份稳定"顺带成立

不是靠"把全图和 crop 一起放面前让模型自己记得"，而是：一旦局部看清并理解成"那对纠缠矩形"，该理解就成了认知结构里的一个节点/锚；它是回填过的"信息"，所以换窗口看不会覆盖它——就像人记住了"那里是那对纠缠的矩形"，再看别处记忆不动。身份稳定是**因理解被记录而独立于当前焦点**。

### 4. A/B 分层共识（YZ 提出，我认可）

把回填分成两层，**都要、缺一不可**：

- **A 层 = 视觉暂存 / 图像层**（当前上下文）
  - 是"看清后"持有原始图像的地方。**价值不是被推理(那是 B 的活)，而是当裁判**：B 的信息若有疑，回到 A 核对。
  - 特征：**可靠但短暂、容量有限**。这就是"留在上下文、只保留少数几张"的原因；其余细节**留在"现实"(机制层图池原图)，模型持锚、按需重看**。
  - 所以 A 的"暂存"不只是上下文塞几张图，而是 **机制层图池(全量) + 上下文工作集(活跃少量) + 模型持锚(能重看)**。容量限制由"工作集"模拟，超出只留锚、细节回图池。
- **B 层 = 信息回填 / 记忆层**（语义层）
  - 局部看清得到的**理解/断言**沉淀为语义节点，写进记忆，**更持久**、跨上下文。
  - 即"场景建模"本身：整体骨架 + 各局部理解。

### 5. A/B 关系 = 校验回路，但可信度方向人和 LLM 相反（我补充，YZ 未反对）

- B = 薄语义快照：快、可推理、但有损、会漂。
- A = 厚原始图像：慢、不可推理、但可靠。
- 链路：**推理走 B，有疑回 A 核对；B 必须能指回 A 的源**(md5/region 链/handle)——即"它知道图像在哪、可重新看"。
- 修正点：**人和 LLM 的信任方向相反**。人是先有 A(暂存可靠)→沉淀出 B(记忆会重构歪)→天然对 B 警惕、回 A 校验。LLM 天然把 B 当权威(它自己生成的描述/锚最顺滑)，A 成陪衬——T1.6 崩即"自造 'range 旁' 不可靠锚"，把 B 放在 A 之上。
- → 落到模型，关键动作不是"要 A 也要 B"，而是**把权威强制放回 A**：B 只当"可被 A 校验的候选"，机制保证"有疑必回 A"。这是给模型注入它本没有(对人是本能)的校验习惯。

## 关键结论/决策

- **模型理解图的范式 = 整体印象 → 局部展开 → 信息(非图像)回填，循环成"场景模型"。** 不是为解决单一定位问题。
- **A(视觉暂存/图像层)与 B(信息回填/记忆层)都要，分层不可缺一**：
  - A 提供可靠校验源、容量有限、细节留现实可重看；
  - B 持久入记忆；
  - 中间由"锚/region 链"桥接，裁决权在 A 下的机制层比对。
- **信任方向：把权威放回 A**（B 永远是候选），这是 LLM 比人更需要强制注入的校验习惯。
- A(图组织)按此再定义 = "图像回填/视觉暂存"误区仍是 A 的一部分但只作校验源；B(签名)更接近"信息回填"。

## 与既有结论的关系

- 与 checkpoint-8(ImageTool/ImageObj 契约:原图层+印象层)、checkpoint-9(focus 机制)、checkpoint-12(信息隔离:主 LLM 只收结果包/关系树导航/模型不读坐标)呼应：A≈原图层+工作集，B≈印象层/记忆。
- handoff-2 的"图组织关系"需重新定位：不是给模型塞"全图+框+crop"去解决身份，而是**如何让模型构建"整体→局部→信息回填"的循环理解**；具体图像组织机制(框/region/工具)是服务该范式的工具。
