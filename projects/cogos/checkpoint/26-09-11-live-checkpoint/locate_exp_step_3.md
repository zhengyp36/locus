# locate_exp_step_3 — 对话式定位实验记录（Step 3：画框定位）

> 承接 `locate_exp.md`（方法转变 + 工具说明 + 素材）。本文件记录对话式定位实验的第三步：阅读全景 → 描述 → 画框 → 自评。一次试验（新鲜上下文）。

## 试验 1（2026-09-06）

### 阶段 1：读全景（pano_800.png，800×600）

输入图：`/tmp/kilo/vision/locate_exp/pano_800.png`（由 extract 从 detail.jpg 生成）。

我如实看到的：
- 背景渐变（顶部青 → 中部青绿 → 底部黄绿/黄），铺一层淡淡网格线，像网格画布。
- 散布大量黑色空心小矩形 / 盒子 + 紧邻文字标签。
- 读出高频词：`vision` `detail` `range` `12345` `width` `height` `draw` `rect` `scale` `focus` `Hello` `HELLO` `Python` `color` `value` `avatar` `write` `track` `flag` `local` `strength` `MAX` `256` `Code` `spaces` 等。

确定性自评：
- 高：整体结构（渐变 + 网格 + 空心矩形 + 文字标签）。
- 中：能读多个具体词，但分辨率低、字母糊，个别靠猜。
- 低：矩形精确数量 / 确切位置尺寸 / 哪个矩形配哪个标签，说不准。

### 阶段 2：聚焦"中心偏右两个纠缠矩形、一个近正方形"

被试问是否看见目标（中心略偏右、两矩形纠缠、其一近正方形）后，我的定位回答：

- 确实看到：中心略偏右、纵向中部，一对靠很近/似重叠的矩形，其一近正方形，旁边紧挨另一个略长的矩形。这对比周围孤立盒子更醒目。
- 估算定位（归一化 [0,1]）：中心约 **(0.59, 0.52)**；近方形框估算 **(0.56, 0.48, 0.09, 0.09)**（x,y,w,h）。
- 自评：能看到"两纠缠 + 一近正方形"= 高确定；精确坐标 = 印象级估算，中确定；怀疑真值在 (0.596,0.513) 附近，我的估计略偏左偏上；旁边似有 `range` 标签被罩入嫌疑。

### 阶段 3：画框（draw）

按自估坐标画框生成新图：

- 命令：`draw pano_800.png --out exp1_rect.png --rect 0.56,0.48,0.09,0.09 --max-dim 800`
- 产物：`/tmp/kilo/vision/locate_exp/exp1_rect.png`（800×600，框像素约 448,288,72,54）
- 结果（ok:true, scale 1.0, PNG）

### 阶段 4：对照画框后图自评

对照 exp1_rect.png：

- 红框**基本罩住目标对**（近方形框 + 相邻框在框内），位置中心偏右、方向对。
- **偏宽一点点**：框右缘/下缘略超出实际矩形，可能把右侧小元素（`range`）罩入边缘。属"略偏"而非"框错对象"。

对照旧实验真值 (0.596,0.513)：本框中心 ≈(0.605,0.525)，基本重合，仅略偏左偏上约 10px 内——优于 V1 实验结果（V1 多次错到 x≈0.455 的左侧 range）。

## 结论（本试验）

- 对话式路径下，**单次任务内的"全图印象 → 粗定位"这一跳成功**：落在目标区域，未像 V1 那样撒网错到左侧 range。信息量与 V1 相同（都是 pano_800），差异在于本次不要求"扫全图枚举"，先行给了"中心偏右"锚点。
- 自评与真值几乎一致，但仍有"偏宽 + 罩入邻近标签"的小误差，且是**主观印象级坐标**，非像素准。
