# checkpoint-12 — ImageTool 定位与交互：信息隔离（讨论收敛）

本会话（vision 视角续，checkpoint-4 之后）从"看图过程"往下推 ImageTool 定位与主 LLM 交互。关键澄清：**ImageTool 帮看图 = 信息隔离**。接 checkpoint-2/8/9/11。

## 当前问题

ImageTool 到底提供什么、主 LLM 如何看图交互；坐标如何组织（防嵌套复杂性）；省 token 与认知自然性如何调和。

## 关键结论 / 决策

### 1. ImageTool 帮看图 = 信息隔离（根本定位，YZ 澄清）

- **不是主 LLM 无视觉输入**（主 LLM **从来看就有**），而是隔离"定位/看图过程"的复杂度，让主 LLM 专注推理。
- 主 LLM 只发**语义意图**；ImageTool 封装定位过程（裁剪/迭代/凑近/换成清晰图）；返回**结果**。
- 契合"主 LLM 只有意图一个工具"：单意图进 → ImageTool 定位 → 结果包（图+摘要）出。

### 2. ImageTool 提供的依据（除图本身 + 描述性摘要）

主 LLM 拿到的结果包自带这些依据（机制层可判、不含语义）：

- **可辨识余量**：还能不能更清晰 / 已到可辨识档 / 到清晰上限或过度缩水边界 → 决定要不要再凑近。
- **信息量/易错信号**：相似多+差异微程度（密度/结构/目标数粗信号）→ 决定要不要拆目标、要不要复核。
- **视野锚/位置**（相对全图）：当前视图在全图的位置/范围 → 决定往哪换、回不回全景、开不开新图。
- **砍掉**：成本（token/时间，不放 ImageTool）；内存/预算余量（太复杂，机制层内部即可）；状态上限（是机制层自己硬停，不是给主 LLM 的依据）。

### 3. 易错 = 目的，信息量只是来源之一（接 checkpoint-11）

- 易错来源四条：看不清(技术→crop 救)/判别难(信息量→降相似+复核)/定位偏(locate 校准)/理解错(语义幻觉→复核哨兵)。
- 信息量判断：LLM 能粗感、不能精确、系统性低估相似密集图 → 不能当标尺，只作方向信号。

### 4. 坐标参考系：统一基于全图，不嵌套（YZ 主张）

- 反对"基于坐标的换算链"（机械、易错、复杂）；保留"嵌套事实"但用关系表达。
- **存储/关系用全图坐标**（扁平、单一，目标关系可直读）；主 LLM 报"当前视野"局部坐标（避 VLM 漂移）；机制层做"当前视野↔全图"单步映射，无链无嵌套。
- 目标 = 全图坐标 + 范围 + region 图；目标间关系直接比较。

### 5. 关系树（YZ 更进一步：主 LLM 不看坐标，用关系导航）

- 用"关系叙事"而非坐标呈现给主 LLM：A(全图)→视野B(A 圈出一块)→子图1=C→视野D→子图2=E。
- **内容图**（A/C/E）= 认知节点（md5/印象/旁注/子图 children）；**视野**(B/D)= 过渡视图。
- 主 LLM 用关系导航，不读数值坐标；坐标只活在机制层（操作），关系是给主 LLM 的语言层表示——**同一结构的两种面孔**（操作层=坐标，语言层=关系）。

### 6. 图 + 摘要同现（一体结果包）

- 不为省 token 设"先看摘要探路、再决定要不要图"——选图/定位已隔离在 ImageTool，主 LLM 拿到那一刻就是**图+摘要一体结果**。
- 图 token 已封顶（几百，不贵）；省 token 靠**对象缓存**（同图重看不重喂）+ **印象轻量**（后续引用走摘要/印象），不靠"摘要探路"。
- 三态交互：首见→图+摘要同现；后续引用同视图→轻量摘要/印象；确需更多细节→再发意图（更近/换块），ImageTool 再定位一轮。

### 7. focus 大小（vision 直觉）

- focus = 以目标为中心 crop 一个 region，"目标占有效像素达标（下限）"硬约束下尽量大（多带上下文），被可靠性预算（token/内存/过度缩放）压住上界，机制层程序权衡，不固定填满。

## 历史修正

- 早前把"先摘要后图"说成"旧模型残留（主 LLM 无视觉）"**归因错误**，已纠正：主 LLM 从来看，信息隔离才是原因。

## 遗留 / 未定

- **关系树 vs 全图坐标**的最终呈现形态：交互用"当前视野局部坐标 + 存储全图坐标"（机制层桥接，折中）vs "主 LLM 完全不读坐标、只给关系叙事"——YZ 倾向后者，未最终拍板。
- ImageObj 内部如何组织裁剪树/关系、印象/旁注挂载——实现时定。
- 子图节点的复用性（信息组织=图非树，对象可复用 vs 裁剪天然树状包含）——实现时与否。
- 机制层粗信号算子、易错与复核触发权重——同 checkpoint-11，实现时定。
