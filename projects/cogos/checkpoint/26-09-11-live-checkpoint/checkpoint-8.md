# checkpoint-8 — ImageTool / ImageObj 契约（视觉功能讨论延伸）

本文件记录 ImageTool 职责边界 + ImageObj 数据结构 + 原图/印象分层的契约设计，接 checkpoint-6（意图）、checkpoint-7（对象化）。

## 当前问题

ImageTool 究竟提供什么功能（帮主 LLM 看图还是只定位）；ImageObj 承载哪些信息（摘要/旁注/印象）；图失效如何分层；全景/焦点/子图的关系。

## 关键结论 / 决策

### 1. ImageTool 职责边界：只定位/提供能看清的图，理解归主 LLM

- **重构 look_at**："帮主 LLM 看图" → "主 LLM 自己看 + ImageTool 只提供定位原语"。主 LLM 有视觉输入（前提，待确认）。
- "只定位" ≠ "无 LLM"：定位内部仍是 locate 判断（画线/凑近/坐标）。**边界 = 输出确定性结果（坐标/裁剪图）vs 理解结论（归主 LLM）**。分工是"确定性 vs 理解性"，非"无 LLM vs 有 LLM"。
- 循环：**主 LLM 驱动渐进看清**（要看清 X → 定位裁剪 → 主 LLM 看 → 再决定下一步看哪）。ImageTool 被动响应定位，主动权在主 LLM。
- 多图对比：主 LLM 先后打开两张图（两 ImageObj）自己对比；ImageTool **不需并行处理多图**，复杂度不收进工具。
- 代价与缓解：主 LLM 自己看 token 更贵；靠对象缓存（ImageObj）减轻（重复看不重复喂全量）。

### 2. ImageTool 统一输出 = 视图 →（图，描述性摘要）

- 两种场景统一成**一个机制**：打开全景视图 / 看细节局部视图，都是"当前视图 →（该视图的图 + 关于该视图的描述性摘要）"。
- **摘要性质 = 描述性**：描述当前视图可见内容（"街景，有楼房行人"；局部"模糊笔画"），**非判断性**（不回答主 LLM 的问题、不总结整图）。识别/理解归主 LLM。
- "看过就给信息"：零边际成本（定位那步 LLM 本来看了区域，顺带描述）；主 LLM 可能借此不拉图。
- **摘要锚定当前视图**，可被主 LLM 拉图核对，**不符以图为准**（主 LLM 审视摘要，不轻信）。
- 契约：摘要 = 对当前视图描述；理解/认定归主 LLM。

### 3. ImageObj = 多来源注释容器（从"图资源"升级为"认知节点"）

- 图上积累两类信息，**带来源标签**、可信度分明：
  - ImageTool 摘要（机制侧，定位描述）
  - 主 LLM 旁注（主体侧，看清后的洞察）
  -（另有定位历史）
- 主 LLM 看图后可产生"**加旁注**"意图写对象——主 LLM 洞察持久化到对象，下次引用不重看。
- 旁注 = **高价值锚的持久化**；随记忆/价值整理；随图内容变化（md5 变）**失效、交主 LLM 重评**（别拿旧图结论理解新图）。
- 旁注结构：第一版纯文本；"旁注 + 关联区域"（锚定某 region）为增强，后置。
- ImageObj 从"图资源"→"**认知节点**"（图 + 多方注释、带来源、可累积、可整理、随内容变化失效）；**呼应封存认知图**（非预先设计、从 cu 痛点长出），值得回看那个设计。

### 4. 原图层 / 印象层（失效分层）

- 对象 = **原图引用**（真实源/数据层，有 md5）+ **对象内视图**（印象/认知层，见第 6 节：全局锚 + 焦点 crop）。
- 人脑类比：真实存在看不见了，记忆中那张"那地方的样子"还在——记忆不完全依赖源头，**印象相对独立**。
- **两层失效语义不同**：
  - 原图失效（md5 变）= 源变，印象标"可能过时"，**不立即删**，交主 LLM 决定（信旧印象继续？/ 重看新图）。
  - 印象失效 = 主 LLM 重看替代 / 按价值遗忘；**独立于源**。
- **访问模式：印象优先，核实才回源**：要用图 → 先用对象内印象（快）→ 信且源未变，直接用；要重新确认现实（源变/要更清晰/印象被动摇）→ 回原图 reload（校验 md5）。
- **印象带版本标记**（对应原图 md5/version）作为"印象优先"的安全性前提（否则拿旧印象当现实，踩陈旧污染）。

### 5. 对象内图落盘形态 = LLM 上下文形式的数据

- 印象落盘，存的是**已转换好、模型可直接消费的"LLM 上下文数据"**，**不是原图文件**。
- 它是"重载恢复状态快照、非重头打开"的**精确定义**：重载印象 = 直接塞回存好的上下文数据，**不走重算**（img-tool info/extract/缩放）。
- 一致性更彻底：印象以独立上下文数据形态存 → md5 只影响"是否对得上现实"，不影响它作为记忆存在。源变只标"可能过时"。
- 成本：图 token 按分辨率算量，落盘占空间；**随价值整理**（保留高价值视图印象、压掉无关），印象是对象内可整理的认知资产。

### 6. 全景锚 + 焦点 crop（两级模型，取代"外围视野"；无图分类，统一逻辑）

- **两级，非三级**：
  - **全局锚**：整图缩略/全景印象（糊），只提供位置感/全局/大小，**从不要求看清**。
  - **焦点 crop**：原生高清，按需看清主 LLM 关心的区域。
- **不需要独立"外围视野"层**：foveated 要的两样——"我在哪 + 看得清"——用两级就够（锚给位置/上下文，焦点给清晰）。"外围取多大"的问题随之消失。
- **无图分类，统一逻辑**：不按"图大图小/清不清楚"分支。因为"看清"只落在焦点 crop（按需、看不出问题），锚从不要求看清（无论图多大都可用，只是上下文信息量随大图渐减，属渐进变化非分支）。
- **子图 = 按需固化，非图结构属性**：
  - 看清某块是 crop 动作（临时视图，看完即弃），**不需要"子图"概念**。
  - 只有当该视图**值得被记住/复用/加旁注**（对象化判据：跨调用共享/记忆价值）时才固化成子图对象挂 `children`。
  - 默认不留、想看即 crop；**固化决定权在主 LLM**。
- 与第 4 节咬合：**锚 = 稳定的全局印象（不变）；焦点/子图 = 动态视图**（用完即弃，或值得才固化）；印象带版本标记、随价值整理。
