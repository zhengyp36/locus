## 意图方案（checkpoint-6，独立内容）

- 意图 = 工具集标签（枚举）+ 自然语言内容；主 LLM 只面对一个意图工具，走厂商 function calling（控制流可靠）。
- 意图结果 = 对象（图/文件/terminal 有身份可复用；搜索为值非对象）。对象 id 可弃、**意图 id（机制层）必留**（异步锚 + 边缘主键）。
- 消息合并 = 意图+结果一条，过程边缘化；保弱意图标签；内部迭代态封装进 cog-func 不合并。
- 结构下沉工具集校验层（存在性/覆盖/权限/歧义拒答，宁可拒绝不瞎猜），主 LLM 意图自由但破坏性语义显式。
- 同步/异步 = 工具集契约属性（默认阻塞/非阻塞），主 LLM 可盖过；异步靠意图 id 落点。
- 边缘信息跟主 LLM 经历走：程序低频写时间线锚 + 主 LLM 周期压缩折叠；在主上下文降注意力存在（可折叠薄锚 + 脚注外置）。
- 开放：多意图/并行未覆盖（待深化）。

## 对象化 + 生命周期 / 记忆遗忘（checkpoint-7，独立内容）

- 对象化 = 函数式轻对象（非 OOP 重对象）；判据 = 状态是否①跨调用共享②有记忆/缓存价值③行为绑定状态。一次性无状态流程保持纯函数，不对象化。
- 对象谱系：IntentObj（值对象）/ ImageObj（轻对象，可变状态+行为）/ agent（cog-actor）。好处集中 = 记忆缓存 + 状态生命周期清晰 + 工具隔离可复用。
- 边缘信息跟主 LLM 经历走（IntentObj 串）、资源状态跟对象走（ImageObj 缓存），经引用链接（统一"跟对象走/跟主 LLM 走"）。
- 信息组织 = **图（非树）**（对象可复用）；未来清理走可达性/引用计数。
- 遗忘机制 = 主动、带价值评估的持续精简（非被动回收）。信息层薄化 + 对象层回收，经价值锚串联；价值评估归语义层（主 LLM），机制层提供框架。
- 对象三级寿命：驻留/淘汰可重载/回收。两个正交信号：淘汰=时间（LRU，机制层）、遗忘=价值（主 LLM）。工作集上限可配置。
- 一致性：淘汰 = 状态落盘迁移，重载恢复状态快照（非重头打开）；保存双语义（显式即时 flush + 淘汰兜底 flush）；md5 指纹 + 访问/重载时校验，变了=失效信号交主 LLM 决定（重看/重读）。
- 对象分类：可写对象（文件，flush+md5）/ 只读对象（图，无 flush，只失效重看）。

## ImageTool / ImageObj 契约（checkpoint-8）

- ImageTool 只定位/提供能看清的图，理解归主 LLM（重构 look_at；前提 = 主 LLM 有视觉输入，待确认）。边界 = 输出确定性结果（坐标/裁剪图）vs 理解结论。循环 = 主 LLM 驱动渐进看清，主动权在主 LLM。多图 = 主 LLM 先后看图自己对比。
- 统一输出 = 视图 →（图，描述性摘要）。摘要 = 对当前视图描述（描述性非判断性、锚定当前视图、可被主 LLM 以图为准审视），理解/认定归主 LLM。
- ImageObj = 多来源注释容器（ImageTool 摘要 [机制侧] / 主 LLM 旁注 [主体侧]，带来源标签）。主 LLM 可"加旁注"意图写对象 = 高价值锚持久化；随记忆整理、随 md5 变失效交主 LLM 重评。旁注第一版纯文本，"关联区域"增强后置。
- 原图层/印象层：对象 = 原图引用（真实源，md5）+ 对象内视图（印象，认知层）。原图失效=源变（印象标可能过时，不立即删）；印象失效=重看替代/按价值遗忘，独立于源。访问 = 印象优先，核实才回源；印象带版本标记。
- 对象内图落盘 = "LLM 上下文形式的数据"（已转换、可直接消费），非原图文件；重载即恢复不走重算；源变只标可能过时。成本按分辨率算量、随价值整理。

## ImageTool 动作集 + focus 定位机制（checkpoint-9）
- 动作集 = **open**（建对象 + 全局锚恒在 + 首视野 + 摘要）+ **focus**（换视野：移动[center]/近看[range 缩小，crop 提分辨率]/远看[range 放大]，归一于 crop(region)）。主 LLM 给语义方向、不报坐标/倍数。
- 全局锚 = 恒定参照，非独立工具；"恒在"= 存在于对象可随时取用（薄锚、按需拉取），非独立 context 工具、非常驻主上下文。**关闭不设**（那是生命周期层的事）。
- focus 精度：程序判"技术清晰度"（分辨率/有效像素/预算/收益上限，启发式），LLM 判"内容是否达成"（语义）。看清不能靠 LLM 自判（VLM 无感）→ 机制用技术基线兜底。
- "何时停"本质模糊 → 用"区间（可接受清晰窗口）+ 硬边界（清晰上限/轮数顶/重试超限）+ 偏向（宁可充分、准确优先）+ 冲突走放弃（能力不足→第一人称转述）"容纳。最终停权在主 LLM，机制层保技术范围 + 强制上限。
- "语言→坐标"分工：主 LLM 是符号推理体，无人类"非语言精确直觉"，意图天然可表达、无"难以言说沟"；翻译（语言→坐标）是定位机制在图上迭代的职责，语言歧义由定位循环吸收。
- "发现异常→想看清水"是典型场景：基于内容的语义兴趣 → 语言给"方向+内容"锚点 → 定位机制落坐标（仍无沟）。边界：异常在糊全景不可见 → 属"如何发现异常"的机制层问题（扫描/候选），后置。
- 贯穿原则：**主 LLM 给语义，机制层补精确；只提供机制，剩余靠主 LLM 与 ImageTool 配合**（看→聚焦→看→换方向）。

## 易错：来源分类 + 方向信号（checkpoint-11，本轮新增）

- **易错是目的，信息量只是来源之一**。易错 = 聚合方向（是否易错→措施），非单一可算量。
- 易错来源分类（各有应对）：看不清→crop（机制层）；判别难（信息量：相似多差异微）→降相似数+复核；定位偏→locate 校准；理解错（语义幻觉）→复核哨兵。
- 清晰度≠信息量：清晰度=像素层面 crop 救；信息量=判别难度。
- LLM 判断信息量：能粗感觉，不能精确（无客观分界、依赖任务），且**系统性低估相似密集图**（相似性合并/模板化，把难当简单）→ 不能当标尺。
- 定位：方向信号（非分数、非精确）指示"该谨慎了吗、该用哪招"；机制层可判的下沉粗信号兜底、语义层判的给把握度。
