# checkpoint-11 — "易错"：来源分类 + 方向信号（讨论收敛）

接 checkpoint-9/10。从"LLM 能否判断信息量"出发，最终收敛到一个更准的定位：**易错是目的，信息量只是易错来源之一**。此前我把"易错"窄化成"信息量信号"，是手段当目的，已修正。

## 当前问题

看这张图/这块内容，容不容易错；若易错，采取什么措施。"信息量"是易错来源之一但非唯一。

## 关键结论 / 决策

### 0. "易错"是目的，"信息量"只是来源之一

- 易错 = 目的/倾向（判断是否容易犯错 → 措施），是一个**聚合方向，不是单一可算量**。
- 信息量（判别难度）只是易错的**来源之一**，不是全部。

### 1. 易错来源分类（各有应对，大多机制层可兜）

| 来源 | 本质 | 应对 | 谁判 |
|---|---|---|---|
| 看不清（技术清晰度） | 封顶压缩/分辨率不足 | focus/crop | 机制层 |
| 判别难（信息量） | 相似多+差异微 | 降相似数 + 复核 | 机制粗信号 + 语义 |
| 定位偏 | 坐标漂移/找错地 | locate 校准 | 机制层 |
| 理解错（语义幻觉/歧义/干扰） | 读对像素、想法错 | 复核哨兵 | 语义（复核） |

- 清晰度 ≠ 信息量：清晰度=像素层面（crop 救）；**信息量=判别难度**。一张高清图信息量可极小（几行字），普通图可极大（密密麻麻/相似格子带点）。

### 2. LLM 判断信息量：能感觉、不能精确、会系统性低估

- 能：基于已进上下文的内容做**相对粗感觉**（"这图内容很密/很杂" vs "很简单"），方向基本对。
- 不能：①精确量化——信息量依赖任务/目标，无独立于目标的客观量，**无绝对分界**，只能给"高/中/低 + 把握度"；②**系统性低估"相似密集"图**——内部表示做相似性合并/模板化（把"很多相似格子"折叠成"几个格子"），而真正易错的细微差异恰藏在被模板化处 → 把"难"误判成"简单一瞥"。
- 结论：**不能当精确标尺**，只能当参考。

### 3. 定位：方向信号而非分数（非精确、无分界）

- 目标不是"信息量分数"，而是说明"**看这张图/这块内容是否容易错**"的方向——指示"该谨慎了吗、该用哪招"。
- 不要求精确、无分界；落地靠各来源既有应对（上表），信息量只是其中一支。
- **易错来源的分工**：机制层可判的（清晰度/密度/定位）下沉为粗信号兜底；语义层才能判的（相似性/语义理解）由 LLM 给把握度。
