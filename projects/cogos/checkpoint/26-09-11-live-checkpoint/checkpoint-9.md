# checkpoint-9 — ImageTool 动作集 + focus 定位机制（ImageTool 讨论继续）

本文件记录 ImageTool 功能接口 + focus 换视野机制，接 checkpoint-8（ImageTool/ImageObj 契约）。记录后 YZ 将 /undo 释放上下文，重读本文件 + status 恢复。

## 当前问题

ImageTool 提供哪些功能（open/focus…）；focus 换视野精确到什么程度、何处停；主 LLM 语言意图与坐标之间的分工。

## 关键结论 / 决策

### 1. ImageTool 动作集

- **open**：建立 ImageObj，全局锚恒在 + 首个视野 + 摘要。
- **focus（核心）**：换视野到某 region，给"该 region 高清图 + 描述摘要"。移动/近看/远看**归一于一个 crop(region)**：
  - 移动 = center 变；近看 = range 缩小（crop 提高有效分辨率，非放大）；远看 = range 放大。
  - 主 LLM 给语义方向（"看左边那栋楼/近一点/移到右侧"），**不必报坐标、不用管倍数**。
- **取子图**（后续确认，见 checkpoint-10 追加）：把某 region **固化为可复用/可加旁注的子图对象**（挂 children）。本质差别于 focus = **固化**：focus 是临时视野（看完即弃），取子图是值得记住的独立单元。判据 = 对象化（跨轮共享 + 记忆价值 + 行为绑定）。
  - 两个消费者：**主 LLM**（固化场景——复用/加旁注/当独立单元/隔离干扰专注；只是看一眼则 focus）+ **复核方**（第三方定位"结论来源的位置"后调用，非主 LLM 主动想起，见 checkpoint-10）。
- **全局锚 = 恒定参照/背景，非独立工具**。"恒在" = 存在于对象、可随时取用，**非常驻主上下文**（薄锚，按需拉取，低注意力背景）。
- **context/看全局 不设独立工具**——全局视野就在那，主 LLM 真正操作的只是"换焦点视野"。
- **关闭：不设**。看图是主 LLM 主动聚焦，"不看了"自然停；关闭是资源/生命周期层的事（对象淘汰/回收），非主 LLM 动作。

### 2. focus 精度：程序判"技术清晰度"，LLM 判"内容"

- **两种"看清"要分清**：
  - 客观清晰度（分辨率/有效像素/预算）——**程序可判**，纯信号层面，与内容无关。
  - 内容看清（"那个字是什么/物体是不是目标"）——**程序判不了**，需语义识别，归 LLM。
- **程序判"技术边界/基线"**：focus 收益上限（再缩有损/超预算）、可辨识档（目标占有效像素达标）、预算。**启发式**，非绝对。
- **LLM 判"内容是否达成 / 方向对否"**。

### 3. "何时停"——本质模糊，但可机制化容纳

- 停本质模糊（语义/主观），**别找精确点**；用"区间 + 边界 + 偏向"容纳：
  - **机制层硬停**：命中清晰度上限 / 迭代轮数顶 / 格式参数重试超限 → 硬停或放弃。
  - **LLM 软停**：内容达成（"看到了"→停；"还不够/换方向"→继续）。
  - **冲突 = 放弃出口**：机制层已到顶、LLM 仍说不够 → 能力不足 → 第一人称转述。
- **偏向：宁可充分、准确优先**——失败模式不对称（看不清=坏、多花 token=轻）。机制层默认保"可辨识档之上"，主 LLM 觉得还需更近才继续。
- **最终停权在主 LLM（语义）**，机制层保证"技术范围 + 强制上限"，**防 LLM 自欺**——因为 VLM 对"看不清"无感，机制用客观技术基线兜底（不能靠"我觉得看清了"停）。

### 4. "语言→坐标"分工 ＋ 无"难以言说"的沟

- 主 LLM 是**符号推理体**，没有人类那种"非语言的连续视觉直觉"（人眼能下意识定位到某点、无法言说坐标——那是生理层）。主 LLM 的"想看什么"本身就是语言/符号，**天然可表达**，不会产生"想说清但说不清"的精确想法。
- **真正的翻译（语言目标→精确坐标）是定位机制（locate/focus）在图上迭代的职责**，主 LLM 不需也不可能替代。语言歧义（哪栋/哪边）由定位循环吸收（试/看/校准）。
- **"发现异常→想看清水"是真实典型场景**：基于内容的语义兴趣（"左上角那个红红的东西"）→ 语言给出"方向 + 内容"锚点 → 定位机制落成坐标。仍无沟。（区分：LLM 的"在哪"是粗粒度语义区域感知，非精确坐标——但足够定位机制解析。）
- **边界**：异常在糊全景里不可见（细节被 token 封顶丢）→ LLM 发现不了 → 属"**如何发现异常**"的机制层问题（缩略扫/候选区域/图像差分），另一层，后置。

### 5. 贯穿原则

- **主 LLM 给语义（意图/方向），机制层补精确（坐标/清晰度/停）**。
- **只提供机制**，剩余配合留给主 LLM 与 ImageTool 的迭代（"看 → 聚焦 → 看 → 换方向"）。
