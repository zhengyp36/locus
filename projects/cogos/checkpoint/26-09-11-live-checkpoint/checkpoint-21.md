**世界观偏差提醒**：`vision-system-design.md` 按旧"网格 4×4 + 报离散格"打造；第 4 轮已作废网格、转向"center/radius/focal + 报连续坐标"，底层需按新世界观重新参数化而非直接可用。

## 二、顺序 / 时间 / 因果 —— 功能等价定调（YZ 推进）

### 我早前的绝对化说法（被纠正）

- 我断言：上下文"顺序"只有两层——机械位置信息 + 语序→叙事时序；模型没有时间轴，先后≠因果（相关性非因果），且会做 post hoc 式叙事性因果推断。此结论是**真值/等价器层面**的。

### YZ 功能等价纠正（成立）

- 从**功能等价**看，人的思维/语言本身就是**线性序列**；因果不是"被记录的外在对象"，而是人把序列**解释成"前因后果"**时构建出的**叙事约定**。人如此，agent 也如此 → 两者同构。
- 所以"用上下文顺序承载时间与因果"对人是事实、对 agent 是**等价结构**。**功能维度上，顺序就是时间+因果的载体**，"不等"只在外部真值层面成立。
- agent 应当、也可以按顺序去**理解**——这就是它的"因果感"来源。

### 落点（与方法论同型）

- 既然因果是**解释**出来的，第 4 轮"会看不会收口/看错方向"就**不是"模型违背客观因果"，而是它的因果解释 vs 任务需要的因果解释没对齐**。
- 与两条既有重构同型：把"模型自报不可靠"重化为"没工具被迫单遍的后果"；把误差重化为"注视=检验的内生反馈"。都是把**缺陷 → 解释/语境错位**，而非本质错误。

## 三、语言精确性 / 英文提示词（话题 2，YZ 续问）

上游问"语言在描述准确性上有没有差异、英文是否更精确、提示词用英文是否更少歧义"。从功能等价承接上文，落点仍是**叙事约定 vs 真值**的区分。

### 语言精确性的两维（优先拆开）

- **表达分辨率**（关系说得清、指代不混淆）：英文更高——靠**显式形式化标记**：关系代词（that/which/whose）、从句引导词、时态体貌、定冠词（the 定指性）、介词。所以多对象"谁指谁/依赖哪个/哪个候选是哪个"这类**关系/指代/嵌套**，英文默认歧义少，也更容易被 attention 还原成结构。
- **判断正确性**（说的关系对不对）：与语言无关。从句只是把关系**叫什么**说清楚，**不承诺关系成立**。

### 关键反直觉：效果来自"写法"，不来自"语言"

- **英文是"免费帮你显式化"**：语法逼你写清标记，所以关系密度高时**默认收益**。
- **中文需"主动"显式化**：中文默认意合；但只要你主动把回指写死（"那个【X】，我们刚才看过的那个"），中英差距会大幅抹平。英语优势=默认迫使显式化，非这门语言"更准"。
- **"代码引用"类比限度**：代码强在括号/类型/命名引用这套**形式系统**；从句只是"弱形式化的关系标记"，给结构感但不保证真值/因果。把"从句=代码=逻辑严密"当推理强，是**表面形式感误当推理强度**（formality illusion / 似逻辑感）。

### 模型侧：不"适应语言"，适配文本分布

- 显式标记多的语言（英文）→ **可解析性更高**，更易被建模成结构；不是"更聪明"，是"更易对齐建模偏好"。
- 意合语言（中文）→ **单轮信息密度更高**，但复杂回指/嵌套缺显式标记时**歧义增加**。

### 实操落点（提示词）

- **英文会"更少歧义"，但那只在其默认显式化之时**；中文加显式化可得相近效果。
- **真正比语言大得多的歧义源头**（别指望英文治好）：① 任务规格没钉死（目标定义/坐标参考系/输出形态）② 符号/编号/地址不一致。
- **"该收口了"属机制/因果对齐层（话题 1），非语言问题，英文救不了。** 切忌盲测英文治它。
- **可落地 A/B（避免"用词差异"混杂）**：不要整个 prompt 盲切换英文；把**关系性最强**的几句（指代候选/依赖链/"上一轮看出是哪块"）改成英文显式标记，其余留在中文，或仍用中文但刻意写成"加显式回指"。测的是"显式化"本身，非"语言"。



- **产品化 vs 快实是两条路**：机制载体（能看/能裁/能路由图）牢；但"镜筒参数化 + 出参换算 + 收图续轮 + 接 ToolRegistry"尚未落到 cogos 工具层——现在能跑的是**探针**，不是**产品化视觉工具**。
- **清晰档语义先拍板**：放大（探针做法）vs 缩 range 取原生像素（img-tool 世界观"永不放大"），二者冲突，属方法上要先定的一条。
- **功能等价定论**：顺序→时间→因果是人对世界的**叙事约定**；功能等价地它就是 agent 该有的理解方式，不是缺陷。问题只在于让它**生成的因果解释对齐到"任务意义的因果"**。
- **语言精度定论**：英文更优在**表达分辨率/关系显式度**（默认显式化标记），不在**判断正确性**；效果来自"把关系写显式"这一写法，中文加显式化可得相近。真正歧义大头是**任务规格/坐标系/符号不一致**，非语言；"收口"属因果对齐层，英文救不了。
