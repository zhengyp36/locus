# checkpoint-16 — 视觉引擎实现思路：三接口功能明确（实现讨论记录）

接 checkpoint-15（看=open/focus/isolate、写=annotate/seal、意图=任务·子任务划分）。本文件专门记录本阶段的实现思路推进（原语接口明确），持续追加，不再逐轮新建。

## 当前问题

明确视觉引擎（视图引擎，看维度）三接口 `open` / `focus` / `isolate` 的功能：目的、输入、内部流程、输出、依赖、边界、失败语义。

## 三接口功能

### open（看整图）

- **目的**：看一张图，建 ImageObj 根。
- **输入**：图源（文件/URL/id）+ 意图指向整图（自然语言，如"看看这张图"）。
- **内部流程**：img_tool `info`（全图尺寸/分辨率）→ 建根（全局锚=全景薄锚 + 首视野=全图）→ 自动摘要（描述整图）。
- **输出**：ImageObj（含对象 id）+ 结果包（全景图 + 摘要 + 依据信号）。
- **依赖**：img_tool info + 摘要 cu。
- **边界**：唯一入口（无对象时）；锚从不要求看清（checkpoint-8：锚只给位置/大小/全局，看清落 focus/isolate）。
- **失败**：图源无效/打不开 → 错误返回，交主 LLM。

### focus（换视野/变清晰）

- **目的**：换视野看清某处（center/range 正交，移动+近看+远看归一；不分 pan/zoom，checkpoint-15 §2）。
- **输入**：语义方向（自然语言，如"看左边那栋楼 / 近一点 / 移到右侧"）+ 当前对象/当前视野。
- **内部流程**：locate（内部 LLM：语义方向 → 全图 region center+range，可迭代试/看/校准）→ img_tool `extract` crop(center, range) → 自动摘要（描述新视图）→ 更新当前视野/图链。
- **输出**：子视图图 + 摘要 + 依据信号（含可辨识余量：还能不能更清晰/已到档/到上限）。
- **依赖**：locate + img_tool extract + 摘要 cu。
- **边界**：图像通道 = 保留**目标 + 周边图**（目标占有效像素达标下尽量大，多带周边图作位置/上下文感，checkpoint-12 §7）；文字通道 = 带摘要。停权在 LLM（内容达成），机制层保技术范围+强制上限（checkpoint-9）。
- **失败/降级**：技术清晰度到顶/轮数顶/重试超限 → 硬停或放弃（能力不足 → 第一人称转述）；方向/目标模糊 → locate 迭代，或转主 LLM 澄清。

### isolate（剥离目标/去干扰）

- **目的**：把目标从背景剥离、排除干扰，只要目标本体。图像通道 = **收敛到目标 bbox、剔除目标周边像素**（与 focus"目标+周边图"相反）；文字通道 = 同样带摘要。
- **触发**：伴随（意图出现可辨识目标即附加，checkpoint-15 §6）或独立（"只要那个 / 背景太乱"）。
- **输入**：目标描述（语义，如"那个红红的东西 / 左上角的楼"）+ 当前对象/视野。
- **内部流程**：locate 精确到目标**边界**（语义目标 → target bbox）→ img_tool `crop(target bbox)` → 自动摘要（描述目标本体）→ 记录为可引用子视图。
- **输出**：isolate 目标图（干净目标）+ 摘要 + 依据信号（含"是否成功剥离"信号）。
- **依赖**：locate（到 bbox 的精度）+ img_tool extract + 摘要 cu。
- **边界**：机制层只管按 bbox 收敛；"哪个是目标"识别归主 LLM（语义）。
- **失败/降级**：目标模糊 / bbox 定位信不足 → 降级只给 focus（带上下文）或标注"目标边界不确定/未完全剥离"，交主 LLM。

## 三接口共同约定

- **两信息通道独立**：**图像通道**（图/像素：focus=目标+周边图，isolate=目标本体、剔除周边像素，open=全图）与**文字通道**（摘要/依据信号）分开。isolate 剔除的是**图像通道的周边像素**，文字通道的摘要/信息照常提供；focus 也产摘要——两者文字信息不缺、差异只在图像裁剪范围。
- **摘要内嵌**：任何产出图的动作（open/focus/isolate）自动完成描述性摘要（非独立方法，checkpoint-14）。
- **依据信号**（结果包自带，不含语义，checkpoint-12 §2）：可辨识余量 / 信息量信号 / 视野锚（位置）。
- **语义输入**：接口收的是自然语言语义参数 + 对象状态，**不收机械坐标/倍数**；坐标落点到 region/bbox 归 locate（checkpoint-9，为分派器预留）。
- **信息隔离**：主 LLM 只发语义意图、只收结果包；定位过程内部消化。
- **图池/对象**：全程基于 ImageObj（可带当前视野、图链、子视图）；错误 + 降级也要有信号，绝不瞎返回（checkpoint-6）。

## 进行中 → checkpoint-17（可行性实验）→ checkpoint-18（已反转）

三接口功能（上方）已收敛，但底层 img_tool 只有 info/extract（呈现/裁剪），缺"定位/指认"；先不写代码组织，用底层工具手走 open/focus/isolate 验证机械链路可行（人工走 → 手动 LLM 走 → 可行才组织）。实验思路与产物见 **checkpoint-17**。

**实验（checkpoint-17）后发生重大反转，见 checkpoint-18**：三接口**三合一为单个取图工具**（机械上都是 `extract(region,max_dim)`，差异只在 region 语义、由主 LLM 意图决定）；摘要作废（主 LLM 自己看）；意图工具 = 加载器（按需加载 + 调用后擦痕迹 + 闲置摘除）。**本文件上方三接口定义被 checkpoint-18 简化取代**，此处仅留历史。
