# checkpoint-10 — 第三方复核防幻觉机制（讨论成型）

接 checkpoint-9，防"语义败"（清晰但看错/幻觉）的机制讨论，从"不可实现地拦截主 LLM 推理"收敛为"旁观复核哨兵 + 触发纠偏"。前置：主 LLM 有视觉输入（已确认）、复核也是视觉模型（概率防御定位）。记录后 YZ 将 /undo 释放上下文，重读本文件 + status 恢复。

## 当前问题

防"幻觉（自信地错）"不能靠主 LLM 自报（错觉者不觉、会报高把握），也不能靠拦截其自由推理（违背主体性、难实现）。能否引入第三方复核机制，以及它是否真能解决问题。

## 关键结论 / 决策

### 0. 定位：概率防御，非根除（YZ 确认）

- 类人自我检查：换视角，**有机会发现问题，但不保证每次发现**。
- 机制层承诺"哨兵 + 触发 + 可纠偏通道"，**不承诺保证对**。把"幻觉必然流出"降为"可能被发现、可能被纠偏"。
- 两个失败模式的防线分开了：
  - 失败 A（知其不知/看不清）→ 靠把握度显式化，低把握→驱动复核动作（不是硬答）。
  - 失败 B（不知其不知/幻觉）→ 靠独立第二通道交叉，不靠自报。
  - 把握度只单向用：**低把握有信号价值，高把握不证明对**。

### 1. 机制骨架：旁观复核哨兵（不拦截推理）

- 机制层**旁路观察**触发点（看图事件、外发消息、思考轮次），不打断主 LLM 自由推理，只在**错误扩散前**出手纠偏。
- 这与我早前"在推理中套强制状态机"不同——那个不可实现且违背主体性。

### 2. 触发点（机制层可观察）

- 主 LLM **看图 = 触发点**（ImageTool 被调用，机制层知道）。
- 看图产生**意图，标注为"需触发复核点"**。
- 复核时机二选一，统一原则=**在错误扩散前出手**：
  - **出口断言前**：看图后很快得出结论、要对外/写记忆 → 出口拦截（此时靠还没堆叠多）。
  - **思考轮次阈值**：看图后一直内循环思考（多轮未落定）→ 机制层按轮次阈值自动触发（避免错误在后续推理累积扩散）。
- 不采用"连续看图就延后复核省成本"——因为错误会累积扩散，即时纠偏优于延后（YZ 拍板，钉子3 回应）。

### 3. 复核对象：意图 ↔ 声称获得 ↔ 局部验证

- 复核任务**不是了解主 LLM 推理脉络**，而是从脉络中定位两件事：**主 LLM 为何看图（意图）、看图拿到了什么（声称获得）**——复核视角。
- 若判断"没从图中获得有用信息"→ 也要复核（**"图里没有我要的信息"本身可能是幻觉结论**——要找的其实在图里但以为没有）。此时核对"看图前想要什么"。
- 核心：复核者验证"那个区域是否真支持主 LLM 的声称 / 是否真有它要找的东西"。

### 4. 复核方式：独立主体 + 聚焦子图 + 视角不同

- 复核 = **另一个 LLM**（独立主体，避免"被幻觉者自查"），从上下文定位"为何看图/拿到什么"，找出**结论来源的位置**，把该位置**子图提取出来再看一次**。
- 视角不同：看局部、聚焦（避免周围干扰），任务框架是"验证声称" vs 主 LLM"生成内容"。
- 独立性分两档：
  - **像素级误读**（低分辨率/封顶看花）→ 局部复核 + 换主体，够。
  - **语义级幻觉**（读对像素、理解错）→ 复核者也视觉模型，**可能一起错**；高价值结论建议**补跨模态**（OCR 纯文本读字/数字）或至少换"验证 vs 生成"框架兜底。

### 5. 结论去向（两条出口）

- **通过 → 丢弃**，不进主 LLM（省上下文，常态）。
- **冲突 → 注回主 LLM**，触发下一轮重推理（即时纠偏）。这是"复核不进主 LLM"的补充分叉——发现冲突时必须能回传，否则"立即纠偏"兑现不了。依赖 cogos 已有续轮（agent-接-cu 已实现）。

### 6. 成本与触发筛选

- 图 token 已封顶（几百 token）不高；但**复核是另一次 LLM 推理**（不只是图 token）。
- 触发仍要筛选：**精确读 / 高价值 / 意图明确要具体信息** 的看图才复核；单纯"浏览全景"的泛看图跳过，否则每步 double 推理。

## 实现形态（YZ 确认，09-05）

把上述机制从"概念"压实为可实现形态：

- **注入方式**：意图结果 = 主 LLM 想要的结果 **+ 一条 system prompt**（规则说明 + 复核工具声明），随意图返回**在当前位置加入**。即写 material 时多塞一条，**不是 cog-unit 内注入**；上下文本体在管理结构，天然可加。这条 system 是**前瞻性引导**（"若从图得出结论，则调复核工具"），主 LLM 没下结论时自然不触发。
- **复核 = 对象**：随 ImageTool（open/focus/子图）产生，复核完成即清（**短命对象**）。对象唯一 → 不管由主 LLM 调、还是机制层兜底触发，都作用于**同一复核对象**，**只复核一次、不重复**。
- **兜底**：沿用既有（主 LLM 没调/看图后 N 轮未落定 → 机制层触发，见 §2 触发点），无变化。
- **厘清两对象**：复核对象（短命、验证任务载体）vs 子图对象（固化、持久认知资产）。复核会取"结论来源位置"的子图 → 复核对象**引用**子图对象 / ImageObj，但自身寿命短。
- **粒度**：以**图/意图为单位**（一次看图 → 一个复核对象，验证这次看图得出的断言），非每断言一个，避免碎片化。
