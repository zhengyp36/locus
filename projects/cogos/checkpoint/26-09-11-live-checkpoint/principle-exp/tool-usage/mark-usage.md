# 标注工具族用法（草稿，供审阅）

标注族 = `mark` / `adjust_mark` / `unmark`，负责"在图上做记号、框选、定位目标"。与 `see`（看图）分开：**`see` 只改变视角，`mark` 族改动图的状态**。

- 三个动作都只能作用在**已存在的图**上（`ref=FIG:<id>`，id 取自注解 `图 FIG:<id>` 照抄），不能标在"还不存在的窗口"上。
- 坐标都相对该 FIG 归一化 0..1、标准图像坐标（x 向右、y 向下、[0,0] 左上角）；坐标落在图内，越界将被 clamp 到图边界。
- 标注会随所属 FIG 的图块寿命存续（K 轮内有效），超龄被清。

---

## mark —— 创建标注

在指定图上新增一个标注，用于标记/框选某个区域或点。

```
name: mark
description: >
  在指定图上新增一个标注，标记某个**位置**（点）或**区域**（矩形/椭圆）。
  ref 必须是 FIG:<id>，标注落在该图本身上；坐标相对该图归一化 0..1。

  kind 决定 pts 的写法：
  - "rect" 矩形 / "ellipse" 椭圆：圈一个区域。pts = [中心, [宽,高]]，宽沿图宽、高沿图高；
  - "point" 点标记：标记单个位置。pts = [点]（渲染为十字，便于看清）。

  返回带标注的该图（重渲染后），并给出该标注的 id（ANNO:n，供 adjust_mark/unmark 用）。
  标注颜色由程序分配（自动保证与背景的对比度、并区分多个标注）。
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `ref` | `FIG:<id>` | 是 | 要标注的图 |
| `kind` | string | 是 | `rect`/`ellipse`（圈区域）；`point`（标记单点） |
| `pts` | list | 是 | 依 kind：区域类 `[中心,[宽,高]]`；点类 `[点]` |

**示例**
```json
{"mark": {"ref": "FIG:1001", "kind": "rect", "pts": [[0.5,0.5],[0.3,0.2]]}}
{"mark": {"ref": "FIG:1001", "kind": "point", "pts": [[0.4,0.2]]}}
```

## adjust_mark —— 调整标注

移动已有标注的位置，和/或改变其大小。`anno_id` 取自 mark 返回/注解里 `ANNO:<n>`。

```
name: adjust_mark
description: >
  调整图上已有的一个标注：改它的位置和/或大小。调整后仍是同一个标注（anno_id 不变）。
  ref + anno_id 指定要调哪个；坐标相对该图归一化 0..1。

  pts 只给新位置：对矩形/椭圆标注，pts = [新中心]（宽高用 size 给，不给则保留原宽高）；
  对点标注（point），pts = [新位置]。
  size 可选，改变矩形/椭圆标注的宽高。

  若想重新定位，也可删掉后重标（unmark + mark），或直接调整。
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `ref` | `FIG:<id>` | 是 | 标注所属的图 |
| `anno_id` | string | 是 | 标注 id（`ANNO:<n>`） |
| `pts` | list | 是 | 新位置：区域类 `[中心]`；点类 `[点]` |
| `size` | [wx, wy] | 否 | 新宽高（矩形/椭圆适用；不给则保留原宽高） |

**示例**
```json
{"adjust_mark": {"ref": "FIG:1001", "anno_id": "ANNO:1", "pts": [[0.45,0.25]]}}
{"adjust_mark": {"ref": "FIG:1001", "anno_id": "ANNO:2", "pts": [[0.45,0.25]], "size": [0.25,0.15]}}
```

---

## unmark —— 删除标注

删除图上已有的标注，返回去掉该标注后的图。

```
name: unmark
description: >
  删除图上已有的标注，返回去掉标注后的图。
  anno_id 指定要删的单个标注（ANNO:n），或填 "all" 清空该图的全部标注。
```

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `ref` | `FIG:<id>` | 是 | 标注所属的图 |
| `anno_id` | string | 是 | `ANNO:<n>` 删单个；`"all"` 清空该图全部标注 |

**示例**
```json
{"unmark": {"ref": "FIG:1001", "anno_id": "ANNO:1"}}
{"unmark": {"ref": "FIG:1001", "anno_id": "all"}}
```
