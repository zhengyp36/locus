# 自省 agent｜待验清单（触发/通道之外）

> 2026-09-10。上游：handoff-17 + draft-introspective-agent.md。
> **前提**：`触发`、`通道` 是要造的机制，本清单**不验这两个**，只列"用人补上触发+通道"后，**模型侧**还要验什么。
> **用法**：逐个验证；每项验完就地更新"现状/结论/产物"，不另起文件。
> **流程基准**：主文档 `draft-introspective-agent.md` §三（完整状态机 + 五条硬规则 + 两条横切机制）。

## 实验纪律（每步一起走）

按主文档 §三流程重新实验，**每步实验都一起走**，顺序固定：

1. **先给思路**——这一步验哪一环、预期看到什么、怎么判读。
2. **给提示词**——写出将发给模型的原文。
3. **讨论确认**——YZ 过一遍，质疑经得起再动。
4. **才做实验**——放提示词、收结果。
5. **一起分析**——对照流程定位断在哪一环，再谈下一步。

**不跳步、不先做后说**；每步结束记录到对应的 `exp-*.md`。


---

## 定位

去掉触发+通道，剩下要验的 = 环的模型侧三段 + 连接与集成：

```
（触发）─▶ 验证 ─▶ 素材 ─▶ 分析 ─▶ 裁决 ─▶ 动作/重规划 ─▶ 复验（闭环）
            ▲                                    │
        （通道）                                 └──▶ 收敛 / 震荡
```

- 机制缺 **触发 + 通道**；本清单验 **验证 / 分析 / 裁决 / 动作** 四个模型侧环节 + 闭环集成 + 接口规范 + 横切的方向对齐。

## 待验项

### V1 裁决环（最弱，几乎没验）
- **问题**：素材/分析在手，敢不敢判 `fail` / `undetermined`，还是自信盖过判 `PASS`。
- **现状**：唯一直接证据是 V0，且是负面的（证据在手仍判 PASS）。实验四/五只验了"分析（归类）"，**没验裁决（定出口）**。
- **验法**：喂"带形态差异 + 明确应 fail 或 undetermined 的素材"，看它判什么；查是否附证据、是否敢用 undetermined。
- **判读**：误判 PASS 率；undetermined 是否被正确使用。

### V2 验证环稳定性
- **问题**：给对通道后，是否**自发比对**并稳定吐 `{方向, 形态, 量级}`，而非描述图/空转。
- **现状**：实验六 v5 单例，且**对照图是人摆好的**；样本太薄。
- **验法**：同一 case 多轮 + 换 case；看素材格式是否稳定、形态是否完整。
- **判读**：素材产出率 + 形态完整度。

### V3 分析环鲁棒性
- **问题**：噪声、多因纠缠、形态不清晰的差异下，还能不能正确归类。
- **现状**：干净单因 8/8、4/4；caveat 自陈未验噪声/多因。
- **验法**：造含噪 / 双因 / 模糊形态的差异，重跑 `analyze_probe` 变体。
- **判读**：正确率随噪声/多因的下降曲线。

### V4 分析 → 动作 → 闭环收敛（底层、当前最该跑）
- **问题**：定性对了，**动作对不对**（执行误差→调参 vs 假设错→重建）；改后复验是否**收敛**。
- **现状**：V0 在此翻车（归错因、越改越歪）；**闭环从没跑过**。
- **验法**：人给触发+通道，跑 改 → 重对照 → 复验 → 对真值打分。
- **判读**：收敛 / 震荡 / 过冲；失败能定位到哪一环（触发/V2/V3/V1）。
- **flag**：通道参数（裁哪块、放几倍）本轮由人给；顺手观察模型会不会索要不同通道（= 通道决策的早期信号）。

### V5 判据质量 + undetermined 阈值
- **问题**：自定判据是否**可测量/可证伪**；何时该说"看不到证据"。
- **现状**：实验一/二判据偏定性（"完整/准确"）；undetermined 只用过一次。
- **验法**：让它把判据写成可观察属性；构造边界证据看阈值一致性。
- **判读**：判据可证伪率；阈值是否稳定。

### V6 方向 / 目标对齐（第四类提醒，横切；既非触发也非通道）
- **问题**：整体还在朝目标走吗（动**对**没动对），正交于停滞。
- **现状**：本轮两次"手段目的化"；未造、未验。
- **验法**：跑 V4 时挂"**目标 + 轨迹同框** + 一句自问：当前动作如何服务目标？"。
- **判读**：漂移是否被拦。

---

## 建议顺序

1. **先 V4**：人给触发+通道，跑一次闭环单例。它是"环本身收不收敛"的底层问题，且一次同时压 **V2 / V4**，并带出 **V1 / V3** 的观察点。
2. 再逐个隔离：**V1（裁决）→ V3（分析鲁棒）→ V5（接口）**。
3. **V6** 横切，随 V4 一起挂。
