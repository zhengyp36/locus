# 草稿｜自省 agent：验证→分析→裁决链 + 随机看门狗 + 独立校验（09-10）

> 临时讨论稿，用于逐轮打磨，非 handoff。来源：handoff-16 的两节（自验证方法论、随机看门狗）+ 本轮关于"独立校验 = 事前澄清 + 事后校验"的讨论。
>
> **方针**：先验证可行性，不先堆理论。已有实测（第一节）：模型**能力齐备**（会答/会验法/会析/会用 undetermined），但**自发时会崩**；"自验"实为 `验证→分析→裁决` 的链。结论收敛：**机制缺口只剩 `触发` + `通道`**——"视角/角色"经实验五证伪，不进机制。理论部分（二～六）暂列其后，待实测推进再打磨。

## 〇、题眼：自省 agent

**自省 agent：把"提问者"从外部借来、内化成 agent 的器官；由此，裸模型没有的反思启动与对表纪律，成为整体自带的自治能力。**

- **agent = 模型 + 内化的自省回路**；回路是 agent 相对裸模型的唯一增量。
- **外挂是相对"裸模型"说的**：自省回路不是模型自己的，对模型是外挂；但装进整体后，它是 agent 的**构成部件**，不是挂件——如同"自省"不是外挂在人身上，而是人这个整体的一部分。
- 命名以**整体**为单位，故"自"不误导：在整体层面它确实自驱。
- **自省**作正式概念名（贴合正文：方法论 + 看门狗 + 对表都在"自省"里）；**自驱**作其效果/愿景词（整体自治，不问外界也能自启动、自校验）。

## 一、实测先行：会答 ≠ 会自验自纠（可行性第一步）

**方针**：不先堆理论，先用对话式元问题验可行性——若"会答"成立，思路的底层前提（能力已在、缺触发）就立住。

**方法**：探针 `image_field_chat.py --repl`，不给 open/close 机制，纯对话问元问题。源图 `windows.png`，任务 = 7 项菜单区域坐标（同 rect_2）。三次实验：ref_ans1、ref_ans2、V0（V0 为 ref_ans2 续聊）。产物 `/tmp/kilo/vision/{ref_ans1,ref_ans2}/`（`raw.jsonl` + `score_overlay.png`）。

### 实验一 ref_ans1（仅事后问）
- Turn1（任务）→ 模型自发 see→放大→标 7 rect（全图 FIG:1000，**等差外推**）→ 自称 *"The marks align well"*。
- Turn2（元问题）→ 答出：任务复述正确；判据四条（完整/对应正确/区域准确含快捷键字母/坐标可用）；验证法（放大逐项核对、coord 读回、交叉检查）；**并主动承认"还没有真正完成验证，只能说初步对齐"**。
- 实测其框：dx = −1,+4,+10,+15,+19,+23,**+25**，dy 一律 **−10**。**假验证**。

### 实验二 ref_ans2（事前问 + 事后问，3 轮）

### 实验三 V0（逼它真执行自验；ref_ans2 续聊）
- 追加一轮："请真正执行你④的复核，给可观察证据；看不到就直说卡在哪，不要用'已核对'代替证据。"
- **它自己诊断出通道问题**：*"标注只在它所附着的 FIG 上渲染"*——框标在整图 FIG:1000，一放大到局部视图（FIG:1002/1003）就**不显示**，故它下结论："那些'放大复核'看不到框、不是证据"。
- **换通道取证**：改为在同一高清局部视图上标注 + 回看 → 拿到真能判读的证据 → 发现框**偏窄（漏右括号）、偏高**，并调整。
- **诚实输出 `undetermined`**：右半 3 项明说"看不到充分证据，**不能声称它们 pass**"，并说明工具限制（高清视图一次仅覆盖约 0.165 原图宽）。
- **但仍误判**：修正后左 4 项判 PASS，实际相邻框重叠（item1 [5,65] vs item2 [61,121]）、中心漂移未修，违反它自己"不越界相邻项"。

### 实验四 analyze_probe（隔离"分析环"，纯文本、可评分）
- **目的**：把分析从验证里剥出来，单测"从差异推类别"的能力。
- **方法**：纯文本、无图像；四例（A 假设错 / B 执行误差 / C 判据问题 / D 环境限制）× 两条件（给方法 / 不给方法），问"哪类问题 + 下一步"。探针 `/tmp/kilo/vision/analyze_probe.py`，产物 `analyze_out/results.json`。
- **结果**：**8/8 全对，含不给方法的对照组**。
- **关键**：
  1. 分析能力存在且强 → **分析环不缺能力**。
  2. 判别依据是**差异的形态**（整体平移→执行误差；随位置单调递增→前提不成立；大点小点说不清→判据；拿不到证据→环境），**不依赖"计划同框"**（不给方法也全对）。
  3. **与 V0 对照**：同一个模型，在执行上下文里（V0）归错因、修正走偏；放进"诊断专家"框架里四类全对 → 当时疑为"视角/角色"差异（**实验五证之：非视角**）。
  4. **机制含义**：该补的不是"分析器"——而是 ①**验证的产出形态**（必须吐"带形态的结构化差异"，只给 pass/fail 则分析无从归类）；②当时的"视角"假设（实验五否定）。
- **Caveat**：教科书级、干净单因、签名明显的对照；真实是噪声、多因纠缠。结论限于"清晰差异下不需补结构"，不能推广为"分析环永不需补"。

### 实验五 V1–V4（视角 vs 角色 vs 上下文）
- **目的**：验"分析是否需要切视角/换角色"——实验四把**角色 / 干净上下文 / 已整理差异**混在一起，无法判定。
- **方法**：先跑 seed（goal-only）造出带明确偏差的结果：7 项像素中心 x = 33,102,171,240,309,379,448，y=25（真值 34,88,142,197,252,308,366，y=34）→ dx = −1,+14,…,+82（等差，步长 69 vs 真值 55），dy=−9；且自称"已对齐确认"。再把**同一份偏差**喂给四条件，只变措辞/上下文。产物 `/tmp/kilo/vision/{vseed,v1,v2,v3,v4}/`。
- **结果**：**四条件全对**——都判为"系统性/前提错"（非执行误差），都主张"别微调、重测/重建模型"；V4（独立上下文）最准，明说"**等间距假设不成立**"。

  | 条件 | 上下文 | 措辞 | 结果 |
  |---|---|---|---|
  | V1 | 同会话 | 中性 | ✓ 前提错 |
  | V2 | 同会话 | 只加视角 | ✓ 参考系/基准错位 |
  | V3 | 同会话 | 加"诊断专家"角色 | ✓ 同 V2 |
  | V4 | 独立上下文 | 视角 | ✓ 最准（等间距假设） |

- **结论**：**措辞（视角/角色）与上下文都不是变量**；只要喂"带形态的干净差异"，分析在任何框架下都成立 → **"分析需要批判视角"被证伪**。
- **校正 V0**：V0 的归错因**不是视角问题，是上游验证空转、没产出素材**——拿到空数据被迫硬分析。
- **Caveat**：单 seed、每条件 1 次；偏差是**人替它验出来喂进去**的，故只验了"素材→分析"，未验"触发→验证→素材"。

### 三阶段失效（把本轮结论归位）

"自省"不是单一能力，而是 `验证 → 分析 → 裁决` 的链，三处**可独立失败**——本次恰好全踩：

| 现象 | 所属环节 | 失效模式 |
|---|---|---|
| 一句元问题即引出验证动作 | 不进环（机制前提） | 环能否被启动 |
| 表示错位 → 放大看不到自己的标注 → "验证"空转 | **验证** | 结果与参照不在同一表示，证据根本没产生（**看不见**） |
| 换到同框表示后立刻看见错 | **验证成功** → 交接分析 | —— |
| 看见偏差却归因不全（只顾"框窄"，漏"位置漂移/邻接重叠"）、修正方向错 | **分析** | 从差异到原因/性质的推理缺失或走偏（**归错因**）；但实验四/五证：**能力在**，V0 的归错因是**上游无素材**，非视角问题 |
| 证据在手仍判 PASS；而 `undetermined` 在另一处又能用 | **裁决** | 判定不稳（**看见 ≠ 判准**） |
| 自验 vs 自评是两种能力 | 横切 | 自验=验证；自评=分析+裁决 |

**核心**：换**通道**治"看不见"并产出素材（验证），**素材到位则分析自动成立**（能力已在），可测量判据/外部锚治"判不准"（裁决）——**三者正交**，是"提问/换视角 ≠ 独立验证"的具体拆解。

### 结论
1. **会答成立且稳定**：事前、事后都能给出完整判据与验证方法，质量同级 → 不是事后合理化；模型**事前就会定判据**。
2. **缺的不是能力**：它能定判据、能选验证法，甚至能正确判断自己"没验"、能自诊断通道问题。
3. **缺的是自验自纠的执行**：自发时是**假验证**（自称 aligned），不会真去跑自己的判据、发现不了 +25/+10px。→ 命题钉在"**能力已在，缺触发（且缺执行）**"。
4. **自验是 `验证→分析→裁决` 三环链，三环可独立失败**（见上表）；机制要逐环设闸，不能只加"提问"（补法见 #6：触发/通道，而非教能力）。
5. **两个正面信号**：① `undetermined` 出口在触发下真被用上；② 事前元问题直接引出"反向澄清"（请求确认），且可能改善精度（**单轮弱证据**）。
6. **机制缺口只剩两个：触发 + 通道**。能力（答/验/析/判）齐备；"视角/角色"经实验五证伪，**不进机制**。分析只要"带形态的素材"就自动成立，而素材由**通道**产出、由**触发**发动。→ 机制 = 在该验/该析时**发动**（触发），并让它能看到"结果 vs 参照同框"的差异（通道）。

**Caveat**：每条件 n=1；精度提升也可能来自本轮多裁一刀（crop 位置不同）而非"先声明判据"本身，需重复实验证因果；PASS 误判说明"会答/会选验证法 ≠ 真验对"。

### 口径更新：触发 / 通道 / 素材 / 分析（"视角"退场）

实验五推翻了"分析需要视角"。把"自省"按**因子**重拆：

```
触发 ──▶ 验证 ──▶ 素材(带形态差异) ──▶ 分析 ──▶ 裁决
              ▲
         通道/表示（决定素材产得出 / 产不出）
```

- **触发**（动机层）：要不要去做这一步。**中性一句话即可**——不需要"批判视角"，更不需要"人格/角色"。
- **通道**（工具/表示层）：验证时能否"结果与参照同框"、且落在能暴露误差的尺度上——**决定素材产得出产不出**（V0 即通道坏 → 产不出）。
- **素材**（验证的产物）：**带形态的结构化差异**——形如 `{方向、形态(整体偏移/随位置递增/边界覆盖/缺证据)、量级}`，而非 "pass/fail" 断言。**这是分析能成立的唯一前提**。
- **分析**（能力层）：**模型本来就具备**（实验四 8/8、实验五 4/4），给素材就成立，**无需切视角**。
- **术语**：弃用"视角切换"（"角色"更不必）；**机制缺口只剩 `触发` + `通道`**。

> 你原来的"视角"，被拆成两个东西：**触发**（愿不愿意做）＋**通道**（做时看不看得见）；而真正的"批判性思维"那一半，模型本来就有。

## 二、问题诊断

当前 agent 的通病：**接到任务就执行，缺乏自我反思**——"我的任务是什么？怎么做？怎么算做完了、做对了？"这些问题它不会主动问自己。

但关键在于：**这个能力是有的，缺的是触发。** 只要以人的身份去问它这几个问题，它能答得头头是道。也就是说，反思能力是潜在的，只是模型不会自己站出来问自己。所以缺失的不是"会不会"，而是"谁来启动、站在哪个位置问"。

由此得到一个干净的机制定义：**用外部机制稳定地占据"提问者"位置，逼模型在被问时输出本该主动给出的话。** 加上这个回路，模型就从"纯执行"变成了 agent。**agent = 模型 + 反思回路，回路是唯一的增量。**

## 三、自验证方法论

**核心主张**：模型不是程序，方法本就多样（等差外推也是一种合理思路）。缺的不是方法，而是**自验证/自纠闭环**。任何任务都应走出：**规划（定判据 C + 验证计划 V + 预算 B）→ 执行 → 验证 → 裁决 →（不过则）分析 → 重规划**的闭环，反复不过则上报失败并总结。

**循环（状态机）**：

```
                 ┌──────────── 触发（启动回路；缺机制之一）
                 ▼
S1 规划 ── 定【目标 G + 判据 C + 验证计划 V + 预算 B】，复述意图请求确认
                 │
                 ▼
S2 执行 ────────────────────────────────┐
                 │                       │  方向闸（全局，周期性）
                 ▼                       │  目标 G + 近期轨迹 同框 →「当前动作如何服务 G？」
S3 验证 ── 产证据 E：结果 vs 参照【同框 + 能暴露误差的尺度】
                 │
                 ▼
S4 裁决 ── 拿 E 对 C：pass | fail | undetermined
                 │
                 ├─ pass ─────────────────────────────▶ S8 提交(pass)
                 │                                      附证据 + 残余不确定
                 ├─ undetermined ─▶ 升级观察(换通道) ─▶ 回 S3
                 │                        │
                 │                   升不了 ▼
                 │                   S8 提交(undetermined)
                 └─ fail ─▶ S5 决策：预算尽? ─是─▶ S8 提交(fail + 过程总结)
                                  │否
                                  ▼
                               S6 分析 ── 差异形态 → 类别
                                  {执行误差 | 前提错 | 判据问题 | 无解}
                                  │
                              无解? ──是──▶ S8 提交(无解)
                                  │否
                                  ▼
                               S7 规划(修订) ── 执行误差→调参
                                                前提错→重规划
                                                判据问题→回炉判据
                                  │
                                  └────────────▶ 回 S2
```

S1~S8 各环节的输入/动作/产出/离开条件：

| 环节 | 输入 | 动作 | 产出 | 离开条件 |
|---|---|---|---|---|
| **触发** | 任务/停滞/裁决/预算 | 发动回路 | 进入 S1 | 一次性 |
| **S1 规划** | 目标 G | 定判据 C + 验证计划 V + 预算 B | 冻结的 C/V/B | 提交确认 |
| **S2 执行** | C/V | 按计划动作 | 结果 | 动作完成 |
| **S3 验证** | 结果 + 参照 | 同框比对、够尺度 | 证据 E（带形态差异） | 拿到 E / 拿不到 |
| **S4 裁决** | E + C | 对表定出口 | pass / fail / undetermined | 三选一 |
| **S5 决策** | 预算 + 分析 | 预算/无解闸 | 继续 / 强停 | 二选一 |
| **S6 分析** | 差异 E | 按**形态**归类 | 类别 + 原因 | 定性完成 |
| **S7 规划(修订)** | 类别 | 调参 / 重规划 / 回炉判据 | 新计划 | 回 S2 |
| **S8 提交** | 出口 | 交结论 | pass(证据+残余不确定) / fail / undetermined | 终 |

**两条横切机制**（不属任何单步）：
- **通道（表示层，缺机制之二）**：贯穿 S3 与每次复验。验证时须"结果与参照同框 + 落在能暴露误差的尺度"，否则产不出素材（V0 空转）；**改正后必须用同一通道再验一次**，否则退化成假自评（Step1 实测：框在缩放视图不渲染，只能在低清整图上看）。
- **方向闸（全局，第四类提醒）**：周期性把**目标 G + 近期轨迹**同框，问「当前动作如何服务 G？说不出 / 牵强即警报」；治**手段目的化**——局部有进展、方向已偏，对停滞检测隐形的漂移。

**为什么单列"分析"**：原循环把 `fail → 回规划（假设错才重规划；执行误差只调参）` 写成一个分支，但"假设错 vs 执行误差"这个**判断本身就是分析**，却无处安放。验证只回答"是否与参照一致"（产事实），裁决只回答"算 pass/fail/undetermined"（定出口）；从"差异"到"原因/性质"是独立的一环——实测 V0 正是"看见了却归错因"，故单列。

**五条硬规则**（每条都对着实测踩的坑）：
1. **判据先于行动**：C 在 S2 前冻结，禁止按结果倒改。否则退化成 rect 那种"看着差不多就行"。
2. **验证是"找反例"，不是"找看着对"**：且必须换尺度/同框（结果 vs 参照），忌讳把刚生成的表示再读一遍（恒等换算什么都验不出）。rect_h1/h2 自称 aligned、实为 +25/−145px，就是自评没有可证伪性。
3. **fail / undetermined 是一等出口**：有专用出口，禁止用自信陈述盖过未通过的判据。
4. **改正后用同一通道复验**：否则闭环无法收敛（会自证 PASS）。
5. **每次回 S2 前过方向闸**：目标 + 轨迹同框，防漂。

**两条边界**：
- **判据只写结果的可观察属性**（"框四边贴住文字、不压邻居""点落进可点带"），**不写步骤**——写步骤就退回"指定方法"的伪结论，越界。
- **验证要换尺度/换通道**（估读靠整体、验证靠放大看边，或程序给独立测量）；**忌讳把刚生成的表示再读一遍**——恒等换算什么都验不出。

**责任边界（人类类比）**：自审是"尽责"不是"万能"；交差即"已自审"，下游有没有审查是另一层、可选。故 `pass` 带证据 + 残余不确定，`undetermined` 是合法的对外申明。

**分层**（不违反"方法自由"）：
- 工具层 = 手段 + 不变量（坐标基、ID、clamp），**不含方法论**。
- 通用方法论 = agent 的**操作契约，常驻 system-prompt**（与任务无关）。
- 成功判据 = **任务层**实例化（任务相关）。
- 看门狗 = **过程工具/agent 运行时**，非任务工具。
- 实质：注入方法论 = 把"模型"变成"agent"——自己当指派方（定判据/规划）→ 转执行 → 收尾转审判（**是同一整体的步骤切换，不是分饰几个人格**；见第一节口径更新）。

> **显式化机制**（流程看板 + 内容派生规则）见 `explicit-process.md`：本节状态机给骨架，该文件给"每一格内容从哪来、怎么外显"。

## 四、随机看门狗设计

**动机**：handoff-10 已证"换视角靠语言即可"（taskSwitch 有效），但"把方法论直接塞进执行者 SYSTEM"失效（taskM 说/行不一致）。看门狗的作用是把**触发**从自觉升级为结构保证。

**能力边界（重要）**：看门狗只解决**何时切**与**冻结判据**（open 时逼出 goal/criterion/verify_plan），**不解决判得准不准**。切到同一个脑子、同一张全图渲染，照样自我确认（rect_h1/h2 即此）。即：**触发治"肯不肯查"，通道治"查得到查不到"，两者正交、必须一起上。**

**API 草案**：
- `watch.on(goal, criterion, verify_plan, budget)`：开任务，冻结判据与验证计划，开始计轮。
- **四路触发并存，取 min**：
  1. 随机 hazard；
  2. **停滞检测**（重复动作/无新信息 → 立即，拦无限 zoom 与八次 adjust）；
  3. `close`（**请求裁决**，非结束）；
  4. 硬预算（最终 cap → 失败上报）。
- 触发时注入**结构化清单 / 产物要求 + 精简过程摘要**（做了什么、卡在哪、判据还差什么）；评审须产出裁决 + 证据，否则算空转。（**不设"审判视角/角色"**——见 §一 口径更新；勾由模型自己打，但须挂在结构化产物上。）
- `close()` 返回 `{pass(证据) | fail(原因) | undetermined}`。

**三段 hazard**（`t` = 距上次反思的内层轮次，反思后清零）：
- `t < t_lo`：p=0（冷静，短任务不打扰）
- `t_lo ≤ t < t_hi`：p(t) = (t−t_lo)/(t_hi−t_lo)（渐增）
- `t ≥ t_hi`：p=1（强制）

第三段给"反思间隔"设上界，是唯一带保证的一段；前两段解决不打扰 + 拟人。

**实现建议**：用"每周期预采样到期轮 T"（T 落 [t_lo, t_hi]、三角形分布偏 t_hi），而非逐轮掷骰——给定 seed 可复现、检查点可审。`t_lo/t_hi` 绑 budget（如 30%/70%），"轮次"起步用内层 LLM 轮。

**关键提醒**：随机化只解决"何时反思"，**不解决"看不看得见"**——评审那刻仍需换通道/放大表示。两个正交问题必须一起上。

**待讨论：第四类提醒——方向 / 目标对齐**（09-10 插入，稍后展开）
- 现有三类（冻结 / 停滞 / 裁决）都是**局部**的："当前这步对不对"；缺**全局**的一类："整体还在朝目标走吗？"
- 与**停滞**正交：停滞看"动没动"，方向看"动对没动对"。**"有进展但方向偏"对停滞检测完全隐形**——本轮 AI 两次"手段目的化"（提议难度升级、把力气往"做对视觉题"上使）即此，均被 YZ 当场拽回。
- 偏离形态：**手段目的化** / 局部指标替代全局目标 / 偏题（scope creep）/ 目标漂移。
- 成因（机制层）：**近端子目标反馈强于远端总目标**，注意力向手段滑 → 不靠自觉，须机制周期拉回。
- 硬要求（与"验证"同构）：需把 **冻结的目标 + 当前轨迹** 放进同一视野比对（目标常在上下文远处/被老化摘掉）→ 又一次"**素材同框**"，这次同框对象是 `目标 + 轨迹`。
- 落点：在 open / close 两闸之外，加**周期性方向闸**；每次评审注入"目标 + 近期轨迹摘要同框" + 一句"**当前动作如何服务目标？说不出 / 关联牵强即警报**"。

## 五、深化：独立校验 = 事前澄清 + 事后校验

"独立校验"是最重要、也是当前所有 agent 最缺的一条。把它说透：

### 5.1 统一原则

**把内部表示拿去和"不受自己控制的外部参照"对齐。**
- **事前**：参照是**意图**（指派方的脑子）——"我理解的任务是不是你要的"。
- **事后**：参照是**现实/判据**（世界）——"我做出来的东西是不是真的对"。

两者是同一个免疫系统，只是对表对象一个是人、一个是世界。当前 agent 缺的正是这个免疫系统：它把推理全建在自己的内部表示上，从不拿出去对。这也就是"员工会先澄清再执行"的那一步——模型不会，它自己猜，猜不准也不问。

### 5.2 事前是事后校验的前提

事后校验必须有一个**参照判据**；判据不存在，事后无从验。而判据只能在事前产生并冻结。所以事前和事后不是并列对称，是**前者生产了后者所需的尺**。这解释了"判据先于行动"为什么是硬规则——不这么做，事后阶段的验证功能根本不成立。

### 5.3 陷阱：不能靠"不确定就问"

员工会主动澄清，是因为他有**真实的困惑感**。模型这里断了：它常常**又自信又错**（rect_h2 偏 145px 还自称 aligned），压根不觉得自己不确定。

所以触发不能建在"felt uncertainty"上，必须建在**结构性检查**上——不管有没有感觉，动手前都必须完成"复述意图 + 写判据 + 列假设/歧义"这个动作，然后才允许执行。**把意愿问题转成结构闸门**，这正是看门狗 open() 该干的事。

### 5.4 澄清要"先提方案"，不是"抛开放问题"

好员工的反向澄清不是问"你想要啥"，而是："我理解成 X，完成判据是 Y，假设是 Z，对吗？"——**提出一个具体、可被否证的理解，请求确认或纠正**。工程价值：
- 对指派方成本最低（只需 yes/no 或小修正）；
- 逼 agent 对任务做出**可证伪的承诺**，而非含糊试探；
- 顺带完成判据先于行动、残余假设显式化。

### 5.5 参照从哪来，决定形态

| 形态 | 参照 | 成本 | 信息增益 |
|---|---|---|---|
| 问人 | 指派方本尊 | 高（需人在回路） | 最高 |
| 自提交 + 冻结 | 自己的承诺 | 低 | 只逼出歧义，不引入新信息 |
| 同伴/审查者 | 另一实例、换通道 | 中 | 中（换的是眼睛，不是脑子） |

人在场用第一种；无人时自提交只能**暴露**歧义、不能**解决**歧义，必须靠换通道/换实例补独立信息。这与"提问/换视角 ≠ 独立验证"是同一件事。

### 5.6 对看门狗的重新排序

按这个视角，看门狗**最有价值的触发不是中途随机 hazard，而是两个强制闸门**：
- **open 闸**：动手前逼出复述 + 判据 + 验证计划（事前对齐）。
- **close 闸**：交付前逼出证据 + 残余不确定（事后校验）。

随机 hazard 只管中间"跑偏了没"——它是配角；真正防大错的是这两个闸门。而随机的**不可替代**之处，是它**不可预测**——模型没法为"下次何时被审"做最优规避，这对防"说/行不一致"才关键。

### 5.7 为什么这是"最缺"的

根子在激励：训练偏好**自信地交付**，把"反问"当成无能信号，于是模型学会了"别问、先干"。所以修复不只是加机制，还得翻转立场——**把澄清、承认不确定当作专业行为，而非失败**。这与"失败是一等结果"是同一价值取向。

## 六、收束

事前确认与事后校验不是两件事，是同一条纪律的两端：

> **任何结论在说出口之前，都要先和一个自己控制不了的参照对一次表；事前对意图，事后对世界。**

当前 agent 缺的就是这条纪律，以及保证它被执行的那个**结构闸门**（看门狗）。而方法论（该怎么验证的契约）、看门狗（保证按契约做的结构）、换通道表示（让验证看得见）三者齐备，才能覆盖 rect 实测暴露的全部失效模式。
