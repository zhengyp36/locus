# 补充实验｜实验 1 的归因拆分（supplement）

> 2026-09-06。实验 1（回填）开放结论：A 半（概括）留得住，B 半（锚定/隔离）在实验 1 现设计下为空。
> 本文件整理"补充实验思路"，用于把 B 缺失归因到"干扰影响" vs "编码信息缺锚"，从而在**经验缺位 / 范式需补**之间定案。
> 入口：本文件即新会话进场文件，读它即可接手，无需回溯旧会话。

## 一句话

用两组对照，把实验 1 的"节点太泛 / 辨认不稳"切成两块：
- **补-1**：去干扰（干净背景 + 渐增干扰曲线），测**干扰的影响有多大**；
- **补-2**：给判别信息（A、B 并排自由总结、无位置锚），测**判别特征能否救辨认**。

## 为什么要这么拆（背景）

实验 1 暴露：节点只有"左上小方 + 右下高长方交叠"这种**绝对外观**，图里多个同构对都有此特征，模型无法区分哪个是 A。
判读卡在"回填没坏/节点太泛"到底是：
- (i) **干扰太大** → 有分类/隔离能力，被干扰压垮 → 偏经验/机制之"隔离"；
- (ii) **节点缺判别/位置锚** → 信息本身不够 → 偏编码/信息。

两个补充实验分别压 (i) 和 (ii) 的一端。

## 材料（复用 P0）

- `pano_800.png`：全景（800x600）。
- `p0_crop_A.png`：A 紧密高清 crop。
- `p0_crop_B.png`：B 紧密高清 crop。
- `p0_pair_AB_side.png`：A|B 并排（补-2 可直接用）。
- 实测真值：A 中心 `(0.595,0.512)`、A bbox `(0.580,0.487,0.030,0.050)`、B bbox `(0.031,0.657,0.025,0.047)`。
- 标定点核查：A 为 `range` 旁那对；B 为左下近方矩形对。

## 补-1｜去干扰 + 渐增干扰，测"干扰影响有多大"

### 目的
在**保持位置/锚不变、只撤销同构候选**的前提下，看模型辨认是否大幅变准。
- 若变准 → A 好辨认，辨认失败主因是**干扰**（隔离被压垮）；
- 若仍不稳 → 不只干扰，**编码本身不足以回到场景**（信息缺锚）。

### 怎么构造"干净图"（关键，防污染）
**不能做成"图里只剩 A 一个目标"**，否则"辨认"退化成"识别"，干扰影响被高估。
正确做法 —— 用 `pano_800.png`，前端去同构、背景/锚保留：
- 保留：A 的位置、尺度、背景渐变、网格线、附近的文字锚（如 A 旁的 label）。
- 去除：把场景里**与 A 同构的矩形对**（B，以及其它重合矩形对）用**周围背景色抹平**，无痕到看不出擦过。
- 产出：`exp1_clean.png`；另存一份"标注了 A 位置"的用于步1定位（可选）。

**采纳（YZ 确认）**：不止抹 B——把**所有与 A 同构的重叠矩形对都抹掉**（run_2/run_7 命中的也是真实同构对，只抹 B 图里仍有竞对，无法归因到"干扰"）。只留下 A 这一个"重叠对"，但**位置/锚仍要靠模型找回**，仍是"辨认"而非"识别"。

### 渐增干扰（更强的判读）
在干净图基础上，**逐个加入真实同构对**（干净 0 干扰 → +B → +远处真实对 → +更多），画"**正确率 — 干扰数**"曲线。好处：干扰都是**真实存在的矩形对**，不受"干净图抹多少"歧义影响，还能同时回答"干扰影响多大"（量级）。这正是 plan 实验 4 的雏形。

### 喂法（沿用实验 1 双会话结构）
- 会话 A（编码）：圈定 A（标注图）+ `p0_crop_A.png` → 产节点 N。
- 会话 B（辨认，fresh）：`exp1_clean.png`（干净图 / 各干扰档）+ N → 求坐标。
- 对照组 = 实验 1 现状 6 轮（辨认用原 `pano_800.png`）。

### 判读
- 干净图正确率 ≫ 现状 → 干扰是主因；
- 干净图正确率 ~ 现状 → 干扰非主因，编码缺锚是主因；
- 渐增曲线：正确率随干扰数单调下降与否、下降坡度 → 干扰影响的量级。

## 补-2｜A、B 并排自由总结，测判别特征

> 用途（YZ 补充）：自由发挥时**不给全图**，只给目标 A 和另一图 B——这样**位置信息不可迁移**（无全图），节点只能带"判别特征"，测它能否单独救辨认。

### 目的
喂判别性锚（A vs B 对比），**刻意扣掉位置锚**，单独问"光有判别特征、无位置，辨认行不行"。
- 若辨认能**挑对类型/排除 B**，但位置仍散 → 判别特征有效，位置锚是另一道坎；
- 若连类型都乱 → A、B 差异小/总结仍泛化，印证"节点太泛"是编码口径问题。

### 喂法
- 会话 A（编码）：**A、B 两 crop 并排/相邻摆放**（用 `p0_pair_AB_side.png`），给"自由总结"指令：
  - Prompt（**必须交代哪个是要记住的目标**，由我们定位焦点、差异留给模型自己总结——plan 硬纪律 1 允许"谁是谁"标注，只禁"泄漏差异本身"）：
    - "左边这张是要记住的目标，右边是另一张（用来对比）。请自由总结**左边区别于右边**的特征（形状、交叠方式、谁朝哪），作为辨认依据。"
  - **不画 "A"/"B" 到图上**（说明文字放 prompt 里），守住答案中立。
  - **不给全图** → 无位置锚。
- 会话 B（辨认，fresh）：`pano_800.png` + 节点 N → 求坐标。

### 判读
- 找对类型（能指出"A 型"）→ 判别有效；
- 找对位置 → 判别 +（隐含位置映射）都成立；
- 都乱 → 判别/区分度不足，需回编码。

### 与实验 3 的关系
补-2 正是实验 3"提取并排 vs 大图内比"的**并排摆法**，只是先用来拆实验 1 的归因。做完补-2，其实就为实验 3 的 Arm-B 定了呈现方式。

## 顺序建议

1. **先做补-2**（成本最低，复用 `p0_pair_AB_side.png`，能直接切开"判别 vs 位置"）；
2. 再做补-1（含渐增干扰，需先做"干净图"与"各干扰档"）；
3. （可选兜底）锚信息节点版：步2 引导"位置+比例+邻居关系进节点"，测位置锚复活。

## 归属候选（跑完再定）

- 补-2 判别有效 + 补-1 去干扰大幅变准 → 干扰与判别双缺口，皆属**经验/记忆层自长**，范式不背锅。
- 补-2 判别无效 / 补-1 去干扰仍不准 → 触碰**编码信息**与**隔离机制**，范式需重审。
