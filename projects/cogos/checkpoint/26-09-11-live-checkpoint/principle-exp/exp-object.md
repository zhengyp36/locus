# 实验 对象｜对象表征：纯特征跨消息重定位（独立对象 + 过程归因）

> 2026-09-06 晚。上游：exp-1（回填 A 半留 B 半空）、exp-2（判别未激活）、本会话（probe-count 装置证明 + 对象表征设计定案）。
> 定位：**验证理论 + 过程记录归因**，不是命中率对比。核心问题从"怎么补锚"改为"对象定义本不含锚，测纯特征能否独立辨认"。

## 一句话

用干净特写把目标编码成自包含 `<object>` 描述（无位置、无锚、无环境），跨 fresh 消息在陌生全景里辨认。**观察模型把什么当成对象的身份**，以及命中/不命中各因什么，从而验证"对象是否天然与环境分离"这一理论。

## 本会话已定案（交付给新会话，勿再讨论）

1. **对象表征形态**：`<object id="A">自包含描述</object>`。`id` 只当句柄（不承担绑定），绑定职责全给内容。
2. **编码输入 = 干净特写 `p0_crop_A`**（纯特征、不含位置、无红框污染）。指示物与特征来源必须分离：标注图 `p0_mark_A` 仅作指示，**不得**用于特征提取（红框/红字会污染并引入幻觉）。
3. **不提醒锚/位置/判别**，模型自由发挥——提醒=注入，会测出"我教的"而非"模型自身的"。
4. **主实验辨认段默认"不说"**（不给"目标可能出现在任何位置"），测默认行为。它是一个**观测点**：若模型自动分离对象与环境 → 理想结果；若做不到 → 追加"说"作对照臂（下一变量，不预设）。
5. **实验目的**：基于观察它能否命中，再通过过程记录解释命中/不命中原因，验证理论；**不围绕命中率**。

## 理论假说（本实验要验证的）

- **H1 对象跨消息稳定**：对象须独立于消息（图号是消息相对的），靠自包含描述容器承载才可在 fresh 存活。→ 结构 + 冒烟初证。
- **H2'（锚归因，已改写）**：对象定义本就不含锚（位置是环境属性，非对象属性）；测"纯特征是否独立、够不够辨认"，而非"锚缺不缺"。干净特写 = 剥离位置的对象，是最纯的对象定义。
- **H3 概括 vs 锚能否共存 / 模型是否天然分离**：自由态下模型把什么当对象身份——只讲身份性（形状/交叠），还是仍掺位置/语境（说明它未理解"对象定义不含位置"）。
- **H4 判别是否倾向激活**：换独立对象 + 容器后，判别是否更常激活。

## 冒烟（已跑，证明通路 + 暴露问题）

- 脚本：`/tmp/kilo/vision/order_probe/probe_object_smoke.py`（单轮，零提示）。
- **smoke1（编码含标注图 `p0_mark_A`）— 污染**：模型把红框+红字"this is A to remember"当目标特征；且辨认段在干净的 `pano_800` 里幻觉该红字去匹配（污染误导定位）。落点 0.535,0.515，距GT 0.060。
- **smoke2（编码仅干净特写）— 通过**：tag `两个圆角矩形重叠，左小方右大长方，浅绿背景`，无污染。辨认 0.585,0.512，**距GT 0.010 命中A**。
- 结论：**对象=自包含描述 tag + 零提示 + 干净输入，这条路通**（单轮即命中）。剩余是"内容精度是否能在同构对间唯一锁定"及"模型是否分离位置"。

## 主实验计划（新会话据此跑）

**研究问题**：模型对干净特写自由编码成 `<object>` 自包含描述后，跨全新上下文、在无标注全景里，能否凭这段描述把目标从多个同构对中辨认并定位？过程里它把"什么"当成对象身份？

**喂法**：
- 编码A（fresh）：`[system: 容器格式]` + `[user: p0_crop_A]` → `<object id=?>…</object>`。
- 辨认B（fresh）：`[user: 注入该 tag + pano_800]` → 中心坐标 + 命名/判断对象。
- 全程零提示（不写位置/锚/判别，辨认端不给"可能在任何位置"）。

**条件**：单臂 6 轮，temperature 0.2，每轮 clean history、独立 out-dir（`n{1..6}`，与 exp-1/补-2 可比）。

**过程记录字段（每轮必记，供归因）**：
1. tag 全文；
2. **身份定义是否含位置/语境段**（如"位于xx附近"）——若含，说明未把位置剥离出对象身份；
3. 判别成分是否可区分同构对（yes/no）；
4. 辨认坐标、误差；命中（dist<0.05）/近（0.05~0.10）/错（并分类：真实同构对/B/幻觉）；
5. 匹配度：辨认选择 ↔ tag 描述是否自洽。

**判据**：见上。核心看"模型把什么当对象身份" + "归因命中/不命中"，非命中率本身。

**产物**：`summary.json` + 每轮 tag/坐标 + 逐轮裁剪核查 `verify/runN.png` + 可视化。

**关键文件**：脚本 `/tmp/kilo/vision/order_probe/probe_object_smoke.py`（可扩成 `probe_object_exp.py`）；素材 `pano_800.png`、`p0_crop_A.png`；GT A=(0.595,0.512)、B=(0.044,0.680)。

## 待观察的分叉（记录为后续选项，不预设）

- 主实验"不说"，若模型默认能自动分离对象与环境 → 理想，收束；
- 若做不到（掺位置/语境，或辨认依赖位置）→ 追加辨认端"目标可能出现在任何位置"作对照臂，测提示松绑是否有效。
