## ② 自验证方法论（核心产出，YZ 主张）

**主张**：模型不是程序，方法多样（等差也是合理思路），缺的是**自验证/自纠闭环**。任何任务应包含：先定义"怎么算正确完成" → 规划 → 做 → 验证 → 不过重规划 → 反复不过则上报失败并总结。

**循环（状态机）**：
```
任务 = 目标 + 判据 C + 预算
  定 C + 验证计划 V（动手前） → 规划 → 执行 → 验证(主动找反例) → 裁决
     pass(证据充分) → 交付，附证据 + 残余不确定
     fail → 回规划（假设错才重规划；执行误差才调参）
     undetermined → 先升级观察，升级不了 → 失败
     反复不过 / 预算尽 → 失败上报 + 过程总结
```

**三条硬规则**（对着实测踩的坑）：
1. **判据先于行动**：动手前声明，禁止按结果倒改（否则退化成 rect 那种"看着差不多"）。
2. **验证是"找反例"，不是"找看着对"**；且必须在**能暴露误差的尺度/通道**上做。
3. **失败/undetermined 是一等结果**，有专用出口；不许用自信陈述盖过未通过的判据。

**判据边界**：只写结果的**可观察属性**（如"框四边贴住目标文字、不压邻居""点落进可点带"），**不写步骤**（写了就回到"指定方法"的伪结论，越界）。

**验证独立性**：换尺度/换通道重观察（产生靠估读、验证靠放大看边，或程序给独立测量）；**忌讳把刚生成的表示再读一遍**（恒等换算什么都验不出）。

**责任边界（人类类比）**：自审是"尽责"不是"万能"；交差即"已自审"，下游有无审查是另一层、可选。故 `pass` 带证据+残余不确定；`undetermined` 是合法的对外申明。

**分层**（不违反"方法自由"）：
- 工具层 = 手段 + 不变量（坐标基、ID、clamp），**不含方法论**。
- 通用方法论 = agent 的**操作契约，常驻 system-prompt**（与任务无关）。
- 成功判据 = **任务层**实例化（任务相关）。
- 看门狗 = **过程工具/agent 运行时**，非任务工具。
- 定位：注入方法论 = 把"模型"变成"agent"（自己当指派方：分析/规划 → 切执行方 → 完成切审判方）。

## ③ 随机看门狗设计（讨论成形）

**动机**：handoff-10 已证"换视角靠语言即可"（taskSwitch），但"方法论塞执行者 SYSTEM"失效（taskM 说/行不一致）。看门狗把视角切换**从自觉升级为结构保证**。

**能力边界（重要）**：看门狗解决**何时切**与**冻结判据**（open 时逼出 goal/criterion/verify_plan），**不解决判得准不准**。切到同一脑子/同一张全图渲染，照样自我确认（rect_h1/h2 即此）。"切换视角 ≠ 独立验证"：角色切换治"肯不肯查"，换通道治"查得到查不到"，两者正交。

**API 草案**：
- `watch.on(goal, criterion, verify_plan, budget)`：开任务，冻结判据与验证计划，开始计轮。
- 触发评审（四路并存，取 `min`）：① 随机 hazard；② **停滞检测**（重复动作/无新信息 → 立即，拦无限 zoom 与八次 adjust）；③ `close`（**请求裁决**，非结束）；④ 硬预算（最终 cap → 失败上报）。
- 触发时注入审判视角 + 精简过程摘要（做了什么、卡在哪、判据还差什么）；评审须产出裁决+证据，否则算空转。
- `close()` 返回 `{pass(证据) | fail(原因) | undetermined}`。

**三段 hazard（YZ 定）**：`t` = 距上次反思的内层轮次，反思后清零。
- `t < t_lo`：p=0（冷静，短任务不打扰）
- `t_lo ≤ t < t_hi`：p(t)=(t−t_lo)/(t_hi−t_lo)（渐增）
- `t ≥ t_hi`：p=1（强制）
- 第三段给"反思间隔"设上界，是唯一带保证的一段；前两段解决不打扰+拟人。
- **实现推荐"每周期预采样到期轮 T"**（T 落 [t_lo,t_hi]、质量偏 t_hi，三角形分布），而非逐轮掷骰——给定 seed 可复现、检查点可审。
- `t_lo/t_hi` 建议绑 budget（如 30%/70%）；"轮次"起步用内层 LLM 轮。

**关键提醒**：随机化只解决"何时反思"，不解决"看不看得见"——仍需评审那刻换通道/放大表示。两个正交问题必须一起上。

3. **undetermined 处理**：先升级一次观察、仍判不了才失败？阈值？
