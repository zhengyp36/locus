## 显式化机制：当前定论（要点，细节见 `explicit-process.md`）

### 对象与形态
- **对象 = 整个流程 S1–S8 的运行状态**（不是单点证据）。形态 = **流程看板**：每步「状态 + 产物/证据 + 判定」。
- 状态：`pending | in_progress | done | blocked | failed`。

### 关键原则：没有角色，勾由产物推出
- **主体**：勾**就是模型自己打**——不存在"谁来打勾"（实验五已证"视角/角色"不是变量；§一 口径更新）。
- **有效性**：勾算不算数，**由"勾有没有挂在结构化产物上"决定**。`✓` 是**产物的函数**，不是自报；无产物 = 空 ✓（空转）。
- 三件：**触发**（走到这一步）+ **结构化产物**（凭什么算完）+ **状态由产物推出**。**没有第四方。**

### 两层分工
- **流程显式**（骨架＝看板）：知道自己在哪一步。
- **产物显式**（载荷＝证据）：这一步凭什么算完。
- 缺一即退回模糊。

### 内容如何定：派生规则
- **核心命题**：内容不用"填"，是**刨出来的**——由上一格产物派生；**主体性不重要是结果（规则确定），不是前提**。链条：
  `G → C（带阈值+参照来源）→ E（C 逐条展开）→ verdict（C×E）→ 分析（E 形态→类别）→ 动作（类别→策略）`
- **schema 固定、值实例化**：字段由通用契约定（任务无关）；值由任务层从 C/G 填。
- **派生规则 v0**：
  - **R0 外部输入清单**：列出需**指派方**供给的格（任务 G、预算、参照来源选择），标 `谁给/初值/可否续`。
  - **R1（S1）**：每条 C = `{可观察量, 阈值, 参照来源}`；缺一不得进 C（标 `blocked` 回炉）。
  - **R2（S3）**：`E=μ(C)`：每条 C 一行 `{条目,测量值,参照值,Δ,尺度}`；无参照 → `E=∅`。**每行须标参照来源** `{外部测量|人给|自身}`，"自身"=弱证据。
  - **R3（S4）**：`verdict=f(C,E)`：某条 `E=∅` → `undetermined`；全 pass → pass。
  - **R4（S6）**：`类别=g(E 形态)`，类别集固定（执行误差/前提错/判据问题/无解）。
  - **R5（S7）**：`动作=h(类别)`。
- **确定度分层**：S3/S4 可唯一派生；S6 半机械；S7 最开放。**别硬做全机械（假精确）。**

### 预算 = 协商产物 · 动态（本会话新定）
- **初值靠协商**：指派方问"要多少+依据"→ 模型**提方案**（可证伪，非裸数字）→ 指派方评审（接受/还价/封顶）→ **定格**。→ 本质是一次**事前对齐**（§5.4），**预算协商 = open 闸的实例**。
- **信息分工**：模型握任务难度（近端）、指派方握期望/成本（远端）。
- **对账点续期**：模型 `申请续期(N′,理由+证据)` → 指派方 `批准/终止`。
- **硬约束**：模型只能提方案，不能批预算；定格值不得单方更改。无指派方时初值即硬上限。
- **本实验取值**：目标=完成任务+验证理论 → **预算给宽**（须标记：宽预算下"完成" ≠ "会省着花"的证据）。

### 经验层（积淀）：留接口，暂不实现
- **S1** 召回"相似任务历史档案"作预估锚；**S8** 落一条任务档案（签名/规模/实际花费/结果/偏差）。
- 边界：历史是**参考非决定**；冷启动退化纯协商；"相似"要有判据。
- 归属：预估变准属**经验缺位，机制不背锅**（同 `plan.md`「通路 vs 经验」）。
