# 视觉"信息回填"原理验证计划（principle-first）

> 2026-09-06。上游：handoff-2 / checkpoint-19 / checkpoint-20。讨论最终收敛为：先证**原理**、证通再想**机制**。本文件是新会话的执行入口——只看本文件 + 材料路径即可跑，无需回溯本会话上下文。

## 一句话

不验证机制（模型怎么抠图、切注意力），只用**静态准备好的视图**验证范式原理：信息回填留不留得住、锚独不独立、并排对比是否更易找差异、多图/模糊背景的干扰规律。

## 执行流程与验收节奏（每一步都要 YZ 验收，含 P0）

- **每完成一步（P0、实验 1、实验 2…），停下来并不做下一步。**
- 用 `tools/feishu_notify.py "<文本>"`（默认 YZ）通知 YZ 来验收，文本写明：这一步做了什么、得到什么（附产物路径）、我的判读、悬而未决点。
- **YZ 加入讨论 / 质疑，经不起推敲就改；YZ 点头通过，再做下一步。**
- 未通过前不自动推进；"下一步"由 YZ 确认后启动。

## 硬纪律（防止被结果带偏）

1. **答案中立**：准备的视图只体现布局/模糊/标注（谁是谁、哪两物并排），**不泄漏差异本身**；否则测的是读题不是视物。
2. **匹配度判分**：主判据是"模型的选择 ↔ 它自己中间那步回填总结"是否自洽，不是"找没找对目标"。避免把"总结不准"误归为"回填坏"。
3. **实测真值**：目标/干扰物坐标用边缘检测实测，不凭肉眼/文字声称。
4. **通路 vs 经验归因**：
   - 回填留不住 / 锚不稳 = 范式问题（需重审）；
   - "找差异 / 注意力"挂 = 经验缺位（记忆层自长），机制不背锅。
5. 每轮**清 history**、独立 out-dir，防覆盖（沿用 `--out-dir <新目录> --history <其内文件>`，跑完改名）。

## P0（先做，卫生）

1. 从 `pano_800.png` 选一个**真实存在、与 A 相似显著度**的矩形对作干扰物 B，实测其 GT（`(x,y,w,h)` + 中心）。**禁止人工画 decoy**（T1.6 教训）。
2. 生成 A 的紧密高清 crop、B 的紧密高清 crop。
3. 备用：A、B 并排"对比视图"，以及模糊背景变体（模糊是为了当锚却不抢注意力）。

## 实验 1｜C3b 信息回填（总闸，最先做）

- **原理**：看清一块后，理解回填成节点，**高清图不在场**仍能唤起并指认。
- **喂**（静态三步）：
  1. `[全图 + 圈定 A + 文字"这是要记住的"]`
  2. `[A 高清 crop + "看清它"]` → 让模型产出**总结**（记录，作为中间结果）
  3. `[只给全图, 不给 crop]` 问"A 在哪 / 是哪个"
- **测**：主要看**匹配度**（第 3 步的选择 ↔ 第 2 步的总结是否一致）；位置 + 实测真值作次要佐证。
- **读**：
  - 匹配高 + 目标对 → 回填成立；
  - 匹配高 + 目标错 → 总结/找差异不准（**回填没坏**，机制不背锅）；
  - 匹配低 → 回填/编码坏（真问题）；
  - 明显要图才能答 → 图像回填倾向（需 A 层图在场）。

## 实验 2｜C4 锚独立

- **原理**：回填后的锚，换窗口/引入真实干扰后**不被覆盖**。
- **喂**：沿用实验 1 流程，但在第 3 步前**插一步干扰**：`[B 的高清 crop + "看这块，与 A 比是什么"]`，再 `[只给全图]` 回测 A。
- **测**：只过 B 后找回的是 A 还是 B（被带走与否）、匹配度。
- **读**：
  - 被 B 带走 / 丢 A → **锚不独立**；结论 = 需要机制层强制锚兜底（这是"通路"该补的，**非范式错**）；
  - 稳找回 A → 锚独立，信息回填自足。

## 实验 3｜对比形式：提取并排 vs 大图内比

- **原理**：两物并排（各自抠出 + 贴图标"左=\(A\) 右=\(B\)"）比"在一张大图里找差异"更容易看出差异（验证是否与人的直觉一致）。
- **喂**（两臂）：
  - Arm A = 整张大图 + 文字"对比图里 A 和 B"；
  - Arm B = A、B 各自抠出并排/分开放（可选配模糊背景当锚）+ 贴图标注。
- **测**：差异找出的正确率 / 差异点质量。
- **读**：
  - B 明显优 → "提取并排"对模型也成立，实验 1/2 的展示方式用 B 的摆法；
  - A 优或持平 → 该假设存疑，需换对比呈现。

## 实验 4｜未知量：多图干扰、模糊背景

- **原理**：多图干扰随图数单调递增（量级未知）；模糊背景能当锚却少抢注意力（未知）。
- **喂**：同一组对比任务，只翻两个变量——图数（仅 A、B 两图 vs 再多塞几张无关图）；背景（模糊 / 干净白底 / 原背景）。
- **测**：差异找出率。
- **读**：得到两条量级曲线；它们决定"这条对比通路是否好走"。**必须实测，不能拍。**

## 顺序与依赖

1 → 2 → 3 → 4。**1 是总闸**最先做；**3 比 2 和 4 早**（2 的干扰步、4 的背景调优都取决于"怎么把两物摆出来"），2 用 3 定的摆法，4 最后精调。
