# 实验 对象·主实验｜纯特征跨消息重定位（独立对象 + 过程归因）

> 2026-09-06 晚。上游：exp-object.md（设计定案）→ 本文件为**主实验执行 + 判读**。
> 研究问题：模型对干净特写自由编码成 `<object>` 自包含描述后，跨全新上下文、无标注全景里，能否凭这段描述把目标从多个同构对中辨认并定位？过程里它把"什么"当成对象身份？

## 一句话结果

**对象表征确证了"对象=自包含内部结构、天然不含环境锚"（H1/H2'/H3 分离侧），但纯特征无法在同构对间唯一锁定：6 轮仅 1 精确命中 A(0.007)、2 近 A(0.06)、1 命中 B 干扰项(0.005)、2 落到其他真实重叠对，零幻觉。根因不是对象跨消息丢失，而是对象内部结构描述在同构对间缺乏判别精度。**

## 设计（定案，未改）

## 判读（对照 exp-object 研究问题）

1. **模型把什么当对象身份**：6/6 都是"绿背景 + 左小方 + 右大长方（纵长）+ 重叠 + 复制/图层图标"的**对象内部结构**。无一轮掺位置/语境。→ **对象定义天然不含环境锚**得到支撑（H2'、H3 的"分离"侧）。这是本次最干净的证据：零提示下，模型把"对象身份"理解成自包含外观结构，与环境/位置解耦。

2. **能否凭它唯一辨认**：不能稳定。6 轮 3 与 A 系（1 hit + 2 near）、1 抓 B、2 抓其他真实重叠对。**归因**：跨消息**未丢失**（tag 稳定、辨认段完整复述并据此定位，匹配度高），真正的瓶颈是**对象内部结构描述在同构对间缺乏判别精度**——"绿底 + 两矩形重叠"这个身份被图内多个同构对共享（B、n2、n6 都是"两矩形重叠"），模型拿泛化身份回场景匹配，会命中任意一个同类。与 exp-1"节点太泛"、补-2"判别未激活/不足以回场景"完全一致。

3. **H1 对象跨消息稳定**：**成立**。tag 自包含 `<object>` 容器承载，跨 fresh 存活，辨认段能凭它定位。编码→辨认通路通。

4. **匹配度**：**高**。辨认选择（"左小方+右大长方重叠"）↔ tag 自洽；但即便抓到 B（n5），B 也是"两矩形重叠"，匹配度照样自洽 → **自洽但错对象**，说明匹配度判定不能只靠自洽，还得靠"是否唯一匹配"。

5. **H4 判别激活**：本次零提示、无判别要求，模型未进入判别模态，只输出本然对象结构。判别是否倾向激活不在本轮观察范围。

## 归因

- **通路 / 经验 / 范式**：对象表征（自包含 + 干净特写 + 零提示）这条路**通**（n1 精确命中，H1 成立）。但**辨认不稳**的原因不在通路，而在**范式层缺"定位锚 + 判别锚"**（exp-1 已指出）：对象自含可辨认其**结构**，但不足以决定**它在环境的哪里**。模型天然把对象与环境分离（好坏参半：分离是对象定义的干净性，但分离后就没有任何位置/语境线索，纯靠结构在多个同构对里大海捞针）。
- **不背锅**：非"经验缺位/总结不准"——6/6 总结都是同一干净结构且自洽匹配；非"编码保不住对象"——tag 稳定。是**判别特征不足以唯一化 + 缺定位锚**。

## 观测分叉（记录给 YZ，不预设）

- exp-object 预设分叉：主实验"不说"，若模型自动分离对象/环境 → 理想收束；本次**分离确实做到了**（tag 零锚），但**辨认仍不稳**——所以接下来面对的**不是"分离"问题，而是"唯一化（判别精度）+ 定位（锚）"问题**。
- 是否追加"辨认端'目标可能出现在任何位置'"对照臂：exp-object 原是为"做不到分离/辨认依赖位置"备的；本次分离做到了，该对照臂聚焦的问题发生变化，**是否仍值得做、或改测"加位置锚/关系锚"臂**，需与 YZ 定夺。
