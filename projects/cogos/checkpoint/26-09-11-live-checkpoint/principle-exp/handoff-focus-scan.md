## 一句话状态 + 结论

**核心假说（已获多组证据支持）**：模型缺的不是"判别能力"，而是"**在杂乱场景里扫描-聚焦-隔离目标**"的视觉注意能力（类似人眼的 saccade-and-fixation）。判别、锚、对比都**不是**瓶颈；瓶颈是**如何把目标从杂乱里扫出来、聚焦到一个局部去核对**。

**收敛结论**：实现"真正意义上的聚焦与扫描"（机制层）是下一步要讨论的方向，而不是再在当前表象层堆 prompt 验证。

## 证据链（结论来源，按强度）

| 实验 | 场景 | 结果 | 含义 |
|---|---|---|---|
| 完整全景(杂乱多同构+文字) | 黑白目标 + 全景 | 抓 B(0.005) / 主实验多轮偏 | **隔离失败** |
| 干净 2 对象(A/B) | 黑白目标 + 只有A/B | 6/6 命中 A，主动排除 | **判别完好** |
| 干净 3 对象(A/B/n6) | 黑白目标 + 3对象 | 6/6 命中 A，并讲清每个不符 | **判别完好** |
| 候选分区·"一致"二分类 | 12候选逐个"是不是目标" | 全部判否（**含A**）| "一致"表述过严，A也被否 |
| 候选分区·"相似"粗扫 | 12候选逐个相似度1-5 | **A=5分召回**；相似组{A,B,cand3} | 粗扫召回成功，A没漏 |

**核心推论**：
1. 判别不缺：干净少对象下场场 6/6 全对，且能精细"描述差异/排除不符"。
2. 缺的是隔离/扫描：杂乱全景单次定位必偏（抓B），因为有多个同构对 + 文字干扰，模型只能"整体印象匹配"。
3. "一致"二分类会把目标也否掉（A被否）；用"相似粗扫"（先粗后细、高召回）A 才被召回——**分阶段（粗扫召回 → 细判区分）是对的方向**。
4. ①粗扫召回（12→{A,B,cand3}，A在组内）②细判区分（{A,B} 时 6/6 判对A），两步都是通的——**组合起来即可在杂乱全景找对A**。

## 下一步方向（新会话讨论：如何真正实现聚焦与扫描）

不要再跑表象层 prompt 验证。讨论/设计"机制层"的聚焦-扫描。可选思路（供讨论，非定案）：
- **人工注入局部化**：分块/滑动窗口/候选裁剪，把模型注意力缩到局部（本会话方案C 已证候选裁剪可召回A）。
- **模型自聚焦**：让模型逐步"圈区域→放大→核对→排除"（工具自治循环，plan 里的方案A diagnose.py，之前刻意绕开）。
- **表示一致性问题**（本会话新发现）：目标图（6x 高清特写轮廓）vs 候选（全图低分辨率小窗口）**尺度不一致**会导致匹配失败（"一致"时A被否、需"相似"才能召回）。真正聚焦时需解决"放大示意 vs 实际小对象"的对应。
- **附发现**：模型对 B 的相对位置描述跨轮不稳定（一会"右上左下"一会"左上右下"），低分辨率+粗扫下会漂，细判需可靠方式定准。
