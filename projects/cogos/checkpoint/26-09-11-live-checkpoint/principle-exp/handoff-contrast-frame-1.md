1. **逐项局部 mark（精确提示词）有效**：C1/C2 均\|Δx\| = 2.6 / 3.1px（B1/B2 为 7.3 / 8.3），均匀累积消失。真凶=均匀假设获证。

4. **核心结论**：感知不是瓶颈；C 的 2.6px、D 的 11px 都是**过程误差**（绝对断言 / 全局假设），远高于感知底。**对比帧（相对判别）能逼到感知底**。

## 讨论结论（本会话概念层，重要）

- 理论「模型 drive、环境 judge、自驱闭环 = 可验证反馈 + 结构门禁」**未证**，只证边界；静态截图不产后果，环境无从判。
- 「遵守规则」vs cogos 理念不矛盾，是**约束位置**问题（过程 vs 结果）。
- **模型按字面执行，不按意图执行**；"不守规则"常是我们的话被字面理解成了另一件事。
- 判据（写规则后自问）：**"照字面做会不会仍落到不想要的结果？"** 会 → 规格/描述问题，改提示词；不会但它仍不做 → **边界冲突**，提示词解决不了，要结构。
- 边界冲突机制：不是"倾向 > 规则"，而是**缺省目标（推进到完成）每步都在，孤立规则无后果、不给对立动作**；规则**服务于**目标才被遵守，**对抗**目标则需后果支撑。
- **结构门禁 ≠ 可验证反馈**（D 组证明）：门禁管"动作能不能做"，反馈管"动作对不对"；二者不可互替。

- **D1 现象**：门禁拒了 6 个（`raw.jsonl` 搜"门禁"，共 6 条，stdout 不打印 tool error），模型改开 7 个局部视野，但对每项套用**同一常数左偏 ~23px**（≈窗口宽 0.28），而窗口中心自带均匀误差（间距 61px vs 真值 ~55px）→ 左端过冲、右端不足。
- **D2 现象**：开了局部视野，但填的坐标仍是整图网格（Δ 与 B1/D0 逐位相同）。

### 离线 2AFC 标定（`calib_afc.py`）

做法：目标项附近渲染红(t−δ)/蓝(t+δ) 双十字，δ=5px，扫中点 t 相对真值中心的偏移，问"哪个更接近字形块中心"。答右 ⇔ 感知中心在 t 右。PSE=感知中心。

细扫（offsets −4,−2,0,+2,+4；2 项 × 6 reps = 12 次/点）：

| 中点偏移 | 工具(T) P(右) | 查看(V) P(右) |
|---|---|---|
| −4px | 1.00 | 1.00 |
| −2px | 1.00 | 1.00 |
| 0 | 0.00 | 1.00 |
| +2px | 0.00 | 0.83 |
| +4px | 0.00 | 0.00 |

- **分辨率 σ ≈ 1–2px**（logistic 斜率 ~1/px；曲线跨度 ~2px）。
- **偏差分项**：工具(T) PSE ≈ −1~−2px（偏左）、查看(V) PSE ≈ +3px（偏右）；pooled PSE ≈ 0。粗扫（±10,±5,0）同向：pooled ≈ −1px。
- 大偏移（|10|px，两十字均远离文字）噪声大、偶发非单调。

## 未决 / 下一步：在线闭环（本交接任务）

**设计草案**：
1. 模型给候选位置 `p`（或先粗定位得到 p）；
2. 环境渲染对比帧：十字对 `p` vs `p±δ`（哑渲染，不判对错）；
3. 模型判"哪个更接近目标中心"（判别式输出，非绝对断言）；
4. 按阶梯/二分缩 δ 迭代到收敛；
5. 判据两轴：① 最终坐标 vs 真值（能压掉多少过程误差，目标 ~2px）② 收敛轮数 / 是否稳定。

**纪律**：**对比策略由模型定**，环境只提供对比帧（否则又变成"把规划外包给程序"，重蹈镜筒前作废层的老路）。

**未决点（待 YZ 裁决）**：
1. `compare` 是否固化为 `image_ctx` 哑原语，还是先用脚本跑通在线闭环。
2. 分项 ±3px 系统偏差：在线闭环只能回到"模型感知中心"，消不掉绝对偏差；是否需要外部锚 / 任务措辞校准（如明确"含括号整体中心"）。
3. 初始定位（窗口选取，D 组的失败点）与细化（2AFC 强项）是否分两段处理。

**建议起点**：脚本级最小闭环，先确认"模型驱动 + 环境出对比帧"能收敛到 ~2px；成了再决定是否固化成工具。
