本文件登记视觉功能讨论（意图工具 + 消息合并压缩）过程中出现的遗留问题。每问题一条，含背景/问题/现状/方向。

## 遗留-1：边缘信息保留但不在主 LLM 上下文，召回机制未定

- **背景**：讨论"工具调用与结果合并成一条"时，决定压缩掉主 LLM 上下文里的非必要过程信息。
- **问题**：像"已打开 `task.png` 这张图"这类**边缘信息**（过程性元信息）——主 LLM 对推理而言不需要它出现在上下文（对推理无意义），但它有保留价值（主 LLM 应该"知道"它打开了一张图，而不是假装图凭空出现）。如何保留、以及未定**如何把这条边缘信息召回主 LLM 上下文**。
- **现状**：未给方案，挂起。
- **类比**：人一样——边缘信息我不关心、不占用注意力，但我知道它在那里；需要时可被召回。
- **方向（未定）**：倾向"保留但不在主上下文"，召回手段（何时/以什么形态注入主 LLM 上下文）待设计。
