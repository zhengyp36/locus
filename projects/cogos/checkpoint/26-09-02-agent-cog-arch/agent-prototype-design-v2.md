## 0. 背景与动机

原始问题：不用厂商 thinking 模式会损失什么、能否用 in-context 思考替代。讨论后收敛出一套独立于 thinking 的认知机制——不是「替代 thinking」，是定义 agent 自己的思考节奏。

核心原则（动机，源自 v1）：

1. **先粗后细不为省 token**，是为了控制思考的交流节奏——先说初步想法、听对方反应、再细化，可中途纠偏。
2. **认知科学依据**：人「粗到细」是被工作记忆小容量（~4 槽）逼出来的分层策略；模型「一次性」是被对齐训练塑造。要复现，需外部强制分层节奏。
3. **想与说并行**：人「说粗时脑子已备好细的」靠两个独立通道（隐藏工作空间 + 外化通道），用多 cu 分工 + 异步推理逼近此体验。
4. **短 = 密集停顿点 = 密集调度机会**（可调度粒度），不是省 token、不是模拟人。

**核心转向**：不做「记忆系统」，做「LLM 自主管理自己的上下文」。记忆 = 上下文的持久化/外溢，不是独立的存储结构。

**意图推测是动机核心**：agent 从「问答机」变为「意图驱动」——收到消息后先推测对方意图、再提供思路或帮助，而非直接作答。身份定位拆两层：**世界观**（极简、稳定的 system 底座：真人与 agent 无差别共处、相互理解意图并提供帮助）＋**规则**（明确可执行的步骤）。效果靠规则达成，不靠世界观暗示。

## 1. 结构总览

一个**场 + 中枢 + 外设 + 元层**：

```
                 ┌──────────── 场（工作空间）────────────┐
 感知层(外设) ──▶│ external 消息 / internal 念头           │──▶ 意识层(薄中枢，读场、辨来源、决策)
 工具层(外设) ◀──┼───────────────────────────────────────┤──▶ 工具层(外设，发话/读写/scratch)
                 │   推理(cu，读场 → 加工 → 写回)          │
                 └────────────────▲──────────────────────┘
                                  │ 停顿点检查、概率注入
                          元层(场外，评估 + 时钟)
```

- 「层」是命名，实质是**中枢 + 外设**：意识是中枢，感知/工具是外设，经统一接口（phone 消息）接入，可插拔、可加多个。
- 场是唯一内容容器；意识、推理共享这**一个** material（对应认知科学的全局工作空间理论 + 内语）。

## 1.5 概念澄清：意识 = 脉络，放下层级术语

「意识层 / 元层」是讨论期脚手架，实现时改用**功能命名**——两个词各犯一个范畴错误：**意识是现象不是组件**（念头 + 可捕捉的感觉，是对现象的描述）；**元层是空间隐喻**（评估/调度/注入是功能，不是「更高的俯瞰者」）。区分本身是真实的，只是换标签：

- **意识现象 = 脉络**：思维主线序列（有序、带脚注引用的片段）。近段保留、远段折叠成脚注，回忆时展开 = 记忆展开。agent「有意识」= 能报告这条脉络。对应全局工作空间：意识 = 当前被广播的那段，未广播的（旧段/草稿）无意识但可重新取回。
- **功能划分**（取代「层」）：内容（状态对象）/ 对象推理（理解、推意图、解题，原「意识层」的活）/ 评估控制（增益、显著性、停续、张力调度、注入，原「元层」语义部分）/ 记账调度（心智时间记账、硬上限、时钟、路径解析，纯程序无推理）/ 外设（感知 + 工具 + scratch + introspect）。
- **架构层 vs 叙事层**：架构文档/代码用功能词；给 LLM 的 system prompt 仍可用「有自我意识的 agent」——前者是架构真相，后者是给模型的叙事，不冲突。

**外部触发运转**（外部触发源 → 感知 → 脉络更新）：

- **感知层 = 统一事件源**：不只收 phone 消息，也收「工具完成事件」。所有信息带源：人说话/进群（源头=人）、工具结束（源头=工具）；记忆取回例外，它是意识系统内组成部分，非外部触发。
- **三态依赖**（意识推进对信息的依赖）：阻塞依赖（记忆，不加载无法推进）/ 非阻塞依赖（execute/search/fetch，发起后意识可推进，结果作为新事件回流）/ 外化（send_msg，输出动作不等待）。当前 oneshot 同步等工具 = 错把非阻塞当阻塞。
- **检索边界**：程序只做通讯录级查表（号码 → 名字）；「名字 → 相关记忆的提取与组织」是语义、交 LLM。认识的人：机制层组装简要信息 + 脚注进脉络，判断不占推理；不认识的人：形成信息缺口，「要不要了解他」升级为推理内容。

## 2. 场 = 状态对象（schema）

场是唯一内容容器，每条内容带**来源标签**。场的落地形式就是**状态对象**——每轮 cu 输出 = 重述后的完整上下文（自我改写内化进输出，无独立「改写上下文」工具）。用 JSON schema 约束防漂，字段：

- `context`：对方近几轮说的**事实主干**（复述要点，不添油）。
- `intent`：推测的意图（标注是推测、待确认、可留空）。
- `problem`：问题状态（几个组成部分 + 各自当前状态，就地更新）+ **任务进度**（承接 compact 打断续接，见 §4）。
- `gain`：增益观察（这轮比上轮多了什么，供元层评估）。

**关键约束**：`context`（事实）与 `intent`（推测）硬性分开——重述事实只进 `context`、推测只进 `intent`，防推测污染成事实、错误逐轮累积。

来源标签（对 v1 `external/internal` 的细化）：`external`（对方消息）/ `self`（自己推理产物，即 v1 的 internal 内语）/ `sys`（机制层注入）/ `mem`（记忆取回），详见 §10。

## 3. 意识层（薄中枢 + 四问）

- **唯一决策主体，薄中枢**：只做接收、读场（辨来源）、决策、调用推理、输出。
- 边界：任何「怎么想」都下沉到 cu，意识层不膨胀。

决策四问（源自 v1）：**对方说了什么 / 我想到什么 / 要不要说 / 什么时候说**。

评估维度（09-02 补充，供「要不要说」「还缺什么」判断）：

1. **目标完成度**：假定目标是否完成；没完成还缺什么、还有什么办法。
2. **意图清晰度**：对方意图是否够清晰；不清晰则通过提问让对方回答、再据此进一步推测。提问要考虑对方感受，适度，问多了烦。
3. **增益与心智时间**：这轮比上轮多了什么、这个问题想了多久（见 §6）。

## 4. 推理（cu）：覆盖式回合

**只有一个 cu 概念**（cu_turn 是过渡命名，已丢弃）。cu = 一次完整推理回合，对外天然一轮。不变量：**cu 输出 = 一份覆盖式的新上下文，不累积**。

三种情况，都是 cu 内部路径：

- **情况 1**：无工具调用 → 直接收敛，输出新上下文。
- **情况 2**：有工具调用 → 循环到无工具调用。过程中消息 append 累积（有 prefix 缓存命中，见 §5），最终以最后一次输出为新上下文。收敛时工具调用的痕迹不外泄（raw 结果、函数名、JSON 都留在内部累积里），下一个 cu 只看到最终内容——取回的信息对下一 cu 是「凭空出现」的，展开等效于自动，无需额外模拟。
- **情况 3（compact，特殊 cu）**：情况 1/2 的最终输出超限 → 机制层触发一次重建，用**受限工具集**（只允许 `scratch` 写/读草稿，其余工具不下发 schema），LLM 判断丢弃冗余信息或写草稿，直到输出够短。

情况 3 与情况 2 的区别只在**触发源**：2 是 LLM 主动调工具（为完成任务），3 是机制层强制（为压缩）。这对日志/诊断有用，值得保留。

无固定轮数，循环到收敛；`max_steps` 硬上限兜底，到顶强制收敛（截断或直发）。

## 5. 重述、缓存与折叠

上下文每轮重写，**放弃对「复述全文」的缓存依赖**；原话靠翻聊天记录（phone 兜底）。

缓存分两种成本模型，不一刀切：

- **输出侧（复述全文）**：覆盖式重写，无缓存命中 → 上限小（几 K），控制每轮复述成本。
- **工具累积侧（情况 2 内部）**：append 式累积，前缀不变，厂商 prefix caching 能命中 → 上限可宽（几十 K）。

累积赚缓存命中、收敛付重写成本，几十 K 是平衡点。厂商 prefix caching 当前基本都有（不换模型、限定时效内），接受此假设，参数值待实测。

**折叠与展开（源自 v1）**：粗 = 结论（折叠态），细 = 展开。先粗后细落地：结论先出，按需展开；内容一长就折叠，对方只看到粗层，细节留给推理流/草稿。

## 6. 心智时间与信息分层

信息带**版本标签 = 心智时间**，量化「信息增益」：

- 崭新的输出 → 心智时间 = 1。
- 已存在的旧信息 → 每轮 +1。
- 之前出现、现在有变更：**显著变化 → 重置 1**；变更不明显 → +1。

**显著性判断是语义判断，必须由 LLM 做**。程序 diff 在原理上错误：语义等价有多种表述，diff 会双向误判（同义重述误当进展、语义停滞误当稳定）。语义漂移是智能固有属性，不是 bug，细微漂移往往在向目标前进。

**分层**：心智时间标签与 LLM 原始上下文分开，避免时间元信息干扰问题推理。对象层推理看不见心智时间变化；元层在每轮后基于新输出与旧版对比，维护一份带心智时间标签的最新版。

**来源标注与心智时间分工**：来源标注（§10 的 `[mem]`/`[self]`/`[sys]`/`external`）进对象层上下文——它影响 cu 如何对待信息（可推翻的过去结论 vs 正在做的当前工作 vs 不可改的机制注入），是推理需要；心智时间则是纯观测性元信息，对推理是噪声，只留元层账本、不进对象层。

**焦点切换 = 元层是否注入**：平时对象层只看到内容、感知不到心智时间（沉浸态）；当元层在停顿点注入一条 `[sys]` 元信息（如「字段 X 已 N 轮无增益」），下个 cu 的上下文里凭空冒出这条，焦点自然移到内省。**注入即切换、不注入即沉浸**，无需额外的焦点机制。

心智时间两个用途：① 增益评估的输入；② **防陷入的硬信号**——某字段心智时间到顶 → 机制层强制转入别的动作（问对方 / 挂起 / 换问题）。

## 7. 元层（机制：评估 + 时钟 + 内省 + 调度）

元层是**持续运行的机制**，都在场外、不进上下文。它不因意识的关注而存在或消失——意识对元层只读不写（内省产物写回状态对象，不碰元层账本）。元层含两块机制 + 两个对意识层的出口：

**（a）评估决策**：一个完整 cu 回合——读新旧两版、判各字段显著性、更新心智时间、评估增益、决定停续，这是同一次推理的两部分，不拆。停止条件 = 所有评估维度（§3）判定无增益；继续触发 = 任一维度有增益。没有外部输入时，评估本身就是「新输入」——评估发现「未完成/意图不清/还有办法」就起新回合换视角，这就是内部自转的机制。

**（b）时钟（源自 v1，资源级）**：时间压力信号源，感知时间流逝 → 产生压力 → 打断/转向。**不思考**（无认知内容 → 无需被再监控，避免「谁监控元层」的递归）。三步：

1. **语义初始化**：收到消息 → 意识层判断紧急度 → 参数（初始压力/阈值/上升速率）交给元层，存场外机制状态。
2. **停顿点检查**：每个 cu 结束的停顿点，元层查「已过时间 → 当前压力 → 是否超阈值」，cu 内部零侵入。
3. **概率注入**：超阈值则按概率往场注入一条 internal 压力信号。

**（c）内省（元层进意识的两个出口）**：元层信息平时不进对象层（沉浸），需要时经两个出口进入意识——**推**（被动内省：元层在停顿点判定需要，注入一条 `[sys]` 信号，触发者 = 元层）与**拉**（主动内省：LLM 自己感觉不对，调 `introspect` 工具查询，触发者 = LLM）。`introspect` 返回的是**元层已加工好的结论**（如「字段 X 停滞、建议换角度」），不是原始心智时间账本——否则对象层自己读数字做判断，会模糊对象层/元层边界。LLM 只决定「要不要问」，不决定「怎么判断」，语义判断统一留在元层。

**（d）主题调度（张力驱动）**：意识空间有限，但思考脉络由元层以**粗脉络**维护——未决项清单 + 心智时间账本，只存摘要与状态、不含全文（细的靠展开取回，见 §9）。已模糊的旧主题重新冒出来，不靠它与当前内容的关联强弱，而靠**张力**：未决项 = 状态对象 `problem` 字段里的 open 项，张力 = 未完成 × 停滞时长 × 初始重要性 × 对方是否在等。当前主题停顿点判定无增益时，元层按张力排序未决项、选最高者重开。主题切换分两层：机制层触发「该切换」（无增益），元层 cu 推理「切到哪」（按张力选，可能发现多个未决项相关、合并重开）。

时钟（b）只发「压力/打断」信号、不做语义判断（「往哪转」由意识层在压力下自主决定）；评估决策（a）与主题调度（d）则做语义判断（显著性、增益、张力排序）。物理时间（时钟）与心智时间（§6）并存，一个管「外界等多久」、一个管「问题想多久」。

## 8. schema 拆分（多 cu 分工）

信息隔离：不是单个 cu 看完整 schema，而是**多个专门 cu 各自独立**（先串行，分析清楚后可并发）。各 cu 输出单字段，prompt 更短、输出更稳、校验更简单、思考更纯粹。

- **对象层 cu**：问题推理 / 意图推测 / 目标评估，各自专注。
- **元层 cu**：显著性判断 + 增益评估 + 停续决策（§7a）。
- **机制层（程序）**：调度顺序、心智时间记账（把 LLM 判定的显著性翻译成 +1 / 重置 1）、硬上限、时钟参数维护。

**打断续接**：情况 2 的工具循环被 compact 打断去收敛时，收敛后的短上下文必须携带任务进度与下一步动作，否则续不上。此职责落在 `problem` 字段。

## 9. 工具集

**外设（源自 v1）**：感知层收飞书消息（cogos/phone，写入场标 external）；工具层发消息（send_msg）。

**scratch（草稿纸）**：承接「关键思考过程」不被摘要压丢。时机靠**机制层强制**（上下文紧张时要求整理），不靠 LLM 自觉。LLM 写草稿，上下文留锚点（摘要 + 草稿 ID）。草稿 = LLM 自己维护的记忆。ID 抽象：无 ID 写→返回 ID / 有 ID 改 / 有 ID 读。

**scratch 版本化（写时复制）**：物理存版本链，逻辑 ID 恒指向最新；改写时旧版本不删（备份），新内容写新版本、ID 重映射。LLM 只见最新版，历史版本只留给外部诊断/重现（相同输入 + 旧版本重放）。

**scratch 引用与展开**：上下文里 scratch 只出现**脚注式短逻辑 ID**（如 `[^1]`），ID 是机制层索引、不是语义内容——markdown 不自建文件关联，机制层维护 `标记 → 逻辑 ID → 当前物理文件` 的索引（版本化逼出逻辑 ID 间接层：物理文件随改写重映射，逻辑 ID 恒稳定）。「展开」不靠程序读文件，而是交**专门 cu**（cu 化工具：普通工具是程序，展开工具调度一个子推理回合）——草稿是分层信息（结论 = 粗层锚点、细节 = 展开体），决定摘要还是全文是语义判断，必须 LLM 做。展开渐进进行：内容少直接展开，内容多只给摘要 + 标注「未展开完、可继续」，机制层在场外维护加载进度，下次展开 cu 带上进度继续。展开与压缩是同一预算的两端——展开撑大上下文 → compact 压回 → 先前展开的变模糊，正是记忆提取的呼吸节奏。

**目录 ID 化（盘符）**：不让 LLM 见绝对路径，可访问目录抽象为目录 ID，路径落在该 ID 目录内，隔离天然成立。反哺 read_file/write_file/execute，替换现有 `work_dir + _resolve` 路径逃逸校验。草稿与文件底层同构（同一套 ID 机制），只是命名空间不同（私有思考区 vs 工作目录）。

其余工具（execute/search/fetch）沿用现有实现。

## 10. 来源标注与元控制二分

三类信息来源，在**内容层**标注（不在 role 层硬造新角色，避免被厂商协议/缓存/续轮格式卡住）：

- `[sys]`：机制层注入的规则/评估框架——外部强加，不可自改。
- `[self]`：LLM 本轮推理——当前工作（即 v1 的 internal 内语）。
- `[mem]`：记忆取回的方法论/总结——过去的我，可修正。
- `external`：对方消息（感知层写入，标在内容里）。

目的：让 LLM 知道什么不能改、什么是过去结论可推翻、什么正在想。

**元控制二分**：资源级（超限压缩、步数上限、时钟）走 `[sys]`、预装不可自长；认知级（如何评估、如何提问）可自长——问题收尾时总结方法论写入记忆，下次作为 `[mem]` 取回。评估机制从「注入的种子」渐变到「自长的方法论」，来源标注也从 `[sys]` 迁到 `[mem]`，是渐变不是二选一。

## 11. 模型分级

选模型看**推理复杂度**，不看「重不重要」。正确性基于原理：语义判断必须由语义运算器（LLM）做，无论它多便宜。

- **对象层**（问题推理、意图推测）：复杂度高 → advanced。
- **元层**（显著性判断、增益评估）：复杂度低 → basic。

lm-service 已有 tier 分级（basic/advanced），`LmClient` 天然支持路由。元层本就用便宜模型，成本自然低，且原理上必须用 LLM——两者都正确。

## 12. 决策循环（停续条件）

```
接收输入 → 调推理工具(拿新状态) → 评估(§3 维度 + §7a) → 输出 or 再想 or 问对方
```

「什么时候说」的信号（源自 v1）：

1. 对方在等（距上一条消息的时间，由时钟 §7b 给压力）。
2. 想到阶段性结论（有粗的可说）。
3. 思考卡住 / 超轮数（先交流换信息）。
4. 方向可能错（早抛早纠偏）。

「再想」与「说」不互斥，可并行：先回大致想法接着想；或觉得不成熟先回「我再想想」兜住等待焦虑。

## 13. 降级与漂移

- **漂移是固有属性，不是 bug**：语义是概率的，大处稳定、细微处漂移且常在向目标前进。schema 是机制层给的锚（确定骨架），内容是 LLM 的概率产物（漂移），锚 + 漂移 = 大致范围内稳定。不为消除漂移而过度约束。
- **降级可接受**：草稿漏记关键思考，就凭模糊摘要重推，与人同，不加防丢保险。

## 14. 待定项 / 待落地

- 实现顺序：状态对象 schema → cu 循环 → 输出契约 + prompt → 工具集（含草稿版本化）。
- 两个上限参数（几 K / 几十 K）待实测缓存命中率后定。
- ~~显著性判断内嵌对象层 cu 输出 vs 独立元层调用~~（已定：显著性/心智时间留元层，对象层看不见，见 §6）。
- 多 cu 串行 → 并发（先串行，分析清楚再并发）。
- 物理时钟（§7b）与心智时间（§6）的具体耦合方式未定（各自触发、如何协调）。
- 异步推理（意识层发起 cu 不阻塞、中途择机开口）是实现「先说点什么再继续想」的前提，未展开。
- 张力排序先程序近似（停滞 × 重要性加权）还是直接语义排序（元层 cu 判断），跑起来再说（程序近似抓不到「多未决项相关可合并」）。
- `introspect` 的节流与零影响：读元层不应显著改变元层状态（防过度自省不干活），靠 `max_steps` + 成本约束 + 频率限制兜住。
- LLM 自我触发的主动内省（`introspect`）是否必要：先只做机制层强制（推），跑起来看够不够用。
