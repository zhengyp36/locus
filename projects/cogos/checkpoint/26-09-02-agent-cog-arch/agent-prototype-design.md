# Agent 雏形 — 认知架构方案

> 工程：cogos（多 agent 运行时，飞书通信总线）。本体 `../cogos`。
> 本文整合 09-01 下午认知节奏讨论的全部结论，是 agent 雏形的设计主文档。
> 过程记录见 `checkpoint-1.md`。

## 0. 背景与目标

原始问题：不用厂商 thinking 模式会损失什么、能否用 in-context 思考替代。
讨论后收敛出一套独立于 thinking 的认知机制——不是「替代 thinking」，是定义 agent 自己的思考节奏。

目标：让 agent 的思考像人一样**先粗后细、边想边说、可中途纠偏、按时机开口**，而非一次性完整输出。

## 1. 核心原则（动机）

1. **先粗后细不为省 token**，是为了「控制思考的交流节奏」——先说初步想法、听对方反应、再细化，可中途纠偏。
2. **认知科学依据**：人「粗到细」是被工作记忆小容量（~4 槽）逼出来的分层策略；模型「一次性」是被对齐训练塑造（无此生理压力）。要复现，需外部强制分层节奏。
3. **想与说并行**：人「说粗时脑子已备好细的」靠两个独立通道（隐藏工作空间 + 外化通道）。用多 cu 分工 + 异步推理逼近此体验。
4. **短 = 密集停顿点 = 密集调度机会**（可调度粒度），不是省 token、不是模拟人。

## 2. 结构总览

不是「多条流并行」，是一个**场 + 角色 + 外设 + 元层**：

```
                 ┌────────── 场（工作空间）──────────┐
 感知层(外设) ──▶│ external 消息 / internal 念头/压力  │──▶ 意识层(读场、辨来源、决策)
 工具层(外设) ◀──┼───────────────────────────────────┤──▶ 工具层(外设，发话)
                 │       推理(cu，读场→加工→写回内语)  │
                 └───────────────▲───────────────────┘
                                 │ 停顿点查压力、概率注入
                           元层(时钟，场外，不思考)
```

- 「层」是暂定命名，实质是**中枢 + 外设**：意识是中枢，感知/工具是外设，经统一接口（phone 消息）接入，可插拔、可加多个。
- 命名冲突忽略：通信层与认知层相互独立。

## 3. 场（工作空间）

- 唯一的内容容器，所有内容放这里，每条带**来源标签**：`external`（外来消息）/ `internal`（内语·念头·压力信号）。
- 意识、推理共享这**一个** material，不存在「多流的 material 如何区分/分配」的问题。
- 对应认知科学：全局工作空间理论（Global Workspace Theory）+ 内语（inner speech）。

## 4. 意识层

- 唯一决策主体，**薄中枢**，只做：接收、读场（辨来源）、决策、调用推理、输出。
- 边界：任何「怎么想」都下沉到 cu，意识层不膨胀。
- 感知场内一切（外来 + 内语 + 压力信号），靠来源标签区分，就像「听到外来声音和内语」。

## 5. 推理（cu）

- **cu 是意识层按需调用的推理工具**，不是独立流。
- `oneshot=True`：不管有无工具调用只走一轮；有工具就执行完结束（不续轮）。cu 回归「单次 LLM 调用」。
- 工具调用的续轮/总结外移到**另起一个 cu**（同样 oneshot），保持逻辑简单。
- **cu 产出 = 一条「文档式结论」（念头）**，不保留消息原始形态（消息数组）：
  - 含前因后果，非摘要（summary）——去不重要的过程细节、保留重要信息与因果链。
  - 效果：每次 cu 后总得到一条想要的消息，不是消息数组。
- 工具结果：工具 cu 执行完结束，另起 cu 总结其结果为文档式结论。
- thread = cu1 -> cu2 -> cu3... 序列；意识层发起的 cu 序列即「念头流」。

## 6. 元层（时钟，资源级）

- 职责：**时间压力信号源**，感知时间流逝 → 产生压力 → 打断/转向。**不思考**。
- 无认知内容 → 无需被再监控（避免「谁监控元层」的递归）。
- 对应「元控制二分」的**资源级**（机制层，预装、不可自长）；意识层决策策略属**认知级**（可自长）。

### 6.1 时钟机制（三步，离散）

1. **语义初始化**：收到消息 → 意识层（或一个 cu）判断紧急度 → 参数（初始压力/阈值/上升速率）交给元层，存**场外机制状态**，不进上下文。
2. **停顿点检查**：每个 cu 结束的停顿点，元层查「已过时间 → 当前压力 → 是否超阈值」，**推理过程（cu 内部）零侵入**。
3. **概率注入**：超阈值则按概率（压力值决定打断概率，软阈值）往场注入一条 internal 压力信号。

### 6.2 边界

- 元层只发「压力/打断」信号，**「往哪转」由意识层决策**；元层不做语义判断（初始化判断由意识层做）。
- 不「删上下文」隐藏时钟——参数存场外即天然不占意识带宽。

## 7. 外设

- **感知层**：收飞书消息（cogos/phone），写入场（标 external）。
- **工具层**：发飞书消息（cogos/phone）。雏形阶段仅此一个工具；read/bash/edit 等后续按需加。

## 8. 决策循环（意识层四问）

```
接收输入 → 调推理工具(拿念头) → 决策 → 输出 or 再想
```

四问：**对方说了什么 / 我想到什么 / 要不要说 / 什么时候说**。

「什么时候说」耦合思考节奏与交流节奏，信号依据：
1. 对方在等（距上一条消息的时间）。
2. 想到阶段性结论（有粗的可说）。
3. 思考卡住 / 超轮数（先交流换信息）。
4. 方向可能错（早抛早纠偏）。

## 9. 折叠与展开

- 粗 = 结论（折叠态），细 = 展开。
- 先粗后细落地：结论先出，按需展开；内容一长就折叠，对方只看到粗层，细节留给推理流。
- 暂不考虑 token 消耗。

## 10. 待定项

- 文档式整理的质量是命门（丢因果→决策全错；噪音没去净→上下文膨胀），「规范化总结」值得单独设计。
- thread 内 material 传递规则（cu2 是否读 cu1 累积）未定。
- thread 推进权（推理 cu 自主走 vs 被意识层逐步推进）未定。
- thread 与现有 CogUnit 树语义的关系（取代 or 并存）未定。
- 意识层决策策略是死规则（资源级）还是可学策略（认知级）——未定，呼应元控制二分。
- 异步推理（意识层发起 cu 不阻塞、中途择机开口）是实现「先说点什么再继续想」的前提，未展开。
