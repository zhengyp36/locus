## 零、路线回顾（本会话开头）

底层三件 → 认知图封存 → agent 认知架构 → terminal/timer + agent 接 cu → **视觉** → **回路（自驱）** → **换帧/上下文组织**。

- **视觉是载体**：它用可控场景先证了一批可迁移通则——单次前向不可全信（需交叉验证）、模型视觉能力 > 思考、思考=非单调增益器、提示词不补像素；cog-func 范式（封装"理解"非"过程"、契约+约束+反馈、主体性=流动的调度权）；坐标换算收归工具（"壳只给事实、模型定策略"的原型）；复读/重做的根因在**上下文组织+反馈信号**而非模型能力。
- **回路**：自驱=议程更新函数 f（ΔA 驱动）；验证=判据谱系轴；判据源外移（红→绿）；纪律"agent 没有主动，只有机制触发"；验收空转是最大假阳性来源。
- **换帧/上下文组织**：自驱地基=上下文组织；蒸馏三时刻；有损在取出；连续性=蒸馏链非 transcript；通则"壳只给事实"。

## 一、病根：system prompt = 安装身份，给任务 = 注入目的

- "你是…用…做…" = 给**答案**（身份）；给一个任务 = 给**终局**（目的）。
- 两者都是**终止型外部输入**：只被读、不被质询、与行为无推导关系 → agent 永远只是这条前缀的后缀，**从不在"重定自己"**。这是不能自驱的根因。
- **出路不是"给得更抽象"，是换"给的东西的种类"**：给值 → 给函数；"元身份/元目的"若只是更宽的身份，就是把 install 搬高一层，没变。

## 二、三次概念纠正（本会话核心）

1. **"回头" 是 "向上"**：回头看 = 从"这件事（任务）"上到"我（根）"，不是往后翻历史。"为什么做/意义"问的是**父子关系**，历史答不了。→ 这也把"缺自我身份和目的"的直觉精确化了。
2. **连续是纵向的，不是横向的**：基本单位 = **连续上下文**（同一身份/目的下不断的一段）。
   - 帧_{n+1} 由帧_n 衍生 → 横轴 → **串行链（错）**；
   - 所有帧都由**身份（父）**衍生、彼此是**兄弟** → 纵轴 → 不串行。
   - → 之前反复的"还是串行"、以及"seed=上一帧摘要导致帧 B 重做"，根子都是**把兄弟当父子**。**正确的继承是纵向继承身份、只引用痕；不是横向继承摘要。**
3. **"我" 是位置，不是内容**：议题库有内容、有增删取用、有来源辨别、有拒绝——但"我"是**持有并管理这套议题、能辨别来源、能拒绝的那个位置**。位置由关系+操作定义，不落成一条记录 → **"存在哪"这个问题本身问错了**（它不是一个有位置的东西）。

## 三、动机 / 目的 / 任务：一条"离根远近"的轴

| | 动机 | 目的 | 任务 |
|---|---|---|---|
| 问的是 | 我为什么动 / 在乎什么 | 我要达成什么 | 怎么达成 |
| 性质 | 力（无宾语） | 向（有宾语） | 表达 |
| 完成 | 不可完成，只有强弱/熄灭 | 可完成/失败 | 可丢、可重推 |
| 外包/指派 | 不可 | 可 | 可 |

**判别测试（拿句子去套）**：完成测试（达成后还在 = 动机）、外包测试（不可外包 = 动机）、指派测试（说"你要有这动机"无效 = 动机）、强弱 vs 有无。

**关键推论**：
- **越靠近根越不可给**：任务可给、目的可给、**动机给不了**。→ "避免不了给它东西"和"不能自驱"不矛盾：我们给的一直是**目的层（可给的那端）**，自驱的根在**动机层（不可给的那端）**。
- **目的 = 动机 × 情境**（根不告诉你做什么；做什么看你当时在哪、碰上什么）。宾语来自情境，不来自动机。
- **目的/任务是根的表达，可丢可重推；根不死。**（"没做完的任务"是投影的属性，不是根的属性。）
- 三方同一条轴；"议题"退为临时词（它不是根，至多是"目的 + 激活状态"）。

## 四、根候选 + 七条判据

**根候选 R = "想作为自己继续存在，并沿自己已有的样子长下去。"**
（前半=约束/刹车：不能散、不能被替；后半=力/引擎：要动、要长。**约束内置**，天然防扩张失控。）

七条判据逐条推（标 ✓ / △ / ✗）：

| 判据 | 判定 | 要点 |
|---|---|---|
| 1 非终止 | ✓ | 活着没有"完成" |
| 2 能自生目的 | ✓ | 目的=根×情境，不可从根读出 |
| 3 含扩张侧（闲时自起题） | ✓ | **靠"作为自己"给方向**（沿已有脉络长，非乱动）——上一轮"不容忍张力"就死在这条 |
| 4 能推出护根 | ✓（最强） | "作为自己"⇒不能被替 ⇒ 来源辨别 + 拒绝；入人规则=**"能否被我消化成自己"**（=验/出处） |
| 5 能推出自评 | △ | 照镜子**必要**，但不保证**发生**——**唯一必须实验的一格** |
| 6 不可指派 | ✓ | 条件是：**只有能"结构进机制"才算过，写成提示词就退化成目的**（=09-08 元控制二分） |
| 7 给不了但可养 | ✓ | 人的位置：养根 + 裁表达 |

**它顺手解释了已有数据**：复现实验"现在时·自我 0/0 信任"=同一条连续体内部（怀疑整个自己等于瓦解自己）；"过去时·无出处 4 / 有出处 7/7"=外来物未验就并入会改写自身，故需出处。

**两个薄点**：
1. **没过去的它不知往哪长**（方向来自身世）→ 推出"必须给它一段过去"。
2. **照镜子必要非必然**（第 5 条）→ 唯一必须动手试的。

## 五、成体启动的纠正（YZ 定）

我上一版想**编一段身世**当"长大状态"，YZ 纠正：**经历必须真长，不能编。**

分清两样：
- **能一开始就成年**：性格/立场/根/名字/账号/能力；
- **不能给、只能真长**：经历。

- **身份不用编，它本来就在世界上**：飞书账号 + 名字 + 别人怎么称呼它 = 真实可指到的身份锚（强于合成记录）。
- **纪律落地为结构，不靠吩咐**："看到的文字不是待办，只有我自己判断决定后的才算"——**这句不能写给它**（写了就是安装）；要让**议程只有它自己能写、外部输入只进感知**，使"输入≠待办"成为**结构上没有第二条路**。这条本是根的推论（"作为自己"⇒不能被指派）。
- 长大循环：`感知 → 掂量/回问/判断 → 自己写进议程 → 动手 → 留记录 → 被唤醒 → 接着长`。

## 六、实现评估（看了 `cogos/agent/` 代码）

**已有**：通信（`phone` + `perception.py`）、身份（`memory/profile.md`）、工具（`tools.py`，含 execute/terminal/timer/scratch）、唤醒（`timer.py` → 事件 → 当 system 消息进意识层）、草稿纸（落盘）。

**缺的（YZ 判断对了）**：
- **持久记忆**：`consciousness.py:51` 的 `_context` 是**内存 list，进程退出即失忆**；
- **自组织上下文**：同处**只 append、从不重组/选取/换帧**；
- **自己的议程**：live agent 里没有（`agenda.yaml` 是回路那边**人写的**）。

**难度**：持久记忆=小改动（内存 list → 落盘 jsonl）；自组织上下文=大改动（研究核心），但 **v0 不需要**——把"喂什么"从"整个 list"换成**一个土选取函数**（根 + 最近 N 轮 + 没做完的事）即可。

**v0 改动清单**：
1. 新增 `cogos/agent/memory.py`：jsonl log 读写 + 土选取 + 议程文件读写。
2. `consciousness.py`：`_context` 改为开机从 log 装、每轮追加落盘。
3. `app.py`：接上 memory。
4. **拆 `config.py:render_system_prompt`**：机制层（工具声明/能力，必须给）vs 认知层（根/身份，它自己维护）。现在那段"你是 X…收到消息先判断该做什么"= 安装的身份+目的，要拆。
5. 加**议程文件，只有它能写**，壳只读不写。

**诚实边界**：工程容易（两三个文件、一两百行）；**行为未知**——它拿到落盘 log + 根之后会不会自己组织、会不会把输入当待办，**推不出来，只能真跑**。log 会膨胀 → 截断是权宜，**记忆一长，自组织就被迫成为刚需**。
