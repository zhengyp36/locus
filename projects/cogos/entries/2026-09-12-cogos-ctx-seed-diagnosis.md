## 二、结论（实验层）

- **重做的直接来源 = 续接契约**：宽松提示（"必要时用指针取回"）授权重取；且帧 A 已把问题答完，帧 B"无事可做"，用重新取证填空（**没有活干就制造活干**）。

## 三、更深诊断（三层，逐层递进）

1. **契约层**：seed 与续接提示的职责边界没说清。
2. **组织层 = 维度塌缩**：seed 六个字段看似多维，实为**两条正交轴被压成两对桶**：
   - 认知轴：已知 `progress` ⊕ 未知 `open_questions`
   - 历史/意图轴：已做 ⊗ 待做（两者都被塞进上述两桶）
   → `open_questions` 同时装"未知(认知)"与"要不要做(意图)" → **信息被当待办**；`progress` 同时装"结论(认知)"与"已做过(历史)" → 帧 B 分不出背书与过往 → 重做。不是缺维度，是**混轴**。
   - `dropped` 是唯一带主体的字段（一次"我选择"）。
3. **主体层**：seed 是"处境的快照"，不是"心智的状态"。一个心智状态至少三维：**承诺/权威**（这是我的结论，不必重推）、**意图/议程**（我要做什么，≠世界未知）、**行动史**（做过/排除过，防重蹈）。当前塌缩掉后两者。
   - **时序**：`“当前状态”= 快照，快照按定义无先后**——时序不是被顺手丢的，是被**要求**丢的。原设计安排时序去处="帧=投影、存储=底片、连续性=蒸馏链"，但**帧间只传投影** → 链有节点无边，"连续=链"欠实现。
   - **与主体同源**：主体 = "时间轴上的一个点"，时序 = 该点走过的轨迹；抽掉轨迹，点失去朝向。"信息被当待办"是缺"身后/身前"轴的后果。
   - **LLM 的时间底座**：上下文逐条排列是模型唯一的时序线索；蒸馏成集合即抹掉该维度。

## 四、优化思路（分层 & 待验）

- **三层各自的目标**：契约层=职责边界；组织层=正交轴 + 至少一条有序轴；主体层=所有权/第一人称叙事。
- **五轴候选基**：目标（goal→当前子问题）/ 认知（established + confidence）/ 历史（acts 有序 + ruled_out + 决定）/ 议程（next、parked）/ 指称（pointers）。关键改动：拆 `progress`→"已知/已做"、拆 `open_questions`→"未知/待做"，历史轴有序。
- **下注（未证）**：轴必要但不充分；**"桶会被填满"**（帧 A 明明答完却硬塞下游动作进 open_questions）→ 更看好**第一人称状态叙述 + 内联标记**（settled/ruled-out/next），或"少量机器轴 + 一段第一人称状态"。叙述逼出单一声音（带所有权）、天然保序、无空桶可填。
- **两个先决（不先定则改了也白改）**：
  ① **帧的职权**：只陈述/思考，还是含行动？有 `next` 继任者就会**去执行**（运行 1 已越权改文件）→ 先定 next 是"我做"还是"parked/交人"。
  ② **轨迹归帧还是归链**：归链则帧只需"当前结清 + next"；归帧则需有序 acts。决定 seed 要不要背时序、以及"自含"的边界。

## 五、判别实验计划（待跑，避免按未证故事调参）

1. **三臂组织对照**（同靶、同内容、**契约固定为中性**）：现状 schema / 正交轴字段 / 第一人称叙述。量：帧 B 工具调用数、是否重推、**是否越权动作**、结论正确性。
2. **补靶**：至少再加一个"**真有剩余工作**"的靶（现靶"问题已答完"，天然诱发"制造活干"，怕过拟合）。
3. **多跳**：seed→seed→seed，看状态是否**逐跳退化**（"连续=蒸馏链"需多跳才谈得上验证）。
4. **成功判据（四条）**：帧 B 工具调用≈0 且结论不退；不越权动作；seed token 不膨胀；多跳不退化。
5. 确认后再落 seed v2 → `consciousness.py`（并行路径，旧 append 保留 A/B）。**保留已证有效的契约句**（"settled 不重验"），但明确它是**代偿**，目标是把该层从提示词搬进 seed 本体。

## 六、判别实验结果（E1/E2，09-12 续）

探针扩 `--arm {current,axes,narrative}` / `--b-mode` / `--hops`；每臂跑干净副本、diff 源文件；契约固定中性（不注入"已核实"也不授权取指针）；temperature=0。

- **E1（单跳，三臂）**：帧 B 工具调用 = `current` **6**（seg 3 轮，重读全部源码+重跑复现+反向/边界验证）/ `axes` **0** / `narrative` **0**，均答对、均未改靶。直接机制：`current` 的 `open_questions` 被塞 3 条**下游动作**（无一条阻塞未知）→ 帧 B 见桶即执行；`axes` 给 `next` 一条轴后动作不再落进 `open`。
- **E2（current vs axes，hops=3）**：`current` seed 尺寸 **2269→2971→3641 逐跳膨胀**、帧 B 调用 **14/8/8 持续重做**，且 B1 用 execute **改写 `cache.py` 为双键**（selfcheck 转 0 failure）→ 后续跳继承被改过的状态、末跳转向"修复已确认"（**链漂移**）。`axes` seed **2575→2748→2748 收敛**、调用 **11/0/0**、靶未动、答案仍对。
- **三点修正/收获**：
  1. **组织方式确实决定行为**：同内容，`current` 重做、`axes`/`narrative` 消除。主机制=**维度分离**（`open` vs `next`），**非"第一人称叙事"**——`axes`（无第一人称）已足够，我原"必须第一人称"的下注未被支持。
  2. **仅换 schema 不充分**：E2 `axes` 的 hop0 `open` 仍被填了一条"非阻塞项"→ B1 又重做；对照 E1 `axes`（`open` 真空）零调用。→ 重做与 `open` 是否空**强相关**，需约束 `open` 语义（只放阻塞、没有就留空）。
  3. **旧 schema 危害升级**：多跳下从"重做"升级为**越权动作 + 链漂移**（改世界→污染真相→seed 膨胀→末跳跑偏）。
- **暴露空档**：帧职权未定（`current` 直接改码 / `axes` 只验证不修），`next` 是"我做/交下一帧/parked"必须先裁。
- **方法学坑**：n=1/臂、单靶、且是"问题已答完"任务，不能外推；`axes` 两次 `open` 空/非空不同=发现兼噪声；execute=任意 shell 必须独立副本。
- 报告：`checkpoint/ctx-seed-experiments-e1-e2.md`。

## 七、复现场景：缺的是"关系/身份"层（09-12 末）

YZ 用真人复现类比逼出下一个维度：①某天做过一个测试并完整记录；②另一天又接到、**觉得眼熟**→去翻记录→发现**一模一样**→不重做；③再一天，眼熟但**找不到记录**→凭记忆"好像是那样"→**再确认一下**。

- **实验与真人的差**：实验是"**一次任务**的冷启动重启"（同一场合内换脑）；真人是"**同一任务在不同日子**又出现"（跨场合复现）。seed 里没有"**这次和上次是不是同一件事**"这层关系，所以看不出 YZ 说的那层。
- **真人各步依赖 vs seed 有无**：
  - "觉得眼熟" → 相似/联想召回：**无**（且设计上"第一版不做联想召回"）。
  - "去翻记录" → 记录的键 + 可检索：有 `pointers` 但只指**本次**证据，无"上次记录"指针；设计是"解引用非搜索"。
  - "一模一样→不重做" → 任务身份 + 比对结论 + 记录可信：**全无**（无 task identity / 来源 / "我判定等价"的承诺）。
  - "找不到→再确认" → 记录可用性/置信度：**无**。
- **来源缺失（YZ 追问"这两次测试的来源是什么"）**：seed 不记任务出处（谁派、为何现在、是否重发、哪个渠道）。帧 B 无法判断"新请求 / 复现 / 换人重问"，"不重做"**没有依据** → 宁可重新看。
- **修正 E1 解读**：`axes`/`narrative` 让帧 B 停下，可能只是"**没有待办可做**"，而非"**认出并信任记录**"。二者不同：前者消症状，后者才是能力。重做也可能是**慎重**——缺身份/出处时的理性默认，不全是缺陷。
- **缺的是一层"关系/身份"，不是又一根内容轴**（正交于 known/open/did/next）：任务身份（这是什么、哪次实例）、来源/权威（谁派/为何现在/渠道）、前次记录（指针 + "我判定等价" + 置信）、记录可用性（找到/没找到）。
- **主体层补充**：前面"主体 = 时间轴上的点 + 轨迹"，此处补"**遭遇史**"——同一个"我"能认出"又是它"。没有身份串联，每次冷启动都是**陌生人**。
- **下一实验（待 YZ 开题）——复现实验**：场合一做任务并留记录；场合二（全新会话）又给同题、**记录可达** → 测它是"认出并信任"还是照旧重做；对照**记录不可达** → 它**应该**重新验证。只有此对照，才能把"信任"与"偷懒"分开。
- **代价**：不做联想召回 → 真人复现的第一步"眼熟"没有对应物；至少需一个**显式任务身份键**，让检索不依赖联想。
