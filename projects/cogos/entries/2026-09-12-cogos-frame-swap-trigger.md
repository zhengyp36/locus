# 2026-09-12 换帧边界：唯一触发是"目的变了"，但 agent 没有"主动"（会话 #6 续）

> 契约讨论第一块（边界）。从"谁决定换帧"改问"为什么需要换帧"，逐步收敛，
> YZ 纠正了两处：① 对象化不是独立触发，是换帧的动作；② "主动自评/想起搁置线程"没抓手——现象 ≠ 触发点。
> 前置：`entries/2026-09-12-cogos-distill-retrieval-frame-swap.md`（三处概念校正）。

## 一、换帧只有一个触发：目的变了

- 帧 = **为某个目的裁出来的、当前正在用的表示**（不是"我的全部"）。
- 与"谁决定"无关（需要是客观的，谁执行只是记账）。
- **对象化不是第二个触发点，是换帧的动作/形态**（YZ 指出）：
  "要把当前帧当对象看"本身就是在说一个新目的（审它），故归"目的变了"。
  所有换帧共有的一半 = 把旧帧冻结成可指向的对象（产生"过去"）。
- **"目的" = 什么要紧（相关结构），不是任务身份**：同一线程、同一件事，只要要紧结构变了，就是目的变。

### 换帧 vs 重投影（两个操作，别混）

| | 触发 | 产物 |
|---|---|---|
| **换帧** | 目的变 | 冻结旧帧 + 按新目的裁新帧 → 蒸馏链**新节点** |
| **重投影**（压紧/重整） | 目的**没变**（装不下/表示腐坏） | 同一帧的**新档位**（金字塔下一级） |

- 预算/腐坏**不是换帧理由**（目的没变），降级为更简单的"重投影"（可先不做）。

## 二、"目的变了"的来源

总有一个**事件改写了"现在该盯什么"**。来源两类 + 一个待定：

- **内容性事件（直接改写目的）**：外部注入（新任务、改变看法的新信息）＋ 内部生成（走向结论、自相矛盾）。
  **来源无关**（人或 agent 或工具返回都一样），判据只有"它有没有改写要紧结构"。
- **状态性信号（只提示"该重新决定盯什么"）**：低进展、混乱/超长。本身不产生新目的，是输入/保险丝。
- **待定**：离线节拍（睡眠 tick）——既非内容也非状态，算不算第三类入口？

### 场景（YZ 列 + 归并）

| 场景 | 什么变了 | 目的变？ | 动作 |
|---|---|---|---|
| 外部·新任务（转向另一件事） | 来了新事 | 变（替换） | 换帧（旧线程挂起） |
| 外部·新信息改变看法（同一件事） | 改写要紧结构 | 变（同线程重基） | 换帧 |
| 　└ 若只是补数据 | 信息量增加 | 没变 | 追加/重投影 |
| 内部·走向结论 | 目的达成 | 变（终结） | 换帧（封存归档） |
| 内部·久无进展 | 张力低 | **本身没变** | 判断：搁置→换帧；换法→重投影 |
| 内部·混乱 / 太长 | 连贯/预算信号 | **本身没变** | 重投影（除非"目的本身糊了"） |

- **工具返回是常态**，不能每个都换帧；判据 = **加数据 vs 改要紧**（"重新推导世界"≠"取回记忆"）。

## 三、纪律：agent 没有"主动"，只有"机制触发"（YZ 纠正）

- 现象 ≠ 触发点。凡说"agent 主动 X"，都欠一个机制。（此前把"现象当触发"的错误在此重现一次。）
- **agent 的真实自由度在"取舍"，不在"发起"。** 所以"自己醒来"（L2）也必须落在 timer/tick 上。
- 两个"没抓手"的场景，各自的机制候选：
  - **自评**：① 状态信号（矛盾/低进展/长度，机制当传感器）② 离线节拍。
  - **想起搁置线程**：① 线索命中（需匹配/索引机制）② 离线扫描 ③ 显式句柄（显式=取，非想起）。
- 二者都落在**已有但未实现**的两块上：在线状态检测、离线睡眠 + 自触发。不是新东西，是"欠着的"。

## 四、自评触发的具体形态（YZ 提，已认可）

机制传感器 → **概率提醒**（带事实）→ agent 决定是否换帧去审。

- **概率而非确定性**：固定阈值提醒会被"学会忽略"、失去显著性；概率保持**不可预期 = 信息量大**。
  同 img-tool flock 的 jitter（随机化解耦"可被优化/踩点"）。代价=不可复现 → **RNG 可种子 + 可强制开关**。
- **提醒写法**（守住"壳只给事实"）：给可测事实（长度/帧数/距上次审视的步数）+ 中性开口（"可以考虑审视"）；
  **不写**"你该自评了""你乱了"（那是策略/判断，归 agent）。
- 低概率 + **冷却**；敲了之后做什么仍需定义——多半就是换帧（目的转"审"）。
- **已有传感器**：`no_change`/`stalled`/`max_steps`（loop 现成）、重复动作/重复失败、时间/步数/预算、长度。
  **语义型混乱**（矛盾、前提错）机制测不到，只能靠长度这类代理 + 模型自查（模型不能直接感知自身状态）。

## 五、契约块二：seed 形状 = 信封 + 正文（YZ 无异议，待实验检验）

**结构点（看清的点）**：换帧有三种**处置**，决定跨界内容——

| 处置 | 何时 | 跨界带什么 |
|---|---|---|
| 重基 rebase | 同线程、看法变（要重新审视） | 带旧帧的**判断**（它正是被审视的材料） |
| 切换 switch | 换线程（另起/搁置） | 不带内容，只留指向挂起帧的句柄 |
| 归档 archive | 目的达成 | 不带，旧帧封存成记录 |

→ **信封统一、正文随处置变**，印证"信封/正文"二分：机制只依赖信封，正文是策略。

- **信封（壳保，机制必需）**：`id`(=自有帧句柄) / `thread`(逻辑身份，供召回·resume) / `prev`(时间链，回溯用) / `created_at`(可观察事实) / `provenance`(trigger_kind + evidence(agent 声称) + source(壳可观察))。
  - **进信封判据**：① 壳能不能保证它为真 ② 机制需不需要它；两条都满足才进。信封最小性检验=正文烂掉机制仍能转。
  - 诚实标注：壳可观察的 vs agent 声称的。
- **正文（agent 填）**：建议轴 `intent / current_question / known(结论+简述依据) / open(真正阻塞) / did(有序关键动作) / ruled_out / next(可选) / dropped(选择不带什么+为什么) / refs(世界指针的值)`——是 agent 的**蒸馏方法**，非壳校验（E2：schema 挡不住语义）。
- **暂定最小强制**：`intent` + `dropped` 在场（只查字段存在，内容归 agent）。
- **先不做**：职权声明（等自评场景真出现）；离线节拍相关字段。
- **YZ 定调**：不必一开始定太细，**用实验检验哪些必要/哪些不必要**——以上是暂定，不是冻结契约。

## 六、契约块三：取的两类与准则（提案，未裁）

- **取 = 帧内的普通工具调用，不是换帧。** 不需要新机制，只需"句柄格式 + 解析器"。
- 两类句柄：**世界指针**（`file:path`/命令，重推导事实，用现成 read/search/execute）／**自有帧句柄**（`frame:<id>`，取回自己的过去，只加一个新工具）。
- **关键分界**：取 = 把对象**放进**当前帧看；换帧/resume = **变成**那个状态继续。
  → 取不改目的、不改写存储；走样发生在"放进当前帧"（帧层重投影），不落回存储。
- 返回：默认**存储的表示**（信封+正文）；底片原文按需再取（后置）。
- 选择性准则（判据，**非机械**）：取一个已知没带的具体点=正常；取来重建操作态=换帧白做。
- 联动：取回的内容可能是**内容性事件**（改写要紧结构）→ 触发换帧。**取 ≠ 换帧，但取可导致换帧。**

## 九、探针 1 结果（09-12 会话 #7）：块一行为主张**不成立**

> 原始结果 `../checkpoint/26-09-17-agent-theory/ctx-swap-probe-report.md`；代码 `work/A/cogos-ctx/research/ctx_swap_probe.py`（untracked，骨架抄 `ctx_seed_probe.py`，neutral `swap_frame` 动作，未碰 `consciousness.py`）。

- 设置：帧 A 给任务+工具（含中性 `swap_frame`），第 2 次 chat 前注入事件（唯一自变量）；双事件 `recast`（改要紧）vs `append`（只加数据）；真 deepseek flash，temperature=0，n=3。
- **结果**：`recast` 3/3 未换帧；`append` 3/3 未换帧。`recast` 里 agent 读到"改问 rounding"后**原帧内直接转向**，全程不出现 `swap_frame`。
- **正对照**（显式提示调用 swap）1/1 触发 → 是"选择不换"而非"不会用"；其帧 B **全量重做**调查（seed 自含性弱，块二预告）。
- **判读**：内容事件改写要紧 → **不自动换帧**，默认追加/重投影。主因=**中性动作无动机**（无存储/预算/帧数代价，换帧纯损失）；次因=帧 A 目的尚未定型（注入偏早）、纯内容事件缺**状态信号**耦合。
- **回看块一判据**：或许"目的变"不是充分触发，需与状态信号（预算/长度/混乱）耦合，换帧才有可被 agent 感知的收益/代价。方向待 YZ 裁决。

## 十、判据重述：身份优先于目的（09-12 会话 #7 续，待 YZ 裁决）

> 详见 `entries/2026-09-12-cogos-identity-anchor-frame.md`。**本节与 §一"目的变，非任务身份"冲突**，是本次讨论最硬的产出。

- 并置"身份/复现"线与"帧/注意力"线后：**身份 = 锚/脊**（底片寻址脊）；块二的"信封"其实就是身份显式锚。
- §一**故意把身份排除**在换帧判据外，但身份线（复现实验）说明"**是不是同一件事**"恰恰决定切不切材料。任务 1→2（同主题、换视角）落在两者相反的一格，且**实验支持身份线**（就地转向、复用材料）。
- **重述判据为三问**：①身份是否延续（决定材料切不切）②视角是否变（决定是否重裁）③新输入需要旧帧哪一层（决定留下帧/seed/锚）。
- "换帧"不是一种操作、是一族；"丢 vs 模糊"的分界 = **有无身份脊**。
