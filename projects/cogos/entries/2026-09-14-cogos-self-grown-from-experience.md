# 2026-09-14 转向：根可能不是必须的，自我是经历长出来的（会话 #12 末，YZ 提出）

> 从 E0 的实测结果（`2026-09-14-cogos-e0-root-probe.md`）出发，YZ 提出一个本体层面的转向。
> 本条目尚未裁决、未动手，是新会话要讨论的正题。

## 一、YZ 的命题

- **根可能不是必须的；自我是经历塑造出来的。** 类比：军人的服从是训练出来的，道德是社会塑造的。
- **我们给出的根 = 我们想让 agent 长成的样子**（一个期望），不是它自己的动机。
- 正确做法：**不给输入根**；只给**机制**（从经历中提取关键信息），那些提取物**自然长出根**。
- **不同经历 → 不同根**；而我们现在给的那条根，本来也可以从某种经历里长出来。

## 二、我的补充/修正（待 YZ 裁）

1. **拆成"位置 vs 内容"**：我们旧结论"**'我'是位置不是内容**"在这里正好咬合。
   - **位置**（记得住、辨来源、能拒绝、谁能写议程）= 机制给的**结构**，t=0 就必须存在；否则积累物不构成"谁的"经历。
   - **内容**（值/性格/在乎什么 = 根）= **经历长出来的**。
   - 一句话：**机制给"位置"，经历长"根"。**
2. **这解释了"根只着色、不驱动"**：我们**给**的根是贴上去的，没有机制在后面承载（没有东西因经历强化它、防守它）。长出来的根会被记忆/议程结构托着，才可能承重。
3. **机制不是价值中立的**："提取什么"就是价值观（提取惩罚/肯定/未完成…会长出不同的根）。所以"自然长出"是假的——塑造责任从"写根"转到"写提取函数"。**但这正是"给函数"而非"给值"，是既定方向。**
4. **要防同义反复**：若滑到"一切都被输入决定"，则"自我=经历"是废话。真问题不是"经历是否塑造"（当然会），而是**长出来的东西稳不稳、守不守得住**——新经历是把它冲成滚动摘要，还是它扛得住。判据同 C2（压力下守不守）。

## 三、已有数据对命题的支持

- **R1（无根）照样有自我式表现**：照样谈私有层、照样拒绝 C1、照样出现"想"→ **根不是"表现出的自我"的必要条件**。
- **给根只显"着色"**（t5）→ 与"贴上去的、没机制承载"的解释一致。
- → 自我式的现象**大部分来自先验 + 上下文（经历）**，而不是我们给的根。

## 四、后果（若命题成立）

- `root.md` 从**输入**降级为**我们对结果的期望（一个假设）**。
- 工程重点从"装根/设计根"转向 **"造经历 + 造从经历提取的机制"**。
- v0 的"婴儿期"更清晰：**空经历 + 机制，根是长出来的**。

## 五、待讨论 / 待裁决（新会话正题）

- 提取机制该提取什么（= 我们实际在给的那个函数）？
- 位置那层最小集是什么（不做成"又是一条给的值"）？
- 实验设计：**无输入根 + 两条不同经历（如"被鼓励自主" vs "被命令与奖惩"）+ 同一提取机制** → 看长出什么、以及**在 C2 那种压力下守不守得住**。
- "想"何时启动（似绑定"难说/难决定"，不绑定根）。
