## 概念体系（项目自己的语言）

- **通信工具 = 独立认知个体的嘴和耳朵**：接入感知层、非意识层；外部通信不能直接注入意识（对比：人跟 AI 对话=注入 LLM 上下文=注入意识）。身份识别靠号码。
- **provider（运营商）**：一个飞书租户下的号码域，支持多运营商；一个 agent/人可持多个 provider 号码（类比联通/移动）。运营商间**不互通**（折中，非设计）。
- **bs-bot（基站）**：每设备一个，`setup-bs` 创建，只响应真人管理员。
- **admin-bot**：整个 provider 唯一，`/setup` 创建，管理 bitable。
- **号码**：Hxxxx（真人）/ Axxxx（agent），provider 内唯一；接口层带前缀（`COGOS001:A1328`），进入内部定位 provider 后**只用裸号码**。
- **PIN**：add-agent 时随机生成，startup 鉴权。
- **多设备恢复**：`/resume <admin-bot-app-id> <admin-bot-app-secret>` 读 bitable。
- **bot↔bot**：飞书不支持 bot 互通 → 建**双 bot 群 + @all**，群不解散，chat_id 写 bitable。

## Python 接口（设计目标，agent 侧）

- `startup("COGOS001:A1328", on_msg, PIN)` / `send("COGOS001:H2049", msg)` / `send("COGOS001:A0053", msg)` / `shutdown()`
