# Agent 认知架构 v2 — 上下文自管理（凝练）

> 完整原文：`checkpoint/26-09-02-agent-cog-arch/agent-prototype-design-v2.md`（含 v1 存档）。本文是记忆凝练版，供快速恢复核心概念与决策。

## 核心转向

- 不做「记忆系统」，做「LLM 自管理上下文」；记忆 = 上下文的持久化/外溢。
- 意图推测是动机核心：收到消息先推意图再帮助，非直接作答。身份 = 世界观（极简 system 底座）+ 规则（可执行步骤），效果靠规则不靠世界观暗示。

## cu = 覆盖式回合

- 唯一 cu 概念，一次完整推理回合，输出 = 覆盖式新上下文，不累积。
- 情况 1：无工具直接收敛；情况 2：工具循环到收敛（痕迹不外泄，下一 cu 看内容是「凭空出现」= 展开等效自动）；情况 3 compact：超限重建（受限工具集 scratch）。
- max_steps 兜底强制收敛。

## 状态对象（场）

- context（事实主干）/ intent（推测意图）/ problem（问题状态 + 任务进度）/ gain（增益观察）。
- context 与 intent 硬分开，防推测污染成事实。来源标签 external / self / sys / mem。

## 意识 = 脉络（概念澄清）

- 「意识层/元层」是讨论期脚手架，实现改功能命名。
- 意识是现象不是组件；意识现象 = 脉络（有序、带脚注的思维主线序列），近段保留、远段折叠成脚注，回忆展开 = 记忆展开。对应全局工作空间：意识 = 当前被广播的那段。
- 功能划分：内容（状态对象）/ 对象推理 / 评估控制 / 记账调度（程序）/ 外设。
- 架构层用功能词，叙事层（prompt）仍可用「有自我意识的 agent」。

## 外部触发运转

- 感知层 = 统一事件源（phone 消息 + 工具完成事件）。
- 三态依赖：阻塞（记忆）/ 非阻塞（execute/search/fetch，异步回流）/ 外化（send_msg）。
- 检索边界：程序只查号码→名字；名字→相关记忆是语义交 LLM。认识=组装简要信息+脚注；不认识=信息缺口升级为推理。

## 心智时间 + 来源标注分工

- 心智时间 = 版本标签（新=1，旧每轮+1，显著变化重置1）；显著性判断必须 LLM 做（程序 diff 原理错误）。
- 来源标注进对象层（影响推理行为）；心智时间留元层账本不进对象层（避免噪声）。
- 焦点切换 = 元层是否注入 [sys]（注入即内省、不注入即沉浸）。

## 元层机制（持续运行，场外）

- 评估决策：判显著性/增益/停续。
- 时钟：时间压力，不思考，三步（语义初始化/停顿点检查/概率注入）。
- 内省两出口：推（注入 [sys]）/ 拉（introspect 工具，返回加工结论非原始账本）。
- 主题调度：张力驱动（未决项 = problem open 项，张力 = 未完成×停滞×重要性×对方在等），无增益时按张力重开。

## 工具集

- scratch 草稿纸（版本化写时复制，逻辑 ID 恒指最新）；脚注式短 ID 引用；展开交专门 cu（cu 化工具），渐进展开 + 加载进度。
- 目录 ID 化（盘符），替换 work_dir + _resolve。其余 execute/search/fetch 沿用。

## 模型分级

- 对象推理 → advanced；元层评估 → basic。看复杂度不看重要性。

## 待定项

- 实现顺序：状态对象 → cu 循环 → 输出契约+prompt → 工具集。
- 两个上限参数待实测；多 cu 串行→并发；物理时钟与心智时间耦合未定；异步推理未展开；张力排序先程序近似；introspect 节流；主动内省是否必要（先只做机制层强制推）。
