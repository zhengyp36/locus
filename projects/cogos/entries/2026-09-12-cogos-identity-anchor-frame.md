## 零、探针 1 的结论（背景）

- 双臂 `recast`（改要紧）3/3、`append`（只加数据）3/3 **均未换帧**；`recast` 里 agent 原帧内直接转向、从不调用 `swap_frame`。
- 正对照（显式提示）1/1 换帧，其帧 B **全量重做**。
- 判读：**不能用它判块一真假**——实验把"是否换帧"交给 agent 自愿，违背契约自定的"agent 没有主动、只有机制触发"；且把块二（seed 自含）的现象当成块一的证据。
- 更根本：**块一的"目的变"不可操作**，且与身份线冲突（见下）。

## 一、换帧的本体没定义，被一个默认实现占领了

契约只在**目的层**定义了换帧（"目的变→冻结旧帧+按新目的裁新帧"）；**机制层是空白**，被 handoff 的默认实现填上：

> 换帧 = 产 seed → 冻结旧帧 → 从 seed 起新帧（新 cu 冷启动）。

这只是一种实现，且假设了三点（均未讨论）：①帧的价值可用 seed（判断）概括；②过程可丢；③"冻结"=丢弃（不可寻址）。
它只适配"**换对象/换线程**"的场景，被错用到了"同主题换视角"场景。

## 二、"丢"还是"模糊"：两个 regime，分界是身份脊

两个模型不是对错，是**工作集能否常驻**的两个 regime：

- **注意力/聚光**（底片常驻）：帧 = 有限注意力/分辨率预算在持久底片上的分配；换帧 = 重分配焦点；旧内容降为**模糊/失焦**，相关了再照回去。
- **容器/换出**（窗口硬、无存储）：帧 = 窗口里的内容；换帧 = 切出去，**"丢"是真的**。

关键分界：

- **有身份/索引脊** → 换帧 = **注意力切换**（旧内容仍可寻址）；
- **无身份脊** → 换帧 = **真丢**（不可再寻址）。

→ 用户上轮"感觉像注意力切换而不是把内容换出去"成立，当且仅当存在身份脊。**所谓"失去锚点"，丢的就是身份。**

## 三、身份 = 锚/脊：三条线的合流点

- 复现实验缺的"关系/身份"层（任务身份、来源/权威、前次记录、记录可用性）= 当前讨论的"锚/句柄"。
- 身份 = **底片的寻址脊**。没有它，新帧认不出"又是它"，也无法决定"不重做"。
- **主体 = 时间轴上的点 + 轨迹 + 遭遇史**（`ctx-seed-diagnosis.md` §七）；"遭遇史"= 底片上可由帧句柄寻址的历史帧。
- **"链有节点无边"**（帧间只传投影）缺的"边"，正是由身份脊（`thread`/`prev`）补上。

**信封/正文 = 身份的显式锚 / 第一人称投影**：块二的信封（`id/thread/prev/created_at/provenance`）就是身份显式锚，正文就是第一人称投影。复现实验测出的"时序框架 + 出处"= 正文口吻 + 信封事实。**块二一直就是在做身份层，只是没这么叫。**

## 四、块一与身份线直接冲突（本次最硬的发现）

- 块一（`frame-swap-trigger.md` §一）**故意把身份排除**在换帧判据外："目的 = 什么要紧，**不是任务身份**；同一线程、同一件事，只要要紧结构变了，就是目的变（→换帧）"。
- 身份线说：**是不是同一件事（身份）**决定要不要重做/复用。

| 情形 | 块一（目的变） | 身份线（同一件事） |
|---|---|---|
| 身份延续、视角变 | 换帧 → **切出材料** | 同一件事 → **保留材料**（复用） |

任务 1→2（同估值系统、换问法）**正是这一格**。块一说切出，身份线说保留；**实验站在身份线一边**（原帧内转向、复用材料；seed 无身份脊时切帧→重做）。

→ 用户早前怀疑的"目的变绑架了我们"，根因在此：它把决定"切不切材料"的**身份**从判据里剔除了。

## 五、重述：判据从"目的"改为三问

1. **身份是否延续**（同 thread / 同实例 / 同一件事）→ 决定**材料/过程切不切**；
2. **视角是否变**（裁法/要紧）→ 决定**要不要重裁**；
3. **新输入需要旧帧哪一层**（过程 / 判断 / 仅指针）→ 决定**留下什么形态**（帧 / seed / 锚）。

配套的概念：

- **主题 × 视角** 两轴（主题≈身份在对象维的投影，视角≈裁法）；"换帧"不是一种操作、是一族，换法由新旧关系定（不相关转向 / 换角度 / 重整 / 归档）。
- **换帧留下什么 = 信封（身份锚，指 prev）+ 正文投影（判断）**；旧帧降为脊上可寻址节点（=用户说的"模糊"）。
- **锚的形态谱**：帧句柄 `frame:<id>`（底片存了）→ 世界指针（可重推）→ 判断摘要（**不是锚**，回不到原文）→ 索引键（靠关联想起）。**锚只在底片常驻时成立。**
- **连续性与"重做=慎重"**：无身份/锚时，新帧无法把旧内容纳入"我的过去"，只能回退世界重推——这正是探针 1 正对照"帧 B 重做"的根因。
