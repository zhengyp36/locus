# cogos 意图的整体看法（2026-09-28 讨论收口）

> ⚠️ **术语现义见 `glossary.md`**（09-30 立）：本文"意图＝意识角色的作用域"口径已于 09-29 收回，现义＝**无声动作指令＝思考→动手的桥**（`entries/2026-09-29-cogos-outer-loop-process.md` §4）。本文留档作旧义来路与机制素材（渲染三律/程序式记忆/边界判据仍有效）。

> **目的重框（09-28 晚）**：意图的意义是**给模型注意力减负**（把注意力留给推理），**不是保密**——少量工具用法留在上下文可接受；执行侧口径见 `entries/2026-09-28-cogos-intent-execution.md`。

## 1. 形态：三件已存在/已定的事，合成一条流水线

1. **呈现**：能力可见（总览到组/能力级）；用法**默认不在视野**（`help` 属执行域、仅意图态），**但可留少量驻留**（见 `entries/2026-09-28-cogos-intent-execution.md` §1/§5）。
2. **就地执行**：不另发"想要什么"给外部分派器；当前任务切为"执行这次意图"，**精确上下文就在这里**，用法在域内展开（help/探索/重试）→ 无损。
3. **渲染（抹痕）**：过程弱化、结果突出；append 时渲染成**自己的消息格式**，不写厂商 `role:tool`。回看视图里一次意图执行 = `{意图陈述} + {结果}`。

**单位是"完成一个功能/能力"，不是一次工具调用**（一意图内可含多轮调用/重试/发现，全被 3 隐藏）。

## 2. 为什么这条对（与已否项的关系）

- 确定（catalog 校验，不靠语义解析）、无损（目标是模型自己的、在自己作用域里做）、无额外 LLM 跳、缓存全命中。
- 原方案的**独立分派器**：在"同模型同上下文"下是恒等变换（可消去）；不同则有损+不确定，且与 checkpoint-17/18（别让机制替模型做语义理解）相悖。→ 09-28 否"独立意图匹配器（执行须精确）"**不用翻案**，本条是其等价呈现形态。
- **但分派器被否 ≠ 执行者被否**：执行者**不是匹配器**（NL→args 靠猜），它带同一套 toolbox+help、能探索 → 精确性不降。这条界限写死：一旦退化成猜参数，立刻回到被否。

## 3. 记忆：程序式记忆（"越来越顺"的机制 + 经验落点）

- **程序性**（技能按任务类型存、入口隐式加载、出口更新）与**情节性**（段）分开；段是意识层锚，procedural **不进意识、不进段**。
- **入口加载** = 权重（长期惯用法=经验沉淀）＋ 活跃度（最近调用情况）= "加载最近调用情况 + 经验沉淀"。
- **出口两写、同一捕获接缝**：① 段（意识层：我要 X→得到 Y）；② procedural（意图层：这类意图的配方）。先捕获后抹痕。**（09-28 晚细化**：② 实为**原始材料封存**，procedural 是**睡中蒸馏**产物；入口加载的落地形态＝`toolbox intent` 懒加载——见 `entries/2026-09-28-cogos-intent-execution.md`。**）**
- **不与 catalog 争权威**：记忆只是先验、被现实纠正（工具变了撞上即调整=机会）。**不引入版本绑定/失效机器**（那是机制替模型预判、多余）。→ 收回"记忆成第二口径/需绑版本"的提法。

## 4. 边界判据（可操作）

- **渲染三律**：① 过程**弱但可辨识**（谁/对什么/哪一次）；② 结果**强且带后果语义**（后果型把关键载荷折进结果："已发给 A0001：『…』"）；③ **绑定不断**（动作指称可当记忆关联键）。"变弱"≠删除。
- **吸收 vs 上浮**：只有"**未触达世界**"且"**不改变目标**"的失败可在域内消化；一旦可能已触达（副作用/非幂等）或该改目标 → 一律上浮。
- **回看只见结果**：回看视图里一次执行 = `{意图陈述} + {结果}`（过程隐藏）；但**工具用法可有少量驻留**（见 `entries/2026-09-28-cogos-intent-execution.md` §1/§5）——目的是**注意力减负，非保密**。
- **可纠正**：先验弱到仍会去试/去看；错误信号能到域内（结构错→边界给；语义错是既有洞）。

## 5. 风险 / 未定

- **语义错无信号**（键合法但意思错，如 `screen.act` 的 `to`=drag 终点）→ 错先验会黏住；procedural 使其更黏。既有洞，非它新增。
- **僵化**：越顺越习惯盲，与上条同源；靠**误差驱动更新**（切点=误差）缓解。
- **长意图的结果粒度**：一条结果要够意识继续推理，不能压成"完成了"。
- **键/粒度**：按能力（path）[+少数模式]，复用现有 **权重+活跃度+取回**，别造第二套记忆。
- **想/调分离**：是否要显式"想"拍（给回看一个意图锚）。
- **多意图/并行**（checkpoint-6 遗留）。

## 7. 落地路径

- **便宜版（先做）**：单上下文，意图执行＝一段 block，回看只渲染头+尾。已满足"不必知道 help"（`help 0/10` 是"行为上不需要"的实证）。前置＝**想/调分离＋捕获＋渲染＋段**，与第一刀（落段）**同接缝，不另立项目**。**执行形态（入口/出口/经验/沉淀/上限）见 `entries/2026-09-28-cogos-intent-execution.md`。**
- **完整版（目标态）**：角色真拆开，用法不进意识上下文（进一步减注意力）。代价＝第二次调用/handoff/执行者可靠性/递归预算。
- **AI 倾向先便宜版**；完整版等有证据（长弧当轮污染真伤）再上。
