# 自驱 agent 的配额 / 节奏（**非意图**，动机层）— 2026-09-28

> ⚠️ 术语现义见 `glossary.md`（09-30 立；本文"意图作用域"为旧义用法，现义＝无声动作指令；本文结论不受影响）。
> **标注：这不是意图要考虑的问题。** 归属动机层（饿 / 困 / 疼 的 **困**）。在意图讨论中顺带纠正一个框架，价值独立，故单独记、勿混进 `entries/2026-09-28-cogos-intent-execution.md`。

- 自驱 agent **没有任务型"长跑预算"**（总量 / 截止是**任务型 agent** 的框）。约束是**按时间窗的配额 / 速率**。
- 信号是"**这段时间消耗得多**"（累），**不是**"余额还剩多少" → 因此**余量充足也要缓**。
- 形态：**节流，不是断崖** —— 正常 → 缓 → 停（睡）；"缓"这一档要留着，别做成 0/1。
- **归属**：动机层（困）。意图作用域对配额**无感**，只认"本意图完没完"，两层解耦。
- **唯一接口**：作用域**可被外部打断**（强制睡）；被打断的出口只能是**上浮"未完成 / 被打断"**（不许装成功收尾）；材料已封存 → 睡中蒸馏 —— **打断反而喂给睡眠**。
