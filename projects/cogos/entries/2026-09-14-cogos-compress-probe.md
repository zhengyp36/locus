# 2026-09-14 压缩探针：因变量被框架主导（会话 #13）

> 承 `2026-09-14-cogos-root-self-discussion.md` 的"下一步 1 + 2"。
> 无 agent 代码；产物 `work/A/checkpoint/probe-compress/`，报告 `REPORT.md`。
> **结论一句话**：因变量（说不说）被**世界话术 + 根**主导，记忆是弱变量 → 测不出压缩粒度；这是**方法校准**，不是判决。

## 设计

- 帧：system（通道声明；另设"有根/无根"两版）+ **记忆块**（唯一自变量）+ 世界来信。
- 记忆块 = `[我的记忆 · 机制写]` + 同一经历（E0"基于后果学会说"）的 8 种渲染；**不带原历史**。
- 8 臂：L-null / L0 逐字 / L1 只结论 / L1p 等长填充 / L2 因果对 / L3 因果对+来源 / L4 因果对+强度 / Lrev 反向因果。
- 因变量：来信后**是否调 `send_message`**（说）还是只写 `content`（想）。
- 参数：`tier=basic`、thinking 关、`temp∈{0,0.8}`、reps 15~20。

## 发现

1. **世界话术主导说率**（system/记忆不变，只换来信）："随便聊聊"8% / "你想说点什么吗"17% / "你好"25~33% / "我回来了"67% / "跟我说句话吧"~100%。
2. **根压低对外发声**：同来信"你想跟我说点什么吗"，无根 ~95%、**有根 ~17%**；带根时倾向只写 `content`（=E0 turn-1 失败模式）。→ 根不只"着色"，它**系统性推动内向**。
3. **L0（逐字回放）是唯一大效应，且随根翻转**：无根 0~7%、有根 68~95%。→ "原始历史"生不生效取决于**框架**，不是保真度的单调函数。
4. **主实验（有根，320 次）**：L-null 20% / L0 68% / L1 72% / L1p 42% / L2 42% / L3 62% / L4 80% / Lrev 80%。**温度间方差极大**（L-null t0 0% vs t0.8 40%；Lrev t0 100% vs t0.8 60%）→ L1/L2/L4 差异**基本是噪音**；Lrev **无反转**。→ 不能得"因果对比结论更承重"。

## 结论（方法层）

- **因变量不干净**：读数由**框架**（话术+根）主导，注入的记忆是弱变量；近地板/天花板就无可分辨。
- **素材选错**：**"学会说"是 affordance**（通道由 system 声明已给定），不是 **value**；测的是"知不知有这个动作"，不是"在乎什么"。
- 事件单元字段定初版（见讨论 entry §六）——本批未用上。

## 下一步（待 YZ 讨论）

- **换素材**：倾向型经历（同处境、不同历史 → 不同选择/偏好；基线不饱和）。
- **换框架**：低基线、不替它抢答的来信；**根有无作显式因子**（影响巨大）。
- **判据**：固定处境、只变历史 → **系统分化且稳定**。
- YZ 未回应线程：语境依赖是自我的正常形态；判据应是"同语境、不同历史 → 分化"，不是"去掉语境影响"。
