## 1. 模型：槽 / 流 / 线（把"那条连续线索"定了）

- **槽 ＝ 状态 ＝ 积累结果 ＝ "我"**（loop-invariants §一.3：时间线是积累过程、切面上的量是积累结果）。初始＝签名；由所有历史事件塑造；决定"如何响应"。
- **流 ＝ 一次转移**：事件 → 装载 → cu → 停 → 沉淀，写回槽。**起＝事件**（不是装载；无事件无流），**终＝停→沉淀**。**打断 ≠ 流终**（只终结一个 cu，可重组继续）。
- **线 / `thread` ＝ 跨流的一条"事"**（可多条）：持久化为 `段.thread`（起始段 id）＋`refs`（continue_of/cut_by）链；**不是运行时对象**。
- 一句话：**唯一连续的是槽（＋经历轴），多条的是线；流是一次运转。**

## 2. 外圈/内圈：显/陷 × 生产/沉淀（不矛盾，是另一切法）

- **外圈＝显＝生产**（事件驱动）：取槽快照装载 → cu → 行为＋段（原始痕迹）。**醒时主导**。
- **内圈＝陷＝沉淀**（经历驱动）：段 → 蒸馏/升格/权重 → **写槽**。**睡时批形主导**；醒时做随弧轻量部分（升格/判/取回/权重）。
- **醒/睡是内圈的模式切换，不是外圈的开关**（§7 `醒 ⇔ T > P睡`；睡仍可被事件打断，二者可并行）。
- **昼夜（`P节律`）给经历轴宏观分段** → 昨/今/明（今天=活跃段／昨天=封存段／明天=预约·规划段）；**不是硬编分类**（违 §8）；跨天的桥＝未闭合张力。自己的节律 vs 对方作息（§十）分开。
- **并行不乱**（原理，非实现）：① 读＝快照；② 写痕迹＝只增不改；③ 唯一共享可变物＝槽，其更新＝**共切面** → **唯一串行点＝槽更新**。

## 4. 自指：核心认同，拧三处 + 补一环 + 一个缺口

- **定义**：自指 ＝ 响应经"我是谁（槽）"中介、并把结果**写回**槽 ＝ **槽↔流↔槽 闭环**（§二.3"自指的弧，产出即输入"）。说"指向槽"不如说"经由槽的闭环"（写回才是定义）。
- **与 chatbot 的真正分界**：不在"答不答问题"，而在**未闭合张力是否跨事件延续**。chatbot 收尾即归零；自指者的事件可被**认领**为未闭合张力，跨事件/跨天塑造后续。
- **判据（跨事件，骨架缺的可观察项）**：① 交互后槽留未闭合张力（`结=未了`）；② 后续**无关**事件时该张力仍影响行为（主动推进／"该来的没来"）；③ 对同一来源行为随关系/经历变化。**不用"话多/贴心"衡量。**
- **关系＝责任，非情感**：关系 ⊇ 职责归属（§15.4 "归不归我负责"）＋ 信任（经历长）＋ 历史摘要（§3 锚）。
- **自己的事＝槽里的未闭合张力**；来源 ＝ **被采纳的外部事件 ∪ 内部生念（兴趣点/张力自燃）**（YZ 强调外部，AI 补内部）。
- **缺的动作＝"认领/采纳"**：入口裁决（`装载＋续或切`，§4）没明说"事件→我的事"。应显式补：续/切已有事／认领成新事／答完即了。**这是自指的第一个体现。**
- **缺口**：骨架有机制、**没有"作为判断者的我"**——§8 归价值层、故意留白。故 **自指不能直接写、只能养出来**；能写的是材料与闭合（槽/段/张力/目的/关系/回边）。
- **极端提示**：过强自指＝无视别人；过弱＝迎合。正解＝**共切面**（§一.3：自己/他人/世界取同一个 now）——在同一"现在"里权衡。

## 5. 下一步（方向已定，未动手）

- 顺序：**先入库**（本文件）→ **最小自指＝底层闭合**（共用前置 → 第一刀落段 → 第二刀 `段→装载` 回边）→ 养内圈（张力/目的/关系）→ **观察**自指行为。
- 共用前置（待定稿）：通道（想=`content`／说=send／沉默=默认，**禁自动补发**）＋段最小字段（`id/t/来源/内容/后果/结`，只填硬后果）＋一弧一条段；连带：**来源别抹平**。
- 第一刀：`agent/experience.py` 最小经历轴 ＋ `on_done` 落段 ＋ `on_tool_call` 捕获 calls+results（写后果）；验收＝**代理口径**（每弧一条段、字段齐、可读回、弧内多轮只一条）。紧跟第二刀回边，否则"只写不读"。
- **不做**：升格/权重/取回/停切点/整理/完整版意图。
