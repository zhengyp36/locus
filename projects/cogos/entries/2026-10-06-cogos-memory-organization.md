## 0. 一句话

记忆＝**图底层（索引→内容有向图）＋ 树视图（摘要层级下钻）**；读＝**多路并行唤起 → 模型终判**；写＝**读即写＋路径传播**；离线只做**蒸馏/结构涌现**；**上下文（活状态）与记忆（持久层）分离**，浮现＝二者之间的连结。

## 1. 职责划分

- **上下文管理**＝活状态（线概要＋最新结论＋过程），**不是记忆**。
- **记忆**＝持久层：raw 经历 ＋ 整理后的经验。
- **浮现（`忆`）**＝上下文与记忆之间的连结动作。

- why：把"活状态"从"记忆"里摘出去，记忆只剩"raw→整理"两级，复杂度被摊开而非增加；"当前记忆/稳定记忆"这对词不引入，避免与已有 `槽` 撞名（槽已覆盖"当前"一部分）。

## 2. 结构：图底层 ＋ 树视图

- **底层＝节点＋类型化关系（图）**：索引→内容有向图。多维关联天然是图（一个内容多入口可达）。
- **树＝只留"层级/偏序"关系的视图**：入口→摘要→详情，逐级下钻。
- **索引是图（多入口可达），内容是树（摘要层级）**。
- **索引表示＝句柄＋描述**（tag 是一句话，非词）。

- why：09-01 checkpoint-7 已拍"树名不副实——标签多对多＝图，底层原语＝节点＋类型化关系；树/列表/集合都是视图非容器"。本会话重新激活的"认知树"思路正确形态＝**图底层＋树视图**，不做"树当底层"。
- 价值：树状下钻控制上下文预算——唤起先取摘要（便宜），需要才下钻详情；符合人脑 gist 先于 verbatim。

## 3. 记忆层次

- **段（经历 raw）**：判结沉淀 append，最新段＝"结论块"。
- **线概要（线级脉络）**：随流/判结更新。
- **经验（跨线）**：离线蒸馏产物。
- **索引**＝结构（人/thread/未了）＋ 大维度（人/主题）＋ 要素（语义描述）。

## 4. 写：读即写 ＋ 路径传播

- 判结 → append 段 ＋ 打结构索引（人/thread/结）。
- **读（唤起）沿路径访问并记录路径**；读完沿路径**反向更新**：详情重投（不矛盾精化／矛盾转变），摘要就地重投或标记待离线。
- **更新范围＝本次访问路径，非全库**。

- why：**读即写＝记忆无"无损读取"**，读即投影、投影即变形更新。兜底＝重投判据（不矛盾精化＝可控走样；真矛盾＝转变物化，旧值留"我以前的看法"），故读着不漂移。
- 摘要"过时"不需离线维护：没访问＝没重投＝保持原样；哪天想起，骨架 `t` 时间戳天然给出"旧"感。

## 5. 读：唤起，多路并行 → 模型终判

- **流内直取**（续流，上下文在手）｜**新流**：结构粗筛 → 大维度匹配 → 要素精筛 → 模型终判。
- **多路并行**各产 top-1~2 有界候选，合并交模型终判；**哪路相关由上下文定，不由机制预加权**。
- 线索＝线概要＋最新结论＋当前输入。
- **机制含 LLM**：选路/要素分解/打分都是调 LLM，机制层管"何时调、以什么线索、结果怎么并"。

- 联想多维：语义/主题、结构相似（类比）、动机/价值、时空邻近、情绪、逻辑因果——**动机非唯一**（10-05"锚空间多维，缺口只一维"早已否"只从缺口出发"）。
- 可借业界：Generative Agents `recency+relevance+importance` 打分合成；MRAgent「重建非检索」＝结构化检索＋多步可改道遍历（本质仍是检索，tag 作中间层先剪枝再取昂贵 content）。

## 6. 离线：只做蒸馏 / 结构涌现

- **职责＝跨经历抽象重组 → 经验/维度（B 的涌现）**；**不维护摘要新鲜度**。
- 重投预测误差门控（事件驱动，非每流）。

- why：读即写已覆盖"内容更新"，离线不需要也不该管新鲜度；离线的独有价值＝E1 定性重组（规律/抽象/泛化/新组合）。

## 8. 新钉概念（进 glossary）

- **读即写**：读即投影、投影即更新；记忆无"无损读取"。兜底＝重投判据＋转变物化。
- **路径传播**：读即写的范围＝本次访问路径（入口→摘要→详情），沿路径反向更新，非全库。
- **检索投影 vs 认领投影**：检索投影（事件→线索→匹配，机制必须）≠ 认领投影（事件→『我』，被否叙事）。现 glossary「投影」已收窄为自指，须拆分。
- **图底层 / 树视图**：图＝底层原语；树＝只留层级关系的视图。
- **唤起多维**：语义/结构/结构相似/动机/时空/情绪；非动机唯一。
- **机制含 LLM**：机制＝实现功能的完整安排；语义子功能调 LLM 是常态，机制层管编排，不与 LLM 对立。

## 9. 被否 / 防重提

- **动机门控当唯一**——否定位（锚空间多维，动机只一维）；动机仍是一路，非主排序。
- **平铺记忆**——否结论；图底层＋树视图。
- **树当底层原语**——否定位（09-01 checkpoint-7）；复活为"树当视图"。
- **投影当认领叙事**——否定位；复活为"检索投影"。
- **离线维护摘要**——否结论；读即写，访问时更新。
- **精确 dict 索引 / 种子当隐藏 prompt**——否结论，留理由防重犯。
