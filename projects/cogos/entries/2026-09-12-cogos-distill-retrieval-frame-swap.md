# 2026-09-12 蒸馏再校正：投影 ≠ 替换，回取 ≠ 立即取，换帧要质变（会话 #6）

> 从 YZ 三个直觉出发（蒸馏内容过长？目的/触发是什么？实验像固定模式），逐轮追问，
> 最后定位到三处概念错误。**结论改变 seed v2 契约与实验设计**。
> 前置：`entries/2026-09-12-cogos-general-agent.md`（模型）、`entries/2026-09-12-cogos-recurrence-arm-analysis.md`（复现实验）。

## 一、实验只做了蒸馏的一半（方向偏的确切含义）

设计三时刻 = 蒸馏（投影）→ 存储（底片原地不搬）→ 加载（按需解引用）。探针实际：

- **投影有**：帧 A 末尾让模型吐 JSON seed（`research/ctx_seed_probe.py:296-312`）。
- **底片无**：帧 A 的 material 用完即弃，只留 `raw.jsonl` 给人类看，agent 够不着。
- **解引用只对世界**：seed 的 `pointers` 定义就是"文件路径#符号 / 命令 / scratch id"（`:64`），
  帧 B 是重读文件（`_FakeLmClient` 第 4 步 `:230-235`）。**没有指向自己帧的句柄**。

→ 测的是"**摘要能否单独站住**"，不是"**投影+回取能否续接**"。
→ 偏的诱因：判据借视觉 P3"纯文字锚重建窗口"，要求"只给 seed、无回取"。视觉那里图块 K 轮老化真的不可回，
  意识层却明确要留底片——**判据把手段变成了目的**。
→ 两个症状同源：seed 被逼"完整"→**长**；丢掉的原件不可寻址→**截断（愚蠢的丢）**。

## 二、底片不需要"读后改写"（撤回 reconsolidation 字面解释）

三层要分开：**存储（字节，默认不变）/ 投影（帧，必然走样）/ 解读（帧内意义，必然走样）**。

- 走样的是"**它在当前处境里的意思**"，不是那串字节。引入上下文的是**帧**，不是存储。
- 取舍压力确实出现在"**要用它的那一刻**"（依赖当时目标），但**结果留在帧里，不污染存储**。
- 存储：只追加版本 / 标过期；取：投影进当前帧；**永不因"读"而覆盖底片**。
- 更正/老化是**独立显式**动作（新版本 / stale / 后台 GC），不是读的副作用。
- 撤回 §九"底片也在变"；"写时付读时省"（索引，**写**时组织）与"有损发生在取出"（**读**时重投影）是两件事，别混。
- 连续性由**帧的蒸馏链**承重，底片只被**引用**（解引用），不被改写。

## 三、两种指针 + 回取的真场景

- **世界指针**（文件/命令）= 重推导事实；**自有帧句柄**（frame/record id）= 取回我自己的过去。
  探针只有前者——所以它那次"取"根本不是回取记忆。
- **立即取**的判据不是早/晚，是**选择性**：
  - 取一个**明知没带**的具体点来收尾 → 正常（轻装+指针的设计）。
  - 要靠旧帧**整体重建操作态**才知道下一步 → **换帧白做**。
- **真回取场景**（YZ）= 若干帧 / 另一场合之后，才想起"我以前做过、可能有用"→ 去回取。
  此时**指针不在手**，需要的是**相关性识别 / 召回**（我们之前明确推迟的"联想召回"）。
- 复现实验其实是它的简化形态（同 task_id、库按身份 key、agent 去查并判断信不信），
  但**壳把指针递到嘴边**（`_env_header`/`build_occ2_task`，`research/ctx_recurrence_probe.py:134-173`），
  缺的是"**无提示自认相关**"。
- 召回第一版可以很土：靠**身份/标签/`dropped` 的形状**（"我当初选择不带的形状"正是日后"可能存过货"的钩子），
  **不做 embedding**（符合"不预造"）。

## 四、换帧的必要性（不是省 token）

- 同一目标下的连贯工作，换帧**没有收益**；"立即整体取"就是反证（等于把收益当场还回去）。
- 只有状态**质变**才值得换，四种（强→弱）：
  1. **从外面看自己**（自评/审结论）——**边界是构成性的**：没有"那边那个帧"就没有可指向、可评判的对象。
  2. **放下一件、拿起另一件**（parked/换线）——每条线程需各自可寻址的帧。
  3. **目标/关注点变了**——旧目标上下文成噪声，须按新目标重新投影。
  4. **装不下**（预算）——最弱，只推出"稀疏按需取"，单靠它加个更大窗口就绕过。
- 唯一不可被 append 替代的收益：**把"我自己"变成一个可以指向、也可以返回的对象**。没有边界就没有"过去"。
- 探针换了帧却立刻重建操作态 → 该边界**只承担了丢 transcript 的坏处**。

## 五、对 seed v2 的输入

**新增/修正**：
- seed 形状 = **判断层**（结论/依据摘要/排除项，自含正确性）+ **句柄层**（**自有帧句柄** + 世界指针）
  + **装载框架**（连续性准则 / 出处 / 可比较事实）+ **职权声明**（这个 seeded frame 能做什么）。
- 换帧触发准则（第四节四种质变点）必须写进契约。
- 取的两类与准则（选择性 vs 整体重建）。
- 补回取半边：**帧存储 + 自有帧句柄 + 选择性解引用**。

**保留的旧结论**（与回取正交）：
- 维度塌缩 / `open`⊕`next` 混轴；schema 挡不住语义（`open` 仍被填非阻塞项）→ 形状不该由壳固定到"填什么"。
- **通则：壳只给事实，模型定策略**；不建信任等级/权威标记；不做"世界敏感/静态派生"分类；不规定"一律重验"。
- **连续性准则**：壳标"当前延续"必须由依据导出，不能口头断言（`plain` 0 调用正因壳谎称"当下"）。
- agent 有合理时序/亲疏启发式、不盲信（篡改被识破）；E1 重做真因是**内容组织**，不是信任。
- 出处字段形态 = **可比较事实**（时间戳/版本指纹），给数据≠给指令。

**作废/降级**：
- 各臂调用数**幅值**（无退路下被放大，方向可信、大小不可迁移）；"零调用=好"。
- "seed 必须自含=记得全"（改为"判断自含"）；§九"底片也在变"。
- `identified` 增量、`missing`/`poison` 加强臂、"自洽但隐微错"对照（已定噪声）。
