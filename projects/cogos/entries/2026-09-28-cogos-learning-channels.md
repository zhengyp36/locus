# cogos 学习通道：先猜 vs 先学 → 选通道（2026-09-28 讨论收口）

> 结论：学习不只试错，至少**三通道**；"先猜 vs 先学"重框为**选通道**；用法知识归记忆（段+权重+活跃度+取回）；"显式思考"的机制含义＝想通道作**可选 slot**。非新任务，作第一刀（落段）验收观察点。
> 同批：`entries/2026-09-28-cogos-loop-pivot.md`（转外圈/内圈）。依据 checkpoint-1 §7.4（通道语义）· 本体 `design-selfdrive-agent.md` §8/§11/§15.4。

## 1. 首猜错 / help 学习环（YZ 定调，AI 修正）

- **结论：当前规模下"先猜一次 → 自纠 → 上下文里看到用法 → 后续不再猜"良性且便宜，不是问题。**
- **AI 曾误判"抹痕破坏该学习环"→ 撤回**：抹痕抹的是**调用外壳**（`assistant.tool_calls` 结构/id/args、`role:"tool"` 格式），**结果内容改成追加消息保留**；help/错误文本在结果里 → 留存。
- **真实残留风险两条（外圈时回看）**：
  1. **上下文红利会被架构换掉**：`_context` 进程内常驻、无上界，设计要改"装载三节+取回"（§11）→ 跨弧/重启"上次出现过"不再自动成立。属**装载**，非抹痕。
  2. **语义错不便宜**：边界校验（`toolbox.py:192-232`）只拦结构性错误（未知键/缺必填/类型），拦不住"键合法但语义错"；写世界类（如 `screen.act` 的 `to`=drag 终点，模型可能当目标元素）会真产生副作用 → 首猜便宜应**按能力类型分级**。
- **附带认识**：实测 help 0/10 → help 退化为"恢复/精确化"工具，发现主要靠模型先验 → §19 先验准则比看上去更承重；能力表一涨、先验覆盖不到就会回到 help。

## 2. 用法知识归记忆（YZ 定调，AI 认同）

- **结论：'用过就记得、久不用淡、再用强化' ＝ 用量知识交给记忆（段+权重+活跃度+取回），是设计既有的切法、非权宜。**
- **分层一致**：接口规范＝机制层（先验定死，catalog 权威）／用法习惯·经验＝价值层（经历长）——同 §8 机制-价值分层、§15.4「机制给戳、经历长判断」。
- **caveat #1 由"洞"变"对记忆的要求"**：常驻 `_context` → 装载三节+取回后，"上次见过"由段/权重/活跃度/取回承载，不必靠常驻；有损＝忘了就便宜重学。
- **记忆承载什么**：① 接口事实（参数名/类型）→ catalog 权威，记忆最多**软先验**，冲突 catalog 赢（同 `time_form` 纪律，别当第二口径）；② agent 自己的惯用法/偏好/历史（重定向再读、联系人号码、机器目录）→ 记忆正域。
- **落地两要点**：① **落段要有承载**——段字段 `内容/后果/结…` 无"调用参数/用法"字段，记忆要"记得怎么调"须定它落哪（进 `内容` or 加字段）；② **抹痕 ≠ 不记录**（抹呈现，沉淀照记）。
- **推论**：边界可读错误从"临时缓解"升为**长期必需件**（软先验记忆 + 硬校验边界）；"猜/help"退成**冷启动兜底**。

## 3. 方法论：交互前的显式思考（YZ 提，AI 补充）

- **YZ 定性**：与外部交互前应有**显式思考过程**——动手则估代价，先学则估成本。差别小则无所谓，越复杂/代价越不对称越重要。**不是要注入 agent，而认为自驱 agent 应当能学会**。
- **AI 补三条约束**（否则"能学会"是空的）：方法论要长出来，必须 ① 可见（显式=想通道）② 有后果（代价落账）③ 能留存（记忆）。**边界上现三条全破**：想通道被"自动补发"污染（违 E0）；`on_tool_call` 丢弃 calls+results（无代价信号）；用法/后果不入记忆。（针对**自造经验/试错**通道；**现成经验**通道另需 供给+信任+留存。）
- **学习不只试错（YZ 修正，AI 采纳）**：AI 上一条把学习窄化成"现实碰撞的试错"＝最贵/最晚/最危险的**一条**通道。学习至少三通道：① **直接学现成经验**（教育/他人/文档 ↔ `help`/`catalog`/接口规范、记忆里"别人教的段"，低、无损）；② **模拟中试错**（沙盒/想象/推演 ↔ 重演 #18、world model，中、可回滚）；③ **现实试错**（高、可能不可逆）。
- **口径更正**：不是"廉价世界学不到、需代价方差"，而是**知识可得性 + 代价异质性**。本例 `help`＝现成经验且近免费 → **"先学"其实更便宜**；猜之所以发生，是现成经验**没被供给到点上**（参数名不进 schema、help 不在手边），非"学不划算"。**"廉价世界里猜理性"仅对试错通道成立**，作全局论断不成立。
- **重框定：非"先猜 vs 先学"，而是"选通道"**——有现成可学→先学；无现成但有模拟→推演；皆无且代价高→先想/求确认；廉价→直接试。**这个"选通道"就是"交互前显式思考"要决定的内容，且它本身也是可学的知识。**
- **信任/校验属"会学"**：现成经验会过期/错（help 说 A、世界是 B）→ 需可信度判断 + 权威口径（catalog 权威、记忆只作软先验，§2）；会学 ≠ 照抄。
- **原生"现成经验"通道**：cogos＝多 agent + 飞书总线 → 经验可跨个体传递（agent 教 agent），人类靠教育而非全靠试错的社会性版本。**只作方向，不承诺现在做。**
- **"显式"的机制含义**：不强制每步先想（overhead + 反向失败 = help-crawl 的对偶）；机制只提供**可选 slot**（想通道），何时填由经历长。想通道语义（E0：想=`content`／说=send／沉默=默认、禁自动补发）因此升为**第一刀关键路径**。
- **与预测的关系**：估代价＝预测，但**不需先造显式预测器**——后果落账+取回+权重即可长出"这类动作危险"的先验；仍是同一接缝：**先捕获后谈**（`on_tool_call` 保留 calls+results）。
- **与动机根汇合**：代价＝疼；"先想再动"是疼的下游，天然该长、不该注入 → 正是 #14 动因根在交互边界的体现。
- **落计划**：非新任务；作第一刀（落段）**验收观察点**——猜错代价是否入段、是否跨弧改变下次策略。前置次序 捕获→段→装载→取回，方法论只在**闭环后**显形。
