## 0. 一句话

**记忆＝一张 索引→内容 的有向图**：写时建入口、检索走入口（**不扫描**）、**重投改写入口的指向**。经历／经验／动机倾向皆记忆；机制通用而记忆独特，故**记忆即自我**。方向：**下一步先落记忆**（经历轴只是经历层雏形）。

## 1. 记忆是什么

- 记忆 = **经历 + 经验 + 动机倾向**，可读可写；机制通用、记忆独特 → **以独特部分指代整体＝那个自我**。
- 初始 agent 无经历、有倾向（好奇心等种子）；倾向可被经历重塑＝记忆改写。**现阶段默认倾向来自基座模型**（提供帮助），非我们注入；缺的是**积累/改写它的机制**。
- 三层，各有身份语义：经历层 ／ 经验层 ／ 外部日志（**非记忆**）。

## 2. 写侧：没有「世界原样」

- **不存在「世界的原样」**。agent 的逐字输入是**外部日志**（＝手机里的聊天记录），**不是记忆**；记忆是**写时那次投影**（＝认领）。agent 的理解/反应即那次投影，现由基座倾向驱动。
- 写侧纪律：**写宽 = 写时建多个入口**（不是存「原样基质」）。因为检索不扫描，能否再激活取决于**别的入口**是否还指着更全的内容。
- why：人一进意识就在投影；把逐字当记忆是误设。日志保留供**开发者**证伪/分析。
- **被否**：**「原样保存／保真基质／原始记录」**（退——暗含「对世界的原样」）；**「保存时投影就错」**（修正为「别用投影**替换掉**入口所指向的内容／别只留窄的」）。

## 3. 投影有两种（务必分开）

- **重投（回忆）**：沿**已有入口**读出 → 投影 → **更新该入口的指向**；**身份/时间不变** → **走样**。同一条经历只有一个身份，**无「选哪份」问题**。
- **蒸馏／巩固**：从若干经历**产出新身份**的高层记录（经验/抽象），来源＝被蒸者 → **金字塔向上长**，慢。
- 「投影产物变成一次新经历」＝后者；「投影改写经历」＝前者。混用会得出「既会变成多份、又该只有一份」的矛盾。

## 4. 索引模型（核心）

- 检索＝**线索命中索引 → 取该索引当前指向的内容**；**不扫描**。
- 重投改写＝**改这条索引的指向**（局部事件）；**别的未触发索引仍指旧内容** → 同一经历、不同入口不同版本，**由线索决定、无需仲裁**。
- **保真无从发生**：要保真需一条绕过索引、直达「底」的读取路——不存在。即便「未重投的入口」取到的也是**写时那次投影**，非世界原样。
- 对上 09-17：**可得（内容在）vs 可及（有入口）**——遗忘＝入口断（可及丢），年龄淘汰＝内容没（可得丢）。「有损是筛选／全量可达会取消筛选」＝**无线索入口者不浮现**，天然自带。
- **粒度问题 = 索引词表问题**：丢不丢看有没有别的入口还指更全内容。热入口快 gist 化、冷入口保留原貌＝**走样不均匀**（符合预期）。

## 5. 时间

- **时间戳属经历本身**，重投不刷新。
- **时间精度随年龄衰减**（精确时刻 → 模糊区间）＝沿时间轴的一次蒸馏。

## 6. 冲击 / 权重

- 冲击＝写时那次投影的产物；＝ **预测误差**（09-17 切点）**＋ 动机相关度**；＝ **入口的初始激活**。
- 权重/冲击**作用于点火/抽样，不作用于删**。高冲击自然引起重投 → 蒸馏成新记录 → 因新时间不被淘汰。

## 7. 淘汰

- 分两步：先丢**可及性**（入口／降激活），年龄到了再丢**可得性**（内容）。
- 不把权重当淘汰判据。调和 09-17「淘汰由后果驱动、不由年龄」：后果（重投）更新入口，年龄清未被重投的内容。

## 8. 晋升 / 长期记忆

- **反复重投、收敛到同一 gist → 支持度↑ → 晋升长期**。
- 机械层「怎么发现反复蒸馏」：**不用代际计数**，用 **来源谱系 + 支持度**（同一特征/结论反复作为投影输出出现）。谱系供**证伪/追溯**，不参与权重。
- **提纯 vs 改写**：提纯＝入口内容反复收敛同一 gist（支持度涨）；改写＝入口内容变出新东西（新内容、自有支持度）。
- why：代际在「两份一起蒸」时无解（既非原物、又重复计数）；支持度＋谱系对两种都成立。
- **被否**：**代际计数**（深度）作通用原语。

## 9. 动机倾向 / 守得住

- 倾向在**金字塔顶层** → 单次经历撬不动 → **「守得住」是聚合深度 ＋ 时间尺度分离的必然结果**，不需额外保护机制。
- **时间尺度分离**：底层快（每次经历都投）／顶层慢（只由中层聚合更新）；倾向更新率 ≪ 经历产生率。
- **待定（承重缺口）**：**顶层如何聚合**（三档频率 ＋ 支持度阈值？）——只给方向，未定。

## 10. 结构表

| 层 | 身份/时间 | 内容 | 变化 |
|---|---|---|---|
| 经历层 | 稳定 | 写时那次投影（**写宽**） | 沿入口重投改写（走样）、衰减 |
| 经验层 | 新身份 | 蒸馏产物（经验/抽象） | 向上生长、慢 |
| 外部日志 | — | 逐字输入/往来（**非记忆**） | 只增、**agent 读不到**、供开发者证伪 |

## 11. 被否 / 防重提

- **原样保存／保真基质／原始记录** → 退（暗含世界原样）。
- **代际计数** → 否（用支持度 ＋ 谱系）。
- **「保存时投影就错」** → 修正（错的是替换/丢入口，不是投影本身）。
- **agent 可读细底/日志** → 否（保真旁路会取消蒸馏；日志开发者读）。
- **破坏式就地改写（删未关注处）** → 否（用保留入口 ＋ 激活漂移；底仅经入口可达，非保真）。
- **倾向当静态 prompt** → 否（缺积累/改写机制，正是本模型要补的）。
- **「先给动机种子」** → 弱化（默认倾向来自基座模型，不必先造种子）。

## 12. 开放（动手前要定）

- **B 索引词表（锚清单）**：入口有哪些、怎么建；承重（决定可及面/粒度）。
- **D 激活/重投规则**：线索来优先走哪个入口、写入给哪些入口、重投改哪个入口的指向；冲击＝入口初始激活。
- **E 淘汰实现**：入口/内容两步、衰减率。
- **倾向更新算子**：三档频率 ＋ 阈值。
- **尚未落码**（纯讨论收口，无证据）。

## 13. 与既有收口的关系

- `经历轴`（第二刀）＝**经历层的读侧雏形**；本模型把「时间＋线/thread＋结＋关联」的读法升为「索引→内容」。
- P8「关联/续线」＝入口的一种（thread）；其「只写不读」遗留，在本模型里 ＝「入口暂无读侧用法」。
- 09-17 被吸收：内容寻址／加权抽样／可得可及／有损是筛选／整理=抽样重演；其「三层（结构化轴/原始存档/后压层级）」≈ 本模型 经历层／外部日志／经验层（**近似，非严格对应**，待并）。

## 14. why 汇总（为什么这么定）

- 「保真在写、蒸馏在读」会滑向数据库 → 改为「**写宽建入口、读时收窄**」。
- 索引模型解决「无锚无法投影／全量扫描不可行」：锚**写时留下**、检索**走入口**。
- 保留入口内容（非破坏式）解决「粒度过粗→重投丢有用信息」：别的入口留原貌，可**再激活**。
- 时间尺度分离解决「会改」与「守得住」的张力。
