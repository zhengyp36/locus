# 2026-10-05 记忆模块 v0 形状 + 生念/自启（讨论收口，未落码）

> 性质：**讨论收口**（纯讨论、未动代码）。承 10-05 定义层（motive-roothood）· 10-03 memory v1/v1.1/v1.2。
> 起点：fork 会话停在"照 shape 写最小版"后，本会话续论——先把"记忆怎么被**使用**"看清，再定 v0 形状，最后解决"从空白如何**自启**"。
> 术语权威＝`glossary.md`（本会落：好奇·新奇取向／空闲事件·tick／浅浮现；补注 注入·种子）。写法：结论 + why + 被否。

## 0. 一句话

记忆模块 v0 **无索引**（`记/忆/整理`、单值）；**种子＝常驻驱动力**（好奇＝未闭合信息缺口＝自产未了），故空白**不需要特殊首启**；**tick＝事件源**（信号→空闲事件，与外事件同一条环）；环路＝**两段 LLM**（机制层投影→意识层生成），事件不直接进 agent；浮现与主动回忆＝同一次 `忆`。

## 1. 用法先行：记忆在更大过程的四个位置

记忆不是主角，是**被机制层在四个时点调用的独立源**：

| 位置 | 时点 | 记忆动作 | 作用 |
|---|---|---|---|
| M1 | 流起点（机制层投影） | **读**（忆） | 给投影提供"自我"、定初始目的/方向 |
| M2 | 展开中（内部事件/预测误差） | **穿插读**（回边） | 纠偏、过去影响现在 |
| M3 | 停/段落 | **写**（记/沉淀/蒸馏） | 固化经历、慢层生长 |
| M4 | 离线 | **整理** | 蒸馏＋重整索引（有损允许） |

- **why**：单值出口因 M1 投影只用"浮现的一点"；语义匹配因 M1/M2 线索与内容非字面相等；写宽因 M3 写时不知未来线索；持久因 M1/M2 与 M3/M4 时间分离。

## 2. v0 形状（无索引）

```
契约：记(经历)->id ｜ 忆(线索)->内容 | 浅浮现(锚) | None ｜ 整理()
数据：种子层 + 段{id, t, 内容, 效价(松/紧), 结(了/未了/挂起), 来源, refs}
边界：单值、无候选、无采纳；认领/决策/自指投影在模块外
```

- **v0 不建索引层**（锚/维度/涌现/索引重整留 v1+）；写宽、无维度。
- `忆` 必含**自我路（效价/未了/近因）＋语义路**，否则塌成主题（退化 RAG）。
- `忆` 输出留**浅浮现**位（类型留位，v0 可先不实现），主动回忆才挂得上。

## 3. 生念：种子常驻 + 好奇＝信息缺口

- **种子＝常驻驱动力、不退役**：空白＝seed-only 投影，成熟＝种子＋浮现叠加。**故无特殊首启分支**——这是本会话的关键修正（此前误把启动当特例）。
- **好奇的本质＝未闭合的信息缺口→张力**（判据＝预测 vs 实际／已知 vs 未知，接"预测误差/冲击"）。"想了解未知"是现象，不是本质。
- **LLM 不"演好奇"**（"哇好有趣"无方向），而是**产出它回答不了的具体缺口/问题**；机制把缺口存成**未了**，驱动由环路给 → **好奇＝自产未了**。
- **两条轴别混**：好奇（张力）造探索方向；效价（松/紧）定什么被沉淀。
- **防伪判据**：好奇表现为**求取信息的行为**（观察/追问/尝试），不是说好奇的话。

## 4. tick / 空闲事件

- **tick＝信号（无内容）**（时钟）；机制收到 tick 后**合成空闲事件**（最小事实模板＝内部事件，如"now；无输入；记忆空"）。信号≠事件，别混。
- **外/内事件统一**：同一环，差别只在内容有无（外事件有内容、tick 事件无内容）。
- 触发最简＝**闲置超时**（已覆盖"超时必然"）；**概率斜坡**（0~t1低→t1~t2升→>t2必然）是精化——好处：省调用／保活性／像"无聊"／不打断。
- **活跃时抑制 tick 不绝对**：活跃态已有内部事件（预测误差）供念，抑制无损失。

## 5. 环路

- `事件 → 装载(解析+投影→处境/张力；读记忆) → 生成 → 动手 → 判结 → 沉淀(写记忆)`。
- **两段 LLM**：A 段机制层（解析+投影，意识不可见）；B 段意识层（装载→生成）。**事件不直接进 agent**，先投影。
- **浮现＝装载里的 `忆`**（被动）；**主动回忆＝把浅浮现的锚再当 cue 喂回（＝再 query）**，不需新机器。`忆` 由**两来源**发起：机制（投影/内部事件）＋意识（意图）。
- **自我＝经历沉淀后涌现**；启动期**前自我**（位置先于自我内容）。空白只空"独特"那半，基座带人形先验，法则是筛子。

## 6. 推进计划（5 步、逐步验收）

先定二级用法（本文）→ 导出对一级的要求（记忆含种子层／段带效价·未了／忆含自我路＋浅浮现位）→ 一起造，**不分"阶段"**。

1. 场景＋判据（空白启动＋跨语义召回，含撤种对照）——不落码。
2. 记忆 v0。
3. tick＋生念。
4. 环路接线。
5. 收口（蒸馏进 entries/glossary/current）。

判据：空白生念（撤种对照不生念）／跨语义召回单条不塌主题／回边读＋落段。

## 7. 被否 / 防重提

- "精确 dict/单条精确索引"（10-03 否）——不得回流。
- "存储 dict/list 够"——作废（索引形态由使用逼定，非容器琐事）。
- 把"一级"当**独立阶段**——作废（只是依赖顺序/接缝）。
- **特殊首启分支**——取消（种子常驻即覆盖空白）。
- 种子＝"隐藏 prompt"——纠正：种子**本就该显露**；问题在模糊词**无操作性**。
- "要活/要动/要探索"当种子——装执著，否。
- "先有自我才有事件"——否（自我是沉淀涌现）。
- 法则有"特有部分"——否。
- 投影＝独立控制拍；认领/采纳作行为词——已否。
