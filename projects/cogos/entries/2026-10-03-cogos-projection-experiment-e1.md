# cogos：投影实验 E1（纯推理能否靠投影持续）——天花板，未证

> 性质：一个**收口实验**，为"投影·控制拍必要性"提供证据；结论未证，间接支持 v2.2 将其降为可插拔占位。
> 上游：`process-current.md` v2.1 #1；结论落 `entries/2026-10-03-cogos-first-cut-flow-claim.md §1`、`glossary.md`（投影/控制拍行）。
> 源 scratch `2026-10-02-projection-experiment/` 已随收口删除；证据 `checkpoint/26-10-03-first-cut/`（`e1-experiment.md` / `e1-results.md` / `e1-run_arm.py` / 原始输出 `out-t*.txt`）。

## 1. 命题（可证伪）

无新外部信息时，**纯推理的多拍推进，只有靠投影注入"新框架"才持续**；仅回喂 / 泛继续会空转。

## 2. 方法

- **模型**：cogos lm-service，`tier=basic`（与 agent 默认一致），`temperature=0`，每拍固定 `max_tokens`；`tools` 关（纯推理）；**N=4 拍**。
- **四臂对照**：A 纯回喂｜B 泛继续（等长控制，**无框架**）｜C 目标对齐投影｜D 『我』对齐投影。B 是关键（控住"多给指令/长度"变量）。
- **度量**：每 case 预写**解图**（正确推理节点序列），逐拍标 推进 / 空转 / 漂移 / 结算。
- **判读**：C/D 显著优于 A/B 且 B≈A → 成立；B 也能推进 → 推翻；C/D 也不动 → 地板。

## 3. 结果

- **C1（服务超时诊断·诱饵）**：arm A **round 0 完整答对**，后续 1–3 拍无新增正确节点，仅膨胀（固守首答、不断加壳）。**天花板 → 弃**。
- **设计调整（YZ 认可）**：改用"**陷阱型**"（round 0 高概率错/不全）＋加"纠偏"维度。
- **T1（监控整点尖峰·反直觉）/ T2（排班·约束陷阱）**：round 0 两臂均**完整答中**（T2 正确判"无解"），后续 1–3 拍无新增正确节点。**均天花板 → 弃**。
- 原始输出见证据 `out-t1-A/C`、`out-t2-A/C`。

## 4. 结论 / 教训

1. 两个精设计陷阱在 `tier=basic` 上 **round 0 即解**，无一产生"错或不全"。
2. **A vs C 无差异**——但属**天花板导致的不可分辨**，**既不支持也不推翻**命题 #1。
3. **负向观察**：arm C 输出更长（T2：C 499 行 vs A 322 行），投影提示诱发大量"逐条核验/再确认"式**膨胀**，C round 1 即触发 `max_tokens` 截断 → 无增量时，投影不但不推进，还可能**放大冗余**。
4. **教训**：靠手写"陷阱"保证 round 0 出错未成功；该模型能力足以秒破。要观测投影增量，题须落在**模型能力边界**上。

## 5. Why it matters（→ v2.2）

- 结合业界评估（主流单趟长思考 A / 外部反馈多轮 B；自评系 C 证据偏弱、适用域窄），实验**未能给出投影的无条件收益**。
- → 判定"投影＝推理质量手段"必要性未证，**降为可插拔占位**（保留"投影·自指＝认领"）。见 `2026-10-03-cogos-first-cut-flow-claim.md §1`。

## 6. 被否 / 留白

- **手写陷阱用例能稳定逼出 round 0 错误** → 否（模型秒破）。
- **原始回喂＋继续**（arm A/B）作为"多拍推进"手段 → 否（无新信息 → 膨胀/不动点）。
- 未定：改题型 / 能力边界题 / 穷举全覆盖 / 改"推进"度量 / 降模型 tier（若日后重验必要性）。
