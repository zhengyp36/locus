# 2026-09-12 通用 agent：上下文组织是自驱的地基（路线修正）

## 起点问题

当前自驱回路是**为工程任务设计的**（任务 → 判据 → 终态）。若不是工程任务呢？纯思考型——为一个目标想一个问题、做调研、做分析、做了一半评估后觉得复杂先放放、转入其他事——这个回路能实现吗？一路推下来，得出路线修正：**自驱的地基是上下文组织，不是调度机制。**

## 一、回路的三处硬缺口

1. **判据是机器二值**。脊梁是"红→绿"，`verdict ∈ {done, needs_human, no_work}`，`needs_human` 的 reason 全是 `no_change/stalled/max_steps/invalid_criterion`。假设"完成"有客观信号（测试）。思考型没有：它的"完成"是判断，不是事实。
2. **没有"半成品"状态**。状态只有 `todo/in_progress/done/needs_human`，`in_progress` 只活在单次 run 内，run 结束必须落终态。"做了一半、先放放"在词表里不存在（`needs_human` 是"我卡住要人"，不是"我主动搁置"）；思考型最有价值的半成品（线索、未解问题、当前判断）无处存。
3. **调度是单条一枪到底**。`pick_next` 一次挑一条、跑到终态。跨 run"转入其他事"天然成立，但同一 run 内不能"停当前、开新线"，也没有"这条该降级/推迟"的决策出口。

## 二、"该放放"由谁决定 = agent 自己

**"放放"不是认知判断（对不对/完成没），是调度判断（继续投注意力的边际收益低）。** 所以"自欺"的失败模式不成立：搁置 ≠ 完成，它不需要正确，后果由这个人自己后面承担。

人敢搁置，靠的不是判断准，是三件事：状态留着、随时能回来、搁错的代价小（丢势能，不丢正确性）——即**可逆 + 持久**。故设计涵义：

- 壳**不替 agent 当裁判**，而是**记账员 + 护栏**：持久化 parked 状态、管预算、把账本低频给人看。
- 机械信号（步数/时间）只配当保险丝（真跑飞才断），**不配当决策者**——否则等于把调度权从 agent 手里拿走，删掉了要建的主体性。
- 帮 agent 做决定，给它看的东西应是**"这一轮我的理解变了多少"**（新问题开了/关了、线索增/原地打转），而非"我对不对"。这是**张力驱动主题调度**的雏形。
- 主体性 = 流动的调度权 → 谁决定放放，谁拥有主体性。

## 三、append-only → 不能换脑/换线 → 不能自评

现状：`consciousness.py` 的 `self._context` 是裸 append（初始化 `[system]` 第 51-53、每消息 append user 第 59-61、回填 assistant 第 94），整条传给 cu 当 `material`，**从不重组、从不截断**。

- append-only 的本质：**帧 = 日志**。你还是你积累的全部，没有"从外面看自己"的位置 → 自我评估结构上不可能（不是难）。
- **换脑 ≠ 另一个 agent**：扔掉当前帧、从蒸馏后的状态重新实例化——同一个 agent 就能做（人就是"睡一觉、退一步、重新给自己讲一遍"）。人脑记忆本就是**有损、摘要、可重组**的 state，append 是人工病态。"另一个 agent"只在**不能**重新实例化时才被迫需要。
- 两个能力，append-only 都堵：
  - **能出（换脑）**：放下当前帧、从蒸馏状态重启 → 自评的前提。
  - **能切（换线）**：多条线程当可寻址对象，一次激活一条 → 搁置/切换的前提。
- 同构先例：视觉侧 `cog_ctx/FigContextManager`（compile 当前轮、K 轮老化、strip 超龄）已是"context = 可重组状态"；意识侧还是 append。

## 四、"扔帧"不是扔掉，是投影（有损 + 指针）

- 帧是**投影**（有损），存储是**底片**；关键分界是**可逆**——扔掉不可逆，换帧可逆。结构三层：帧内蒸馏 / 帧外转存 / 索引寻址。
- **硬约束：蒸馏产物必须带出处指针（gist + provenance，不是 gist）**。没有地址的结论无法重启、无法质疑，等于真扔了。
- 什么进帧 vs 转存，判据不是"重不重要"，是三条：①**能不能重推导**（可重推导只留指针）②**会不会被质疑**（承重推理转存，帧内留一行"怎么来的"）③**是否影响下一步决策**。
- 加载：帧内脚注/ID 可见，结论被质疑或不足时按需展开 = 已定的 **"scratch 脚注引用 + cu 化展开" / "目录 ID 化"**。纪律：阈值放宽成"重要的都留"，帧立刻退回 append。

## 五、有损是预算机制，取舍才是智能

- **转存也不是原样存储**：原样会爆炸（每层投影又生新 raw，越滚越大）。有损不是缺陷，是**预算机制**。
- 不是"帧 vs 真相"两态，而是**多级有损表示的金字塔**：换脑 = 上下移动，可逆 = 回到更细一级（**仍是有损**），不是恢复原始。
- 形式即 rate-distortion：**取舍 = 选失真度量**。取舍原则（直觉版）：丢可重推导的；丢可预测/冗余的、留意外/低概率的（出乎意料 = 信息量大，这条最狠）；丢与当前目标无关的；留 provenance + **"我丢了什么"的形状**。
- **无差别有损 = 截断（愚蠢的丢）；取舍 = 蒸馏（聪明的丢）**。策略依赖目标 → 是**智能本身**，不是固定压缩算法。
- 存储层自己也得会忘（老化、合并、GC），不是档案馆；**K 轮老化/摘图块**是同构的"有损遗忘"原语。
- 收口：**自评 = "能对自己的表示做取舍"这个 faculty 本身**，不是单独要建的能力。自评永远对着有损的自我 → 不可能完全正确（人也一样）；要紧的是**损失诚实、可再查**。

## 六、通用性 = 判据谱系，不是两种 agent

- 目标是一个 substrate，**工程与纯思考都是它的实例**；"工程 vs 思考"不是两个物种——**工程是"判据恰好可机器廉价判定"的极端**（红绿 = 线程状态可被外部廉价验证）。
- 轴：判据强弱（机器可判 ←→ 只能判断）；工程在硬端（不太需换脑，外部裁判跑一下就知道），思考在软端（必须换脑）。
- 通用化落点：**判据抽成可插拔接口**（返回 pass / fail / uncertain + 证据），红绿/自判/人判都只是实现。工程任务不回退（继续用红绿实现），思考任务接自判/人判。
- **"判据源外移" = 沿这条谱系把判据往 agent/人挪。** 现有 dogfood 是"判据强"端的验证，**不是白走**。

## 七、路线评估：方向没偏，权重偏

- **没偏、该继续**：机制/执行层 / 源外移 / 判据纪律 /"壳跑判据防自证"/ dogfood 实证；机制层归人、元控制二分（资源级机制 / 认知级策略）——哲学切分对。
- **偏三点（从深到浅）**：
  1. **单位错（最根本）**：整套是"任务 → 判据 → 终态"，6 格模型是其投影；思考型是"线程 → 状态 → 挂起"。用装任务的格子装线程，装不下——这正是"结构好像为工程任务而设"的根。
  2. **地基被归支线**：路线图把"跨会话记忆"放支线；但**上下文组织（换脑：可重组 + 有损蒸馏 + 指针索引）是 L3 的前置**——"议程自生 = 对自己的线程做取舍/调度"，正是换脑本身。
  3. **两跳里漏了最深一跳**：路线图说 L1→L3 只有两跳（常驻唤醒、议程安全件）；**append → 可重组**是第三跳，且在两者**上游**。没有它 L3 必撞墙。
- **L2 无地基 = 自动化，不是自驱**：先补地基再提速；否则自触发只会产出更多 `needs_human`。
- 一致点：L4"双自驱共驱、调度权流动"的前提就是"能换脑换线"。

## 八、下一步建议（三刀 + 路线修正）

- **第一刀（优先）**：意识上下文 **状态对象 + 冷启动重启**。从显式 state 启动 cu（非 append transcript），与旧路径并存可 A/B。判据 = **冷启动重建**（借视觉 P3"纯文字锚重建窗口"招）：只给 state、不给 transcript，能否重建出足够继续推进的上下文。
- **第二刀**：**线程单位 + parked/resume**。把"放放/换线"做成能跑的动作；判据 = 恢复后不依赖 transcript 仍推进，且可逆。
- **第三刀（后置，别预造）**：**判据接口抽象**（loop 的硬编 pytest → 可插拔判据接口）。
- **修正**：上下文组织 支线 → 主干，与 P1/P2 并行；L3 开题前先铺第一、二刀；6 格"验证"格改述为**判据谱系轴**。
- **边界**：冷启动重建是**代理判据**，只证"状态自含"，不证"想得好"；真正的取舍策略从失败里长（符合"不预造"）。
- **分工**：结构性大跳，探索型——一个 owner 设计 + 实现同一人，另一工位末端复核；B 的 task-6/7 不受影响。

## 九、帧与上下文：三时刻 + 两节拍（09-12 续，模型精化）

- **帧内串行（append）是正确的起点**：不先贴身接触问题，没资格蒸馏。串行不是缺陷。
- **换帧是三时刻，别混成一步**：①蒸馏（换帧时，agent 主动；**取舍全在此**）②存储（旧帧**原地不动、不挑不搬**——"转存" = 不销毁，不是选择动作）③加载（新帧工作途中按需"拉"）。
- **有损发生在取出，不在存入**：存可相对原样（后台老化兜底）；有损重组发生在每次读/再蒸馏。神经对应 **reconsolidation**——**读会改写存储**，底片也在变。
- **连续性 = 蒸馏链，不是 transcript**：帧一次性、链承重。换帧 ≠ 旧帧变成新帧，是"**从旧帧的蒸馏重新长出**"新帧；旧帧作为独立过去帧仍在（可寻址）。
- **两节拍**：
  - **在线**：帧内串行 → 按需拉取 → 取出即走样（并回写）。
  - **离线（睡眠）**：批量重放（含白天没主动取的）→ 固化 / 抽象 / 裁剪 / 重组。不可省，两个理由：①**存储预算**（否则爆炸）②**抽象必须同时持有多帧，单帧结构上做不到**——按需拉取**替代不了**。离线有自身取舍（重放 recent/salient/surprising）→ 能救回"没被任务取"的东西、让结构涌现。梦境式"无任务重组"是 L3 议程自生的机制候选。
- **检索不是搜索，是解引用**：主路径 = 按 seed 指针 O(1) 取；难路径 = 无指针联想召回（后期优化）。**不变量：seed 自含、指针只加细节不载正确性 → 续线程永不需搜索**。若续不下去要靠搜原文 = 蒸馏失败。视觉 `taskB`"纯文字锚自含"是同证。
- **记忆组织 = 写时付、读时省**：索引建在**蒸馏链**（小）而非原始帧（大）；读 = 解引用 / 拿当前帧线索查小索引。暴力"过一遍帧 + 过一遍记忆"被**写时组织**吸收。

## 十、落地思路（四原则 + 三步）

- **四原则**：①seed 自含 ②写聪明读便宜 ③帧一次性链承重 ④不做联想召回（第一版）。
- **三步**：①**在线闭环**（seed + 冷启动重启 + 指针解引用，让"帧→蒸馏→重播种"手跑一圈）②**多圈 + 停/换**（parked/换线，"放放"到此才成立）③**离线睡眠**（批量重放/抽象/裁剪）。
- **第一刀**：`consciousness.py` 加并行路径（seed 显式启动全新 cu，旧 append 保留可 A/B），**不动 loop**；seed 粗形状 `intent / current_question / progress / open_questions / pointers[] / dropped[]`（末项=诚实字段"我选择不带什么"）；靶 = dogfood 仓库上"调查并回答一个机制问题"（真值 YZ 持），fixture 强制**至少一次换帧**；判据 = 冷启动续对（硬）+ 诊断漏了什么（软）；探索型单 owner 设计+实现，另一工位末端复核。
- **先不做**：联想/向量召回、embedding 索引、睡眠完整版、判据接口抽象、把 seed schema 设计全。
- **退出条件**：每次重启都丢承重线索且**不收敛** → 说明缺一层（多级金字塔 / 目标感知取舍），那时再上第二级，**不硬修 schema**。冷启动重建是**代理判据**，只证 seed 自含，不证想得好。
