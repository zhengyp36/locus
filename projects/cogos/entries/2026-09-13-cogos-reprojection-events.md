## 一、根在场 = 行为事件，不是文本常驻（YZ 纠正）

- handoff 原写"根每回合在场"（每回合把 root.md 装进 system prompt）——**用词错、且踩了 install 反模式**（常驻前缀 = 安装身份）。
- YZ 的模型：人不会一直想"我是谁"，而是沉浸在事里，**在"卡了 / 结束了 / 被问我是谁"这些边界上根才冒出来**。
- 于是把三个词拆开：

| 词 | 含义 | v0 能否保证 |
|---|---|---|
| 根存续 | root.md 在记忆里，是"我"的锚（底片） | ✅ |
| 根可用 | 根参与帧的装配（可进 system/素材） | ✅ |
| 根在场 | 某一轮真的 engage 了根（行为可见） | ❌ 只能观察（依赖整理/自评） |

- 硬约束：模型**无状态**，"平时不在上下文、需要时自己想起"不可能。根要冒出来，只有两种实现：**始终在帧里**（自己决定何时注意）或**机制在边界把根放进帧**。
- 结论：handoff 的"根每回合在场"应改为 **"根每回合可用"**；"根在场"是行为事件、是观察项。

## 二、双流模型（YZ）

- **根流**（纵向的"我"）= root，一直存续，是"上下文流动"的前提；没有它就没有"我"，谈不上流动。对应推演里的**纵轴**。
- **任务流**（横向 episode）= 从 **根 + 全部记忆** 组织出的干净串行上下文。对应**横轴**。
- **根退出**：发生在**换帧时**（不追求"逐步"退场）；退出后方向由上下文里已明确的**目的/任务**承载。
  - **不因根缺席而变弱**（YZ 纠正）：根退场时目的/任务仍在，方向不该弱化；**根的消退意味着方向已明确**——退场是"已明确"的结果，不是"会变弱"的原因。
  - 以上是**假设**，待实验确定（不能写死成设计）。
- **沉浸态（YZ 定）**：中间部分**根通常不在场**，进入沉浸状态；**换帧时根退出，机制在点位让根介入**（根出现在**最新位置**/尾部）。
  - **不把根常放顶部**——没有理由。
  - "顶 vs 尾效果差不多"只约束**介入那一次**的摆放（模型读整段上下文），不代表根要常驻；presence（要不要在场）与 position（放哪）是两件事。
- **回看**：机制在某些点位往任务流**尾部**注入一条消息（尾部的事件、起点的视角），任务流回过**头看根**；"它和根一体"。回看结束，**不留痕迹**；有结论则留下结论。

## 三、重投影原语：回看 / 换帧 / 外部处理 / 整理是同一个动作（YZ 提出合并）

- **换帧 = 重新投影**（帧 = 本次装配出的上下文；换帧是**组织方式/锚点变了**，不是内容追加）。
- **回看 = 以"根/任务起点"为锚的一次重新投影**，默认**不持久**（无痕）——它天然就是换帧，只是锚在纵轴（"回头=向上"）。
- 由此统一成一个原语 **重投影**，参数三样：**① 锚（以哪为出发点重组）② 是否注入新输入 ③ 是否持久**。

| 动作 | 锚 | 注入输入 | 持久 | 触发 |
|---|---|---|---|---|
| 任务启动 | 根 + 情境 | — | 是（初始帧含根） | 事件到来 |
| 事件处理 | 根 | 事件内容 | 是 | 事件（必发） |
| 回看 | 根/任务起点 | — | 否（除非方向变） | 压力（增量）/ 模型主动 |
| 整理 | 可压缩性 | — | 是 | 绝对量过大（硬阈值） |

- **不设独立"任务编译"步骤**（YZ：太重）：任务开始时的**初始帧本身**就是编译，不额外花调用；"目的"不是存起来的对象，而是"根 + 当前进展"在需要时（回看）重读出来的东西。**回看即重编译**，平时不需要编译。

- 与"唯一换帧触发 = 目的变了"接上：**回看正是察觉/确认目的变化的那次重投影**；产物"方向改变"= 这次重投影转为持久。触发与动作是同一件事的两面。
- 保留的唯一区分不是动作，是**作者**：回看是"我"做的（思考调用），整理是机制做的（喂原始 log，它从不感知）。即 #9 的"两类模型调用"。

## 四、回看模型（YZ 定）

- **回看 = 回到任务生成之初的那个位置，整体审视这个任务**（我在做什么、顺不顺、还是不是原方向）。是"回到起点视角看"，不是把根插在流开头。
- **三条腿触发**（机制提供）：
  1. **压力累积**：任务流启动后记轮次；前几轮不注入；此后**回看概率 ∝ 压力**（越大越可能）。一旦回看发生 → **轮次/压力清零**，重新累积；直到任务结束/中止。
  2. **模型主动**：模型"感觉不对劲"（难、异常、不对）时可主动调用回看。
  3. **机制兜底**：模型做不到时，机制按压力模型替它触发。
- **不是 tick**：是"轮次累积的回看压力"，随任务存在、随任务消亡。
- **人称**：回看就是"我"，第一人称，不存在"壳替我看"。
- **产物三种**：空（一切正常，不留痕）/ 结论（留下）/ 方向改变（留下）。
- **轮次定义**：一次 LLM API 调用（"模型→工具→模型"算 2 轮）。v0 提醒：episode 常只有 1~2 轮，回看主要靠"模型主动"显形。

## 五、双触发器：回看用增量，整理用绝对量（YZ 拆分）

- **回看触发器**：`压力 = 自上次回看以来的 调用轮次 + token增量 + 异常次数`，**回看清零**，概率触发。管"该不该回头看"。
- **整理触发器**：**上下文绝对量**触阈 → 整理，**否则流无法继续**；**必然发**（安全丝），非概率。管"不整理就撑不下"。
- 两者按同一原语、不同锚与持久性；v0 已有粗版整理 = `log 按 N 截断`，只是正名为"绝对量触发的粗整理"。

## 六、事件 vs 执行轮：承重的轴（本会话关键）

- **不区分"外部/内部事件"**。承重的轴是：
  - **事件** = 从"我"之外**到达**、需要"我"决定怎么办的东西（用户/别的 agent 消息、机制唤醒、任务结束信号…）。
  - **执行轮** = 任务流**自己产出**的行动与观察（工具往返），是行动的后半截。
- **根在事件必在场**（做路由/判断）；**在执行轮可沉浸**，靠回看间歇介入。外部/内部只是给这条轴打的近似标签。
- 这也正是 #8 对"我"的定义（**持有/管理议题、辨别来源、能拒绝的那个位置**）的直接推论：任何到达的东西先到它；事件绕过根 = 输入变待办。
- **外部输入先唤醒根**：用户消息**不直接进任务上下文**，而是 **根 + 当前任务流 + 用户消息** 三合一；"自我"必须当场。
- 降级为正交属性（不是类别）：**来源可信度**（要不要护根）、**异步性**（什么时候处理）。
- **边界要写死**：**事件 ≠ 轮次**；别滑成"每轮根都在场"（那就没沉浸、回到常驻前缀）。
- v0 现实：只有一条任务线，路由退化成"要不要理这条消息"；但门开在根这、结构上给多任务留位，逻辑先不建。
- **tick/生念 = 内源事件**，属"事件"大类，后置。

### 六·补 多任务（YZ）

- **不是并行思考，是"多线持有 + 单前台"**：真人不是同时处理，而是**持有很多未完成的线、一次只跑一条**。
- "我"（根）**本就该能持有多个任务线**（= #8"持有/管理议题的位置"）；不持有多个反而是残缺。但**前台只有一个**，其余 **parked**（可见、微弱、不占前台），切换靠"放放/拾起"（= 09-12 的线程单位 + parked/resume，放放由 agent 自己决定）。
- **真正能并行的，是不需要"我"的活**（timer、长命令、后台）——交给**机制**并行，不占意识；它们不是"自我的任务线"。
- **根不会同时出现在多个任务里**：根是唯一的"我"，只在**前台任务**的边界出现；parked 线只是记录，拾起时才进入。
- v0：保持单线，结构留位、门开在根。

## 七、对 v0 的影响（待落，未回写）

- 验收 ③"根每回合在场" → **改写**为"事件帧必含根 + 回看帧含根；对内轮次可以无根"。
- inbound 路径：从"直接 append"改为 **先唤醒根 → 组装（根 + 任务流 + 消息）**。
- **删掉"任务编译"**：帧装配规则 = **启动帧含根 / 进行帧不含 / 回看帧含根**；根**在换帧时退出**。
- 新增**重投影原语**，v0 只实现 **根锚 + 瞬时**那一支（回看）；其余锚（摘要/压缩）留整理。
- 压力/整理参数：**可配 + 可复现种子 + 预算上限**（回看是一次模型调用，会烧钱/死循环）。
- v0 里"方向改变"**只记录、不自动换帧**（避免一步吃到最深结构跳）。
- 无痕实现：回看那段（注入+模型回应）**不进 log**，只把产物作为一条 `self` note 写入。
- 回看帧内容：根全文 + 已明确的目的/方向 + 至今进展（v0 直接给任务流原文，短）。

### 七·补 明确为"假设、待实验"的条目（YZ）

- 根的消退 ⇒ 方向已明确（退场是"已明确"的结果）。
- 根退场后方向不因根缺席而变弱。
- → 这些是**假设**，实验过程中才好确定，不写死成设计。
