## 1. 过程 v2.2：去掉"投影·控制拍" `[定]`

- **改动**：环由 `事件→装载→（生成→投影·控制拍）⇄动手→判结→沉淀` 改为 **`事件→装载→生成⇄动手→判结→沉淀`**。原先每轮生成后的独立"控制拍"（整理/对齐/取回经验/判停）**降为可插拔占位，第一刀不实现**。
- **收窄后"投影"只剩一种＝自指**：装载时把事件投到『我』、即**认领**（自驱来源，保留）。独立的控制拍被降级。
- **职责去向**：**判停** → 生成拍**自带决定性输出**（继续动手 / 收束）＋机制硬闸（预算 / 无进展）；**整理·对齐·取回经验** → 先挪进装载或生成上下文，或不做。
- **why**：投影作为"推理质量"手段**必要性未证**——主流是单趟长思考（A）/外部反馈多轮（B），自评系（C，就是投影）证据偏弱、适用域窄（候选多且互斥 × 自适应 × 动手贵 × 材料够模拟）。把承重压回『我』/经历轴。
- **后果**：**"多轮纯思考"不发生**（无投影注入新框架，纯推理只在一趟内）。
- **被否**：① 保留控制拍为首刀必选项；② 用 `think` 伪工具续命（循环须机制闭合；投影若启用须注入**独立于生成**的信息）；③ 从理论**彻底删**"投影"概念（投影·自指＝认领，保留）。
- 必要性论证与实验见 `entries/2026-10-03-cogos-projection-experiment-e1.md`。

## 2. 第一刀 ＝ G2 脊柱 ＋ G1 退化解

- **环**：事件 → 装载（认领）→ 流 → 生成⇄动手 → 判结 → 落段（单流；多次动手仍只落一段；段含思考原话＋工具事实）。
- **认领**：装载产出「定性＋采纳（理｜搁置｜不理）」。`理`→跑生成⇄动手；`搁置`→不推进、段记"未了"；`不理`→不推进、段记"了"、不回复。
- **目标定位**（3 条原承重目标重评后）：**#1 生成/投影可分 → 否决**；**#3 纯思考 reasoning 捕获 → 消解**（捕获点＝生成拍自身）；**#2 流是沉淀单位 → 存活**（机制选择，非经验赌注）。**新焦点 G1 认领/自指**＝"自驱 vs 反应式"分界、唯一存活的行为赌注。
- **实现**：新增 `cogos/agent/flow.py`（`Flow`/`segment_from_flow`/`SegmentStore`/`parse_verdict`）；改 `cogos/agent/consciousness.py`（接入装载/流/段，material 按流现装）＋ `app.py`（默认『我』＋ `SegmentStore` 透传，`Agent(..., me=...)`）；测试 `tests/agent/test_flow.py`＋`test_app.py`；探针 `scripts/exp_first_cut_claim.py`。cogos master **`91fd1de`**（6 files changed，已 push `6c33380..91fd1de`）。
- **段最小字段**（memory/segments.jsonl）：`id/t/来源(event+locator)/内容/过程(assistant reasoning＋工具事实)/后果/结(占位)`；`预测=None/refs=[]/thread=id` 占位。

- **语义（探针，真实 deepseek-v4-flash＋FakeTelecom）**：同一事件（"执行 cat HELLO.txt 并回传"）×两套『我』——
  - `[take]`（YZ＝搭档，分内事）→ **采纳＝理**，toolbox×4，外发 1，段`过程`6 项（思考＋动手）。
  - `[ignore]`（陌生人，与我无关）→ **采纳＝不理**，tools=[]，外发 0，段内容"未推进（采纳=不理）"。
  - **`采纳 diverged: True`**。骨架跑通、认领分叉成立（换『我』→分叉是必然，非经验赌注）。
- **真实身份 e2e（公开入口真用）**：起真 feishu daemon＋lm-service，跑真 app `python -m cogos.agent.app --agent ~/.cogos/agent/tangyu`；真机飞书 `李恪 COGOS002:A0001` → `唐钰 COGOS002:A0005`（真模型、真 profile 默认『我』）。结果：装载判 **采纳＝不理**（"来自陌生联系人 A0001…与我无关且存在安全风险"），未动手、未回复、落一段（`结=了`、`过程=[]`）。→ **公开入口→装载→流→落段 全链路真机通**；默认『我』对非通讯录来源判"不理"（理分支由探针覆盖）。

## 4. 目标内自决（决策点 D1–D8）

- **D1 循环形态＝甲**：复用现有"一个运行时单元内部多轮模型⇄工具"，不物理拆"生成拍/动手"。why：目标只要求可观察行为；甲不引入易碎的结构化出口协议、不动 runtime。**被否**：乙（生成拍＝`tools=[]` 单次 cu＋驱动层循环＋结构化出口）——留待单趟不够时。
- **D2 认领分叉**：`理`→跑生成⇄动手；`搁置`→不推进、段记"未了"；`不理`→不推进、段记"了"、不回复。
- **D3 『我』按运行注入**（`Agent(..., me=...)`／`Consciousness(me=...)`），不改 profile 语义。
- **D4 流边界**：一个到达事件（飞书消息 / system 事件）＝一条流；不做挂起/续流/并发多流。
- **D5 段存储**：`memory/segments.jsonl` 追加。
- **D6 判结**：模型收束（无工具调用结束）＝`了`；撞硬闸（`MAX_TOOL_ROUNDS`）或出错/被打断＝`未了`。
- **D7 捕获**：每轮 reasoning（或该轮 content）在 `on_tool_call` 记入段`过程`；工具调用+结果同点记入；末轮 reasoning 在 `on_done` 记入。
- **D8 探针**：FakeTelecom＋真实模型，固定事件×两套『我』各跑一次，比对`采纳`/是否动手/落段。

## 5. 设计遗留（非阻塞）

1. **装载 regex 只认 `采纳: 理|搁置|不理`**：模型"拒绝执行…"式表述会默认成"理"（可加规则 / 改提示）。
2. **锚（P8）仍是手写『我』占位**：`_default_me()` 从 profile 拼 persona＋contacts；真锚（槽/关系/张力）未建。
3. **生成/动手未物理分离**（D1 甲）；**"未了→回边"只占位**（P7 判结主体仍缺）；**控制拍占位**未启用。

## 6. 被否 / 防重提

- **投影·控制拍＝必要** → 否/待定（必要性未证，v2.2 降占位；启用须注入独立于生成的信息）。
- **think 伪工具续命** → 否（循环机制闭合）。
- **从理论彻底删"投影"概念** → 否（自指＝认领保留）。
- **弧＝与流并列的持久单位 / 弧＝流内连续执行段** → 否（弧＝流旧名，退役）。
