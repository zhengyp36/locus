# cogos 意图执行模型（作用域：模式 / 允许集 / 缓存 / 沉淀）— 2026-09-28 讨论

> ⚠️ **术语现义见 `glossary.md`**（09-30 立）：本文"意图"的旧口径（作用域）已于 09-29 收回，现义＝**无声动作指令**；"意图态/非意图态"拟改名（候选"执行态"，撞 cu 的"执行态"，见 glossary）。本文**机制内容（模式/允许集/缓存/升级梯）仍有效**，仅术语待换。
> 结论：意图执行 = 一个有**显式入口与出口的作用域**，由**模式决定工具允许集**；入口加载经验 / 粗 help 只为"会用法"、不负责解锁；出口把**真实调用过**的用法缓存成机制固定格式；结果当场出、方法睡中蒸馏。
> **目的（YZ 定调）**：**给模型注意力减负** —— 把注意力留给推理，而非工具用法。**不是保密**：少量工具用法留在上下文是可接受的，只要不占太多。

## 1. 模式与允许集（两条规则）

1. **意图态**：可调用当前视角工具集里的**任何**工具。
2. **非意图态**：只可调用**上下文中缓存的**工具。

- 定义：**缓存 = 意图态下真实调用过、且尚未被淘汰**的工具用法（证据驱动；加载但未调用过的即丢）。
- 这是**模式决定允许集**，不是模糊属性。enforcement = `call` 里一次集合判断；命中不了给可读错误："该能力不在你当前上下文；进意图态载入"。
- `help` **只在意图态**可用（探索用法）；`call` 两种模式都可用。

## 2. 视角与工具集

- **可调用 = 当前视角下属于其可访问工具集**。不同视角看不同工具集：
  - **agent 视角**：agent 的工具（catalog 能力）；
  - **机制视角**：机制工具（整理上下文 / 睡中蒸馏）。
- **机制侧不设第三模式**：机制模型直接按**意图态**跑，只是工具集是它自己的（全可调）。机制注入短暂，真出现时再管，现在不建模。

## 3. 入口：`toolbox(intent, enter, <content>)`

- 以意图内容进入意图模式；同时**主动加载**该方向的经验（无经验则给**粗 help**）作为**探索入口**。
- **加载不为解锁**（意图态本就全可调），只为"知道怎么用"。
- `help` 逐层探索。**不变量**：从总览必须能逐层到达 **call-ready** 用法；达不到 = **引导词 / 摘要缺陷**，是验收项。
  - 精确化：不是"路径存在"（静态必然），而是**每层摘要有区分度** —— 模型能为当前意图选对分支。动态门槛，靠 harness 测。

## 4. 出口：`toolbox(intent, exit, <result>)`

- 带意图结果退出；结果即该收尾动作的参数（**显式退出**，不悄悄退），捕获点唯一。
- 退出时机制**自动缓存本次真实调用过**的工具用法。
- **与异步**：`run` 发起即返回后提示会问"完了吗" → 应答"已发起"即出口；真结果作事件唤醒**新弧**，靠 correlation 关联回原意图（现存缺口）。

## 5. 缓存管理（机制固定格式；cache-aware）

- **驻留 ≠ 经验**：驻留是**机制注入、格式固定**（机制才能统一数轮次 / 淘汰 / 重排）；**经验是 agent 自由格式**，意图态内存在，**不沉淀成驻留**。
- **稳定内容 append 一次、原地不动** —— 在历史里，前缀缓存一直覆盖，后续近乎零成本；只有**淘汰那一刻**付代价，代价 ∝ 它离尾部有多远。
- 故 **TTL 要短**：趁还在尾部附近就淘汰；漂远了就直接淘汰（丢部分缓存是取舍，离得越远代价越大）。
- 例外：**出口提示**每轮不同、当轮生效下轮摘 → 用**尾部重贴**。两类按"内容是否稳定"分开处理。

## 6. 出口提示（可能的结束点）

- 机制**不判"完没完"**，只在边界注入提示让模型自判（合"机制不替模型做语义判断"）。
- 形态：**上下文尾部**、只留一条、当轮生效、下轮自动摘。
- 触发：一次**实质工具调用**后（成功 / 失败皆可能结束）→ 提示；**连续同域调用通常不提示**；**无工具调用 或 跨工具组** → 提示。
- "实质" = 可能成为完成点的能力调用；**排除 `help` / `intent`（纯认知动作）**；**`cancel` 算实质**（改在途状态、取消 ≠ 撤销，其结果带"是否已触达世界"，并入后果轴）。
- nudge 上限（小，1~2）：提示后仍无调用 → 不再无限注，强制收尾。

## 7. 结束两件事（同一捕获接缝，先捕获后抹痕）

1. **整理结果** —— 意图的目的，出口即出。
2. **方法沉淀** —— "去掉本次调用内容"的**纯方法**，**轻量原始记录**，**睡中蒸馏**，然后删原始材料。

- 收益：捕获（快、哑、不判断）与固化（慢、智能、抽样重演）**时间分离**；样本不够不急于归纳。
- 抹痕只作用于**模型视角（回看）**，原始材料另行封存给睡眠 —— **隐藏 ≠ 丢弃**。
- 回看里一次执行 = `{意图陈述} + {结果}`（过程隐藏）。

## 8. 上限与升级梯

- **作用域步数上限（宽）**：防跑飞、不管细活（模型可能真要多轮）。
- **超限语义 = 有界失败**：结束本轮、返回失败、**允许下次重进**；必然**上浮**（若已可能触达世界更不许静默重试）；失败结果**带够材料**。
- **升级梯**（scope 目标类型）：**执行 → 诊断 → 求助**。
  - 判据：**结构、可复现、与本 agent 无关 → 诊断**（改去搞清工具，产物=更新经验）；**可达性、权限、需裁决 → 求助**（产物=对世界/对人的请求，走外圈）。
  - **升级计数跨 scope 持久**（按目标 / 能力记失败次数），否则"下次重进"攒不到"多次"。
- 诊断产物也进原始材料，睡中蒸馏回 procedural（工具变了 → 诊断 → 改经验闭环）。

## 9. 验收口径（注意力减负）

- 上下文里**工具用法的占比**（设上限，别挤掉推理）；
- **同一热串里的重复学习次数**（应趋近 0）；
- **任务完成质量不降**。

## 12. enter/exit ＝ 界桩（09-30 整理补录，源 `-4` 会话 `ses_f13ec6421ffecZZYnkUyUXeKJG` / `15:30` `ses_f13f17af9ffeyOQQPUdtDiYxSm`）

- §3/§4 的显式 `enter`/`exit` 命令＝**界桩**。理由：**意图无声，不标记就留不下痕**——没有界桩，事后（沉淀/回看/机制）无法知道一次意图从哪起到哪止。
- 机制据界桩**切段**（段的来源边界、缓存驻留区间、对账窗口都以界桩为界）。
- 属实现关键，非可选装饰。
