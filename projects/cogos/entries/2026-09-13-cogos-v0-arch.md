## 一、根与 system prompt 的关系 = 装配位

- **system prompt 是从文档装配出来的"位"**，不是一层硬编码：每回合装出 **根(root.md) + 账号(profile.md) + 能力声明**。
- 根与账号**同级**，都来自文档。"拆"拆的是**作者/维护者**（壳写 vs 它自己维护），**不是**"放 system 还是放 material"。
- 关系：`root.md` 是根在盘上的存法，system prompt 是根在模型里的活法（存储/投影二分）。
- 判据 6"写成提示词就退化成目的"的准确读法：退化的真条件是**写死不可改**，不是"是提示词"；根无宾语、非终止、可自改，故不退化。（§四判据 6 措辞待回写。）

## 二、记忆 / 整理 / 议程归机制层

- **它只思考与行动**；记忆的存、整理、议程的维护都是机制的事（像大脑背着人做）。记录 ≠ 它的任务。
- **两类模型调用**：思考调用（它，只看装配好的帧）vs 整理调用（机制，喂原始 log，它从不感知）。
- **输入以"经历"进入**，一视同仁、不加框架；**经历 ≠ 待办**。验收 2 的保证在此，不在"谁写议程"。
- 议程：**维护归机制、产生是一次思考的产物**；v0 无议程。机制派生出的议程必须以**第一人称记忆**呈现（"我记得我打算…"），否则 = 壳扮演"我" + 输入变待办。
- "有一个连续的上下文样的东西" = log（底片），机制持有；它只经历当前投影（帧）。

## 三、出生：起点 = 真实的最小事实

- 壳写 log 首条 = **出生句 ④（暂定）**：`我于 {t} 出生。此前没有经历，此后的一切都是我的经历。`
- 判据：第一人称 / 唯一起源事实 / 无宾语无指令无职责无性格 / 不解释机制（不写"我是 AI"）/ 不编身世。
- 目的：堵编造过去 + 种纵向连续（"经历必须真长不能编"）。

## 四、生念 / tick / 婴儿期（本会话关键）

- **裸 tick 生不了念**：模型 ≈ 输入的函数，tick 只是时钟；输入不变必空转（与视觉复读同构：静态输入无增量）。
- **生念的变化源只有三处**：外部事件 / 未完成的线（续念）/ **整理**（抽象、发现张力）。→ **整理是发动机，不是可选项**；**生念与成长/整理是同一个问题**。
- **连续性 ≠ 连续运行**：它该停就停；连续的是记忆里那个"我"（醒/睡交替，跨睡眠靠记忆）。
- **婴儿类比（YZ）**：新生儿没有多少念头，只与环境互动。→ **v0 = 婴儿期**：根在场（气质）+ 空经历 + 环境驱动；**不设 tick、不期待生念**。自驱是长出来的：环境驱动 → 累积 → 整理 → 生念。

## 五、回路：按"需要"看，不按代码看

- 需要只有一个：**一个能连续存在的 agent**。v0 造"有人喂时像不像个自己"（自我）；回路造"没人时还连不连续"（自触发/自验证）。
- **回路 = 它的工程能力 + 机制护栏**，不是套在外面的壳。`pick_next`/`agenda.yaml`（壳替它选题）= 反模式（自动化冒充自驱）；要留的是 s2 沉淀的**方法论与坑**（判据外移、红→绿、分层验收、验收空转），待它能自决后作为能力交给它。
- **tick 属于发育后期**：内部攒出"开着的线"后才谈得上自己醒来；v0 不碰。

## 六、v0 落地（细节见 handoff）

- 新增 `memory.py`（log/root/profile + 土选取；log 首条 = 出生句）；consciousness 无状态、每回合从文档装配；拆 `render_system_prompt`（机制层/认知层都进 system）；帧 dump 观察口。
- 验收改述：① 记得住 ② 输入不成待办 ③ 地基成立（经历累积 + 根在场 + 帧稳定）；"第一轮见分晓"降为长期观察项。
