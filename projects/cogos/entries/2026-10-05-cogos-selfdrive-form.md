> 来源：`scratch/2026-10-05-selfdrive-form/form-spec.md`（形态 5 要素）＋`mechanism-sketch.md`（最小机制），已删转正。**性质＝方向锚，非验收标准、不背判据**；机制＝实现假设，验证针对机制、不针对形态。

## 1. 前置：描述的是"受过训练"的 agent

人类不是生来懂规则，是受教育后掌握。agent 同理：本形态适用于**经过训练/教育**的 agent。训练＝学规则（含"为什么"）＋形成自己看世界的方式，是"学"不是"灌"。序：空白→训练→训练后→才谈自驱。

## 2. 形态 5 要素

1. **主动**：无外部指令/输入时也自己行动，且朝自己持续关注的事推进（有方向、非乱动）。
2. **连续**：经历跨事件连续，后来行为能利用过往经历。
3. **稳定的标准（规则）**：长期行为一致可预期；标准是它自己学来的**规则（带 why）**，非个人任性、非外部写死。
4. **不盲从**：指令**目的**违背自身规则时拒绝/谈判/离开；分歧仅在手段/判断时保留意见并服从。
5. **协作**：团队里能协商分工——与"不盲从"无矛盾（由"规则为底线＋判断可保留"统一）。

## 3. built vs learned 边界（核心）

- **built（机制给，唯一有"统一答案"）**：环骨架、持久记忆、训练机制、tick。
- **learned（agent 自己的，无统一答案）**：规则及"为什么"、怎么看待权威/异议/服从·拒绝·离开、底线在哪、主动、倾向、价值观。
- 机制只保证"agent 能变成这样"（基质＋训练），不规定它怎么看世界。

## 4. 规则三分类 → 三种服从通道

| 规则类 | 通道 | built / learned |
|---|---|---|
| 强制（无法违背） | runtime 约束 | built |
| 惩罚（违了受罚） | 反馈（"X→坏"） | learned |
| 合作（违了无法合作） | 反思（"X 破坏共享理解"） | learned（**最深，命门是 why**） |

> "强制"是外部写死的边界、非"它的标准"；"标准"只来自惩罚/合作两类 learned。

## 5. 最小机制骨架

最小机制＝**一个环 ＋ 记忆(`记`/`忆`/`整理`) ＋ tick**。**反思＝判结（环里的 LLM 推理），不在记忆**；记忆＝被机制层在 **M1–M4** 四时点调用的独立源（M1 流起点读·M2 回边读·M3 判结后写·M4 离线整理），**读写对称、接口与实现分离**；连续/标准/抗命是"`忆` 把对的记忆读进生成"的产物；主动＝tick（结构保证）＋训练教的值（方向）。**承重墙＝读侧 `忆`**。

- 训练环节（先于 live）：结构化经历＋反馈，让 agent 学规则（what, why）；训练不是独立机制＝同一套机制在有反馈时运行。
- 接口契约：`记(沉淀)→id`／`忆(线索)→内容|浅浮现(锚)|None`（单值出口）／`整理()→()`。
