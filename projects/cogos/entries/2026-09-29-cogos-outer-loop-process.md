## 1. 外圈：一轮流

**流 ＝ 事件 → 装载 → 思考 ⇄ 动手 → 沉淀；主体是 1..n 个 `cu`（机制不介入的 append 区间）。**

### 1.1 事件
- 来源：**外部事件**，或**内部事件**（槽里的未了张力自燃）。
- **事件之间交织**（不是串行）：可**搁置**当前流、可**注入改变**它；可有**多条流并存**。
- 什么算"一个事件"需判定；识别/切分归**装载**，不归事件本身。

### 1.2 装载
- **事件 × 槽 的投影**：定性——这是什么、跟"我"什么关系、要不要理、续哪件旧事（＝**认领/采纳**，自指的第一个动作）；同时取用相关能力与工具经验。
- 产出：本轮**小而聚焦的上下文** + "这件事是什么"的定性。
- 被搁置的流只是挂起，**不沉淀**；「暂停」与「结束」要分开。

### 1.3 思考 ⇄ 动手（主干；每一步都带控制）

**思考**（发散，工具关）：从当前信息往下推。每轮结束交给**思考的控制**（机制驱动，四件事）：
1. **整理内容**（＝**蒸馏**：压缩、去杂质）；
2. **对齐目标**（离目标多远）；
3. **取回相似经验**（按锚，喂回下一轮当参考，不当答案）；
4. **判停**：继续想 / 转动手（另有卡住、预算、无进展的强制出口）。

**动手**（受控，分两类）：
- **探询**（取信息，当世界的问句）：反馈即时，当场接着想；预期＝会观测到什么。
- **执行**（改环境，落一个决定）：动作本身落地，反馈常**延迟、以未来事件回来**；预期＝会造成什么。
- 共同**前置**：为什么动 / 在哪动 / 预期什么（或已决定）；**提交**那一下就是**意图**（无声指令）＝思考→动手的桥。
- 共同**后置对账**：探询看"观测 vs 预期"，执行看"落地了吗、没落地为什么"。
- **动手的选择本身是思考的产物**：探询是"想不通才动"，且**从最可能的地方动**。

**结果 → 回到思考**，循环到闭合。

### 1.4 沉淀（流闭合时）
- 写**段**：`来源 / 内容 / 后果 / 结`（**含思考痕迹**）。
- 更新**槽**：关系、主题、未闭合张力。
- **结＝了 / 未了**是自驱开关：全了 → 无张力、永远反应式；全不了 → 淹没。

## 2. 内圈：睡 / 批形（经历驱动，陷/沉淀）

1. **对成堆的段做蒸馏**（同一蒸馏操作的离线版）：找反复出现的（情境 → 做法 → 效果），**泛化** → **经验**。重复出现才沉淀（一次性的不值当、易过拟合）。
2. **经验按锚分区存**（不是一处）：工具经验挂**工具**；思考经验挂**目标/张力类型、主题/线、装载定性出的情境**。
3. **取回 ＝ 按锚路由**（直取，不搜索）。锚＝当前已知的状态特征，不是运行时算的相似度。
4. 更新**槽 / 权重 / 升格**（后续）。

## 3. 两环的接口

- 外圈 → 内圈：**段**（痕迹）。
- 内圈 → 外圈：**经验**——进思考控制（让思考有效）、进取用（让工具顺）、进**动手门槛**（动不动/在哪动）。
- **自驱回边**：沉淀的**未了张力** →（内圈）→ **内部事件** → 下一轮流。
- **上下文纪律**：记忆不在上下文里（在内圈存储）；上下文只放"此刻要用的"，靠**压缩（蒸馏）＋外部存储＋按锚取回**，不靠长上下文/缓存。

## 4. 本轮定下的名字

- **意图** ＝ 无声的动作指令 ＝ **思考→动手的桥**。判据：有声＝思考；无声且落实为动作＝意图；无声且属机械＝执行。**不是**工具 / 一次调用 / 层 / 工作单元。
- **蒸馏** ＝ 压缩/整理**操作**；在线用在思考控制里，离线就是**沉淀**（在内圈）。**不是**思考控制的伞名。
- **思考的控制** ＝ 伞名（整理·对齐·取回·判停）；**动手的控制** ＝ 前置＋对账。
- **行动两类**：探询 / 执行（都贵：探询贵在步数，执行贵在代价）。
- **段** ＝ 流的沉淀记录；**cu** ＝ 机制不介入的 append 区间；**流** ＝ 1..n cu 串起；**线/thread** ＝ 跨流的段链。

## 5. 收回 / 否掉（含 why）

- **收回**：段＝一次动作；意图＝工作单元/作用域（类别错误：有声的思考被并入无声的指令）；"动手只是实验"（限窄）；"想清楚只对执行"（对**所有**动手成立）；"两个蒸馏别混"（认成同一原语两尺度）；"思考的控制叫蒸馏"（蒸馏只是整理那一件）。
- **否掉**：`think` 伪工具续命（靠模型自觉 + 训练依赖）；纯 append 自反馈（无信息增量）；给模型一套"形状＋锚"的方法论（机制给的是节奏/结构，不是方法）；硬性"工具禁用两态"（可不必，门能强制）。
- **关键 why**：
  - "没动作就结束"是问题（机制把"继续"绑在工具调用上），方向＝给**内部推演空间**。
  - 空间由**机制驱动**（不用训练模型主动续命）；蒸馏每轮以**目标**为参照重整，且是**注入经验的口子**。
  - 经验是**改变动手倾向**的关键：思维更廉价、可逆优先，是**学出来的**；经验既管**动不动**（门槛）也管**在哪动**。动作门的对账/预期差正是养经验的料。
- 沿用更早：不先做完整意图（依赖倒置）；不排全零件序；先做权重（否）。
- **fork 分支丢弃物（09-30 整理时补记为被否，防重提）**：段＝一意图一条；以意图为工具＝定界原语（口径 b）；先写一页工作单。三者均 fork 会话提出、后期讨论推翻，此前未在任何 entry 记为收回。

## 6. 未定

- **经验怎么沉淀**（重复门槛、泛化粒度）与**取回**（锚的分类学）——分类最好**长出来/涌现**，别硬编；分太细稀疏、分太粗退回搜索。
- **沉淀判"结"的主体**——"作为判断者的我"仍缺（自驱开关无人把守）。
- **硬性两态 vs 只用门**。
- 落码层：段字段、落点、蒸馏的调用形态、预算/无进展兜底、压缩窗口（批量化改写）。

## 7. 形状（骨架）

```
事件(外部/内部) ──交织──→ 装载(事件×槽投影) ──→ [ 思考(发散) ⇄ (整理·对齐·取回·判停) ]
                                                        │
                                                        └─→ 动手(探询/执行) ─→ 结果 ─┐
                                                        ┌───────────────────────────┘
                                                        ▼
                                           沉淀(段 + 槽) ──未了张力──→ 内部事件 (回外圈)
                                                        │
                                                        ▼
                                        内圈(睡/批形): 段 ─蒸馏→ 经验(按锚分区) ─取回→ 外圈
```
