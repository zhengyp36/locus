# 2026/10/25

元层对意识过程的控制：
- 无助推而继续：Proceed，工具介入点
- 有助推而继续：Relay，任意介入点
- 重构上下文而继续：Switch，任意介入点
- 停止：Stop，任意介入点

元层对意识内容的组织：
- 意识起点(醒)：
  - 第一次醒：使用出生模板
  - 第二次醒：从经历/记忆中取，结合事件(如果有)
- 意识过程：重构、助推，这是怎么组织内容；结合事件(如果有)/经历/记忆，这是内容来源。
- 意识终点(睡)：把意识内容整合到记忆/经历中，这是内容的去向。

**内容组织没有点明的核心：动机/方向/目标**

元层与意识层的关系：
- 意识层前向推理，元层对齐目标/方向/动机
- 元层与意识层围绕相同的核心-目标/方向/动机

关于LLM：
- LLM在语义的方向下前进
- 语义有方向，但方向不是唯一的，也不是完全确定的，方向选择具有概率随机性，有些方向大
概率，有些方向小概率，但都可能发生
- 两层LLM可以实现方向校准，意识层推进，元层校准

动机/方向/目标从哪里来：
- 持续存在，这是基础条件。agent每天会睡会醒，能想能动。
- 所处环境，这决定长成什么形状。agent处于人类社会中，用工具与世界互动。

# 2026/10/19

**自驱agent**
1. 工具
2. 意识过程 => 记忆沉淀

**助推:** LLM上下文在没有输入新user消息时推理会自然结束, 如果这时输入新user消息则推理会继续, 因此每次输入新user消息称为一次助推

**弧:** 一次助推从推理开始到自然结束称为一弧

**流:** LLM上下文从零开始, 提供助推形成的一弧或连续多弧, 构成流

**元层流-意识装载:** 刚醒来时意识流无内容, 通过一个元层流完成意识流的内容装载
**元层流-记忆整理:** 

**意识流:**
起点-醒(意识上下文装载) -> LLM推理 -> ... -> (元层介入) -> LLM推理 -> ... => 终点-睡(意识上下文沉淀)

**意识流-序列(seq)->经历:**

- 上下文整理生成SEQ过程
SEQ0: (SeqStart)->LLM推理->...
SEQ1: (SeqStart)->LLM推理->...
...
SEQx: (SeqStart)->LLM推理->...

- SEQ聚合过程
T1: SEQ0 => SEQ1 => SEQ2 => SEQ3(当前意识流上下文)
T1: SEQ0 => SEQ1 => SEQ2 => SEQ3 => SEQ4 => SEQ5(当前意识流上下文)
T2: SEQ2(含SEQ0/1/2) => SEQ3 => SEQ4 => SEQ5(当前意识流上下文)

SEQ1的SeqStart来自于SEQ0的上下文整理, 元层可周期介入判断要不要整理上下文(比如主题变化), 另外上下文过长自动触发整理

**元层介入-时机:**
- 外部事件: 装载事件, 装载相关记忆索引 (可能切换主题)
- 一弧结束 (可能切换主题)
- 意识流上下文太长
- 一弧时间较长, 周期概率介入
- 睡眠时整理记忆

**其他**
1. 切换主题时, 意识流不断, 前一个主题的内容逐渐退出
2. 意识能否主动整理记忆上下文
