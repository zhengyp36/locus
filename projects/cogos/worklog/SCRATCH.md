**助推:** LLM上下文在没有输入新user消息时推理会自然结束, 如果这时输入新user消息则推理会继续, 因此每次输入新user消息称为一次助推

**弧:** 一次助推从推理开始到自然结束称为一弧

**流:** LLM上下文从零开始, 提供助推形成的一弧或连续多弧, 构成流

**元层流-意识装载:** 刚醒来时意识流无内容, 通过一个元层流完成意识流的内容装载
**元层流-记忆整理:** 

**意识流:**
起点-醒(意识上下文装载) -> LLM推理 -> ... -> (元层介入) -> LLM推理 -> ... => 终点-睡(意识上下文沉淀)

**意识流-序列(seq)->经历:**

- 上下文整理生成SEQ过程
SEQ0: (SeqStart)->LLM推理->...
SEQ1: (SeqStart)->LLM推理->...
...
SEQx: (SeqStart)->LLM推理->...

- SEQ聚合过程
T1: SEQ0 => SEQ1 => SEQ2 => SEQ3(当前意识流上下文)
T1: SEQ0 => SEQ1 => SEQ2 => SEQ3 => SEQ4 => SEQ5(当前意识流上下文)
T2: SEQ2(含SEQ0/1/2) => SEQ3 => SEQ4 => SEQ5(当前意识流上下文)

SEQ1的SeqStart来自于SEQ0的上下文整理, 元层可周期介入判断要不要整理上下文(比如主题变化), 另外上下文过长自动触发整理

**元层介入-时机:**
- 外部事件: 装载事件, 装载相关记忆索引 (可能切换主题)
- 一弧结束 (可能切换主题)
- 意识流上下文太长
- 一弧时间较长, 周期概率介入
- 睡眠时整理记忆

**其他**
1. 切换主题时, 意识流不断, 前一个主题的内容逐渐退出
2. 意识能否主动整理记忆上下文
