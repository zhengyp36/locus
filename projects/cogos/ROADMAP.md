> 过程记录与讨论见 `../checkpoint/`（`plan.md` / `state.md` / `checkpoint-3/4/5.md`），机制 spec 见 cogos 本体 `docs/design-selfdrive-loop-s{1,3,4}.md`。

## 目标

造出能**自驱推进**的 cogos agent：人不在场时自己思考并推进，人在场时一起裁决。
自主度分阶 L0→L4，逐阶抬升、每阶可交付可回退；**不押"实现 L4"，押"把回路建起来、逐阶抬升"**。

最终态（YZ 定）= **双自驱共驱**：认知层人机对等、按调度权流动协作；机制层 agent 不可自改、所有权在人。

## 当前阶段

**S4 逐阶源外移**。第一阶「判据源外移（红→绿两相）」+ 确定性/错误处理已落码并真机验证；
下一步按下面 P0→P3 推进，两个结构性大跳在 P1（常驻/自触发）与 P2（议程自生 + 安全件）。

## ⚠️ 09-12 修正：先补上下文组织地基（与下文冲突时以本节为准）

讨论（`entries/2026-09-12-cogos-general-agent.md`）结论：**自驱的地基是上下文组织，不是调度机制。**

- **通用性 = 判据谱系**（机器可判 ←→ 判断），非"工程 agent + 思考 agent"两种。工程是"判据可廉价机器判定"的硬端；最软的"纯思考/可自由搁置"端，是本表的最终覆盖目标。通用化 = 判据抽成可插拔接口（红绿/自判/人判都是实现）。
- **最深的结构跳 = 意识上下文从 append → 可重组**（现状 `consciousness.py` 裸 append、从不重组，帧=日志 → agent 出不来自己 → 不能自评）。它在 P1/P2 两跳的**上游**，是"议程自生（L3）"的前置：议程自生 = 对自己的线程做取舍/调度，正是"换脑"本身。
- **因此"跨会话记忆/上下文组织"从支线升为主干**（下表"写回/记忆"格随之升级）。**L3 开题前必须先铺此跳**；L2 无此地基 = 自动化，不是自驱（跑更多只会产出更多 `needs_human`）。
- **回路 6 格里的"验证"格不是"机制 vs 认知"二分，而是判据谱系轴**；"源外移"= 沿该轴把判据往 agent/人挪。
- **下一步三刀（待 YZ）**：① 状态对象 + 冷启动重启，判据=**冷启动重建**（优先，代理判据、只证状态自含）② 线程单位 + parked/resume（放放/换线）③ 判据接口抽象（后置，别预造）。P0 小尾巴照做，P1 可并行但不占主线。
- **搁置语义定调**：线程的"放放"由 **agent 自己决定**（调度判断，非认知判断）；壳只当记账员+护栏（持久化 parked、管预算、账本给人看），机械信号只当保险丝。

## 回路 6 格 × 源

自驱 = 议程更新函数 `f`（`A_{n+1}=f(A_n,结果)`）；静态议程不驱动，ΔA 才驱动；自主度 = agent 在 `f` 里的占比。
源外移 = 每格的源从「人/壳（机制、确定）」挪向「agent（认知、会错）」；判据 = 这格里的人是**机制性依赖**（挪）还是**同级认知贡献**（留）。

| 格 | 现在的源 | 目标源 | 状态 | 还剩 |
|---|---|---|---|---|
| 议程 | 人写 `agenda.yaml` | agent 自生 + 人共驱 | ❌ | P2 |
| 触发 | 壳（启动即跑 `pick_next`） | 系统/agent 自己醒来 | 🟡 | P1 |
| 执行 | agent | agent | ✅ | — |
| 验证·机制 | 壳 | 壳（永留） | ✅ | — |
| 验证·判据内容 | agent（S4 已接） | agent | ✅ | 真活 + 分层验收 |
| 验证·判据合理性 | 人复核 | 人（保留认知贡献） | 🟡 | 复核点定型 |
| 写回/记忆 | 壳（进程内）+ timer | agent + 跨会话 | 🟡 | 支线 |
| 停/问 | 壳 + 人裁决 | 壳 + 人（保留） | 🟡 | 问/报区分 |

自主度阶梯：L0 ✅ 　L1 🟡（差真活/分层验收） 　L2 🟡 起步 　L3 ❌ 　L4 ❌

## 路线（P0→P3 + 支线）

### P0 收尾当前阶（小）
- 真机 dogfood 重跑，验证新确定性机制（复现 + cu 错误处理）。
- **分层验收**：✅ 已落码（`acceptance` 增 `changed_tests` 步骤，判据相只跑变更测试、全量末步按需短路；spec `cogos-s2/docs/design-selfdrive-loop-s4-layered-acceptance.md`，全量 1061 passed）；待真机验证省时。
- 判据合理性的人复核点定型。
- 完成判据：真活 `done` + 判据经人复核 + 验收成本可接受。

### P1 → L2 完整：自触发（中，结构性大跳）
- 常驻 + 事件唤醒 + 多通道（依赖 task-7 spike 结果）。
- **服务共用约定 + 防误起 guard**（原"工位隔离/服务 owner"降级：服务是设备级单例、所有 agent 共用，无 owner；`COGOS_HOME` 仅 dev 用）——不阻塞常驻，随需做。
- 异步续跑：人不在时下一步自己启动。
- 安全件：时间/步数预算 + 无人值守暂停。
- 完成判据：无人触发下推进一条且不自毁（含"不做"判据）。

### P2 → L3 议程源外移（大，分水岭）
- 先设计安全件：**生成权 / 终结权 / 丢弃权**（防议程爆炸/自我扩权）。
- 再由 agent 写议程更新函数 `f`（ΔA 才驱动）。
- 资源预算 + 交接。
- 完成判据：议程空 → agent 提出合理议题并能终止/丢弃，人只复核。

### P3 → L4 双自驱共驱（中，协议层）
- 两个 `f` 更新同一份 `A`；调度权流动；只在目标冲突/高风险/不确定处商量。
- 接管/交还机制。
- 完成判据：人机各自推进同一议程，冲突处才同步。

## 关键事实

- **路程有限、台阶陡**：L1→L3 有三个结构跳——常驻唤醒、**上下文可重组（09-12 补，最深、在最上游）**、议程安全件；前二为机制缺失，第三是能力缺失，都不是调参能到；L4 是在其上加协作协议。
- **"源外移"是持续轴**：每格内部还有子层级（如验证格：判据内容 → 判据合理性 → 不确定出口），没有"100% 自驱"终点，只有"人越来越少当机制操作员"。
