## 0.5 术语速查（脱离上下文自包含）

> 读法：先读 §0 的权威 entries → 再读本节 → 再 §2 起。本文件是**增量/修正**，不重述主干。

- **三态**（资源交互）：**read** 拉快照（有界：`limit` + 时延上限）；**write** 产生对外影响（发起即落、不等待）；**notify** 变化通知（是**事件**非调用；工具侧只有订阅）。别名 **triad**。
- **locator**：资源实例的**定位符/寻址**——哪个会话、哪个文件、哪条消息、哪个通道。read/write 都需要；通知要带它。
- **外部 / 自身**（10-01 旧词）：外部工具＝改世界/取外部信息（发起即落）；自身工具＝读/写/看 I/O 边界（有界）。**本轮改述**为"三态上的**控制修饰**（源自控与否）"，不再当方向维。
- **10-01**：指 `../../projects/cogos/entries/2026-10-01-cogos-process-toolface-close.md`（本轮的直接上游）。
- **取值型 / 后果型**：09-28 `run` 语义讨论（N3）旧分型；后果型＝write（有副作用）、取值型＝read（取回值）。`run` 的错位＝后果型被当取值型。
- **槽**：10-01 口径＝**分布式并集＝"我"**（经历轴/工具经验/思考经验/主题/关系/未了张力，各落点各处更新）；详见 `glossary.md`。本轮拆出"痕迹层 vs 当下"两义。
- **痕迹层 / 当下**：痕迹层＝长期的我（＝槽的分布式痕迹）；当下＝每步按锚装配出的"此刻的我"，**生产**发生于此。
- **装载 / 生产 / 沉淀**：装载＝入口把相关痕迹带进当下（＝自动浮现）；生产＝当下的推理/动手；沉淀＝把当下产物写回痕迹层（多离线）。旧名对应：外圈=生产、内圈=沉淀、装载=读侧。
- **浮现 / 回忆**：同一原语 `cue → 痕迹激活`；cue 来自外部事件＝自动浮现，来自 agent 自问＝主动回忆；后者依赖前者给的**种子（线索）**。
- **锚 / P8**：锚＝检索键/索引键；**P8＝锚分类学（尚未定）**，是装载直取与浮现/回忆的前提。
- **P7**：判"结"主体缺（自驱开关无人把守）。
- **dirty bit + ack**：通知＝"未读有→无"的边沿，仅通知一次；**一读清位**。
- **内联预算 0~K**：**K＝单次投递可携带的载荷上限**；0＝纯信号（只 locator）。
- **边沿 / 电平 / 背压**：边沿＝每个变化都通知（说话，靠"回话"限速即背压防丢）；电平＝只看最新状态（盯屏，中间可丢）。
- **efference copy**：动作的**即时回执**（"已发出"），区别于**后果反馈**。
- **write 的两种反馈**：即时回执（机制同步返回"已受理"）＋ 后果对账（事后经 read/perceive 看效果）。

## 2. 候选结论（结论 + why + 被否）

### A 工具形态 = 三态 read/write/notify（资源视角）
- 三态：**read**（拉快照）/ **write**（对外影响）/ **notify**（变化通知）。旧 **取值型/后果型** = read/write；perceive 补上旧二元缺的第三格。
- **控制维与方向维正交**：占住与否 = 源是否"自控"（自身有界可阻塞 / 世界发起即落）；方向 = read/write/notify。10-01 的"外部/自身"改述为三态上的**控制修饰**。
- **契约**：read＝有界阻塞（`limit` + 时延上限）；write/notify＝发起即落。"有界"与"不被占住"＝**同一契约的两半**。
- **三态是接口空间、非必填**；工具 = 子集。**fs 无 notify 是边界选择，非缺口**。
- 层级：资源（三态）vs 工具（面）；meta（toolbox/help/enter/exit/意图）**不属工具**。
- 被否：把"外部/自身"当方向维（撤）；fs 缺 notify 当缺口（撤，见 §3）。

### B 通知/订阅语义
- **dirty bit + ack**：有变化即通知一次 → **一读即清**；订阅**只看之后**；通知**不带（无界）内容**。
- 被否：**"追平复位"**（读游标追平才复位）——替 agent 判断"读完没"；撤。改"一读即清，读完与否归 agent"。
- 实现注：清信号在读**开始**、别吞读期间的变更；读游标仍由机制持有（否则重复吐）。
- **代码事实**：term `observe` 1-based、默认一屏（rows=24）、`limit` 无上限校验；屏幕缓冲 `scrollback=1000` 行（不可配），超限 evict、**行号漂移**；大输出应"重定向 + `fs.read`"（设计 §5.2）。现有 term 事件只有 **notify token**（OSC，会话级/一次性），**无"屏变"通知**。

### C 投递：信号 vs 内容（**是设计，非默认**）
- 收成**一个旋钮：内联预算 0~K**（0=纯信号；超预算截断 + "去 read"分页）。
- 判定三问：内容会过期吗 / 有界吗 / 谁掌注意力。三种体制：**边沿带背压**（说话）、**电平最新为准**（盯屏）、**信号 + 拉取**（消息/文件/term）。
- **通信"特殊在信号"**（寻址给我 → 默认开/重要），**内容持久无界 → 拉取**；两件事拆开。
- **通知带"有界载荷"**（locator + 可截断预览），**永不携带无界/完整载荷**（修正早前"一律不带内容"）。
- **管理员特权撤**：带内无不可关类；权威走**控制面**；mute 只压打断、不藏数据。

### D 感知层 = 装载（命名归位）
- "感知层（模型做输入侧注意力闸）"**就是装载这一步**，不必另起名。
- 结论（经 YZ 纠正后）：**用模型做输入侧注意力闸正当**——被否的是**输出侧**分派器；注意力分配本就该由模型判。
- 约束：**闸打断不闸数据**（muted≠dropped，可检索）；**有界叶子、非第二心智**；判据**可查可调**。
- 延迟真实但可收：常开闸便宜、贵处理放突破后；并行 + 超速降级"最新为准"。

### E 命名与接口
- **概念统一（read/write/notify、locator、有界、class、合并）+ 映射显式；接口字面不强行统一**（按领域与模型先验；合 09-28 模型面命名准则）。
- 判据：**改了名字、过程行为不变 ＝ 非冲突**；承重的是角色/契约一致。
- 应有接口 spec 见 §5。

### F 记忆流：装载/生产/沉淀/浮现/回忆/锚
- **写是闭环**：write = act + **即时回执**（efference copy）+ **后果对账**（经 read/perceive）。"write 是盲的"改为"有即时回执，后果需对账"。
- **装载 = 入口那次自动浮现**（按锚拼"此刻的我"），非"有意读资源"。
- **"直接进入当下 vs 装载进入"是伪二分**：进入当下**总伴随浮现**，只差**程度**（热上下文≈0；陌生消息浮现多）。
- **补"生产"环节**（此前被"读槽/写槽"隐喻吞掉）：**痕迹层（槽＝长期的我）→（装载＝自动浮现）→ 当下（事件＋浮现）→（生产＝推理/动手）→ 沉淀＝写回痕迹（多离线）**。对应旧名：**外圈=生产、内圈=沉淀、装载=读侧**。
- **槽的两义拆分**：应分**痕迹层（长期我）** vs **当下（此刻的我＝投影）**；勿单一存储（10-01 已撤）。
- **浮现/回忆同源**：都是 `cue→激活`，只差**谁发 cue**（外部事件＝自动浮现 / agent 自问＝主动回忆）。主动回忆**依赖种子**（＝浮现给的线索），无线索则退化为全量搜索。
- **线索 = 锚 = 索引键**；浮现/回忆/搜索 = **同一锚检索在三种命中粒度**下的表现（窄锚直取 / 宽锚给线索 / 无锚全扫）。参数是**锚粒度**，非线索长度。
- **要设计的只有一件事：锚组织（P8）**。"线索的组织"＝锚分类学；**不需要新的"线索层"**。

## 5. 候选设计件：应有接口 spec（摘要）

逐资源 read/write/notify；`[增]`=未实现应增。

- **通信**：write `send`/`send_file`；read `list`(enumerate)/`read`(会话消息,窗口)；notify 新消息（默认订阅，带 locator）。
- **term**：write `open`/`close`/`run`/`write`/`write_key`/`interrupt`；read `observe`/`list`；notify `[增]` 屏变、进程退出（默认关，带 session id）。
- **fs**：write `write`(原子)/`edit`(.swp 会话)/`move`/`delete`；read `read`/`list`/`stat`(版本令牌)；notify 无。
- **screen**：write `open`/`close`/`act`；read `fetch`(image)；notify `[增]` 界面变化（默认关，带通道/帧）。
- **vision**：read `look`/`locate`（作用在 image 产物）。
- **web**：read `search`/`fetch`；无 write/notify。
- **通知横切 `[增]`**：`subscribe`/`unsubscribe`/`list_subscriptions`（kind: message/term/screen/alarm/custom）；闹钟 write `remind`；自定义 `signal`。
- **命名原则**：角色统一、字面按领域（observe/fetch/read/send/act）。
