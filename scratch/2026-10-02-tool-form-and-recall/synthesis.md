# 工具与信息进出：整合版（2026-10-02）

- 性质：**讨论态整理**，非收口；结论未蒸馏进记忆层。
- 来源：本会话讨论（工具形态 × 记忆流）的完整整合；冲突以上游权威 entries / `glossary.md` 为准。
- 读法：本文件是 `discussion.md` 的收敛版，二者同主题；`discussion.md` 保留六段主线与过程记录，本文件只留整合后的图景。

## 一、位置

工具是 agent 与环境（世界／人／其他 agent）之间**唯一的交换界面**。信息经工具进入 agent，agent 经工具作用于环境。它不列举功能，它定义内外交换的通道。

## 二、进入：模式（方向）

三态：`read/fetch`（主动拉）、`notify`（被动进）、`write`（出）。

- **read 有界**：时延上限不中断读，而是"先给一部分、可续读"。界限分模态——文本＝ `offset+size`（字节窗口，可继续读更多）；图像＝降采样拿全貌 ＋ 局部窗口拿更多像素细节。
- **notify 载荷 0..K**：必带来源；内容可有可无、可少可全（仅当内容自身有界）；内容无界时给 locator＋可截断预览，不携带无界体。
- **write 是闭环**：act ＋ 即时回执（"已受理"）＋ 后果对账（事后经 read/perceive 看效果）。不是单向。
- 契约根：**阻塞只能来自自身**——自身 I/O 有界，世界/外部发起即落。

## 三、模态与读者（切分读者，不切分资源）

- 模态＝载荷的解码形态，当前 {文本, 图像}，由模型原生输入能力定义；能力扩则读者扩。
- **模态决定"用哪个读者"，不决定模型**（模型由 lm-service 按内容选）。
- 读者：`text`（文本，`offset+size` 访问）／`vision`（图像，`window` 访问）。二者是处理不同模态的**基本读者**。
- **读者 ≠ 资源**。资源另带寻址、状态、写侧、控制（term 行漂移/eviction、文件版本令牌……），这些不属于模态。故调用面 = **资源×模式，读者按载荷模态选**：`fs.read`、`term.observe` 内部走 text 读者，`screen/GUI` 走 vision 读者。模态是读者的二分，不是工具的二分。

## 四、物化/转换链

读者只能作用在**已物化的产物**上：

`资源 → 载荷 →（物化/转换）→ 读者`

- 图片消息不是直接 vision.see：资源先把它物化成 image 产物。
- 不可直读的文件（docx/pdf/专有格式）：上电脑用软件渲染/转换，再以 text 或 image 读——同一链上的转换步骤。
- 资源清单：
  - **通信**：文本消息→text.read；图片消息→（物化）→vision.see；其他文件→上电脑经软件看。
  - **电脑**：term（文本→text 读者）、GUI（图像→vision 读者）。

## 五、装载与浮现：持续过程

- 既非"入口一次性装载"，也非与浮现串行。
- 到达即触发**第一波浅浮现**：信息 ＋ 一小簇相关痕迹一起进当下；该簇带 **more 指针**（"还有内容"）。
- 处理过程中**持续浮现**（更深），但**必须过注意力闸**（可查可调，muted≠dropped），否则淹没当下；进不来的可作内部事件排队等空档。
- more 指针 ＝ 主动回忆的**种子**；据此主动拉取，否则回忆退化为全量搜索。

## 六、事件↔槽的绑定

- **主动绑定**：agent 设闹钟、调工具时，机制当场把事件与该**经历**绑成锚。例：设"运动"闹钟——title 是展示载荷，机制把它绑到"周三运动"那段经历；日后想到运动→闹钟浮现，想到闹钟→"为运动而设"浮现。agent 不必知道连接如何成立。
- **即时兜底绑定**：无任何绑定的事件进入时，机制给它一个绑定。陌生人（有号码）发消息：号码/通道/时间＝**结构锚**（机制直接盖）；内容主题＝**语义锚**（需一次理解，即闸的活）。兜底绑定拆两半：结构归机制，语义靠一次理解。
- **突兀→找原因**：无关事件触发 agent 追问（这人为何找我／这事件为何来），途径是直接问或据已有信息推测。
- **输出对称**：write/act 的发起与后果同样绑锚，否则"做过什么、效果如何"不可回忆。

## 七、浮现＝回忆

同一原语 `cue → 痕迹激活`，只差谁发 cue：外部事件＝自动浮现，agent 自问＝主动回忆。线索＝锚＝索引键；检索差别是**锚的粒度**：窄锚直取／宽锚给线索／无锚全扫。主动回忆依赖种子（第一波浮现的 more 指针即是）。

## 八、notify 的具体语义

变化＝边沿，`dirty bit + ack`，一读即清，订阅只看之后；载荷见 §二。闹钟是 notify 的**自设未来触发源**，title（展示）与锚（机制绑定）分离。

## 九、输出侧的模态不对称

输入侧 text/vision 成对；输出侧不成对——文本可直接写（fs/term.write），图像目前只能靠 GUI 上的动作**间接**产生，没有生成能力。模态维只在读者处对称，在写者处是缺的。

## 十、收敛点与未知

- 装载直取、浮现/回忆、感知相关性全压在**锚的组织**上：不止分类，还包括"何时由谁盖章、键有哪几类"。这是 **P8，枢纽**；不定则检索退化为全量搜索。
- **仍未知**：机制兜底时用来绑"当时的经历"的**结构锚**怎么划（粒度、生命周期）——决定 P8 落地。
