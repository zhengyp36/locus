# 问题：总结/沉淀脱离上下文后丢信息（可恢复性）

- 发现：2026-10-02，会话内总结 `scratch/2026-10-02-tool-form-and-recall/discussion.md` 被指出"脱离上下文可能读不懂"。
- 状态：**讨论推进中**；主解法方向＝**递归蒸馏**（§4），未落记忆层。
- 一句话：raw 不再当"兜底存储"，而作**构建期 oracle**；产物是 **A+B 的自包含闭包**，raw 补完转审计、不再喂模型。

## 1. 问题

在上下文里写"总结"时，会把当前会话当作**隐含共享地面**（用未定义符号、无锚断言、悬空指代），产物**只有在场者/作者读得懂**。会话一结束上下文即消失，**文件是唯一载体**——于是信息丢失且无法恢复。

## 2. 为什么发生（结构性，非粗心）

- **写者永远在场**：写的那一刻上下文都在，"这词显然懂"的判断被污染（知识诅咒）。
- **模型无外部记忆**：推理时"记忆"＝上下文窗口，**分不清"权重里的常识"与"本会话内容"**。
- **无事后反馈**：模型**不会回来重读自己的笔记**，学不到补偿；真正触发的是**外部提问**。
- **训练分布**：语料里摘要多是"圈内人写给圈内人" → 先验偏向"靠共享上下文压缩"。**（弱、不可证；讨论中降权，论证不依赖它。）**

## 3. 发现方式及其局限

"回读一遍"只是**模拟缺席读者**（符号是否定义 / 断言是否带锚 / 指代是否悬空）。有效但**不可靠**：判断被污染、只查想得到的类别。→ **发现机制是外部的**，不能靠自省。

## 4. 解法方向

### 4.0 先否掉两条

- **保 raw + 索引回退**（两层兜底）：raw 太重；本质是**推迟"留什么"的判断**（偷懒）。业界主流正是这个（§6），但**没解"弃 raw"**。
- **多重蒸馏保可靠**：同源多视图盲区重叠；正交视图（partition/aspect）能减共同盲区，但**并集仍非无损** → 只能做**降级/观测**，不能当承诺。
- **死理**：弃 raw 后，可靠性只能来自**冗余**或**收窄承诺**；不许留 raw 就没有冗余原料，于是唯一可保证的是"把承诺收窄到可判定"。本方案自证的是**可读**（未证**完整**）。

### 4.1 递归蒸馏（主方案）

1. 模型基于上下文蒸出 **A**；原文记 **RAW**。
2. 模型**只读 A**（不看 RAW），标出读不懂处，回 RAW 找答案；**局部措辞/指代问题 → 直接改 A**；**背景/术语缺失 → 写入 B**（不并进 A）。
3. 模型**只读 A+B**，仍有不懂再回 RAW。

- 本质：把"缺失读者"从**事后验收**升级为**生产方式**；**读者模型＝同模型 − RAW**（未来读者＝同权重＋无本会话 context），故精准命中知识诅咒。
- **raw 角色转变**：raw 只在**构建期**当 oracle 被读；A+B 闭包一成，raw 转审计、**不再喂模型**。

### 4.2 结构＝两级索引（角色分级）

- **A＝内容层**：结论 + 推导过程。
- **B＝背景层**：定义/指代/上下文，且 **B 自身闭合**（B 里用的词在 B 内定义，可互指）。否则"层"会无界膨胀、把无穷回归伪装成分级。
- **级＝角色（2 级基本够）**；**递归＝补到 B 闭包**（判据：读者无问题／B 停长），**不是固定轮数**。
- 两个操作：**补**（承重背景进 B / 内联 A）／**删**（读不懂且不承载意义 → 从 A 删）。**删是 B 的泄压阀**（难解释又不重要的直接去掉，B 不涨）。
- 残留情形：**重要、但解释起来很重**——删不得、全补则 B 膨胀；第三条路是**把该背景粗化**成一条更粗的定义。

### 4.3 过程（要点，非 raw）

- 蒸馏**不能只留结论**，须留**关键推导过程**（"看得到结论怎么来的"）。
- 理由：只有结论支持**查表**；结论+过程支持**继续推理**（agent 的活是往下想）。结论脆（前提一变即废），**过程可重推/可修/可证伪**；过程多不可复现 → **不可逆残渣，必须显式写**。
- 归属：过程属 **A**（"为什么成立"，内部证成）；B 是"词是什么"（外部支撑）。二者对称。

### 4.4 遗漏与选择

- 遗漏是**蒸馏的本分**（取舍），不是缺陷；关键在**留什么漏什么**（＝P8/选择）。
- 区分：**故意漏**（判断过可丢）／**无意漏**（写者没意识到要用，知识诅咒产物）。
- A/B 那套**两种都抓不到**（读者只报"A 里有但不懂的"）。抓**无意漏**要靠**用途探针**：让"未来要干活的人"提**完成任务所需**的问题，用**用途**暴露缺口，而非用"读懂"。

### 4.5 视角与方法（边界）

- 是否关键**由 agent 视角定**，不追"真关键"（记录是"它的"，视角即权威）。唯一要查的是**写者视角 == 读者视角吗**；跨视角需重新校准 A。
- 递归是**方法**，非可写死的标准："过程多细""A 对不对"尺度归 agent；方法只给流程（补/删 + 闭包判据 + 两级）。

## 5. 与 cogos 的关系

这正是**沉淀**要面对的问题：段/痕迹是"**现在的我写给未来无上下文的我**"。本方案给沉淀一个可操作流程：

- **P8（锚/选择）** 是选择与索引的枢纽，决定 A 的取舍与 A/B 的连接；
- **锚是"可恢复性"底座**（不只检索）；
- **段的 `来源/内容/后果/结`** 是 A 的骨干，"结"记录未了张力；**过程**对应"思考痕迹"。

## 6. 外部核对（prior art，已上网核）

- **MemGPT / Letta**：分层分页（main context + recall/archival storage）；`warning`/`flush token count` 触发逐出；递归摘要＝"summarized along with existing summaries"；**逐出原文 stored indefinitely in recall storage**。→ 业界＝**留 raw + 按策略淘汰**，淘汰信号是容量/新近（任意），损失不可控。 `arxiv:2310.08560` · `letta.com/blog/agent-memory`
- **RAPTOR**：自底向上递归聚类+摘要成树；**叶子是原 chunk**；跨抽象层检索。 `arxiv:2401.18059`
- **Generative Agents**：memory stream 记全部经历 + relevance/recency/importance 检索 + reflection 写回。 `arxiv:2304.03442`
- **context distillation**：同模型去 context 复现行为（Askell 2021；Snell `arxiv:2209.15189`）——本方案结构近亲。
- **decontextualization**：解析代词/桥接/省略使单元自包含（Choi et al., TACL 2021，"Making Sentences Stand-Alone"）；且**逐字原文单独存**以防重写破坏定位（＝A/B 分离的既有做法）。
- **ClaimNorm / self-contextualized assertions**：把乱文本蒸成自包含断言。
- **迭代摘要 drift**：多数实现注"resummarizing summaries causes semantic drift and information loss"（有说 ~23 轮）；**LessWrong 实验**：退化程度与压缩比**不相关**（损失取决于丢了哪一维，而非压掉多少）。
- 未核（只查了摘要或未查）：continual learning 的 **generative replay vs experience replay**、CBR 的 **case index**、**LAM**（lossy agent memory with error bound）。
