## 2. 意识过程 → 记忆沉淀

- **助推**：LLM 上下文无新 user 消息时推理会自然结束；输入一条新 user 消息让推理继续 = 一次助推。
- **弧**：一次助推从推理开始到自然结束。
- **流**：LLM 上下文从零开始，一弧或连续多弧构成流。
- **元层流**：意识装载（醒来时意识流无内容，靠元层流完成装载）/ 记忆整理。
- **意识流**：醒（上下文装载）→ LLM 推理 → …（元层介入）→ … → 睡（上下文沉淀）。
- **SEQ**：上下文整理生成 SEQ 序列；`SeqStart` 来自上一 SEQ 的上下文整理；元层周期介入判断要不要整理（主题变化），上下文过长自动触发。
- **元层介入时机**：外部事件（装载事件/装载相关记忆索引，可能切换主题）/ 一弧结束 / 上下文太长 / 一弧时间较长周期概率介入 / 睡眠整理记忆。
- **其他**：切换主题时意识流不断、前主题内容逐渐退出；意识能否主动整理记忆上下文（待定）。
