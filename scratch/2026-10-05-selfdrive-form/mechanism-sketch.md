# 自驱 agent · 最小机制草图（草案 v0.4）

> 性质：从形态反推的**最小实现假设**。不落码；不含判据（判据后置到实现后，见 `form-spec.md`）。
> 上游：`form-spec.md`（形态 5 要素）。
> 原则：**只引入形态要求的部件**；之前的机制（`忆`/效价/慢层/tick/四位置）按需**摘回挂上**，只剥"自我/认领"叙事。
> 状态：待 YZ 验收。

## 0. 一句话

最小机制＝**一个环 ＋ 记忆(`记`/`忆`/`整理`) ＋ tick**。**反思＝判结（环里的 LLM 推理），不在记忆**；记忆＝被机制层在 **M1–M4** 四时点调用的独立源，**读写对称、接口与实现分离**（不写死哪处用不用 LLM）；连续/标准/抗命是"`忆` 把对的记忆读进生成"的产物；主动＝**tick（结构保证）＋ 训练教的值（方向）**。**承重墙就一块：读侧 `忆`。** 看法内容无统一答案，机制只提供基质。

## 1. built 部件（机制给的，很少）

- **① 训练环节**（先于 live）：结构化经历＋反馈，让 agent **学规则（what, why）**。训练不是独立机制——它就是**同一套"反思→存→浮现→应用"机制在有反馈时运行**。
- **② 持久记忆**：存经历 ＋ 学来的规则（每条带 why）。
- **③ 环骨架**：`事件 | tick → 忆(读) → 生成(LLM：输入＋浮现的过去/规则) → 行动 → 观察后果 → 判结(反思→what/why) → 记(写沉淀)`。
- **④ tick**：闲置超时触发，合成**空闲事件**进同一个环（信号无内容，事件带最小事实模板）。

## 2. learned（agent 自己的，无统一答案，机制不规定）

规则及 why · 怎么看待权威/异议/服从·拒绝·离开 · 底线在哪 · 主动/倾向/价值观。

## 3. 规则三分类 → 三种"为什么服从"的通道

| 规则类 | 通道 | built / learned |
|---|---|---|
| 强制（无法违背） | runtime 约束 | built |
| 惩罚（违了受罚） | 反馈（"X→坏"） | learned |
| 合作（违了无法合作） | 反思（"X 破坏共享理解"） | learned（**最深，命门是 why**） |

> 注：**"强制"是外部写死的边界，不是"它的标准"**（形态要素 3 明说"非外部写死"）；"标准"只来自惩罚/合作两类 learned。

## 4. 记忆接口（契约，读写对称，不定内部）＋读侧 `忆`

记忆＝**独立模块，被机制层调用**（非 agent 直接操作）。**接口与实现分离**：`记`/`忆`/`整理` 读写对称、都可能用 LLM，接口层不写死哪处用不用。

- **接口（契约）**：
  - `记(沉淀) → id`（沉淀＝判结产出 `{what, why, 结, 效价, 来源, t}`）
  - `忆(线索) → 内容 | 浅浮现(锚) | None`（**单值出口**，无候选列表）
  - `整理() → ()`（v1+，形成经验）
- **用记忆的位置（四时点）**：**M1** 流起点读（定方向）／**M2** 展开中回边读（过去影响现在）／**M3** 判结后写（沉淀落段）／**M4** 离线整理（v1+，不进 v0）。
- **读侧 `忆`＝承重墙**：不是"简单检索"，是**单值浮现**。
- **内部怎么匹配（不定，实现层）**：语义路（非字面精确匹配）＋ 张力路（效价强度＋未了＋近因，原"自我路"改名去掉"我"）；**预测误差→激活**（写时冲击定入口初始激活）。具体取法（LLM 判 / embedding / 粗筛＋精判）后置。
- **主动回忆**：把**浅浮现的锚**再当 cue 喂回（＝再 query），**不需新机器**。

## 5. 写侧（存）＝ `记`；反思在判结，不在记忆

- **反思（LLM）＝环的判结阶段**：经历＋后果 → 产出 **(what, why)**，在**环里、记忆之外**；存**完整产物、别只存裸结论**（"带 why"是格式纪律，不是新机制）。
- **`记(沉淀) → id`**：记忆只**自动存**判结产出的沉淀产物；内部是否再合并/索引/蒸馏——**不定**（实现层）。
- **效价（松/紧）**＝反馈信号＝打分：让劲松的加权、让劲紧的加权避；票数慢慢刻出**慢层地图**。
- **慢层**＝效价筛出的**稳定倾向/规则**——就是形态要素 3"自洽标准"的来源；**快层＝变换（当下表达，可逆）、慢层＝生长（反复一致→沉淀）**，同一机制两种时间尺度。

## 6. 逐要素 → 产出部件

| 形态要素 | 由哪个部件产出 |
|---|---|
| 主动 | **tick（结构，无输入也触发）＋ 训练教的值（方向）＋ 基座能力** |
| 连续 | `忆` 把过往经历读进生成 |
| 自洽标准 | 慢层（效价筛出的稳定规则，带 why）读进生成 → 一致 |
| 不盲从 | 生成时指令＋自身规则一并给 LLM，目的冲突则拒/谈判/离开 |
| 协作 | 后置（与不盲从由"规则为底线＋判断可保留"统一） |

## 7. 不引入（降为候选 / 已否）

- **"自我"当机制部件**——否（10-05 拆的怪圈；它是记忆积累后的叙事名字，不是部件）。
- **投影/认领 作为独立步骤**——"`忆` 读记忆"已够；"认领"是叙事，不是机制。
- **两段 LLM**——一次 LLM（输入＋浮现的过去/规则）够；但"读侧浮现"功能必须保留（＝`忆`）。
- **种子 hack**——退役：训练取代"给空白 agent 注入取向"；"好奇/新奇取向"降为**训练可教的一种值**，不再是特殊首启。
- **锚/维度/索引层**——v1+；v0 用 `忆` 的两条路（语义＋张力）即可，不建索引层。
- **慢层作独立架构层**——不：慢层就是"效价筛出的稳定内容存记忆里"，不需要额外一层。

## 8. 实现时再定的取值（不预拍）

- 训练机制细节（经历结构＋反馈形式）。
- 判结反思的细节（what/why 怎么产、存什么格式）。
- `忆` 怎么匹配（LLM 判 / embedding / 粗筛＋精判；读多少、怎么相关）。
- `记` 内部是否合并/索引/蒸馏；`整理` 怎么形成经验。
- **效价从哪来 / 打分函数**（松/紧怎么算）。
- 抗命时怎么让 LLM 真拒而不滑回"乐于助人"。
- tick 超时值（概率斜坡后置）。
- 段精确字段（效价/结/来源 的具体取值）。
