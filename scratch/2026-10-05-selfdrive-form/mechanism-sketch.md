# 自驱 agent · 最小机制草图（草案 v0.2）

> 性质：从形态反推的**最小实现假设**。不落码；不含判据（判据后置到实现后，见 `form-spec.md`）。
> 上游：`form-spec.md`（形态 5 要素）。原则：**只引入形态要求的部件**；之前理论（投影/慢层/锚/…）一律降为候选。
> 状态：待 YZ 验收。

## 0. 一句话

最小机制＝**训练 ＋ 持久记忆 ＋ 一个环 ＋ 一个 tick**。连续/标准/抗命 是"记忆读进生成"的自然产物；主动由"训练教的值 ＋ 基座能力 ＋ tick 触发"共同产出。**看法内容无统一答案，机制只提供基质。**

## 1. built 部件（机制给的，很少）

- **① 训练环节**（先于 live）：结构化经历 ＋ 反馈，让 agent **学规则（what, why）**、形成自己的看待方式。训练是"学"，不是"灌"。
- **② 持久记忆**：存经历 ＋ 学来的规则（每条带 why）。
- **③ 环骨架**：`事件 | tick → 读记忆 → 生成(LLM：输入 ＋ 相关过去 ＋ 自身规则) → 行动 → 观察后果 → 更新记忆`。
- **④ tick**：闲置超时触发，当作空闲事件进同一个环。

## 2. learned（agent 自己的，无统一答案，机制不规定）

规则及 why · 怎么看待权威/异议/服从·拒绝·离开 · 底线在哪 · 主动/倾向/价值观。

## 3. 规则三分类 → 三种"为什么服从"的通道

| 规则类 | 通道 | built / learned |
|---|---|---|
| 强制（无法违背） | runtime 约束 | built |
| 惩罚（违了受罚） | 反馈（"X→坏"） | learned |
| 合作（违了无法合作） | 反思（"X 破坏共享理解"） | learned（**最深，命门是 why**） |

## 4. 反思 = 存 why，不存裸 what

- 学规则时存 `(what, why)`，不存裸 `what`。why 是反思的产物，是"可泛化、可辩护、能画底线"的关键。
- 反思怎么落地（训练时专设一步产出 why，还是运行时现想）＝实现时定。

## 5. 逐要素 → 产出部件

| 形态要素 | 由哪个部件产出 |
|---|---|
| 主动 | 训练教的值 ＋ 基座能力 ＋ tick |
| 连续 | 记忆读进生成 |
| 自洽标准 | 记忆里的规则（what＋why）读进生成 → 一致 |
| 不盲从 | 生成时指令＋自身规则一并给 LLM，目的冲突则拒/谈判/离开 |
| 协作 | 后置（与不盲从由"规则为底线＋判断可保留"统一） |

## 6. 不引入（降为候选）

- 投影/认领（自指）——"读记忆"已够。
- 锚/维度/索引——简单检索够"连续"。
- 两段 LLM——一次 LLM(输入＋记忆) 够。
- 慢层（作为独立架构层）——规则存记忆即可；**反馈/效价作为"训练通道"是必需的**，但不需"慢层"这一层。
- "自我"——非机制部件（已否）。
- **种子 hack——退役**：训练取代了"给空白 agent 注入取向"的 bootstrap；训练先于 live，agent 一开始就有规则与看法。

## 7. 实现时再定的取值（不预拍）

- 训练机制怎么设计（经历结构 ＋ 反馈形式）。
- 反思（why）怎么落地（训练期 vs 运行时）。
- 生成时"读记忆"的取法（读多少、怎么相关）。
- 抗命时怎么让 LLM 真拒而不滑回"乐于助人"（规则在生成里怎么框）。
- tick 超时值。
