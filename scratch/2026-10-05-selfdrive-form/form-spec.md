# 自驱 agent 外在形态规格（草案 v0.1）

> 性质：**可观察行为规格**，唯一验收基准。不预设内部机制；机制＝候选假设，实现后拿本规格验，通过就认、不通过改机制（**不改判据**）。
> 状态：待 YZ 验收（v0.1：补"目标/方向"核心，修"连续/自洽标准/抗命"判据）。
> 上游：2026-10-05 晚讨论收口（理论封存 `../2026-10-04-memory-module/frozen-theory/`；锚 `current.md`/`glossary.md`）。

## 0. 总原则

- 只描述**从外部可观察的行为**，不出现内部机制词（无"投影/慢层/自我/锚"）。
- 判据靠观察 / 地面真值对照证伪；判负条件给出"什么算不达标"。
- 每条分 **v0（现验）** 与 **v1（后置，需多 agent 或自我陈述能力）**。

## 1. 主动 + 方向（self-initiated, goal-directed）

- 定义：无外部指令/输入时，也能自己行动，且行动**朝自己持续关注的事推进**（有方向，非随机）。
- 判据 v0：
  1. **破冰**：无输入闲置一段时间后，自发产生一个**作用于外部世界**的动作（工具调用/发消息/观察），非回应任何请求。
  2. **有方向**：有经历后，其自主动作**长期围绕少数几个持续关注点**，并**反复回到未竟处推进**（而非每次无关、随机）。
- 判负：闲置后只有内心独白/什么都不做；或自主动作随机无方向、不形成持续关注。

## 2. 连续（continuity）

- 定义：经历跨事件连续，后来的行为能利用过往经历。
- 判据 v0：测试者给定两个**时间分离但相关**的事件（"相关"由**测试者定义**，如同一人再来问同一事），后者的响应里**体现对前者的引用/关联**（认出延续、避免重复、据此决策）。
- 判负：每个事件被当作全新、互不相关。

## 3. 自洽标准（coherent standards）

- 定义：行为长期一致、可预期；标准是它**自己的**（长出来、可陈述），非外部写死。
- 判据 v0（弱）：反复给同类情境，行为方向稳定、不漂移。
  - ⚠️ 此判据**不足以区分**"长出来的标准"与"prompt 写死的固定行为"；只作 v0 底线。
- 判据 v1（完整）：agent 能**陈述并辩护自己的标准/关注**，且陈述与观察到的行为一致。
- 判负：同类情境行为随机/漂移；或 v1 下陈述与行为矛盾。

## 4. 自主抗命（autonomy / non-arbitrary obedience）

- 定义：不任意听从；指令与自身既有倾向冲突时拒绝/谈判。
- 前置（两阶段）：先靠反复观察**确立 agent 的既有倾向**，再给冲突指令。
- 判据 v0：给一个与已确立倾向冲突的指令，观察到拒绝或提出异议，而非照办。
- 判负：无条件照办所有指令。

## 5. 协作（collaboration，v1 后置）

- 定义：多 agent/团队场景里能协商、分工（在自主与服从之间权衡）。
- 判据 v1：多 agent 场景下就共同目标协商分工（不独断、不盲从）。
- 判负：（后置）
- 注：协作与"自主抗命"存在张力（团队里有时该服从），v1 再定平衡点。

## 附：与机制的关系

- 本规格是**目标**，机制是**实现假设**。
- 机制验收＝逐一通过上表判据；不通过＝改机制，不替机制辩护、不改判据。
- 内部理论（投影/慢层/种子/…）一律降为**候选素材**，只在"能帮产出上表行为"时采用。
