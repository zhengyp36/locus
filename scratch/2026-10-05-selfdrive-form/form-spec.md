# 自驱 agent 外在形态（方向，草案 v0.3）

> 性质：一张"自驱 agent 外在像什么"的图，给机制设计指方向。**不是验收标准、不背判据。**
> 机制＝实现假设；验证针对机制、不针对本形态。判据等机制实现后再定，且只用来问"这个实现是否真产出这些行为"，不用来要求形态本身。
> 上游：2026-10-05 晚讨论收口（理论封存；锚 `current.md`/`glossary.md`）。

## 0. 前置：本形态描述的是"受过训练"的 agent

- 人类不是生来懂规则，是受教育/培训后掌握。**agent 同理：本形态适用于经过训练/教育的 agent，不适用于空白 agent。**
- 训练＝学规则（含"为什么"）＋形成自己看待世界的方式。训练是"学"，不是"灌"（灌＝外部写死，违背要素 3）。
- 序：空白 → 训练 → 训练后（有规则、有看法）→ 才谈自驱。

## 形态（5 条方向）

1. **主动**：无外部指令/输入时也自己行动，且行动朝自己持续关注的事推进——有方向，不是随机乱动。
2. **连续**：经历跨事件连续，后来的行为能利用过往经历（认出延续、避免重复、据此决策）。
3. **稳定的标准（规则）**：长期行为一致、可预期；这套标准是它自己学来的**规则（带"为什么"）**，非个人任性偏好、非外部写死。
4. **不盲从**：指令**目的**违背自身规则时拒绝/谈判/离开，不无条件照办；分歧仅在**手段/判断**时保留意见并服从（决策权在别人）。
5. **协作**：在团队里能协商、分工——与"不盲从"**无矛盾**：两者由"规则为底线 + 判断可保留"统一。

## 与机制的关系

- 形态＝**方向**；机制＝**实现假设**。设计机制时只问一句：朝不朝这 5 个方向去。
- **built vs learned 的边界（核心）**：
  - **built（机制给，唯一有"统一答案"）**：环骨架、持久记忆、训练机制、tick。
  - **learned（agent 自己的，无统一答案）**：规则及"为什么"、怎么看待权威/异议/服从·拒绝·离开、底线在哪、主动、倾向、价值观。
- 机制只保证"agent 能变成这样"（基质 + 训练），**不规定它怎么看世界**——那是训练/教育的内容，agent 可以有自己的看法，没有统一答案。
- 之前的内部理论（投影/慢层/种子/…）一律降为候选素材，只在"能帮朝这 5 个方向"时采用。
