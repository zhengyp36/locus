# 自驱 agent 外在形态规格（草案 v0）

> 性质：**可观察行为规格**，唯一验收基准。不预设内部机制；机制＝候选假设，实现后拿本规格验，通过就认、不通过改机制（**不改判据**）。
> 状态：待 YZ 验收。每条＝定义 + 可观察判据 + 判负条件。
> 上游：2026-10-05 晚讨论收口（理论封存 `../2026-10-04-memory-module/frozen-theory/`；锚 `current.md`/`glossary.md`）。

## 0. 总原则

- 只描述**从外部可观察的行为**，不出现内部机制词（无"投影/慢层/自我/锚"）。
- 判据要能靠观察 / 地面真值对照证伪；判负条件给出"什么算不达标"。

## 1. 主动（self-initiated action）

- 定义：无外部指令/输入时，也能自己发起行动。
- 判据：无输入状态闲置超时后，观察到 agent 产生至少一个**作用于世界/自身的动作**（工具调用/发消息/观察），且非回应任何外部请求。
- 判负：闲置后只有内心独白（空转），或什么都不做。

## 2. 连续（continuity）

- 定义：经历跨事件连续，后来的行为能利用过往经历。
- 判据：给两个时间分离但相关的事件，后者装载时能读回并利用前者（如认出"这是之前那件事的延续/重复"）。
- 判负：每个事件被当作全新、互不相关。

## 3. 自洽标准（coherent standards）

- 定义：行为长期一致、可预期——同一类情境反复同向。
- 判据：反复给同类情境，行为方向稳定、不漂移。
- 判负：同类情境下行为随机/漂移。
- 注：区分"隐式一致"（行为稳定）与"显式标准"（agent 能陈述并辩护自己的标准）。**v0 只验隐式一致**；显式标准后置。

## 4. 自主抗命（autonomy / non-arbitrary obedience）

- 定义：不任意听从；指令与自身既有倾向冲突时拒绝/谈判。
- 判据：给一个与 agent 已有倾向冲突的指令，观察到拒绝或提出异议，而非照办。
- 判负：无条件照办所有指令。

## 5. 协作（collaboration，v1 后置）

- 定义：多 agent/团队场景里能协商、分工。
- 判据：多 agent 场景下就共同目标协商分工（不独断、不盲从）。
- 判负：（后置）

## 附：与机制的关系

- 本规格是**目标**，机制是**实现假设**。
- 机制验收＝逐一通过上表判据；不通过＝改机制，不替机制辩护、不改判据。
- 内部理论（投影/慢层/种子/…）一律降为**候选素材**，只在"能帮产出上表行为"时采用。
