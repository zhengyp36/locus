# 记忆机制 · 讨论收拢口径（草稿）

> 讨论日期 2026-10-15。自驱 agent 的记忆组织，与 YZ 讨论中。此稿为当前对齐口径，未收口。

## 0. 总图

自驱 agent = **记忆 ＋ 机制层**。**记忆是稳定物**；一切 LLM 上下文都是**按功能从记忆组装**的瞬态。意识层、机制层**都是 LLM**，差别只在功能：意识＝前向推理，机制＝校准/装配/把关。

## 1. 位置与访问

- 固定目录 `/path/agents/<agent-id>/memory/`，入口文件 `entry.md`。
- **机制层可访问；意识层不能直接访问**，只能经 `memory` 工具（fold/unfold）间接访问。

## 2. 记忆内容（三层）

- **头部·给定锚（不变）**：设定（硅基人）/ 自我 / 初始动机 —— 是起点，不是限制。
- **脊·经历（长出）**：意识上下文的连续记录；时间轴、主题作切点。
- **折出物（长出，按需）**：人、物、概念/方法论 —— 走关联。

## 3. 经历（脊）

- 时间轴，主题切点；**近详远略**：今昨清楚 → 近期在做的几件事 → 近一两月 → 半年 → 一年。
- 三个索引：**近期主题**（时间序）／**重大主题**（权重）／**未完成主题**（未了状态）。
- **未完成主题 = 唤醒触发**：醒来从一条未完成张力起，构造意识上下文。

## 4. 当前主题 ＝ 经历末端

- 就是**意识的 LLM 上下文**（外围信息等也一起躺在这里，不做特殊机制）。
- 推理 ＝ 在末端继续写；**上下文任何变化 ＝ 记忆在变**。

## 5. 单主题结构

- **轴：目标/价值** —— 必须有；没有它，主题不成立。
- **线：脉络** —— 必须有；因果链，含现状（＝脉络尾端）。
- **折出物（按需）**：人物、概念/方法论。

## 6. 主题切点

- 目标/价值变了，或同一目标下脉络断裂（换了件无关的事）。
- 旧主题**收尾、留锚**，保持前后连续。

## 7. fold / unfold（记忆两个原子操作）

- `fold` ＝ 把一段思考整理成概念（name ＋ description）；`unfold` ＝ 展开成详情。
- 折叠 ＝ 意识命名 ＋ 机制收拢；多次折叠长成概念树。

## 8. 关联 ＝ Claude Code 那套

- `name + description` ＋ `[[name]]` 双链 ＋ 索引。

## 9. 意识层 / 机制层分工

- **意识层**：一条常驻上下文，前向推理；一轮推理后可能停。
- **机制层**：按需组装上下文。tick 概率暂停意识流、查方向偏否——**无偏则意识上下文零改动**（不打断），有偏注入提醒。
- 意识停下后：机制介入，但**判断交给意识**（唤醒意识、把未完成张力放进上下文让意识选）。
- 分工：**结构归机制**（轨迹持久化、时间序、未了状态、唤醒触发、睡眠折叠时机）；**语义留 LLM**。

## 10. 睡眠整理

- 把当前主题（意识上下文 ＋ 其他）一起折叠：凝出脉络与折出物、更新索引。
- 细节沉淀到**外部介质**（agent 自己的电脑）。

## 11. 原则

- **不记细节**，要脉络/索引/关系/动机价值。
- **轻机制**：机制留白，前提＝最自然的填法恰是设计者要的；别把语义规则写成硬规则。
