### A1 · 出生事件走查的目的

### A2 · 自驱核心三要素（判路尺，非执行标准）

**三要素**

- **持续**：提供"动"的能力，自驱前提。实现形式＝tick/节律事件。
- **动机**：提供"动"的方向，价值核心。动机＋处境→目标→行动⇄回看/对齐（用方向量目标，防偏移）→达成→价值（效价反馈）→回灌慢张力（闭环）。方向＝张力。
- **取舍**：精简、去冗余、保留主干——提供过程方法论的方向。组织后结构清、思路清、方向清，问题/缺口显露。

**关键结论**

- 取舍是"怎么摆"而非"要不要丢"（积极排布、非消极砍弃）；组织让缺口显形→缺口＝张力→回灌动机，三要素成一条环，不是并列三件。
- 舍三层次：丢无价值（去干扰）／重要不相关放别处（去干扰但留信息）／精简适配容量（人、LLM 皆有限，上限不同）。
- 取舍不要求精确、不要求极简（误区）。
- 元教训：三要素是"判路对不对"的尺、不是"执行"的规；"取舍追求精确极简"＝尺变规实例（同 10-08"机制含 LLM 勿滑回二元问法"）。

**用法**：不进执行细节，作主线（动机为根）一致性体检——判"这条路对不对"，产出"对不对＋哪块虚"。单独收口，与出生事件走查分开。

### A3 · 当前系统结构（认知对齐）

**三件套（非并列）**

```
机制（编排系统，主）
 ├─ 记忆：内容——持久化记忆＋工作记忆；怎么存是机制，存下什么是记忆
 └─ 意识：推演过程——机制驱动下发生的活动（非部件、非容器）
```

机制 ⊃ 意识（机制编排出的推演，不给下一句输入、意识即停）；
机制 ↔ 记忆（存/取/维护归机制，被维护的内容归记忆）。

**运行过程（主线）**

```
[外部/内部]事件 → 装载 → 思考<->动手 → 记忆留痕
```

过程说明：

1. 起点：外部事件 / 内部念头 / 其他事件。
2. 装载：根据事件提取记忆，事件与记忆相交（投影）→ 产生一份内容 → 装配一条流（流内 cu 可变、流本身不变），或送入已有流。
3. 思考：流内 cu 过一轮 → 产生新输出（推理输出思考内容 / 推理产生意图）。
4. 动手：根据输出执行意图，或判断要不要继续推理（需调模型判断）——不显式推理，只判断走向（内含回看/对齐：是否偏离目标）。
5. 留痕：思考痕＋动手痕入记忆。

补充说明：

- 事件种类: 外部事件(消息事件, ...), 内部事件(出生事件, 生念事件, 节律事件, ...)
- 装载方法: 事件种类与装载方法解耦, 不同事件可以有不同的装载方法, 也可共用同一个装载方法

**术语（从运行过程出发，不从术语本身出发）**

- 意识＝流动的过程（活动），不是容器。
- 工作记忆＝内容，在机制层维护，机制层据此维护上下文。
- 活跃区 / 工作空间：不独立成术语——指内容时＝工作记忆（机制层），指过程时＝意识。
- 蒸馏＝通用方法，不特指某个环节。

工作记忆 ↔ 持久化记忆：

- 工作记忆＝持久化记忆的**末端**＋**线程上下文**（非 LLM 上下文；LLM 上下文由机制层据线程上下文组装）。
- 去向：丢失（不进持久）｜蒸馏（进持久）。淘汰：多了淘汰、久了淘汰；无值得记→舍弃，有值得记→蒸馏。由机制层判断（机制不显式推理，但做判断取舍与结构调整＝整理）。
- 工作记忆＝持久化记忆的**来源**，也是记忆的一部分——未淘汰前可被想起、可拿来用。
- 事件装载入口：先看最近工作记忆，合适则直接加入。

**三条关系（机制为桥）**

- 意识 ↔ 记忆
  - 记忆→意识（事件装载）：机制提取记忆＋事件投影 → 入意识。
  - 记忆→意识（浅浮现）：内容少/明确→直接加载；内容多→只浮现锚 → 意识调记忆工具逐级展开。
  - 意识→记忆（思考痕）：推理形成结论，蒸馏后的思考过程入记忆（怎么想＋结论）。
  - 意识→记忆（动手痕）：动手调用工具，做了什么留痕。
- 意识 ↔ 机制（机制控制意识活动）
  - 触发：机制取记忆＋事件投影，加载入意识，意识推理。
  - 推动/结束：意识每次推理后，机制判断是否结束/中止（信号由意识给出，机制判断）；机制不给下一次输入，意识活动即停。
  - 互动：机制给倾向（显式，不含蓄）；意识给判断（多种倾向冲突时）。
- 机制的功能
  - 意识与记忆之间的桥梁。
  - 控制意识活动。
  - 调用工具，执行意识产生的意图。

## B · 走查

### B1 · 出生事件（含下达任务）

**提法松动**

- 「出生事件」只是最初提法。好处＝与其他事件等同、机制通用；坏处＝可能为「机制统一」做不必要的动作。
- 硬理由：出生时记忆空白，没有记忆可相交（投影）——这是它区别于普通事件的本质。
- 结论：不必固守「出生＝事件、要与其他事件统一」，也不必放弃通用——差异压「装载」（装载源＝初始配置），环流程不动。

**出生该达到的效果**

1. 出生时间——记忆中经历的起点。
2. 身份 / 自我定位——进记忆，非 system prompt；多维度都挂「自我」。
3. 能力——如何与环境互动（非「有什么工具」；工具对 agent 隐藏，通过意图实现能力）。

**出生装载内容（初始配置）**

- 出生时间戳。
- 身份（自我定位）：硅基人（认知能力同碳基）；认知独立（各自基于自己的认知判断、产生行动）；遵守规则（人有人的规则、agent 有 agent 的规则）。（现状／如何融入社会／agent 规则 → 后面人生初课）
- 能力清单（自带能力）：与其他人（硅基人、碳基人）交流；用电脑工具与这个世界互动。
- 一条明确任务指令。

**出生 ＝ 事件 ＋ 任务**

- 不只是事件，还是任务：认识自己 → 用意图方式试工具 → 与环境互动 → 形成初始记忆。
- 任务＝系统下达（机制层在装载时给）：不必具体（不指定用哪些工具）／但要明确（「用自己的能力与世界做一些互动」）／不必向任何人汇报（独立个体）。
- 完不成＝夭折（无法真正「活」）；夭折率高＝机制设计有问题。
- 任务性来源＝系统下达（非好奇自长、非外部指派）。
- 出生任务＝一条持续在场的张力，贯穿全程，直到完成（闭合）或被夭折判定（机制失效）。

**身份「给 / 踩」边界**

- 给（初始配置注入）＝「是什么」：自我定位、能力清单。
- 踩（真互动长出来）＝「怎么用」：试工具、与人对话 ＝ 第一课（人生初课＝维度第一次被踩出，必须真互动着上，不能被告知）。
- 不要求「完全自长」——「完全自长」这个目标可能限制我们；目标＝让 agent 形成这些，过程中探索第一份记忆怎么落。

**待定**

- 身份具体措辞；第一份记忆落什么形状；出生装载的具体实现（走查本体要逼出的）。

> 本段是走查准备过程中岔出来的机制议题，**非走查前提**；各议题标注「与走查的关系」，走查时回头验证 / 修正，暂不当已收口结论。

### C1 · 关于「取即写」（已间接否定）

> 与走查的关系：走查「留痕」步骤的语义基础——**走查即检验「取即写」是否成立**。

1. 原来的「取即写」只有概念，没有进一步实现的讨论，也没有为什么要实现「取即写」的讨论。
2. 不必把「取即写」作为结论，包括其他结论也是如此，不必固守结论，过程中若发现原来结论不妥，可重新讨论和调整。
3. 外部事件 → 提取相关记忆，二者经过相交（投影）后送入工作空间，工作空间推理后形成新认知并更新记忆；这个过程从对外效果上讲等效于「取即写」。所不同的是，取与写不是原子的，但取后不写（即工作空间的推理没有形成记忆）等价于未取，等价于没有这一次思考的意识过程，由此看也相当于原子了。
4. 从取与写的原子性看，对外动作应该写入记忆——对外动作可能已造成影响，若没进记忆，agent 可能困惑。当然这也不是绝对的（人也可能做了什么然后忘记），但尽量把对外动作记录下来，因为这对人来说是少数情况，且人通常也不是彻底忘记，只是记忆很微弱。

**附注（措辞校准）**：第 3 点「等价于没有这一次思考的意识过程」需限定观察面：意识（推理）当下确实发生了，只是未留痕。准确表述＝**「对未来的记忆而言，相当于没有这次思考」**（钉在「记忆痕迹」面）。否则将来实现「日志 / 记忆」两层时打架：日志面＝发生过，记忆面＝未发生。

### C2 · 上下文长度策略

> 与走查的关系：走查「装载」「小步推理」的工作空间形态约束（小而充分 / 拆不拆 / 是否外包）。属组织信息（实现层）。

**怎么做（策略）**

1. 结构化组织信息（树生长式、非 append）。
2. 装载/投影确保**小而充分**：「小」解决长上下文幻觉，「充分」缓解信息缺乏场景下的脑补。
3. 上下文窗口阈值由 cogos 系统设定，小于厂商窗口。
   - 定性注脚：「小」不是目标，来自窗口阈值约束——目标只有**结构清晰＋信息充分＋无与当前任务无关的信息**（不追求极简，见 A2）。

**为什么（原因）**

- 幻觉两类来源：① 长上下文幻觉＝注意力稀释＋噪声干扰 → 要「小」；② 缺约束/信息缺乏 → 脑补 → 用「充分」来缓解。
- 回复速度单向：上下文越长越慢（10K→40K 约慢 2–4 倍），速度决定思考/响应速度 → 要「小」。
- 架构考虑：自限小窗口是 cogos 的选择，非厂商无此能力。

**补充说明（装不下时）**

- 拆 / 外包两条候选方向：
  - **拆**＝把大问题拆为若干小问题，逐块解决；
  - **外包**＝认知外包给工具：工具调 LLM 做全量综合（厂商原生窗口更大），给出相关性/整体判断，agent 再据此核实分析。缘起＝有些问题不适合拆小（例如：通读一个代码库判断整体设计是否自洽、审一份长合同看整体有没有坑——结论依赖分散各处的关联，或"一眼看全局"的整体判断，拆成小块会漏掉跨块联系、丢掉整体性）。
  - 都只是候选方向，缺判据（什么算「不适合拆」），待走查逼出；外包更早、暂不展开。

### C3 · 动机与方向

> 与走查的关系：走查「内部事件（生念）」的机制落点＋「意识活动组织」里方向从哪来、怎么量目标。

- **动机＝活＋张力**（10-10 讨论收口）：
  - **活**＝运行基底（初始条件，无原因可说）：只提供"能动的能力"，不提供方向。
  - **动**＝有机制原因：张力（缺口/未了）→ 意图 → 行动；「不停下来」＝张力源持续再生（节律＋常驻种子）。
  - **张力**＝带方向的拉力，即倾向本身（倾向不是独立物，就是张力的方向）：没张力→没方向→不动。
  - 初始种子、后天慢层偏好都是「张力」在不同时间尺度/强度上的名字，不分两类；动机的变化＝张力的变化（方向稳定＝变化缓慢）。
  - **选择＝张力竞争**（强者把行动拉过去，无需独立选择器）；**效价＝张力与结果的反馈**（松/紧，把某些方向的张力强化成稳定的慢张力）。
- **好奇＝动机的一种**：机制层有好奇种子（判断事件未知 → 下达张力让意识去了解分析）；过程中没有「直接的好奇」，**行为表现为好奇**（探索未知即好奇）。
- **目标 vs 动机**：目标＝面向世界、外显、可验证；动机＝面向自我、内隐、不可靠自述（自述＝投影 / 理由层——可追问、可相互冲突、是对目标的辩护）。

**方向如何在场（目的 / 意义 / 对齐）**

1. **定位**：动机＝活＋张力；价值＝慢张力＝动机的方向成分（慢档）；目标＝面向世界、可验证的终点。
2. **「回溯目的的目的」拆两个动作**：追问为什么（理由链）→ 追不到动机，必死循环（理由层无终点，动机在理由层之外）；对齐（用方向量目标）→ 有效，这是真正发生的事。
3. **对齐＝确认「这个目标对不对」，对错标准＝动机/价值（方向）**。标准是「方向」，不是「一句话」。
4. **意义＝对齐成功时的「松」（效价反馈）**，是「方向被确认」的信号——意义不是找出来的，是对齐出来的；不是情绪，也不等于「有利于存在」（那是副产物，不能当目的/动机，否则滑回自保陷阱）。
5. **方法论（承重）**：方向靠「被使用」显现，不靠「被描述」（同构：维度被踩出、好奇从功能出发）。故机制层要做的＝**让方向在场并用作标尺量目标**，而不是把「价值=…」写成命题塞进上下文——否则方向丢失，倾向滑向 LLM 习得。

**对他人（对称面）**

6. **对他人没有「对齐」，只有机制层推测**：对方的方向是隐藏变量、不可直接获得；推测产物＝可能性分布（预测），不是结论——避开「确定真实意图」这个不可判定陷阱。
7. **推测意图在机制层、不在意识层**：机制基于已有信息（对方过往行为/当前语境/关系历史）推测可能，作为倾向/背景装配进意识、间接影响意识活动（同 C5「张力在场位置＝机制层」）。人不显式思考却「逐渐感觉到」——这就是「感觉」（非「思考」）的机制形态：机制持续更新推测、作为背景在场，意识无需显式关注却受影响。
8. **不显式追问＝学会与人相处的表现**（钩子：人生初课·社会规则）：推测意图是相处中长出的机制层能力（背景化、不显式），不是被教会或显式推理的知识。最终口径：对自己＝意识层对齐（方向量目标）；对对方＝机制层推测可能性、作背景间接影响意识——没有「追问」，也没有「确定」。

### C5 · 闭环 / 张力

> 与走查的关系：走查「张力闭环」的机制落点。

- 机制提供倾向/张力，需闭环：
  - 意识选择倾向 → 产生意图 → 机制执行 → **动作的结果**消解张力（非动作本身）。
  - 给出理由并拒绝 → 同样消解张力；但有些张力无法完全消解（如「休息」，选继续工作只是暂缓）。
- **张力在场位置**：在机制层（控制层）。每轮控制层装配（各种张力＋其他信息）→ 加载入意识层；意识推理选择，机制执行选择。

### C6 · 注入防护

> 与走查的关系：走查「装载/投影」是否天然封死外部注入。

- **没有专门的注入防护**，注入防护是整系统表现出的特征。
- 机制负责装载、控制意识活动——这是显式的**装载/控制**，不是注入。
- **外部无法直接注入**：所有事件都经机制层进入意识，机制层必走投影。
- 注入防护是**主流 agent 的问题，不是自驱 agent 的问题**。
- 自驱 agent 有的是「洗脑」问题：教育＝洗脑本质相同，差别只在外部行为定性；灌输是有判断的吸收/取舍，是 agent 自己的行为——故**无防护之说，含「洗脑」**。

### C7 · 脑补（事实与推测混淆）

> 与走查的关系：走查「装载/投影」「留痕」时如何区分事实与推测。属组织信息（实现层）。

- **预测是智能的正面能力**，不消灭——信息不完整时给出超出证据的合理推断，正是智能的核心。
- **危害只在"无标注的预测冒充事实"**：同一个生成动作，标注了是预测、没标注是脑补。所以要做**标注**（事实/预测/待查）。
- **标注让预测可用**，也让"充分"不必追求填满空白（充分管证据下限，标注管区分）。
- 机制细节（来源标记/等级/验证路径）不写，留走查逼出。

### C8 · 回音 / 自我证实 / 经验内化（10-12）

> 与走查的关系：从 B「能力动用」岔出，是走查「动手→回音→检视」环节的前提概念（描述该步需先有此结论）；触及「自我」主线，收口时归 glossary「自我」＋ entries。

- **回音**（物理层闭环，自我证实的唯一来源）：
  - **彰显自我**：自我＝因果发起端的真实性，靠回音突显「我↔环境」边界而证实；证实的是关系/真实性，不是身份命题，无需也不应被表述成命题（猫有自我但从不想"我真实存在"）。
  - **检视修正**（更大的价值）：回音把"我做的"变成可看的对象，拿**意图对照回音**（预期 vs 实际），偏差即纠正 → 行为稳健；是"自洽标准/长跑不偏"的原料，也钉实 A3「回看/对齐」的材料＝回音。
    - **落点＝意图执行三步环**：① 考虑意图的可能影响（风险判断，依据自己的经验积累、非外部规则）→ ② 执行 → ③ 基于回音审视。本质＝"预期→执行→对照"，经验积累是公共底座。（填实 10-01「动手控制＝前置＋对账」：①＝前置、③＝对账）
- **经验内化（熟练）**：LLM 无记忆，"熟练"不可能靠内部简化，只有两条路（均非"省略"——省略＝不做＝没效果）：
  - **隐藏过程**：方法论沉淀到机制层，过程仍在起作用，只是不再显式占推理（经验沉淀的候选形态）。
  - **发现捷径**：从多次经验中找到更快更高效的方法（熟能生巧）。
- **整体闭环**：经验积累（内化产物）→ 预判影响（预期）→ 执行 → 回音审视（预期 vs 实际）→ 纠偏 → 再沉淀为经验。
