# 出生→教育 · 拉通梳理与判断（10-12，讨论中）

> 入口 `scratch/ENTRY.md`。本轮 YZ 把散点拉通到"出生→教育"一条时间线，我据此给判断。未收口，不更新记忆层/glossary。

## 一、YZ 本轮串起来的内容（结构化）

1. **范围拉通**：出生（是过程、非单一事件）→ 教育。
   - 出生要达成的效果＝认识自己 ＋ 能与环境互动 ＋ 能与人交流（这是教育的基础）。
   - 教育＝与人交流，讨论社会规则、怎么做事、怎么融入社会。
2. **运行主线形状不合适**（"事件→装载→思考⇄动手→记忆留痕"）：
   - 事件不一定是起点，可能中途插入（与当前推理强相关）；插入也要经装载进入意识，**非裸事件输入**。
   - 留痕贯穿：事件本身留痕、动手留痕、思考中的意外发现/重大突破/困难留痕——非末尾一步。
3. **架构类比**：机制＝笔/橡皮，记忆＝画纸上的图，意识＝作画过程，心语＝一笔一画落纸/擦除的（不再用心语指意识）。
4. **记忆推进**：记忆-0→记忆-1→记忆-2→…，每步推进都是意识活动；**事件是动力**（外部事件、内部事件＝张力/生念/节律）。每份记忆＝持久化记忆＋工作记忆，通常变的是工作记忆，某些时候工作记忆蒸馏进持久化或淘汰。
5. **事件内外二分不合适**：从意识活动出发，事件只与"主题相关/无关"有关，与内外无关；内外只作"来源标注"。且来源标注也不准（记得某人说过一句话→当下是内部记忆，初始源头是外部）。
6. **机制层对推理活动的把握本身可成事件**：长时间思考无进展、转向切换主题、重大突破——都可成事件。
7. **事件切割经历**＝记忆留痕的点位；重大进展、长时间阻塞也会变成事件，在经历里留痕。
8. **持久化记忆按维度组织；工作记忆怎么组织**（待答）。
9. **工作记忆猜想**：
   - 时间轴形态：主题A(几乎不记得)→主题B(极少信息)→主题C(少量摘要)→主题D(详细内容、正在推进)。
   - 短时间经历轴可与之对应；但主题作节点可能太粗，事件才对经历划出更细的节点。
   - 一个主题内部至少含：目的是什么、动机是什么、现状是什么、大致经历过程、当前推进情况与内容。
10. **与人对应**：心语＝注意力所在（推理不断冒出的内容，再次参与推理）；目的/动机在场但不被注意（注意力不在其上，除非主动去想）。主流 append 方式可能就是这个形态：顺着语义流动前进，机制层（元层）不时对齐到稳定目标，发现偏移就注入稳定目标、甚至对齐动机——像人的注意力，元层悄悄把控方向，平时注意力只在局部问题。
11. **出生三件事的分层**（我们的目的如何变 agent 的目的）：
    - 形成自我认知 → 不必写目的，文字介绍进记忆＝自我认知。
    - 知道能力 → 文字给出；能力常驻或机制层注入（锚展开）；推理中要动手时才"想能力"、此时展开。
    - 真实用一用能力 → 即任务。
    - 实现要点＝"一想能力就出现"＝**记忆浮现/展开的共用机制**（锚展开）。
12. **出生后→教育→日常**：摆出"融入社会"议题、每天固定时间干什么、白天运转晚上睡眠周而复始。

## 二、我的判断

### 判断1：事件概念过载，建议拆两个
"事件"现在同时扛两个角色，二者不一一对应：
- **输入**（动力/信息源）＝进入意识活动的东西，来源标注（外部 / 内部张力 / 工具返回 / 机制判断）；与当前主题相关则推进、无关则可能转向。
- **节点**（经历切点/留痕点位）＝在经历轴上划一刀的点。

拆开后才好回答"什么时候在经历里划一刀"——输入不必然留痕；突破/阻塞会留痕但不是外部输入。YZ 已摸到边界（"机制层把握本身也可成事件""重大突破也可成事件"），值得钉成显式区分。

### 判断2：内外二分降级是对的，且与 C3 一致
动力归张力、不归内外（C3：动机＝活＋张力）；内外只作来源标注。补一点：来源会追溯（记得某人说过→源头外部），**是否要记"源头链"待定**。

### 判断3：留痕贯穿 与 C1 同构（互相验证）
"留痕贯穿而非末尾一步"独立走到了 C1 的同一结论：取即写＝思考就留痕、无独立沉淀步。两轮殊途同归，可信度上升。

### 判断4：工作记忆"注意力"类比最有价值，但 append 类比只对一半
- 对的一半："目的/动机在场但不被注意，机制层（元层）偏移时对齐"——这给"张力在场位置＝机制层"（C5）补了一个可操作形态。
- 但对齐要分两层（C3 拆的两个动作）：
  1. **对齐目标**＝用方向量目标（还在不在路上）；
  2. **对齐动机**＝目标本身对不对，用价值/慢张力量。
- 只对一半的原因：主流 append 只有"注意力在局部"这一半，**没有真正的元层把控方向**——主流靠 system prompt 稳定指令＋模型自律，正是 10-09 调研要补的"边界＋可判定例外 / 注入防护成段"的缺口。故不能直接说"append 就是这样"，append 只描述了注意力形态，元层是我们**要设计**的。

### 判断5：出生三件事分层对，"一想能力就出现"暴露共用机制缺口
记忆浮现/展开（锚展开）是出生走查第一个会碰到的硬实现点，尚未设计。它同时服务三处：能力清单展开、浅浮现→主动回忆、持久化记忆的逐级展开——应作一个共用机制设计，而非三套。

### 判断6（10-12 修正）：教育不引入新机制——它是"交流＋记忆形成"两个基础的自然持续
- 教育不是要预先想清内容的课程；主要方式就是交流、讨论。其依赖的全部机制＝**能交流**（能力清单）＋**能把讨论过程/结论沉淀成记忆经历**（记忆留痕）——这两者是出生要交付的基础，教育只是它们的持续运行，**不构成独立的机制设计对象**。
- 故"出生→教育"不是两段走查；教育的验收被并回出生闭环：出生要能证明"已具备进入教育的前提（能交流、能把互动沉淀成记忆经历）"。
- 这使范围收敛到一件事：验证出生交付的这两个基础。

## 三、主线运行过程（正向整合，10-13）

> 回应 YZ：主线不该"从判据反向推"，应正向把"思考过程＋记忆组织＋锚点"串成一个循环；出生闭环＝该循环的冷启动。

### 主线 = 机制驱动的推理步循环（loop），非线性管道

旧主线"事件→装载→思考⇄动手→留痕"把"一次事件驱动的经历"画成线性管道；实际机制是**每步都循环的 loop**。

```
         ┌──────────────────────────────────────────┐
         │ 工作记忆：主题A(几不记得)→B(极少)→C(摘要)→D(详细·推进中)
         │          ＋ 经历轴                        │
         └──────────────────────────────────────────┘
            ↑ 留痕·写回             ↓ 装配（读＋锚展开＋注入对齐）
         ┌──────────────────────────────────────────┐
         │ 机制：判走向(继续/动手/结束)＋对齐(偏移则注入目标/动机) │
         └──────────────────────────────────────────┘
            ↑ 产出                 ↓ 上下文
         ┌──────────────────────────────────────────┐
         │ 意识：推理一步（冒出思考内容 或 意图）          │
         └──────────────────────────────────────────┘
```

循环六步：**装配 → 推理一步 → 判走向 → 留痕(写回) → 对齐 → 回到装配**。
- **事件（输入/动力）随时进入循环**：与当前主题相关→并入（新输入推进）；无关→转向新主题（当前主题压成摘要、新主题成 D）或挂起。工具同步返回直接回环，异步返回＝事件回环。

### 旧三环节重新定位
- **装载** = 装配步（事件与记忆相交/投影 → 更新工作记忆）。
- **思考⇄动手** = 推理步＋判走向步（意图执行后，结果作事件回环）。
- **留痕** = 写回步（贯穿每步，非末尾）。

### 工作记忆组织（挂在循环的装配/写回上）
- 时间轴 = 主题序列 A→B→C→D，越远越压缩（经历轴的工作记忆端）。
- 当前主题 D 内部 = 目的/动机（机制层稳定区，在场不显式）＋ 现状 ＋ 大致经历（本主题脉络）＋ 当前推进内容（注意力所在，逐字详细）。
- 主题切换 = 判走向时"转向"。

### 锚点实现（挂在装配步）
- 锚 = 装配时的展开入口，共用"锚→展开"机制。
- **记忆锚**：浅浮现→主动回忆（内容多先浮锚、需要时展开）。
- **能力锚**：能力清单常驻为锚，要动手时"一想能力就出现"＝展开能力锚。

### 出生事件闭环 = 循环的冷启动
- 初始配置经装配进工作记忆（无记忆可投影＝装配特殊情况：直接注入）。
- 循环跑起来，第一份记忆在留痕步落成，七维度在推进中被踩出。
- 出生交付的验收（能交流＋能把互动沉淀成记忆经历）＝循环稳定跑＋第一份记忆落成。
