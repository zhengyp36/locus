## 0. 一句话

一个自驱 agent ＝ **一个在转的环**（事件→装载⇄生产→判结→沉淀）**＋ 内圈闭合**（段→蒸馏→经验→取回）。第一人称是**意识**；LLM 横切每个语义点；机制是确定性脚手架。稳定单位是**流**。

## 1. 角色层（v1 定死）

- **意识** `[定]`：有声、**过程的第一人称**；只做思考、发意图；**看不见执行**。
- **执行** `[定]`：无声；承接意图 →（展开用法/选工具/调用/析结果/对账），自身也用 LLM；可起**流2**。
- **机制** `[定]`：确定性脚手架——事件端口、`cu`（实现区间）、界桩、存储、锚盖章、注意力闸的执行；只在语义点调用 LLM。
- **LLM** `[定]`：**横切能力**，出现在思考/执行/装载闸/沉淀蒸馏等每个语义点；**不是一层、不与 agent 并列**。
- **命名收口** `[定]`：第一人称用**意识**；`心智` 退出直接同义（若保留，只作"整体我"的别名，不再作第一人称）。理由：判据是 glossary 已定的**有声/无声**，二值、可切。
- **桥＝意图**（无声动作指令）；**界桩**＝意图 `enter/exit` 的机制标记。`[收]`

## 2. 环（以流为单位）

```
事件(外/内, 交织, 可多流并存)
  → 装载[持续过程]  ⇄  生产[思考⇄动手]
  → 判结(流级)
  → 沉淀
  → 回边: 结=未了 → 张力 → 内部事件
内圈: 段 → 蒸馏 → 经验 → 按锚存/取
```

- **稳定单位＝流**；`cu`＝实现区间（见 §3.6）。`[定]`

## 3. 各段

### 3.1 事件 `[收]`

- 来源：外部 / 内部（未了张力自燃）；交织、可搁置、可注入、多流并存。
- 什么算一个事件 → 归**装载**判定。
- 自指分界＝未闭合张力是否**跨事件延续**；事件可被**认领**。
- 补充 `[定]`：事件必带 `locator`；事件↔槽**绑定**（见 §3.2）。

### 3.2 装载 `[定]`

- **形状＝持续浮现，与生产并发** `[定]`。"一次投影"降为它的**第一波退化情形**（泛化，非取代）。
- 引子 `cue → 痕迹激活`：到达即**第一波浅浮现**（信息 ＋ 一小簇相关痕迹 ＋ **more 指针**）；处理中**持续浮现**，须过**注意力闸**（可查可调，`muted≠dropped`）。
- **事件↔槽绑定** `[定]`：主动绑定（设闹钟/调工具时机制当场绑到"当时的经历"）／兜底绑定（结构锚归机制、语义锚靠一次理解）。
- **痕迹层 vs 当下** `[定]`：痕迹层＝长期的我（槽的分布式痕迹）；当下＝按锚装配的"此刻的我"，生产发生于此。
- 产出：小而聚焦的上下文 ＋ 定性（＝**认领**，自指第一个动作）。
- **首刀只落退化版（占位桩）**，不验并发/闸 `[留]`。
- 结构锚粒度/生命周期 → P8 `[留]`。

### 3.3 生产 ＝ 思考 ⇄ 动手

- **思考**（意识，有声，工具关）＋ **思考控制四件**：①整理(蒸馏) ②对齐目标 ③取回经验 ④判停。`[收]`
- **判停**＝步级门（继续想／转动手），**不含**流终止。`[收]`
- **动手**：前置(为什么/在哪/预期)→**提交意图**→后置对账；分探询/执行。`[收]`
- **意图＝桥，起/持「一条流」**（流2）；**不是 cu 边界**；界桩是机制标记，cu 是实现。`[定]`
- **多流并发**：进入意图后如遇新事件，**意图流独立推进、思考流也独立推进**；事件可搁置/注入某条流。`[定]`
- **流2**：目标型意图 spawn 一条嵌套流；**结果作为事件回流1**（不内联返回）；"正常返回"与"被打断"是**同一种，只差时序**。`[定]`
- **spawn 判据** `[定]`：良构意图（目标可核、无需自行推理选工具/迭代）→ 执行器**内联**；欠定/需推理 → 流2。内联/嵌套是**执行器细节，意识无感**，不破坏"只有一种意图"。

### 3.4 判结（流级）＋ 结束点 `[定]`（新增）

- **判结 ≠ 判停**：判结决定"这条流是否**停止推进**→沉淀"。
- **结 ∈ {了, 未了}**；另有**挂起**态——在等预期外部事件（发了消息等回），**非结束**，不沉淀、保留线，事件回来续。`[定]`
- **框架用「张力」而非只用「目的」**：不是每条流都有目的（反应式事件被认领成未闭合张力也算一条流）。∴ **达成→了**；**努力无进展→未了（搁置）**。`[定]`
- **判结主体＝P7**，留白；本节只定**位置**与**取值**。`[留]`

### 3.5 沉淀 ＝ 段 `[定]`

- 段：`来源 / 内容 / 过程 / 后果 / 结`（`过程`＝思考痕迹，显名）。`[定]`
- 首刀最小字段：`id / t / 来源(event+locator) / 内容 / 过程(assistant reasoning + 工具事实) / 后果(事实+receipt, 待对账) / 结(占位)`；`预测=None / refs=[] / thread=id` 占位。`[定]`
- 首刀 `过程` 存**机械 trace**，蒸馏后置。`[定]`
- **段的责任单位＝流** `[定]`（弧的收口见 §3.6/§5）。
- **捕获在 cu（`on_tool_call`）、装配在流** `[定]`：`on_tool_call` 是工具调用+结果同时在手的唯一咽喉点（`runtime.py:106-111`；结果形如 `{ok,...}`，`tools.py:1455-1467`），在此**捕获** `{name,args,result}`；段按**流**装配，故实现须有 **cu→流 归属**。`[注]`

### 3.6 cu 与流（实现关系）`[留]`

- **cu**＝当前代码执行单元（机制不介入的 append 区间）；**不稳定**，被事件打断即变。
- **流**＝稳定语义单位；跨 cu、跨打断持续（例：进入意图后新事件来，意图流续跑，思考流并行）。
- 实现须有 **cu → 流 归属**（否则段碎成一堆 cu 记录）。
- `[留]` **弧 vs 流**：glossary 说"稳定单位是弧"、蓝图说"每弧一条段"、本稿说"段单位＝流"——三者待收一个。**下一轮讨论**。

### 3.7 回边 / 内圈 `[收]`

- 回边：结＝未了 → 张力 → 内部事件 → 下一流。
- 内圈：段 →（蒸馏）→ 经验 → 按锚分区存 → 按锚**直取**（不搜索）。
- 醒/睡＝内圈模式切换；睡可被事件打断、可并行。
- 两环接口：外→内＝段；内→外＝经验（进思考控制/取用/动手门槛）。
- 上下文纪律：记忆不在 context；压缩＋外部存储＋按锚取回。
