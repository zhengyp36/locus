## 二、合并后的完整流程图（与最新相符）

```
┌─ 事件 ────────────────────────────────────────────────────────┐
│  来源: 外部事件 / 内部事件(未了张力自燃)                          │
│  性质: 交织 · 可搁置 · 可注入 · 可多流并存                        │
│  (什么算一个事件 → 归装载判定)                                    │
└───────────────────────────────┬───────────────────────────────┘
                                 ▼
┌─ 装载 ────────────────────────────────────────────────────────┐
│  事件 × 槽 投影 + 认领/采纳 (= 自指的第一个动作)                  │
│  取用: 相关能力(能力面总览常驻) + 工具/思考经验(按锚)             │
│  产出: 小而聚焦的上下文 + "这件事是什么"                          │
│  搁置的流只挂起, 不沉淀 (暂停 ≠ 结束)                            │
└───────────────────────────────┬───────────────────────────────┘
                                 ▼
┌─ 思考 (发散, 工具关)  ⇄  思考控制 ────────────────────────────┐
│  思考控制四件: ① 整理(蒸馏) ② 对齐目标 ③ 取回相似经验 ④ 判停    │
│  判停: ──继续想──▶ 回到思考        ──转动手──▶ 动手            │
└───────────────────────────────┬───────────────────────────────┘
                                 ▼  (转动手)
┌─ 动手 (受控: 探询 / 执行) ────────────────────────────────────┐
│  前置: 为什么动 / 在哪动 / 预期什么                              │
│  提交意图 (无声指令 = 思考→动手的桥)          [enter 界桩]        │
│  执行: · 外部工具 不占住 (发起即落点; 结果靠事件 / 有界读窥测)    │
│        · 自身工具 有界   (读 = 一次少量 + 时延上限)              │
│        · 工具层只报事实 (超时 ≠ 失败; 参数错近真失败)            │
│  结果 → 对账 (探询: 观测 vs 预期 / 执行: 落地了吗) [exit 界桩]    │
│  事件可在界桩处串入 → 并行 (运行事实, 非调用契约)                 │
└───────────────────────────────┬───────────────────────────────┘
                                 ▼  结果回思考 (循环到闭合)
┌─ 沉淀 (流闭合) ───────────────────────────────────────────────┐
│  写段: 来源 / 内容 / 后果 / 结   (含思考痕迹)                    │
│  更新槽: 关系 / 主题 / 未闭合张力                                │
│  结 = 了 / 未了   ← 自驱开关                                    │
└───────────────┬───────────────────────────────┬───────────────┘
         结=未了  │                                │  (全了 → 无张力, 反应式)
                 ▼ 未了张力                       ▼
        ┌─ 回边 ─────────┐            ┌─ 内圈 (醒/睡: 经历驱动) ──────┐
        │ 未了张力 →      │            │  段 ─蒸馏→ 经验              │
        │ 内部事件         │            │  经验 → 按锚分区存            │
        │ → 回到"事件"    │            │  (重复出现才沉淀)            │
        └─────────────────┘            └──────────────┬───────────────┘
                                                      │ 取回 (按锚路由, 直取不搜索)
                                                      ▼
                                装载 / 思考控制 / 动手门槛  (回外圈)

槽 = 分布式并集("我"): 经历轴 / 工具经验(挂工具) / 思考经验(挂目标·张力·主题)
     / 主题 / 关系 / 未了张力 —— 各落点各处更新, 装载=读侧
经历轴 = 图: 时间(索引) + 线/thread + 结状态(未了=活的) + 关联(人/主题/经历)
```
