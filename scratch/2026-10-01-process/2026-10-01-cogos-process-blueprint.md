## 0. 一句话

一个自驱 agent = **一个在转的环 + 内圈闭合**。外圈（事件→装载→思考⇄动手→沉淀）让它**会动**；内圈（段→蒸馏→经验→取回）闭合，才叫**自驱**。`[outer-loop §1~3 · 本体 §0]`

## 1. 外圈：一轮"流"

**流 = 事件 → 装载 → 思考 ⇄ 动手 → 沉淀；起 = 事件（无事件无流），终 = 停→沉淀；主体是 1..n 个 `cu`。** `[outer-loop §1 · slot-flow §1]`

### 1.1 事件
- 来源：**外部事件**，或**内部事件**（槽里的未了张力自燃）。`[outer-loop §1.1]`
- **事件之间交织**（非串行）：可搁置当前流、可注入改变它；可有**多条流并存**。`[outer-loop §1.1]`
- 什么算"一个事件"需判定；**识别/切分归装载**，不归事件本身。`[outer-loop §1.1]`
- **自指分界**：不在"答不答"，而在**未闭合张力是否跨事件延续**；事件可被**认领**为未闭合张力，跨事件/跨天塑造后续。`[slot-flow §4]`

### 1.2 装载
- **事件 × 槽 的投影**：定性——这是什么、跟"我"什么关系、要不要理、续哪件旧事（＝**认领/采纳**，**自指的第一个动作**）；同时取用相关能力与工具经验。`[outer-loop §1.2 · slot-flow §4]`
- 产出：本轮**小而聚焦的上下文** + "这件事是什么"的定性。`[outer-loop §1.2]`
- 被搁置的流只是挂起，**不沉淀**；**「暂停」与「结束」要分开**。`[outer-loop §1.2]`

### 1.3 思考 ⇄ 动手（主干；每步都带控制）

**思考**（发散，工具关）：从当前信息往下推。每轮结束交给**思考的控制**（机制驱动，四件）`[outer-loop §1.3]`：
1. **整理内容**（＝**蒸馏**：压缩、去杂质）；
2. **对齐目标**（离目标多远）；
3. **取回相似经验**（按锚，喂回下一轮当参考，不当答案）；
4. **判停**：继续想 / 转动手（另有卡住、预算、无进展的强制出口）。

**动手**（受控，分两类）`[outer-loop §1.3]`：
- **探询**（取信息，当世界的问句）：反馈即时，当场接着想；预期＝会观测到什么。
- **执行**（改环境，落一个决定）：动作本身落地，反馈常**延迟、以未来事件回来**；预期＝会造成什么。
- 共同**前置**：为什么动 / 在哪动 / 预期什么（或已决定）；**提交那一下就是意图**（无声指令）＝**思考→动手的桥**。
- 共同**后置对账**：探询看"观测 vs 预期"，执行看"落地了吗、没落地为什么"。
- **动手的选择本身是思考的产物**：探询是"想不通才动"，且**从最可能的地方动**。

**结果 → 回到思考**，循环到闭合。`[outer-loop §1.3]`

### 1.4 沉淀（流闭合时）
- 写**段**：`来源 / 内容 / 后果 / 结`（**含思考痕迹**）。`[glossary·段 · outer-loop §1.4]`
  - 本体 §5 完整 schema：`id / t,host / 来源 / 内容 / 预测 / 后果 / 结 / thread / refs`；**第一刀最小字段**＝`id/t/来源/内容/后果/结`，`预测=None / refs=[] / thread=id` 占位。`[本体 §5 · loop-pivot §3]`
- 更新**槽**：关系、主题、未闭合张力。`[outer-loop §1.4]`
- **结＝了 / 未了**是**自驱开关**：全了 → 无张力、永远反应式；全不了 → 淹没。`[outer-loop §1.4 · glossary·结]`

## 2. 内圈：睡 / 批形（经历驱动，陷/沉淀）

1. **对成堆的段做蒸馏**（同一蒸馏操作的离线版）：找反复出现的（情境 → 做法 → 效果），**泛化** → **经验**。**重复出现才沉淀**（一次性的不值当、易过拟合）。`[outer-loop §2]`
2. **经验按锚分区存**（不是一处）：工具经验挂**工具**；思考经验挂**目标/张力类型、主题/线、装载定性出的情境**。`[outer-loop §2]`
3. **取回 ＝ 按锚路由**（**直取，不搜索**）。**锚＝当前已知的状态特征，不是运行时算的相似度**。`[outer-loop §2]`
4. 更新**槽 / 权重 / 升格**（后续）。`[outer-loop §2]`

- **醒/睡是内圈的模式切换**，不是外圈的开关：`醒 ⇔ T > P睡 = P整理 + P节律`；睡仍可被事件打断，二者可并行。`[slot-flow §2 · 本体 §7]`

## 3. 两环的接口

- 外圈 → 内圈：**段**（痕迹）。`[outer-loop §3]`
- 内圈 → 外圈：**经验**——进思考控制（让思考有效）、进取用（让工具顺）、进**动手门槛**（动不动/在哪动）。`[outer-loop §3]`
- **自驱回边**：沉淀的**未了张力** →（内圈）→ **内部事件** → 下一轮流。`[outer-loop §3]`
- **上下文纪律**：记忆不在上下文里（在内圈存储）；上下文只放"此刻要用的"，靠**压缩（蒸馏）＋外部存储＋按锚取回**，不靠长上下文/缓存。`[outer-loop §3]`

## 4. 工具面

- **工具二分**（裁 P2）`[close §1.1]`：
  - **外部工具**（改世界/取外部信息）：**不占住**——发起即**落点**（文件/作业句柄），结果靠**自身窥测**（事件/有界读）。
  - **自身工具**（读/写/看，＝I/O 边界）：**有界**——读＝**一次少量＋时延上限**。
  - **判据＝自控有界**；**根＝阻塞只能来自自身**。**"同步/发起即返回/异步"整组退休**；分叉＝事件在 `enter` 界桩处串入（运行事实，非调用契约）。
- **工具层只报事实**：**不定义成功/失败，只报"发生了什么"**；**超时≠失败**（读到部分可续读＝策略）；**参数错误**近真失败。`[close §1.2 · glossary]`
- **工具面三层**：① 能力面＝总览（常驻 `system-reminder`）；② 用法面＝`help` 逐级（**仅动手内**）；③ 事实面＝世界事实（图在哪/系统是什么），**归装载/记忆，不属工具面**。`[close §1.4]`
- **结论**：不必知用法就能用能力（`help 0/10` 已证）。`[close §1.4]`

## 5. 槽 ＝ 分布式并集（＝"我"）

- 分量与落点：经历→**经历轴**（时间序）；工具经验→**挂工具**；思考经验→挂**目标/张力/主题**；主题、关系、未了张力→**各自处**。`[close §1.3]`
- **各落点各处更新**；**无统一"更新槽"动作、无需黏合**。`[close §1.3 · glossary·槽]`
- **"唯一连续"＝认领出的同一根线；"单一写者"＝心智**（并行动手只写自己的 result/段）。**装载＝读侧**。`[close §1.3]`

## 6. cu / 线 / 经历轴

- **cu ＝ 机制不介入的 append 区间**（实现单位，**非语义单位**）；机制一介入（重组/叫停）→ cu 结束。**稳定单位是弧**，**一弧可多 cu**；打断＝重组入口。`[cu-boundary §1-2 · glossary·cu]`
- **父子关系属编排、非 cu 本体**（关系 ≠ 属性）→ **只拆不建**（已执行 `6c33380`）。`[cu-boundary §3]`
- **线 / `thread`** ＝跨流的"一件事"（可多条）；持久化为 `段.thread`＋`refs` 链（**非运行时对象**）。`[slot-flow §1 · cu-boundary §4 · glossary]`
- **经历轴 ＝ 图**：时间（索引）＋线/thread＋结状态（**未了＝活的**）＋关联（人/主题/经历）；装载＝图上按相关性取，**不是顺序回放**。`[slot-flow §1 · glossary]`

## 7. 承重缺口 + 下一步

- **P7 判"结"的主体缺**：自驱回边开关无人把守（骨架有机制、无"作为判断者的我"；§8 归价值层、**故意留白**——自指只能养出来）。`[outer-loop §6 · slot-flow §4]`
- **P8 锚分类学未定**（倾向涌现）：槽分布式后，它是**装载直取**的前提；不定则退化成搜索。`[outer-loop §6 · close §3]`
- **P9**"防呆＝生念的临时来源"表述不清 → 重述或删。`[close §3]`
- **下一步**：落**首个受控循环**（思考控制＋动手门；**段＋回边作底座**），用**最小实现/探针逼 P7、P8 长出来**——不再纯概念推演。`[close §4 · outer-loop]`
- **已定的落码顺序**（更早记录）：**第一刀＝落段**（`agent/experience.py` 最小经历轴 ＋ `on_done` 落段 ＋ `on_tool_call` 捕获 calls+results；验收＝代理口径：每弧一条段、字段齐、可读回、弧内多轮只一条）→ **第二刀＝`段→写回→装载` 回边**（最简/占位装载；紧跟，否则"只写不读"）。`[slot-flow §5 · loop-pivot §3 · cu-boundary §0]`
- **不在第一刀**：升格/权重/取回/停切点/整理/完整版意图。`[slot-flow §5 · loop-pivot §3]`
