# 时间轴（三向 · 修正版）

> 性质：讨论稿（**未收口、未动手**）。承接 `README.md`（经历轴·组织与实现）；把"经历轴"正名为**时间轴**，整合过去/现在/未来，含 10-03 二次修正（**未来不进轴**）。
> 术语权威＝`glossary.md`；`经历轴 → 时间轴` 待收口回填。
> 写法：结论 ＋ why ＋ 被否。

## 0. 一句话

时间轴 = 经验的**底座**（地址寻址的底，保真、服务证伪），按时间索引经历。**轴只装过去**；现在在轴头/运行时，未来是**读侧派生 ＋ 现场构建**，不占轴。

## 1. 命名修正：经历轴 → 时间轴

- 原名"经历轴"只覆盖过去读法，名不副实；正名**时间轴** = 所有经历（含"起意图/做决定"这类心理事件）的时间主序，也是未来投影的底座。
- 更正：更名理由**不是**"要装未来"（那被 §3 否定），而是"它是按时间索引经历、未来由其投影的基底"。
- 被否：保留"经历轴"名。

## 2. 轴上只有过去；现在与未来在别处

| 向 | 是什么 | 在哪 |
|---|---|---|
| 过去 | 已发生的段（含"我起了意图/做了计划"这类**心智事件**），append | **轴上** |
| 现在 | 写入头 append head ＋ 进行中的流（未落段） | 轴头 / 运行时 |
| 未来 | 未发生，**不是经历** | **不在轴上** → 读侧议程视图 ＋ 世界计划物 ＋ 现场构建（§4） |

- 关键区分：**"我计划了 X"这个事件是经历（在轴）；"计划的内容 / 未来本身"不是经历（不在轴）**。

## 3. 为什么不把未来放轴上

- 计划若当"未来段"写轴，**到期未办就要回改轴** → 破 append-only / 保真（YZ 10-03 指出）。
- 从经历讲，**计划的内容未发生，不是经历**；只有"起意图"这个心理事件是经历。
- 人对未来也不存储：未来是**读时构建**（prospection / episodic future thinking，回忆与想象共用网络），存的只有过去（含前瞻记忆里的"意图"）。
- 被否：未来段写轴；可变状态（待办 / 到期 / 未办）写轴。

## 4. 未来从哪来（计划 vs 展望）

**（a）计划（已定的具体未来行动）→ 两处找：**
- **议程视图**：派生自轴上的"意图 / 预期 / 挂起"段，挑出未闭合开放项（"打算做 X，还没做"）。
- **世界计划物**：计划书 / 日程 / 待办 / 消息——外化脚手架，直接读。

**（b）展望（对未来的开放想象）→ 不是找，是构建：**
- 原料 ＝ 经历轴（过去）＋ 当前处境（此刻）＋ 动机/倾向（动机亦从经历长出）→ 在生成拍内重组出"如果……会……"。

**（c）闭环**：构建出决定 → 追加**意图段**（带 `target_t`）→ 派生进议程 → 以后才"找得到"。
→ **未来先被构建、写成过去，才成为可检索的议程项。**

- 咬合旧概念：**议程** ＝ 开放项视图；**生念**（09-13 v0）≈ 展望的构建动作。一个"存开放的未来"，一个"生成未来"，配套。

## 5. 时间在轴上的角色（用法视角）

> 方法：先列用法，再判定它是"底座 / 字段 / 派生 / 维度"。

| 角色 | 典型用法 | 怎么支撑 |
|---|---|---|
| 主序（底座） | 经历的顺序 | append 顺序，免费 |
| 字段 `t` | 算距今、时间感、时效 | 段自带，读时算 |
| 权重输入（派生） | 近因 / 衰减 / 未了年龄 | 喂权重函数，不建索引 |
| 范围键 | 整理窗口、**议程视图**（未来） | 游标 / 派生视图 |

→ 结论：**时间不建 `by_time` 倒排索引**。

## 6. 与其余 5 维的关系

- **时间轴 ＝ 底座**；来源/人、主题、thread、结状态、工具 ＝ 轴上的**标签**（倒排索引）。
- "时间"**不与其余 5 维并列**。
- 结状态管开放项（未了 / 挂起），是议程视图的来源之一。

## 7. 机制接口（三向）

- **现在 → 过去**：流判结 → 沉淀成段 → 落在轴头之后。
- **过去 → 现在**：装载读轴（按锚取相关段；近因靠尾序）。
- **现在 → 未来**：生成/判结写**意图段**（内容 ＋ `target_t`）。
- **未来 → 现在**：在**议程视图**上做到期/未了检查 → 触发认领（回边来源）。判断在视图上做，**不改轴**。
- 兑现 / 放弃 ＝ **追加新段**（"做了 X" / "放弃 X"），旧段不动。

## 8. 组织与实现（承 README「实现分层」）

- **时间主序(段) ＋ 维度倒排索引 ＋ 蒸馏挂锚**（一份底三种组织，非三库）。
- L0 段日志 → L1 读侧索引/视图 → L2 取回 → L3 读数(P8) → L4 写结(P7) → L5 回边。
- **读侧视图**：`open_knots`（未了）＋ `agenda`（未闭合意图/预期/挂起）——议程即"未来面"。
- 段字段：`t`（发生）＋ 内容 ＋ 5 维标签 ＋ `target_t`（意图段可空）＋ `结状态`（开放项由视图派生，**不写回旧段**）。
- 最小实现：**升级 `SegmentStore`，不重写**；第一版索引 ＝ 来源/人、thread、结状态；**不建 by_time**；未来靠 agenda 视图。
- 计划物外化：可另写真实文件，轴只记"写了 / 读了它"。
