## 本会话推演链（结论 ＋ why ＋ 被否）

1. **P7/P8 是什么**：`P7＝判"结"的主体（自驱开关无人把守）`；`P8＝锚分类学（装载直取前提）`。位置：P8 在**装载**（读关联），P7 在**判结/沉淀**（写结状态）。
2. **P7/P8 是同一个"我"的两面**（装载读取算子 / 判断标准）→ 不能分开建，依赖同一底座＝**经历轴**。
3. **"我"的工作定义**：不是实体，是**自指回路**（自己的过去回头影响现在）＋**边界**（分清"我造成的"vs"世界造成的"）内累积的内容。
   - 总判据：**掐断"历史回读"，行为塌回反应式 → 真有"我"在做功**。
   - 分级：0 反应式 → 1 有轨迹 → 2 有边界 → 3 从自己出发 → 4 取舍（该顶就顶）→ 5 反身（自我进入装载成为对象）。
   - 意识：**功能判据可定；主观体验不可判定，不作工程目标**（避免他心问题当目标）。
4. **方向/目标不注入**：从"与社会交流"里长出。根取**正向**（参与/创造，开环）而非"避免离群"（负向、闭环、防御）；机制上＝**给一个会回应的社会 ＋ 让偏离有代价**，不是写死目标。被否：把"融入"当目标写进去；用"离群之痛"当引擎（只能防御性维持）。
5. **经历轴是底座**：P7＝写它上面的 `结状态`；P8＝读它上面的 `关联`；"我"＝沿它的读写闭环。
6. **经历轴理论存量**：`#18`（表示＝段 / 切分＝误差 / 取回＝内容寻址 / 整理＝抽样重演）＋认知依据；`09-29` 收窄为**图**（时间 ＋ thread ＋ 结状态 ＋ 关联）。
7. **轴 vs 记忆**：轴＝**地址寻址的底**（保真、服务证伪）；记忆＝**内容寻址的用**（有损、被筛选、服务想起）；**同一份底、两套入口**——"链只服务证伪，不服务想起"。
8. **"轴不能是记忆库"的真正理由**（不靠权威，按目的重推）：
   ① 同一批数据有**五种读法**（装载 / `P整理` / 生念 / 眼动 / 迸发），库封装一种必覆盖不全 → 返工；
   ② 记忆的结构＝"我"的结构，要**涌现**，封库＝用预设 schema 决定"我"＝变相注入；
   ③ 库引入可变状态（索引/权重），破"只增不改 ＋ 可重建"。
   → 修正说法：**轴必须是低层原语；记忆层只能长在它之上，不能与基底焊死**。判据：取回口径变了，要不要动基底。
9. **组织方式**（YZ 定方向）：**时间主序(段) ＋ 维度倒排索引 ＋ 蒸馏挂锚**——同一份数据的三种组织，**不是三个库**。
10. **6 维**：时间、来源/人、主题、thread、结状态、工具。**派生（非维度）**：误差、权重、蒸馏(经验/关系)。
    - 存：段(append-only，带 6 维字段)；每维一个倒排索引 `值→[段id]`（派生、可重建）。
    - 写时能打就打（来源/thread/预测/refs/涉及主题）；事后算（工具/主题簇/误差/权重/经验）。
    - 取：键集 → 各索引取 → 合并去重 → 近因×权重排序 → 预算截断。

## 维度方案细节（补充记录 · /undo 安全）

> 来源：上一会话末尾。写全以防重读 transcript。

**用法先行（谁/何时/读什么/写什么）**：装载＝按处境从各维取（经历段/经验/关系/未了）；生成⇄动手＝取用法/事实；沉淀＝写段（时间序事实）；睡/整理＝读成堆段→写经验/关系/主题，挂各自锚（新记录，不改旧）。

**6 维清单**（由"哪里要用"反推）：

| # | 维度 | 是什么 | 哪里要用 |
|---|---|---|---|
| 1 | **时间** | 主序 `t`（经历的本质） | 装载近因、整理扫描、衰减 |
| 2 | **来源/人** | 谁触发、涉及谁 | 装载(谁的活/和谁)、关系、判结责任归属 |
| 3 | **主题** | 这件事关于什么 | 装载相关经历、整理同类聚合、经验挂靠 |
| 4 | **thread/线** | 属于哪条"事" | 装载续哪件、自指(未了跨事件) |
| 5 | **结状态** | 了 / 未了 / 挂起 | 回边(自驱)、装载悬着的、判结写 |
| 6 | **工具** | 用了/涉及哪个工具 | 动手(用法/配方)、工具经验 |

**派生量/层（先别当维度建）**：误差(预测 vs 后果→切分/权重) · 权重/活跃度(排序/筛选) · 蒸馏(经验/关系，挂 6 个锚上)。

**存取**：存＝主序段(append-only,带 6 维字段)＋每维一个倒排索引 `值→[段id]`(派生可重建)；写时能打就打(来源/thread/预测/refs/主题)，事后算(工具/主题簇/误差/权重/经验)。取＝一组键→各索引取→合并去重→近因×权重排序→预算截断。最小实现＝`segments.jsonl`＋进程内 `dict` 索引(启动扫一遍重建，不落盘)。

**第一版 vs 后加**：第一版段放全 6 维字段、索引只建 **时间/人/未了/thread**、蒸馏与权重不做(权重固定 0，排序只按近因)；后加判据＝每加一维/索引须说出**哪个用法卡住了**，否则过度设计。

**轴 vs 记忆**（§7 详版）：轴＝地址寻址的底(保真/服务证伪)；记忆＝内容寻址的用(有损/被筛选/服务想起)；同底两入口，`链只服务证伪`。

**实现分层（event-sourcing）**：L0 段日志(唯一真相,append-only) → L1 读侧索引(by_time/by_thread/open_knots/by_anchor,可重建) → L2 取回(retrieve: 机械优先、加权抽样、非 top-N) → L3 读数(P8 self_now) → L4 写结(P7 预期×对账) → L5 回边。**存图否：不存，读侧派生**；升级 `SegmentStore` 不重写。

## 本会话补充：写 / 整理 / 读 与"回忆"（10-03 末，讨论态）

> 从"使用角度"审视维度后的收窄；仍讨论态、代码未动。承接上文，补"时间怎么用 / 三操作 / 回忆怎么组织"。

1. **时间的角色（三 + 一）**：① 底座/顺序（`id` 单调、顺序白送）；② 坐标 `t`（算远近、衰减因子，进"活跃度"派生量）；③ 取回通道（整理按时段聚合）；④ **"现在"不在轴上**（＝主槽活状态、取不回），轴只沉淀 过去 ∪ 未来规划。→ **修正**：先前"时间不建索引"降级为"**装载主路径不用 `by_time`，整理/时段要用**"。
2. **三向已在文档（非缺口）**：装载三节 过去/现在/刚刚；昼夜 昨/今/明（昨＝封存段／今＝活跃段／**明＝预约·规划段**）。**未定的是"未来规划落成段 / 预测 / 挂起"**，不是没考虑未来。
3. **写（沉淀）**：段＝一弧一条；append-only、**顺序不记**、**引用实时记**、**层级后压**（写新记录、**不并段**）。当场能打就打（时间/来源/thread/预测/refs），判结打 `结`，事后算（工具/主题/误差/权重）。缺口：**P7 谁写 `结`**、**P8 关联怎么打**。
4. **整理（睡时＝物化）**：机制触发（`T>P睡`）→ **雇整理 cu**（抽样重演）→ 产物（经验/关系/主题/**后压节点**）**写回轴、新记录**。**不并段**：回忆的"大段"＝**后压概括节点**（粗、自带内容），原段不动 → **多分辨率**。
5. **读（读时＝现算，不整理）**：机制取材（内容寻址、加权抽样、预算、给"为什么取它"、产**对位关系**）→ **生成拍当场串成话**。**读时不另起整理模型**（对位依赖当前处境，处境在生成拍；另起＝多一跳＋失真）。兜底：物化层缺又要粗粒度 → 临时雇 cu 即用即弃。
6. **回忆 ≠ 回放**：轴给材料，**连续性靠生成重建**（"想起≠接上"）。**轴上段数＝意外数，不是事件数。**
7. **切点＝误差 vs 第一刀＝事件界**：**判定沿用事件界（切细）**。why：底 append-only ＋ 可后压 → **细能合、粗不能拆**；回忆的"连续性"由**后压节点**复现（"当天一大段"＝后压），不靠一开始就合并。故"切点＝误差"卡点**可放心搁置**。

**本会话新增待确认**：a) ~~切点用误差还是事件~~ → 已决：事件界（切细）；b) 读时兜底现整产物落不落轴（倾向先不落）；c) 未来/计划落成段 / 预测 / 挂起（搁置）。

## 认可口径：段 schema ＋ 首版索引（10-03，YZ 认可）

> 动手前唯一要钉的＝**不可逆的 L0 段字段**；其余卡点全占位搁置。形状见 `experience-py-shape.md`。

**段字段（L0，append-only，不可回头补）**：

```
id 单调 / t,host 坐标 / 来源 / 人[] / 主题(可空,只存不索引) /
内容 / 预测(可空) / 后果(含沉默) / 过程(思考痕迹+工具事实) /
结(了|未了|挂起) / thread(起始段id) / refs[(kind,id) continue_of|cut_by]
```

**不字段化**：误差、权重、工具（从 预测/后果、过程 派生）。

**首版索引（读侧，可重建）**：`by_time` · `by_person` · `open_knots` · `by_thread`；**不建** 主题/工具。
`retrieve(键集)` ＝ 各索引取 → 去重 → **近因**排序 → 预算截断（**权重=0**）；`open_knots()`。

**搁置表（占位默认 / 触发回来）**：切点＝事件界(切细)｜未来无生产者｜P7＝D6 退化解｜P8＝只机械打(来源→人/thread/结)｜权重＝0｜读时现整＝不做。

**层级模型（跳表 / RAPTOR）**：结构像**跳表**（多分辨率、稀疏上层、可下钻），但上层是**自带内容的概括节点（不是指针）**，故更近 **RAPTOR / 多分辨率森林**；生长靠**后压**（抽样重演），不均匀、无再平衡。

**淘汰**：淘汰的是**读侧可达/权重**，**不是删记录**（append-only、旧段永不动）。顺序：原始存档(material) → 段 → 后压节点（**记得最牢**）；驱动＝**后果 ＋ 被处理过，不是年龄**。首版不做（权重=0）。
