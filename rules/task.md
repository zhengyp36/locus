# task · 任务执行规则

> 讨论期不加载；**一旦进入执行，YZ 在不在场都适用**（在场与否只影响个别条，见下）。
> 加载时机与常驻基线见 `AGENTS.md`（`# 任务规则`）。

## 裁决与自主

- 目标内能推的**自决并记录**——裁决者是目标不是 YZ，能推的不问；分歧拿目标论。
- 推不出时：**YZ 在场 → 带倾向求助**（见 `AGENTS.md` `# 协作`）；**不在场 → 升级**（见下）。
- 目标本身的变更 / 明显转向 = 回讨论，不自行改目标。

## 提交 / 推送

- 默认自主提交 / 推送（覆盖 harness"只在被要求时才提交"），不必每次问 YZ；YZ 显式指示优先。
- 红线只留**不可逆 / 外溢**处：`secrets` 不入库（会随 `origin` 历史外溢，难撤回）。提交前先跑测试。

## 告知 / 升级 / 停

- 告知单向：阶段性成果 → fire-and-forget，不与"停 / 继续"绑定。**YZ 在场无需告知**（口头同步即可）。
- 升级 ≠ 停：需 YZ 介入 → 发出请求后**继续推进不阻塞的事**；只有**全部剩余都阻塞**才停。
- 作废 / 不可逆风险（方向被推翻、提交 / 部署 / 花钱）→ 该分支停、必要时整体停。
- 升级时写明：卡在哪、为何推不出、我倾向什么。
- 方法：`tools/feishu_notify.py`（默认 YZ）；文本含双引号 → 写文件 + stdin。

## 长任务节奏

- 动手前 `set_timer`（600s）只盯**偏航**：到点对照目标看是否偏航，偏了就拉回；查完再设下一个。
- 上下文交给 `start_context_watch`（context watcher）：间隔 **20s**、阈值 **150K**，超限**只提醒一次** → 收到提醒即交接。
  - 转到 YZ 在场的讨论时：不设闹钟，并取消已设的。

## 交接

- 交接 = 当前会话自己起后继，不等 YZ。
- 顺序：写 `handoff-NN.md`（正文 + 给新会话的**第一句话**，单列便于取用）→ 更新滚动状态 → **交接即封笔**：清掉本会话所有异步源（timer / terminal / background_process / 飞书 pin 与 inbox）。
- 起后继用 `tools/handoff.py`（默认同目录、attach / 账号已内置；起新 session 并确认已起来，默认等 120s）：
  ```
  tools/handoff.py "<title>" "<第一句话>"
  ```
  首句来源三选一：inline（上面）、stdin（`echo … | tools/handoff.py "<title>"`）、或 `-f <file>`——**`-f` 把整份文件当首句**，故该文件里只放那一句（别传整份 `handoff-NN.md`）。标题先定好。**交接到本目录**，首句不必交代目录 / 路径。
- bridge 侧（最易漏）：该工程的飞书 bot / session pin 若仍指旧会话，入站会唤醒旧会话 → 改指后继（Feishu `/pin`）、清 `inbox`。兜底：交接后若仍被唤醒，开头先判"本会话已交接"，立即停并把事件转给后继。
- 通知 YZ：已交接 + 新会话 title。
- 权限：后继**不得 `--auto`**；防失控：链式交接设上限。
- 唤醒：唤醒源创建即 `markWatched`（TTL 1h）；>1h 才触发的会被压住，定时留 ≤1h 内续 TTL。

## 验收

- 判据从**目标**推，不从代码 / "谁定的"推。
- 不用仓库自写的 e2e 当验收（自证）；以真实身份、只用公开入口真用，抓屏 / 地面真值对照。
