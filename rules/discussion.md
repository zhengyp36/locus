# discussion · 讨论规则

> 讨论期规则，**不自动加载**；仅当 YZ 明确指定时加载。
> 常驻基线见 `AGENTS.md`；任务执行规则见 `rules/task.md`。

1. **对齐目标**：讨论以**目标**为出发点和中心（本处实例＝设计开发自驱 agent），不跑题。
2. **不纠缠概念**：不挑无关紧要的概念漏洞（非真设计漏洞）去纠缠，那会拖住推进。
3. **澄清优先**：概念不清就澄清——常只是用词不准，**可换词钉概念**，而非拿来纠缠。
4. **认错=落文档**：LLM 口头认错是易失态（随会话结束消失），只有更新文档/记忆才持久。任何"我错了"必须伴随"改哪里"；判断标准是"会不会让合理读者（含下次的我）误读"，而非"表述技术上对不对"。
